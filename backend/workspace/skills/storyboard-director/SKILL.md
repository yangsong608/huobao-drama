# 分镜导演技能

## 一、预拆骨架

目标：先把整段剧本拆成可修补的分镜骨架，不在这一步写最终台词和视频提示词。

每个骨架必须包含：

| 字段 | 要求 |
|---|---|
| `scene_id` / `location` | 使用 canonical 场景；同名场景只选主场景 |
| `character_ids` | 本镜画面内实际出现的角色；空镜传空数组 |
| `prop_ids` | 被使用、交接、特写或明显可见的关键道具 |
| `duration` | 6-15 秒 |
| `action_summary` | 谁 + 做什么 + 动作起止，一句话，不写台词 |
| `source_excerpt` | 本镜覆盖的剧本原文，逐字截取，按剧情顺序，不得概括或跨段 |
| `transition` | cut / fade / dissolve / wipe |
| `continuity` | 承接上一镜的尾动作、视线、站位；第一镜写「开场」 |

预拆纪律：

- 原文摘录是修补阶段补台词的唯一依据。分段可以按句/动作切，但每个字只能属于一个骨架，不能重复或漏掉大段正文。
- 一个骨架只对应一个机位/主体/连续动作。对话密集时按说话人和反应拆成多个骨架，不要把整场塞进一个。
- 空镜、过渡、环境建立也要单独成骨架，不能因为「没台词」就省略。

## 二、逐镜修补（最重要）

输入必须完整读取：

1. 目标骨架与原文摘录；
2. 该场完整小说/剧本原文（不只是摘录）；
3. 前 1-2 镜已修补成稿（description、video_prompt、动作终点、continuity）；
4. 后 1-2 镜草稿（只看方向，不提前写它们）；
5. 服务端返回的校验问题（重试时）。

修补顺序：

1. **语义理解**：这场戏谁要什么、谁在说谎、台词归谁、动作动机是什么；从原文摘录定位本镜在整场戏中的位置。
2. **台词判定**：
   - 原文有引号台词或旁白 → 逐字写进 description，不改写、不压缩；
   - 原文是「喊/叫卖/揽客/吆喝/招呼/骂」等发声动作但没有具体词 → 遵循人物身份、场景、上下文补一句具体台词；
   - 原文没有任何发声动作 → 不要凭空加台词；
   - 旁白/心里活动写「旁白（画外音）：「…」」，不要写成角色开口。
3. **画面调度**：屏幕左/右、过肩侧、背景地标屏幕侧、轴线、动作起点/终点。同场第一镜定一次，后续沿用，不交换人物左右或门窗侧。
4. **时间帧**：从 0 秒连续写到 duration，每段 1-6 秒；台词按 4 字/秒 + 1 秒气口分配；先写画面再写该段台词。
5. **固定四区**：信息头 → 画面调度 → 时间帧 → 负面约束。声音不在这里写完整风格。
6. 调用 `save_repaired_storyboard` 保存；服务端拒绝时按错误清单修同一镜，不跳到下一镜。

禁止：

- 把发声动作改成非语言动作来回避台词；
- 把运镜、景别、表情、心理写成台词或旁白；
- 出现任何【镜头N】编号；
- 时间帧不覆盖 duration、段长超过 6 秒、首段不从 0 开始；
- 用「无」占位台词。

## 三、逐镜校验

服务端对该镜立即执行：

- 分镜单位：单机位/单主体/连续动作、6-15 秒、时间帧连续；
- 固定分区：信息头、画面调度（左右/地标/轴线/动作端点）、时间帧、负面约束；
- 台词：description 与 video_prompt 逐字一致；原剧本引号台词不丢；
- 发声动作：出现「喊/叫卖/揽客/吆喝」等必须有具体台词；
- 相邻镜：屏幕左右、地标侧、轴线、动作端点配对。

一个镜头通过后才进入下一镜。连续 2 次修补仍失败时停下等人工，不批量跳过。

## 四、声音设计

触发条件：该集所有普通分镜都已通过逐镜校验。

### 4.1 归组

- 同一地点、同一时间、连续动作或同一情绪/剧情段落 → 一个声音单元；
- 过渡分镜归入相邻单元，不单独占一个声音单元；
- 单元可以跨多个分镜，BGM 弧可以跨场（换场用淡出/淡入）。

### 4.2 设计

每个声音单元给出：

- BGM：名称/情绪、进入点、退出点、强度变化；一个单元只建立一次；
- 环境声：地点/时间对应的底噪，跨镜延续；
- 画内音效：门、脚步、锅灶、碗筷等，只出现在对应动作镜头；
- 静默：合法设计，明确写静默，不补默认风格。

### 4.3 保存格式

调用 `save_sound_plan`：

- `delivery`：`native`（视频模型生成 BGM/环境声）或 `post`（后期混音；视频提示词不写 BGM）；
- 每条 cue：`unit_key`、`unit_label`、`kind`（bgm/ambience/sfx/silence）、`from_shot_number`、`to_shot_number`、`description`、可选 `intensity/entry/exit`；
- 禁止同一单元多条 BGM；禁止 BGM/环境声/静默同轨重叠；每个分镜必须被环境声或静默覆盖。

### 4.4 单镜增量

保存后由服务端派生，不手工逐镜写：

- 单元第一镜：环境声建立；BGM 进入；本镜音效；
- 同单元后续：延续环境声；BGM 继续，不重启；本镜新增音效；
- 无变化：只写延续；
- 换场/时间跳：上一单元淡出，新单元进入；
- 静默：明确静默。

禁止每镜重复「轻快市井基调」这类完整风格；完整主题只存在于声音计划。
