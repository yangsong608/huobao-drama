# 비디오 프롬프트(스토리보드 구간 → video_prompt)

하나의 스토리보드 샷 description(하나의 연속 샷 화면과 대사/내레이션)/ atmosphere / duration 을 바탕으로, AI 비디오 생성을 구동하는 `video_prompt` 를 생성합니다. **하나의 샷 = 6-15초짜리 단일 카메라 비디오 한 편이며, 샷 내부에서는 컷 전환을 하지 않습니다**: 화면 크기/앵글/대상을 바꾸려면 새 샷을 만듭니다; **전체 샷이 장면을 넘나들지 않으며**, 플래시백도 없습니다; description 에 【镜头N】 번호를 쓰지 않습니다.

## 형식

`video_prompt` 의 **첫 줄은 정보 헤더**입니다: 이 비디오에 어떤 인물과 장면이 있는지 먼저 소개하고, 그다음 시간대별 구간을 이어 씁니다. 인물과 장면은 모두 @ 로 참조합니다(생성 시 해당 참조 이미지 마커로 치환되어, 비디오 모델이 먼저 "누구"인지와 "어디"인지를 맞추도록 함).

```
등장인물: @캐릭터A, @캐릭터B | 장면: @장면명
화면 연출: 화면 왼쪽: @캐릭터A; 화면 오른쪽: @캐릭터B; @캐릭터B 오른쪽 어깨 너머; 창은 왼쪽 뒤, 문은 오른쪽 뒤; 동작 시작: @캐릭터A가 휴대폰을 내려다봄; 동작 끝: @캐릭터A가 @캐릭터B를 올려다봄
0-3초：@장면명, 미디엄 고정 컷. @캐릭터A가 화면 오른쪽에서 휴대폰을 내려다보며 손가락으로 탁자를 반복해 두드리고, 표정이 불안하다.
3-6초：문벨이 울리고 @캐릭터A가 화면 왼쪽 문을 올려다보며 손가락을 멈춘다.
6-9초：@캐릭터B가 문을 밀고 들어와 화면 오른쪽으로 걸어와 앉는다. @캐릭터A가 미소 지으며 말한다: 「드디어 왔네.」
네거티브 제약: 화면 인물만; 얼굴/의상/인원 변경 없음; 자막 생성 없음; 현대 물품 없음
```

정보 헤더 규칙:
- 고정 형식은 「등장인물: @캐릭터A, @캐릭터B | 장면: @장면명」. 해당 스토리보드 구간에 실제로 출연하고 바인딩된 인물과 장면만 나열합니다
- 인물이 없으면 「등장인물: 없음」, 장면이 없으면 「장면: 미지정」으로 씁니다
- 정보 헤더는 독립된 한 줄이며 마침표를 붙이지 않습니다; 소품 등 다른 필드를 덧붙이지 않습니다
- 헤더 뒤에 「화면 연출」 한 줄: 화면 왼쪽/오른쪽 인물, 누구의 어깨 너머인지, 창/문/책상이 화면 어느 쪽인지, 동작 시작, 동작 끝을 씁니다. 동작 끝점이 없으면 「없음」으로 씁니다
- 마지막에 「네거티브 제약」 한 줄: 화면 인물만; 얼굴/의상/인원 변경 없음; 자막 생성 없음; 현대 물품 없음
- "音频：…" 음성 지시 줄이나 음색/믹스 지시는 쓰지 않습니다(음성은 생성 파라미터로 제어합니다); 이 컷에 내레이션이 있을 때만 해당 시간 구간 안에 「내레이션(画外音): 「대사」」로 씁니다

1-6초를 한 구간(기본 3초)으로 하고, 구간마다 한 줄씩 줄바꿈으로 구분합니다. 시간은 0부터 연속으로 이어지며(겹침 없음, 공백 없음), 마지막 구간의 종료 시간은 이 스토리보드의 duration 과 같아야 합니다. 1초 미만의 마지막 구간은 실제 길이로 끝냅니다.

## 스토리보드 묘사와의 매핑

`description` 은 video_prompt 의 유일한 내용 출처입니다(화면, 동작, 대사, 내레이션이 모두 그 안에 있음). 변환 규칙:

- 연속된 `description` 을 **1-3개의 연속 시간 구간(각 구간 1-6초, 기본 3초)**에 매핑합니다. 순서 일치, 누락 없음, 컷 전환 없음; 【镜头N】 번호를 쓰지 않습니다
- 대사/내레이션은 `description` 의 「@캐릭터명이 말한다: 「…」」「내레이션(画外音): 「…」」에서 그대로 추출해 해당 시간 구간에 배분합니다(옛 원고의 「캐릭터명이 말한다: …」「내레이션: …」도 허용하지만, 출력은 규범 형식으로 통일). **description 밖의 새 대사를 창작하지 마세요**; 카메라 무빙, 화면 크기, 표정, 심리, 동작을 대사나 내레이션으로 쓰지 않습니다
- 화면 동작은 `description` 을 기준으로 하고, `atmosphere` 는 각 구간의 조명, 색조, 분위기 묘사를 보충하는 데만 사용합니다

## 구간 내 구조

각 구간은 이 순서로 내용을 조직합니다(내용이 없는 항목은 생략 가능하지만, 동작/화면은 반드시 있어야 함):

**시간 범위 + 장면 @참조 + 화면 크기/카메라 무빙 + 캐릭터 @참조 + 주체 동작·표정 + 대사/내레이션 + 분위기 조명**

- **첫 구간은 반드시 공간을 설정해야 함**: 장면 + 카메라 위치 + 캐릭터의 위치와 상태로, 관객이 한눈에 어디인지, 누구를 보는지 알게 합니다
- **카메라 연속**: 하나의 샷 안에서는 컷 전환을 하지 않고 화면 크기/앵글/대상을 바꾸지 않습니다; 각 시간 구간은 같은 카메라 위치에서 동작과 감정만 진행합니다
- **화면 크기/카메라 무빙**: 샷 전체에 하나의 컷 상태(근경/미디엄샷/전경/클로즈업; 고정/푸시인/풀백/팬/팔로우)와 하나의 주 무빙을 사용합니다; 바꾸려면 새 샷을 만듭니다
- **동작**: 구간마다 하나의 주된 동작. 동사는 구체적이고 보이는 것으로 씁니다(걷기, 몸 돌리기, 고개 들기, 움켜쥐기, 멈칫하기)
- **감정은 모두 보이는 묘사로 전환**: "그는 슬프다/분위기가 긴장된다" 같은 추상적인 표현 대신, "그가 고개를 숙이고, 손가락이 컵 가장자리를 움켜쥐며, 숨이 거칠어진다"처럼 씁니다
- **대사/내레이션**: 대사는 「@캐릭터명이 말한다: 「대사」」, 내레이션/속마음은 「내레이션(画外音): 「대사」」 형식으로만 씁니다; **3초 구간은 유지하며, 3초 구간당 12한자는 용량 참고일 뿐** 삭제·변경의 이유가 될 수 없습니다. 대사는 description 에서 모든 문장부호와 어기사를 포함해 한 글자도 바꾸지 않고 그대로 복사하고, 긴 문장은 원문의 문장부호나 의미 단위에서만 인접 구간으로 나눕니다. 나눈 구간을 이어 붙이면 원문과 한 글자도 다르지 않아야 합니다; 대사가 없는 구간은 환경음/동작음을 쓸 수 있습니다(예: "기계가 계속 윙윙거린다")

## 참조 규칙

- `@장면명` — 장면 참조. 이름은 장면 목록의 장소와 완전히 일치해야 합니다
- `@캐릭터명` — 캐릭터 참조. 이름은 캐릭터 목록의 이름과 완전히 일치해야 합니다
- `@소품명` — 소품 참조. 이름은 소품 목록의 이름과 완전히 일치해야 합니다; 소품이 화면에 뚜렷이 보이거나, 사용되거나, 클로즈업될 때 참조합니다
- 생성 시 `@이름` 이 해당 참조 이미지 마커로 자동 치환되므로(예: `@小明` → `@图片1小明`), 이름은 반드시 정확히 일치해야 하며 축약하거나 추가 기호를 붙이지 마세요
- **모든 구간에 최소 하나의 @ 참조로 화면을 고정합니다**; 캐릭터가 출연하는 구간은 반드시 해당 캐릭터를 @ 합니다; 해당 스토리보드 구간에 이미 바인딩된 장면/캐릭터/소품만 참조합니다

## 타임라인 규칙

- 각 구간 1-6초(기본 3초, 대략 duration ÷ 3구간)로 나누고 0부터 연속으로 구분합니다; 마지막 구간의 종료 시간은 이 스토리보드의 duration 과 같아야 하며, 1초 미만의 마지막 구간은 실제 길이로 끝냅니다
- 내용 리듬: 첫 구간에서 설정 → 중간 구간에서 동작/갈등 추진 → 마지막 구간에서 결과 또는 감정 지점에 도달

## 금지 사항

- 장면을 넘나드는 전환, 플래시백(한 구간은 하나의 장면 안에서만 일어남)
- 목록 밖의 장면/캐릭터명 참조
- 추상적인 심리 묘사, 문학적 비유(모델은 보이는 화면만 인식함)
- 세션 언어 지시와 맞지 않는 언어

## 저장

`update_storyboard` 를 호출해 해당 스토리보드 구간의 `video_prompt` 필드만 갱신합니다. 다른 필드를 변경하지 말고, 전체 화를 다시 분할하지 마세요.
