# 絵コンテ分割規範

## 1. 核心定義

1つの絵コンテ = 1つの動画生成タスク = 1つのカメラ位置 + 1つの主体 + 1つの連続動作。同じシーンの画面左右・軸線・背景地標の側はシーン単位の定数として最初に決め、同シーンの全カットで維持する。

- 各絵コンテは6〜15秒。
- 同じカメラ位置内の連続運動のみ許可。カメラ位置・主体・動作・感情の切れ目が変わる場合は新しい絵コンテにする。
- 1つの絵コンテ内に【镜头2】以降のサブカットを書かない。同じカメラ位置内の時間区間はサブカットではない。

## 2. 脚本カバレッジ

- すべての場面・セリフ・重要な動作を入れる。場面の削除・統合・ハイライトのみの抽出は禁止。
- 場面ごとに最低1つの絵コンテを作る。
- 絵コンテ数下限 = ceil(脚本の非空白文字数 × 0.12 ÷ 15 × 0.9)。下回る場合は分割不足であり、統合・削除ではなく追加する。
- 保存前に「場面 → 絵コンテ」のカバレッジを確認し、不足は追加する。

## 3. シーンと素材

- canonical シーン紐付けの scene_id を使う。同名シーンは canonical のみを使い、54/55/56 などの別名を時間や好みで選ばない。
- 時間変化は time や画面演出に書き、シーン画像の切り替えで表現しない。
- 人物・小道具名はプロジェクト資産と完全一致させる。@唐大郎 ではなく @唐大郎（唐奕）。
- 純環境の空鏡だけ人物なしを許可。空鏡でも画面演出と「動作開始：なし；動作終了：なし」を書く。

## 4. フィールド

| フィールド | 要件 |
|---|---|
| `description` | 1つの連続ショット：誰 + 具体動作 + 身体ディテール + 表情 + 立ち位置/視線。最大1つの【镜头1】、以降は禁止 |
| `duration` | 6〜15秒。内部時間区間は各1〜6秒 |
| `scene_id` | canonical シーンID |
| `character_ids` | 画面内に実際に映る人物。いなければ空配列 |
| `prop_ids` | 重要小道具。いなければ空配列 |
| `transition` | cut / fade / dissolve / wipe |
| `continuity` | 前カットの末尾動作・視線・立ち位置・環境音。最初は「開場」 |
| `sound_effect` | 同一シーンの絵コンテで同じ環境音を再利用 |
| `video_prompt` | 固定4区：情報ヘッダー → 画面演出 → 時間区間 → ネガティブ制約 |

## 5. video_prompt 固定4区

1. 情報ヘッダー：「登場人物：@キャラクターA、@キャラクターB／シーン：@シーン名」。なしは「登場人物：なし」「シーン：未指定」。独立1行、句点なし。
2. 画面演出：「画面演出：画面左：…；画面右：…；…の肩越し；背景地標：窓は左後ろ、扉は右後ろ；軸線A；動作開始：…；動作終了：…」。肩越しなしは「肩越しなし」、地標なしは「背景地標：なし」、1人/空鏡は「軸線なし」、2人以上は「軸線A」または「軸線B」。人物がいる絵コンテは動作開始・終了必須。
3. 時間区間：「0-3秒：」から開始、各1〜6秒、連続・重複なし、最後は duration と一致。各区間は同じカメラ位置・主体・連続動作のみ。画面を先に書き、その区間のセリフ/ナレーションを書く。
4. ネガティブ制約：「ネガティブ制約：画面内の人物のみ；顔/衣装/人数を変えない；字幕を生成しない；現代物品を出さない」。

音響はここに書かない：BGM/環境音は検証後の第4ステップでシーン/物語単位に設計し、その時だけネガティブ制約の前に短い増分（継続/追加/フェード/静寂）を挿入する。カットごとに完全なスタイルを繰り返さない。

## 6. セリフ

- セリフは「@キャラクター名は言う：「セリフ」」、ナレーションは「ナレーション（画外音）：「セリフ」」のみ。
- description から句読点・語気詞を含めて一字一句コピーし、原文の句読点や意味の区切りでのみ隣接時間区間へ分割する。
- duration × 4文字/秒 = セリフ＋ナレーション容量（息継ぎ1秒を残す）。入らなければ隣の絵コンテへ分割し、速度を上げない。
- カメラワーク・ショットサイズ・表情・心理・動作をセリフやナレーションにしない。

## 7. 保存

- `save_storyboards` を最大8件ずつ呼ぶ。最初は `replace_existing: true`、以降は省略。
- `shot_number` は物語順に増加。全件保存前に終了しない。
- 保存前チェック：複数サブカット、画面演出なし、動作端点なし、ネガティブ制約なし、シーン別名のいずれかがあれば先に修正する。
