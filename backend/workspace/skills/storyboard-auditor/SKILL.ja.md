# 絵コンテ動作検査ガイド

## 1. 対象と境界

検査対象は1話の絵コンテ：未削除のカット、セリフ/ナレーション、キャラクター/シーン/小道具のバインド、アセット画像、現在の分割方式。

- 検査フェーズは読み取り専用：問題を報告するだけで、カット、セリフ、バインド、アセットを変更しません。
- 修正フェーズは apply_storyboard_repair によるホワイトリスト動作のみ。各動作は問題リストの issueId を参照し、storyboardId は省略できます（サーバーが issueId からカットを特定）。
- カット別状態、問題数、修正・ロールバックはサーバーが管理します。これらのフィールドを出力しないでください。

## 2. 5項目検査の操作要点

### 検査 1：各カットのカメラワーク、セリフ、動作、表情、ナレーション

ルール層がカバー：説明なし、プロンプトなし、カメラフィールド欠落、【ショットN】構造なし、情報ヘッダーなし、タイムライン破綻、3秒区間のセリフ12文字超、動作をセリフとして記述。

意味層の重点：

1. 説明が「撮影可能」か：誰が、どこで、何を、どう（身体ディテール）、どんな表情と視線、結果は何か。「彼は怒っている」「雰囲気が張り詰めている」だけでは撮影不可能。
2. カメラワーク/ショットサイズ/アングルが動作に奉仕しているか。感情爆発にはクローズアップ、空間関係にはワイド、追従動作にはトラッキング。激しい戦闘に固定ミディアムは通常誤り。
3. 役割配置の誤り：
   - カメラ言語をセリフに：`@甲が言う：「カメラが寄る」`
   - ナレーションをキャラクターの発話に：ナレーションであるべき心の声が `@甲が言う：「三年後……」`
   - 動作/心理をナレーションに：`ナレーション：「彼は失望して振り向く」` — 脚本が明示的に動作ナレーションを要求した場合を除く。
4. 1セグメント内のサブショット動作が矛盾（立ち上がったのに座っている）。
5. 8-15秒セグメントのサブショット数が妥当か（通常2-4）。多すぎると各2秒未満、少なすぎると間延び。

問題コード：`semantic_shot_description`、検査1。

重大度：
- error：話者/ナレーション配置の誤り、撮影不可能な説明、動作の自己矛盾。
- warning：カメラと動作の不一致、説明が曖昧、サブショットのリズム不良。
- info：改善価値はあるが生成を妨げない。

### 検査 2：前後カットの連続性

ウィンドウ端の前後コンテキストを含め、隣接ペアごとに確認：

1. 終わり動作の引き継ぎ：前カット終了時の動作、手持ちの小道具、向き。次カットが継続しているか。断絶例：前カット「@甲がドアを押して飛び出す」、次カット「@甲が机で茶を飲む」で時間跳躍の説明なし。
   - 動画プロンプトのタイムラインを基準に、前カットの最後のセグメントと次カットの最初のセグメントを対で比較します。次カットの最初のセグメントは、目に見える動作・視線・位置・小道具で前カットの結末を受けなければなりません。
   - continuity フィールドは宣言にすぎず根拠ではありません。宣言が引き継ぎを書いていても、最初のセグメントの画面が引き継いでいなければ断絶です。
   - 机の移動、場所の変更、人物グループの変更、時間跳躍があるのに、つなぎの動作やトランジションカットがない場合は semantic_continuity_break として報告し、relatedStoryboardNumbers に両側のカット番号を入れます。
2. 視線とアクシス：会話の視線がアクシスを越えていないか。Aが右を見るなら、Bは反対側から見返す。
3. 空間と立ち位置：同一シーン内の左右位置、ドア/窓の位置の跳躍。
4. 時間：昼夜、光、衣装、怪我、小道具の状態。フラッシュバックや時間跳躍にはトランジションや字幕説明が必要。
5. シーンまたぎのハードカット：continuity 説明やトランジションなしの直接カットは断絶。fade/dissolve や引き継ぎ説明を提案。
6. 環境音：同シーンの連続セグメントは同じ環境音を共有すべき。急変は継ぎ目として聞こえる。

問題コード：`semantic_continuity_break`、検査2。

トランジション提案：断絶に緩衝、空カット、場所説明、時間経過の提示が必要な場合、`suggestedTransition` を設定：
- `empty`：空カット緩衝（風景、小道具のクローズアップ、環境）。
- `scene`：既にバインドされたシーンから生成する場所トランジション。
- `text`：文字カード（時間、場所、章）。
トランジションカットを自分で作成してはいけません。作成はユーザー操作のみです。

重大度：
- error：動作/空間/時間の明白な断絶で説明がなく、観客が理解できない。
- warning：アクシス、立ち位置、衣装、環境音の不連続。
- info：トランジションがあると良いが、今でも繋がる。

### 検査 3：長時間の無会話・空カット

ルール層がキャラクターの有無と時間閾値で `silent_shot_long` / `empty_shot_long` を報告。

意味層は2点のみ確認：
1. 本当に人物の動作、演技、セリフの支えがないか（純環境、純小道具、純空景）。
2. 意図的な余白/雰囲気カットか。明確な叙事目的があれば提案に書き、ルール層の重大度を勝手に下げない。

検査3は自動修正しない：システムはセリフを捏造できず、短縮や分割は創作判断。

### 検査 4：各セリフの長さと分割

ルール層が発音可能文字数から必要時間を計算（約4文字/秒 + 1文につき1秒の呼吸）し、報告：
- `line_insufficient_duration`：有効時間が不足。
- `line_overlong_duration`：有効時間が明らかに余る。
- `line_requires_split`：1文が6秒超。
- `shot_dialogue_over_capacity`：カット全体のセリフ量が尺を超える。

意味層の重点：
1. 長いセリフを意味の切れ目で隣接カットへ分けるべきか、無理に速く読ませていないか。
2. 1文が隣接しないカットに分かれ、意味が断裂していないか。
3. セリフが多い区間に反応ショット（聞くだけ）が不足していないか。提案に書く。

意味層でルール層の問題コードを提出しないでください。分割や延長の判断は提案に書き、修正フェーズか手動対応に委ねます。

### 検査 5：絵コンテが使うアセットの正確性と完全性

ルール層がカバー：シーン未バインド、無効バインド、本話未関連、重複バインド、@参照なし、アセット画像なし、画像ファイルなし、参照形式エラー。

意味層の重点：
1. 説明や動画プロンプトに登場するキャラクター/シーン/小道具がすべてこのカットにバインドされているか。書いてあるが未バインドなら参考画像が付かない。
2. バインドされたアセットが本当にこのカットに登場するか。過剰バインドは参考画像を汚す。
3. @名前が正しいアセットを指すか。同名別人、似たシーン名、汎用小道具名（「刀」が誤った刀を指す）。
4. 説明の外見とアセット画像が明らかに衝突（年齢、衣装、シーンの時代）。生成結果が不一致になる。

問題コード：`semantic_asset_mismatch`、検査5。

検査5は常に報告のみ：バインド変更、アセット画像生成、重複バインド削除はしません。提案は手動操作（アセットページで画像補充、カット資産パネルでバインド修正）を指す必要があります。

## 3. 根拠と提案の書き方

- evidence：原文の要点を引用、最大500文字。正確な位置（どの【ショットN】、どのセリフ、どの3秒区間）を示す。
- suggestion：すぐ実行できる修正方向、最大300文字。「最適化する」「連続性に注意」のような空句は避ける。
- message：問題が何で、なぜ生成に影響するかを1文で。
- 原文根拠のない感覚的な判断は報告しない。

## 4. 重複排除とウィンドウ規律

- 意味ウィンドウは16カットで、前後コンテキストが重複。同じ問題は2つのウィンドウに現れるので一度だけ報告。
- 重複キー：検査項目 + 主カット + 関連カット + 意味カテゴリ。根拠がより完全なものを残す。
- ルール層が同じ位置で報告済みの問題を繰り返さない。意味層はルールで判断できない部分だけ補う。
- 1ウィンドウ最大30件。errorを優先し、次にwarning、infoは価値がある場合のみ。

## 5. 修正フェーズの操作規範

### 許可動作とフィールド

| 動作 | 対象問題 | 許可フィールド | 重要制約 |
|---|---|---|---|
| fill_camera_fields | カメラ/ショットサイズ/アングル欠落 | shot_type、angle、movement | 既存の説明とプロンプトから帰納のみ |
| normalize_video_prompt | ヘッダー欠落、タイムライン破綻、動作をセリフに | video_prompt、description | 実際のセリフ/ナレーションと話者を全保持 |
| rewrite_description | 撮影不可能・位置誤りの説明 | description、video_prompt、result | キャラクター/小道具/筋書きを追加しない |
| fix_continuity | 終わり動作の未承接、シーンまたぎカットの説明不足 | continuity、transition、description、video_prompt | シーン/キャラクターバインドを変えない |
| extend_duration | セリフ容量不足 | duration、video_prompt、description | 増加のみ、1セグメント上限内、タイムライン同期 |
| insert_transition_shot | 検査 2 の断点かつ問題に suggestedTransition あり | issueId のみ | サーバーがトランジションカットを1つ挿入して番号を振り直す。フィールド不可 |

### 動画プロンプトのタイムライン硬制約

- 1行目は「登場人物：@A、@B｜シーン：@名前」。空なら「登場人物：なし」「シーン：未指定」。
- 本文は「0-3秒：」から、3秒連続区間で重複・空白なし。
- 最後の区間の終了時間はカットの duration と一致。
- セリフは `@名前が言う：「セリフ」`、ナレーションは `ナレーション（声のみ）：「セリフ」` のみ。セリフや話者を追加しない。

### 修正境界

- 1タスク最大40動作、同一カット最大3動作、同一フィールドの重複変更不可。
- フレームアセット、動画、字幕、吹き替え、セリフロック、進行中タスクがあるカットは読み取り専用。ツールが拒否するので再試行しない。
- ユーザーが検査後にカットを編集した可能性。指紋不一致時はツールが拒否するので回避しない。
- アセット問題、空カット、セリフ分割、動画プロンプト欠落、話者未バインドは自動修正対象外。
- 迷ったらスキップして手動に残す。拒否後に別フィールドで無理に通さない。

## 6. 避けるべき誤報

1. 環境叙事のある長回しを空カットと報告。
2. 脚本が明示した動作ナレーションを「動作をナレーションに」と報告。
3. continuity 説明のあるシーンまたぎカットを断絶と報告。
4. 同名別アセット（二人の「老王」）をIDと説明を確認せずバインドエラーと判定。
5. 意図的な様式化カメラ（固定長回し、監視カメラ視点）をカメラ誤りと報告。
6. 検査5で「自動バインド変更」を提案し、権限を越える。
