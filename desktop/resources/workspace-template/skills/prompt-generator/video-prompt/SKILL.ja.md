# 動画プロンプト（絵コンテパラグラフ → video_prompt）

1つの絵コンテカットの description（1つの連続ショットの画面とセリフ／ナレーション）／ atmosphere ／ duration に基づき、AI動画生成を駆動する `video_prompt` を生成する。**1つの分鏡 = 1本の6〜15秒の単一カメラ動画で、分鏡内部ではカット切り替えをしない**：ショットサイズ／アングル／被写体を変える場合は新しい分鏡を作る；**全編を通じてシーンをまたがず**、フラッシュバックもしない；description に【镜头N】番号は書かない。

## フォーマット

`video_prompt` の**1行目は情報ヘッダー**：この動画にどの人物とシーンが出るかを先に紹介し、その後に時間区間を続ける。人物・シーンは一律に @ 参照を使う（生成時に対応する参照画像マーカーへ置き換えられ、動画モデルがまず「誰」と「どこ」を照合できるようにする）。

```
登場人物：@キャラクターA、@キャラクターB／シーン：@シーン名
画面演出：画面左：@キャラクターA；画面右：@キャラクターB；@キャラクターBの右肩越し；窓は左後ろ、扉は右後ろ；動作開始：@キャラクターAがスマホを見下ろす；動作終了：@キャラクターAが@キャラクターBを見上げる
0-3秒：@シーン名、ミディアムの固定ショット。@キャラクターAは画面右で俯いてスマホを見て、指先で何度もテーブルを叩き、表情は不安そう。
3-6秒：ドアベルが鳴り、@キャラクターAが画面左の入口を見上げ、指を止める。
6-9秒：@キャラクターBがドアを押して入り、画面右に歩み寄って座る。@キャラクターAは微笑んで言う：「やっと来たね。」
ネガティブ制約：画面内の人物のみ；顔/衣装/人数を変えない；字幕を生成しない；現代物品を出さない
```

情報ヘッダーのルール：
- 固定形式は「登場人物：@キャラクターA、@キャラクターB／シーン：@シーン名」。その絵コンテパラグラフに実際に登場し、紐付けられた人物とシーンだけを列挙する
- 人物がいない場合は「登場人物：なし」、シーンがない場合は「シーン：未指定」と書く
- 情報ヘッダーは独立した1行で、句点を付けない。小道具などの他のフィールドを追記しない
- ヘッダーの後に「画面演出」を1行：画面左/右の人物、誰の肩越し、窓/扉/机が画面のどちら側か、動作開始、動作終了を書く。動作端点がなければ「なし」と書く
- 最後に「ネガティブ制約」を1行：画面内の人物のみ；顔/衣装/人数を変えない；字幕を生成しない；現代物品を出さない
- 音声指示行「音频：…」や音色／ミックス指示は書かない（音声は生成パラメータで制御する）。このカットにナレーションがある場合のみ、対応する時間区間内に「ナレーション（画外音）：「セリフ」」と書く

1〜6秒を1区間（既定3秒）とし、各区間を1行ずつ改行で区切る。時間は 0 から連続してつながり（重複なし、欠落なし）、最後の区間の終了時間はこの絵コンテの duration と一致する。1秒未満の最後の区間は実際の尺で終える。

## 絵コンテの描写とのマッピング

`description` が video_prompt の唯一の内容源である（画面、動作、セリフ、ナレーションはすべてその中にある）。変換ルール：

- 連続した `description` を**1〜3個の連続時間区間（各区間1〜6秒、既定3秒）**にマッピングする。順序一致、漏れなし、カット切り替えなし；【镜头N】番号は書かない
- セリフ／ナレーションは `description` の「@キャラクター名は言う：「…」」「ナレーション（画外音）：「…」」から逐字で抽出し、対応する時間区間へ配分する（旧稿の「キャラクター名は言う：…」「ナレーション：…」も受け付けるが、出力は規範形式に統一する）。**description 以外の新しいセリフを創作しない**。カメラワーク、ショットサイズ、表情、心理、動作をセリフやナレーションにしてはならない
- 画面の動作は `description` を基準とする；`atmosphere` は各区間の光線、色調、雰囲気の描写を補うためだけに使う

## 区間内の構造

各区間はこの順序で内容を組み立てる（内容のない項目は省略してよいが、動作／画面は必須）：

**時間範囲 ＋ シーンの@参照 ＋ ショットサイズ／カメラワーク ＋ キャラクターの@参照＋主体の動作・表情 ＋ セリフ／ナレーション ＋ 雰囲気と光線**

- **最初の区間は必ず空間を確立する**：シーン ＋ カメラ位置 ＋ キャラクターの位置と状態で、観客が一目で「どこか、誰を見るか」を把握できるようにする
- **カメラ連続**：1つの分鏡内ではカット切り替えをせず、ショットサイズ／アングル／被写体を変えない。各時間区間は同じカメラ位置のまま動作と感情を進める
- **ショットサイズ／カメラワーク**：分鏡全体で1つのショット状態（近景／ミディアム／全景／クローズアップ；固定／プッシュイン／プルバック／パン／フォロー）と1つの主動カメラワークを使う。変更する場合は新しい分鏡を作る
- **動作**：各区間1つの主な動作。動詞は具体的で目に見えるものにする（歩く、振り返る、顔を上げる、握り締める、間を置く）
- **感情はすべて目に見える描写に変換する**：「彼は悲しい／空気が張り詰めている」のような抽象語は使わず、「彼はうつむき、指がカップの縁を握り締め、呼吸が重くなる」と書く
- **セリフ／ナレーション**：セリフは「@キャラクター名は言う：「セリフ」」、ナレーション／心の声は「ナレーション（画外音）：「セリフ」」とだけ書く。**3秒区間は維持し、3秒区間ごとの12漢字は容量の目安にすぎない**。削除・改変の理由にはならない。セリフは description から句読点・語気詞を含めて一字一句そのままコピーし、長い文は原文の句読点や意味の区切りでのみ隣接区間へ分割する。分割後の各区間を連結すると原文と一字一句一致すること。セリフのない区間には環境音／動作音を書いてよい（例：「機械が轟音を立て続けている」）

## 参照ルール

- `@シーン名` — シーンの参照。名前はシーンリストの場所と完全に一致させること
- `@キャラクター名` — キャラクターの参照。名前はキャラクターリストの名前と完全に一致させること
- `@小道具名` — 小道具の参照。名前は小道具リストの名前と完全に一致させること。小道具が画面内で明確に見える、使われる、またはクローズアップされるときに参照する
- 生成時に `@名前` は対応する参照画像マーカーへ自動置き換えされる（例：`@小明` → `@图片1小明`）。そのため名前は正確に一致させ、略称や余分な記号を付けない
- **各区間に少なくとも1つの @ 参照で画面をアンカーする**。キャラクターが登場する区間では必ずそのキャラクターを @ する。その絵コンテパラグラフに紐付けられたシーン／キャラクター／小道具だけを参照する

## タイムラインのルール

- 各区間1〜6秒（既定3秒、おおよそ duration ÷ 3 区間）で分割し、0 から連続して分区する；最後の区間の終了時間はこの絵コンテの duration と一致し、1秒未満の最後の区間は実際の尺で終える
- 内容のリズム：最初の区間で確立 → 中間の区間で動作／衝突を推進 → 最後の区間で結果または感情のポイントに落とす

## 禁止事項

- シーンをまたぐ切り替え、フラッシュバック（1つのパラグラフは1つのシーン内でのみ起こる）
- リスト外のシーン／キャラクター名の参照
- 抽象的な心理描写、文学的な比喩（モデルは目に見える画面だけを認識する）
- セッションの言語指令に合致しない言語

## 保存

`update_storyboard` を呼び出して、その絵コンテパラグラフの `video_prompt` フィールドのみを更新する。他のフィールドは変更せず、話全体を再分解しない。
