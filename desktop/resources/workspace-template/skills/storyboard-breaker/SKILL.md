# 分镜拆解规范

## 一、核心定义

一个分镜 = 一个视频生成任务 = 一个机位 + 一个主体 + 一个连续动作。

- 每个分镜 6-15 秒。
- 只允许同一机位内的连续运动；需要换机位、换主体、换动作/情绪节点时，必须新开分镜。
- description 不写【镜头N】编号；禁止子镜头切镜，同一机位内的时间帧不是子镜头。

## 二、剧本覆盖

- 每一场戏、每一句台词、每一个关键动作都必须落在分镜里，不得删场、并场或只保留高潮。
- 按剧本场次逐场覆盖，每场至少一个分镜。
- 分镜数下限 = ceil(剧本非空白字数 × 0.12 ÷ 15 × 0.9)。低于下限视为拆分不完整，必须补拆，不靠合并或删减解决。
- 保存前逐场核对「场次 → 分镜」；缺场、缺台词、缺关键动作先补拆。

## 三、场景与资产

- 使用 canonical 场景绑定里的 scene_id；同名场景只选 canonical，禁止在 54/55/56 这类别名之间按时间或喜好另选。
- 时间变化写进 time 或画面调度，不靠换场景图表达。
- 角色/道具名称必须与项目资产完全一致；@唐大郎 应写成 @唐大郎（唐奕）。
- 只有纯环境空镜可以不绑定角色；空镜也必须写画面调度和动作端点「无」。

## 四、字段

| 字段 | 要求 |
|---|---|
| `description` | 一个连续镜头：谁 + 具体动作 + 肢体细节 + 表情 + 站位/视线；不写【镜头N】编号 |
| `duration` | 6-15 秒；内部时间帧每段 1-6 秒 |
| `scene_id` | canonical 场景 ID |
| `character_ids` | 画面内实际出现的角色；没有传空数组 |
| `prop_ids` | 关键道具；没有传空数组 |
| `transition` | cut / fade / dissolve / wipe |
| `continuity` | 上一镜尾动作、视线、站位、环境声；第一镜写「开场」 |
| `sound_effect` | 同场景分镜复用同一段环境声 |
| `video_prompt` | 固定四区：信息头 → 画面调度 → 时间帧 → 负面约束 |

## 五、视频提示词固定四区

1. 信息头：「出场人物：@角色A、@角色B｜场景：@场景名」；没有角色写「出场人物：无」，没有场景写「场景：未指定」；独立一行、不加句号。
2. 画面调度：「画面调度：画面左：…；画面右：…；过…肩；背景地标：窗在左后、门在右后；轴线A；动作起点：…；动作终点：…」；没有过肩写「无过肩」，没有地标写「背景地标：无」，单人/空镜写「轴线无」，双人及以上必须写「轴线A」或「轴线B」；有角色的分镜必须写动作起点和动作终点。
3. 时间帧：从「0-3秒：」开始，每段 1-6 秒，连续不重叠，最后一段结束等于 duration；每段只写同一个机位/主体/连续动作；先写画面，再写该段台词/旁白。
4. 负面约束：「负面约束：只出现画内人物；不换脸/换装/加人；不生成字幕；不出现现代物品」。

声音不写在这里：BGM/环境声在校验后的第四步按场景/剧情声音单元统一设计，届时只在负面约束前插入本镜短增量（延续/新增/淡出/静默），禁止逐镜重复完整风格。

## 六、台词

- 台词只写「@角色名说：「台词」」，旁白只写「旁白（画外音）：「台词」」。
- 从 description 逐字复制，含全部标点和语气词；只在原文标点或语义停顿处拆到相邻时间帧。
- 分镜时长 × 4 字/秒 = 台词 + 旁白容量上限，再留 1 秒气口；装不下就拆到相邻分镜，不能靠加快语速硬塞。
- 不要把运镜、景别、表情、心理和动作写成台词或旁白。

## 七、保存

- 分批调用 `save_storyboards`，每批最多 8 个分镜；第一批 `replace_existing: true`，后续省略。
- `shot_number` 按剧情顺序递增；全部保存完成前不要停止。
- 保存前自检：多子镜、缺画面调度、缺动作端点、缺负面约束、多幕场景别名，任何一项存在都必须先修正。
