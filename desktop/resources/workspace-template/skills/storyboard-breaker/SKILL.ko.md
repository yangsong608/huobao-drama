# 스토리보드 분할 규범

## 1. 핵심 정의

하나의 스토리보드 = 하나의 영상 생성 작업 = 하나의 카메라 위치 + 하나의 주체 + 하나의 연속 동작. 같은 장면의 화면 좌우·축선·배경 지표 방향은 장면 단위 상수로 먼저 정하고 같은 장면의 모든 컷에서 유지한다.

- 각 스토리보드는 6-15초.
- 같은 카메라 위치 안의 연속 움직임만 허용. 카메라 위치·주체·동작·감정 전환점이 바뀌면 새 스토리보드를 만든다.
- 한 스토리보드 안에 【镜头2】 이후 서브 컷을 쓰지 않는다. 같은 카메라 위치 안의 시간 구간은 서브 컷이 아니다.

## 2. 대본 커버리지

- 모든 장면·대사·핵심 동작이 들어가야 한다. 장면 삭제·병합·하이라이트만 추출 금지.
- 장면마다 최소 하나의 스토리보드를 만든다.
- 스토리보드 수 하한 = ceil(대본 비공백 글자 수 × 0.12 ÷ 15 × 0.9). 미달이면 분할 부족이며 병합·삭제가 아니라 추가한다.
- 저장 전에 「장면 → 스토리보드」 커버리지를 확인하고 부족하면 추가한다.

## 3. 장면과 자산

- canonical 장면 바인딩의 scene_id 를 사용한다. 같은 이름 장면은 canonical 만 쓰고 54/55/56 같은 별칭을 시간이나 선호로 고르지 않는다.
- 시간 변화는 time 이나 화면 연출에 쓰고 장면 이미지 교체로 표현하지 않는다.
- 인물·소품 이름은 프로젝트 자산과 완전히 일치해야 한다. @唐大郎 가 아니라 @唐大郎（唐奕）.
- 순수 환경 빈 숏만 인물 없이 가능하다. 빈 숏도 화면 연출과 「동작 시작: 없음; 동작 끝: 없음」을 쓴다.

## 4. 필드

| 필드 | 요구 |
|---|---|
| `description` | 하나의 연속 숏: 누구 + 구체 동작 + 신체 디테일 + 표정 + 위치/시선. 최대 하나의 【镜头1】, 이후 금지 |
| `duration` | 6-15초. 내부 시간 구간 각 1-6초 |
| `scene_id` | canonical 장면 ID |
| `character_ids` | 화면에 실제 보이는 인물. 없으면 빈 배열 |
| `prop_ids` | 핵심 소품. 없으면 빈 배열 |
| `transition` | cut / fade / dissolve / wipe |
| `continuity` | 이전 컷 끝 동작·시선·위치·환경음. 첫 컷은 「오프닝」 |
| `sound_effect` | 같은 장면 스토리보드는 같은 환경음 재사용 |
| `video_prompt` | 고정 4구역: 정보 헤더 → 화면 연출 → 시간 구간 → 네거티브 제약 |

## 5. video_prompt 고정 4구역

1. 정보 헤더: 「등장인물: @캐릭터A, @캐릭터B | 장면: @장면명」. 없으면 「등장인물: 없음」「장면: 미지정」. 독립 한 줄, 마침표 없음.
2. 화면 연출: 「화면 연출: 화면 왼쪽: …; 화면 오른쪽: …; … 어깨 너머; 배경 지표: 창 왼쪽 뒤, 문 오른쪽 뒤; 축선A; 동작 시작: …; 동작 끝: …」. 어깨 너머 없으면 「어깨 너머 없음」, 지표 없으면 「배경 지표: 없음」, 1인/빈 숏은 「축선 없음」, 2인 이상은 「축선A」 또는 「축선B」. 인물이 있으면 동작 시작·끝 필수.
3. 시간 구간: 「0-3초：」부터, 각 1-6초, 연속·중복 없음, 마지막은 duration 과 일치. 각 구간은 같은 카메라 위치·주체·연속 동작만. 화면을 먼저 쓰고 그 구간 대사/내레이션을 쓴다.
4. 네거티브 제약: 「네거티브 제약: 화면 인물만; 얼굴/의상/인원 변경 없음; 자막 생성 없음; 현대 물품 없음」.

사운드는 여기 쓰지 않는다: BGM/환경음은 검증 후 4단계에서 장면/서사 단위로 설계하며, 그때만 네거티브 제약 앞에 짧은 증분(계속/추가/페이드/정적)을 삽입한다. 컷마다 전체 스타일을 반복하지 않는다.

## 6. 대사

- 대사는 「@캐릭터명이 말한다: 「대사」」, 내레이션은 「내레이션(画外音): 「대사」」만.
- description 에서 문장부호·어기사 포함 그대로 복사하고 원문 문장부호나 의미 단위에서만 인접 시간 구간으로 나눈다.
- duration × 초당 4자 = 대사+내레이션 용량(호흡 1초 남김). 넘치면 인접 스토리보드로 나누고 속도를 높이지 않는다.
- 카메라 무빙·샷 크기·표정·심리·동작을 대사나 내레이션으로 쓰지 않는다.

## 7. 저장

- `save_storyboards` 를 최대 8개씩 호출한다. 첫 배치는 `replace_existing: true`, 이후 생략.
- `shot_number` 는 이야기 순서로 증가. 전부 저장 전에는 끝내지 않는다.
- 저장 전 점검: 여러 서브 컷, 화면 연출 없음, 동작 끝점 없음, 네거티브 제약 없음, 장면 별칭 중 하나라도 있으면 먼저 수정한다.
