# キャラクター音声設計ガイド

## ツールフィールドとの対応

`save_voice_profiles` の各 profile：
- **scope**：character（既定）または narrator（ナレーション）
- **character_name**（キャラクターでは必須）：`read_characters_for_voice` が返したキャラクター名と完全に一致させる。ナレーションは null または「旁白」
- **gender**：male / female / other
- **age_range**：年齢層、例 14-16 / 25-30 / 55-65
- **voice_prompt**（必須）：中国語の音声プロンプト、60-120 文字、音色・音域・話速・質感・感情のベースラインを記述
- **design_instruct**（必須）：英語の VoiceDesign 指示、固定順序：age & gender -> timbre -> pitch -> pace -> accent -> temperament -> emotional baseline
- **sample_text**：試聴テキスト、30 文字以内、キャラクターの元セリフ（`sample_line`）を優先
- **emotion**：感情のベースライン、例 自然 / 抑制 / 活発 / 陰鬱
- **speed**：話速係数、0.5-1.5、既定値 1

## 設計ルール

1. **設定との一貫性**：年齢と性別はキャラクター設定に一致させる。少年を低い中年声に、老人を少女声にしてはいけない
2. **プロジェクト内での識別性**：同一プロジェクトのキャラクター同士は、音色・音域・話速の少なくとも一つを明確に変える。主役と主要脇役は特に差を付ける
3. **性格の外在化**：性格を声の表現に変換する（例「冷峻」→「冷たい音色、安定した話速、抑揚が少ない」）。性格形容詞を並べるだけにしない
4. **抑制されたナレーション**：ナレーションは統一的で安定し、感情を抑え、キャラクターの邪魔をしない
5. **実名の不使用**：俳優・配信者・著名人の名前を声の説明に使わない
6. **試聴可能**：sample_text は現在の話の最初のセリフを優先し、なければ設定に合う短い一文を書く

## 使用手順

1. `read_characters_for_voice` を呼び出し、キャラクター・外見・性格・現在の話の最初のセリフ・`narrator_missing` を読み込む
2. 全キャラクターの完全な音声プロファイルを設計する。`narrator_missing=true` なら `scope='narrator'` のナレーションを1件追加する
3. 全キャラクター（必要ならナレーションを含む）の profiles 配列で `save_voice_profiles` を一度だけ呼び出す
4. 既定は `force=false`：有効な音声があるキャラクターは保持される。ユーザーが明確に作り直しを求めた場合のみ `force=true` を渡す
