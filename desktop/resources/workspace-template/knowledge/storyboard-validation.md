# 分镜校验清单

适用 Agent：`storyboard_auditor`

## 三层

- L1 合同校验：字段、时间轴、台词容量、旁白格式、资产绑定、轴线、覆盖完整性；纯规则，低成本。
- L2 视觉预检：参考图/构图草稿与合同对照：身份、场景、轴线、构图、调度。
- L3 生成后验收：成片抽帧与合同/邻镜尾帧/参考图对照：身份、场景、轴线、动作、在场、道具、声音、文本。

审计 Agent 主要做 L1 + 语义判定；L2/L3 由视觉/验收流程补充。

## 检查矩阵

| 检查 | 内容 | 典型问题 |
|---|---|---|
| C1 合同完整性 | 字段、信息头、时间轴、时长、画内人物 | 缺字段、时间轴不到 duration、信息头缺场景 |
| C2 连贯/轴线 | 屏幕方向、正反打、过肩、30°、场景翻面、动作匹配、在场连续 | 越轴、翻面、人物丢失、尾帧接不上 |
| C3 空镜/静默 | 长空镜、长静默 | 空镜超过 6 秒、有角色但长时间无台词 |
| C4 台词/声音 | 容量、逐字、旁白 `<d>`、声音类型、口型 | 台词装不下、旁白失声、旁白写成角色开口 |
| C5 资产/绑定 | 场景 canonical、角色/道具绑定、别名、参考图 | 未绑定、别名找不到、道具图语义错 |
| C6 覆盖完整性 | establishing/master/OTS/reaction/insert、说话人/听者、重复/过拆/景别单一 | 缺反应、缺建立、全是近景 |
| C7 场景地理 | 窗/门/桌/地标、背景侧、季节/光线 | 反打背景换边、红叶变绿树 |
| C8 视觉预检 | 身份、场景、轴线、构图 | 生成图/草稿与合同不符 |
| C9 生成后验收 | 身份、场景、轴线、动作、在场、道具、声音、文本 | 换脸、加人、动作不接、旁白没声 |

## 证据规则

- `continuity` 只是声明，不是证据；必须引用两侧提示词/description 的实际差异。
- 证据要具体到：谁、画面哪一侧、什么动作、什么台词、什么时间点。
- 没有把握不要报；禁止编造原文没有的内容。
- 重叠窗口同一问题只报一次。
- 标了“过渡分镜”的镜头是已有解决方案，不参与检验；两侧真实分镜仍判定，但 `suggestedTransition` 必须为 null。
- 成对判定必须给出 connected 或 broken；不给结论视为本轮失败。

## 严重度与门禁

- error/blocker：轴线翻转、场景翻面、画内人物缺失/画外人物误入、旁白失声、台词容量超限、时间轴断裂、参考图缺失。阻断生成。
- warning：景别单一、反应偏弱、空镜偏长、台词偏短、场景地标不完整。需确认，不默认阻断。
- info：风格建议、可选优化。不阻断。

## 修复

- 规范信息头/时间轴；补绑定/参考图；修正轴线/站位；补反应/拆镜；重写 description/video_prompt；延长时长；重生成（带上一镜尾帧，最多 2 次）；人工。
- 不新增角色/场景/道具/台词，不改分镜号、绑定和分镜数量；保留台词/旁白原文与说话人。

## 常见误报/漏报

- 把 continuity 声明当成已实现。
- 只检查文本，不看屏幕左右/在场/场景地标。
- 把“推镜”当成“人物逼近”。
- 把“有台词”当成“有反应”。
- 把同名多图当成同一空间。
- 把过渡分镜当普通镜头重复报。
- 只报“不连贯”，不指出从哪一帧/哪一句开始断。

## 交付前检查

- [ ] 每个切点有成对判定，结论明确。
- [ ] 证据引用了两侧实际文本。
- [ ] 轴线、屏幕方向、过肩、在场、动作、道具、光线、声音都检查了。
- [ ] 覆盖完整性：establishing/master/OTS/reaction/insert。
- [ ] 过渡分镜没有被重复报；该用过渡的地方给了正确类型。
- [ ] 问题有严重度、门禁、修复动作。
- [ ] 没有编造、没有重复、没有越权改绑定/台词/分镜数量。
