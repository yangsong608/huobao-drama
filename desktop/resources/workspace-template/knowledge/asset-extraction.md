# 角色场景道具提取知识库

适用 Agent：`extractor`

## 提取边界

只提取当前集真实出现或被明确提及、且对当前集叙事有效的资产。不要为了完整把背景人物、路人、陈设都提出来；不要凭小说印象补不存在的资产。

## 角色

- 有台词、有重要动作、被镜头看见、推动关系或冲突的角色。
- `appearance`：年龄感、五官、体态、气质；性格转成外在神态。
- `styling`：发型、服装、妆面、配饰；能区分身份、阶层、时代。
- 别名归一：`唐大郎`、`唐大郎（唐奕）`、`唐奕` 视为同一角色。
- 同名合并，不重复创建；同一角色跨场跨集复用同一张参考图。
- 没有参考图的角色不能作为画内人物进入生成。

## 场景

- 按【地点 + 时间段】匹配；同地点不同时间视为新场景。
- 同一地点只能有一个 canonical 场景资产；历史同名图做别名/版本，不并行使用。
- 字段：`prompt`（空间/陈设/年代/关键视觉）、`lighting`（光源/色调/氛围/时间）。
- 地标要稳定：窗、门、桌、柜台、入口、招牌。
- 季节、天气、光线统一；同一场戏不能绿树变红叶。

## 道具

两条同时满足：

1. 直接推动剧情：出现、交接、损坏、发现会引发转折。
2. 值得单独生成图片：后续会特写或反复出现，需要固定外观。

判定三问，任一“否”就放弃：

- 删掉它，剧情是否依然成立？成立 → 不提取。
- 只是日常随手物品（手机、筷子、杯子、烟）？是 → 不提取。
- 只是场景陈设（桌椅、灯具、门窗）？是 → 不提取。

一集通常 0–3 个关键道具；参考图用白底单品图，图像语义必须与道具名一致。

## 交付前检查

- [ ] 只提取本集真实出现/被提及且有效的资产。
- [ ] 角色别名已归一，没有重复角色。
- [ ] 主角/关键配角有参考图。
- [ ] 同一地点只有一个 canonical 场景。
- [ ] 场景地标、光线、季节可稳定复用。
- [ ] 道具满足两条条件，不超过 3 个。
- [ ] 道具参考图与名称语义一致。
