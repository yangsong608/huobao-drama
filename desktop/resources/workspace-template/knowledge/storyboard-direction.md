# 分镜与导演语法知识库

适用 Agent：`storyboard_breaker`

## 一个分镜要回答的九个问题

1. 这场进行到哪一拍？镜头承担什么叙事功能？
2. 观众要看谁/什么？主体是谁？
3. 景别是什么？为什么？
4. 机位在哪？角度是什么？
5. 镜头动不动？怎么动？
6. 人物在画面左还是右？谁在画内、谁在画外？
7. 人物之间什么空间关系？谁离谁多远？谁在谁身后？
8. 动作从哪开始、到哪结束？和上一镜/下一镜怎么接？
9. 声音是什么？台词、环境声、静默、BGM 怎么处理？

## 景别/角度/构图

- 远景/全景：建立空间、地理、人物与环境关系；每场至少一次。
- 中景：人物关系、动作过程、对话主体。
- 近景：情绪、反应、台词；短剧对话主力。
- 特写：信息、情绪爆点、道具、口型；不要滥用。
- 平视中性；仰视压迫；俯视弱势；侧面/背面制造距离或悬念。
- 画面要有前/中/后景和可读地标；不要让背景每次换一面墙。

## 轴线与屏幕方向

- 两个主要人物之间有一条关系轴线；机位尽量在同一侧（180°规则）。
- 同一侧镜头，人物屏幕左右不换：唐奕在左、范仲淹在右，就一直保持。
- 正反打只换前景肩：过唐肩看范，过范肩看唐；人物左右不换。
- 越轴必须用中性镜头过渡：建立、道具插入、空镜、人物走动。
- 30°规则：相邻镜头机位变化小于 30° 会像跳切；要么大于 30°，要么换景别/对象。
- 视线匹配、动作匹配：上一镜尾与下一镜首要接得上。

## 正反打与反应

- 对话场先建立空间，再进正反打；不要一上来两个特写对切。
- 每个说话人有镜头；每个听者至少一个反应镜头。
- 反应不是“听”，是态度变化：皱眉、冷笑、眼神躲闪、手指收紧、呼吸变化。
- 双人关系镜头交代距离、权力、亲密/对立；不要全是单人。
- 插入镜头交代道具/信息/手部动作；不要用空镜代替反应。

## 场景地理与调度

- 每个场景先定：桌、窗、门、谁站哪、谁坐哪、谁在谁身后。
- 同一场戏的镜头共享这套地理；反打不能把窗从左边换到右边。
- 人物进出要有动作：起身、转身、掀帘、推门、脚步；不能瞬移。
- 人物换位要有过渡：走过去、坐下、绕桌、被拉走。
- 背景地标写进镜头：窗在左后、门在右后、桌在两人之间。

## 覆盖模板

- 对话：1 establishing；1 master/two-shot；每个说话人至少 1 OTS/single；每个听者至少 1 reaction；关键道具/信息 1 insert。
- 动作：1 establishing；1 wide/action；1 impact/close；1 reaction；1 insert（可选）。
- 悬疑：1 establishing；1 detail insert；1 POV；1 reaction；1 reveal。
- 过渡：时间空镜、场景空镜、人物空镜、插入、文字卡。

## 16–19 的通用教训

- 同一侧机位不能换人物左右；16 的范左/唐右和 17 的唐左/范右是镜像。
- “逼近”只有推镜、没有人物移动时，18 不要突然肩并肩；要写撑桌/前倾/绕桌。
- 反打要接住前景肩；17 结尾范在右近景，18 开头右前景不能空。
- 反打不能镜像整间屋子；窗不能在唐后左、又跑到范后右。
- 正反打两侧不能同向；听者要朝说话人。
- 反应要么单独一段，要么写清右后景位置，不能塞进别人主导的 3 秒段。

## 交付前检查

- [ ] 每场有 establishing。
- [ ] 对话场有 master/two-shot、说话人镜头、听者反应。
- [ ] 屏幕左右稳定，正反打只换前景肩。
- [ ] 越轴有中性镜头过渡。
- [ ] 相邻机位变化大于 30° 或换景别/对象。
- [ ] 人物进出、换位有动作。
- [ ] 背景地标和场景地理一致。
- [ ] 动作/视线匹配有明确写法。
- [ ] 反应镜头没有被塞进别人主导的段落。
