# 前后镜连贯与过渡分镜知识库

适用 Agent：`storyboard_breaker`、`storyboard_auditor`、`prompt_generator`

## 先分清两层

- 剪辑转场：`cut / fade / dissolve / wipe`，决定 A 片段怎么接 B。
- 过渡分镜：在 A、B 之间插入一条真实分镜 C，有自己的时长、画面、参考图和生成任务。

不要用“把下一镜改成 fade”代替过渡分镜；同场连续对话不要乱插空镜。

## 每个切点一份成对合同

- 关系：正反打/动作匹配/视线匹配/时间跳/新场景。
- 轴线侧、屏幕左右、过肩。
- 画内/画外人物。
- 上一镜尾动作、下一镜首动作。
- 上一镜尾视线、下一镜首视线。
- 道具状态、光线/时间、声音桥。
- 上一镜尾帧作为下一镜首帧参考。

## 六条硬规则

1. 同场同对话，只换机位/景别，不换屏幕左右；正反打只换前景肩。
2. 越轴必须有中性镜头过渡。
3. 人物在场连续：尾帧有谁，首帧要能接上；进出必须有动作。
4. 动作匹配：上一镜尾动作 = 下一镜首动作。
5. 场景地理一致：同一面墙的地标不换边。
6. 声音桥不断；需要静默明确写静默。

## 首帧/尾帧链

- 默认上一镜尾帧作为下一镜首帧参考。
- 没有尾帧的镜头（第一镜、空镜、并行生成）说明原因。
- 逐镜串行生成，保证下一镜拿得到上一镜尾帧；无连续性要求的空镜可并行。
- 生成后并排看“上一镜尾帧 / 本镜首帧 / 本镜尾帧”。

## 什么时候必须用过渡

| 情况 | 过渡 |
|---|---|
| 同场景时间跳跃、光线变化、等待 | 时间过渡空镜 |
| 换地点/换场 | 场景过渡空镜 |
| 人物退出/进入/换人、轴线改变 | 人物过渡空镜 |
| 信息/情绪/章节切换 | 插入或文字卡 |
| 同场景连续对话 | 不需要，直接正反打 |

## 五种过渡

- 时间空镜 `time_empty`：光影、蜡烛、蒸汽、钟表、窗外天色、茶凉；匹配本场景地标/光线/季节/环境声；1–3 秒。
- 场景空镜 `scene_empty`：门、街、院落、招牌、桌面、交通工具；匹配新场景地理/人物去向/声音桥；2–4 秒。
- 人物空镜 `character_empty`：脚步、背影、手、门帘、放下/拿起物件、空椅；匹配服装/道具/方向/轴线/尾帧；1–3 秒。
- 插入 `insert`：信件、地图、刀刃、碗筷、书页、手部；匹配道具状态/位置/光线；1–2 秒。
- 文字卡 `text`：时间/地点/章节；匹配字体/风格/安全区；1–2 秒。

## 过渡自己的合同

`from/to`、`kind`、`reason`、`time_cue`、`location_cue`、`character_cue`、`cast_on_screen`、`direction`、`light_time`、`audio_bridge`、`duration`、`geo_ref`、`tail/start_frame_ref`。

## 使用边界

- 同场连续对话不插过渡。
- 一个场景边界最多一个过渡；不允许连续两个无信息空镜。
- 过渡不能掩盖动作不匹配或人物瞬移；能直接匹配就切。
- 时间空镜只在时间/光线明显变化时用。
- 场景空镜必须建立新地理；人物空镜必须接住进出方向。

## 16–19 的应用

- 17→18：同场同对话，不要过渡；要尾帧接首帧、过肩前景、同一面墙。
- 18→19：同场同对话，不要过渡；要正反打和群像反应；孙郎中/范公子需要先建立，用人物插入镜头给反应。
- 19→20：范/孙退、范公子接话，人物换位；插 1–2 秒人物过渡空镜，再接 20 的唐/范公子过肩。
- 20→下一场：换地点用场景空镜；同地点时间跳用时间空镜；同场连续动作用直接切。

## 交付前检查

- [ ] 每个切点有成对关系说明。
- [ ] 屏幕左右稳定，正反打只换前景肩。
- [ ] 越轴有中性镜头。
- [ ] 人物在场连续，进出有动作。
- [ ] 动作/视线/道具/光线/声音有承接。
- [ ] 该用过渡的地方有过渡，类型正确。
- [ ] 同场连续对话没有被空镜打断。
- [ ] 过渡分镜有自己的时长、线索和地理引用。
