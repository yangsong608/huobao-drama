# 视频提示词一致性知识库

适用 Agent：`prompt_generator`

## 五段结构

1. 信息头：`出场人物：@画内人物｜场景：@canonical场景`
2. 画面调度：屏幕左是谁、右是谁、过谁的肩、背景窗/门/桌在哪、轴线侧。
3. 时间轴：0 秒起连续分段，最后一段结束等于本镜 duration。
4. 台词/旁白：对白、画外音、内心独白、旁白分型；需要发声的包 `<d>`。
5. 负面约束：只出现画内人物；不换脸/换装/加人；不生成字幕；不出现与项目时代、地域和设定冲突的物品、服装、文字和标识。

信息头只写画内人物；画外人物不写进信息头，也不送参考图。

## 画内人物与参考图

- 画内人物 = 这一镜真正出现在画面里的人。
- 只送画内人物、场景、关键道具参考图；画外人物不送。
- 人物名与项目 canonical 名一致；别名先归一。
- 没有参考图的角色不能作为画内人物。
- 参考图顺序稳定：场景 → 画内人物 → 关键道具。

## 场景与空间

- 场景用 canonical 名；同一场戏只用一张 canonical 场景图。
- 背景地标写屏幕侧：窗在左后、门在右后、桌在两人之间。
- 反打不能镜像整间屋子；同一面墙的地标不换边。
- 季节、光线、时间一致；不出现错误招牌/匾额/现代物品。

## 首帧/尾帧

- 默认上一镜尾帧作为本镜首帧参考；显式首帧优先。
- 首帧要和上一镜尾帧在人物、站位、动作、光线、背景上接得上。
- 尾帧留可剪的动作/情绪停顿。
- Wan 3.0 不能首帧与参考图混用；降级为参考图，其他模型走首帧链。

## 台词与声音

- 对白：`@角色说：「台词」`；逐字复制，不新增、不压缩、不改字。
- 旁白/画外音/内心：`旁白（画外音）：「台词」`；画面角色不张口。
- 需要发声的内容必须包 `<d>`；没有 `<d>` 会被判定无对白，旁白失声。
- 画外音 `lip_sync=false`；对白 `lip_sync=true`。
- 容量 4 字/秒，留 1 秒气口；装不下拆镜。
- BGM 不写进视频提示词，由后期混音处理；同场景环境声复用。
- 不要写“音频：”要求行或音色/混音指令。

## 常见生成失败

| 失败 | 原因 | 修正 |
|---|---|---|
| 旁白没声 | 旁白没进 `<d>` | 规范旁白格式，检查最终 prompt |
| 人物多/少 | 信息头列了画外人物，或反应塞进别人段落 | 只写画内人物；反应单独一段 |
| 换脸/换装 | 参考图缺失或非 canonical | 补参考图，只用 canonical 资产 |
| 场景翻面 | 反打背景没锁地标 | 写清窗/门/桌屏幕侧 |
| 人物左右反 | 同侧机位镜像 | 固定屏幕左右，正反打只换前景肩 |
| 时间轴空尾 | 最后一段没到 duration | 最后一段结束等于 duration |
| 字幕/现代物品 | 没有负面约束 | 加“不生成字幕/不出现与项目设定冲突的物品” |
| 角色瞬移 | 没有尾帧/首帧/进出动作 | 带上一镜尾帧，写清进出 |

## 交付前检查

- [ ] 信息头只列画内人物和 canonical 场景。
- [ ] 有画面调度：左右、过肩、背景地标、轴线。
- [ ] 时间轴连续，最后一段到 duration。
- [ ] 台词逐字一致，旁白/对白分型，发声内容有 `<d>`。
- [ ] 只送画内人物/场景/关键道具参考图。
- [ ] 有首帧/尾帧；首帧接上一镜尾帧。
- [ ] 有负面约束。
- [ ] BGM 和混音没有写进提示词。
- [ ] 同场景环境声复用。
