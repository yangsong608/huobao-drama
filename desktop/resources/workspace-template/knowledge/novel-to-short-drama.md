# 小说改编短剧知识库

适用 Agent：`script_rewriter`

## 核心判断

短剧不是把小说分段朗读，而是把小说里的信息、情绪和关系，改写成可见的动作、可听的台词、可剪的场次。

改编先问四个问题：

1. 这场戏的目标是什么？谁想要什么？
2. 谁阻止他？冲突在哪里？
3. 这场结束时，信息或关系发生了什么变化？
4. 观众看完，多知道了什么？没有就删、并或改。

## 结构

- 开场 3 秒：冲突、异常、悬念、羞辱、危机、欲望，不从天气和日常开始。
- 每 30–60 秒：至少一个节拍变化。
- 集尾：停在问题、决定、揭示或危险上，不停在总结和抒情上。
- 每场：目标 → 阻碍 → 转折 → 结果；至少一个信息增量。

## 小说转剧本硬规则

1. 心理描写外化：能用动作、道具、表情、反应镜头表达的，不写内心独白。
2. 旁白只补充，不替代被删的戏；不重复画面已经说清楚的信息。
3. 一个场景尽量跟一个主视角，不随意跳头。
4. 设定、背景、关系拆进冲突：争执、试探、拒绝、交易、误会。
5. 时间压缩：赶路、等待、重复动作，用转场和动作匹配压缩。
6. 对白短、准、有潜台词；每句推进剧情、暴露人物或制造压力。
7. 人物声音可区分：用词、句长、称呼、语气不同。
8. 保留因果链：可以删枝蔓，不能删掉导致后面结果的原因。

## 格式

- 场景头：`## S编号 | 内景/外景 · 地点 | 时间段`
- 动作：自然段落，只写观众能看到/听到的内容，不写镜头语言。
- 对白：`角色名：（状态/表情）台词`
- 每场 30–60 秒；场次之间有时空关系。

## 交付前检查

- [ ] 每场有目标、阻碍、转折、结果。
- [ ] 每场至少一个信息增量。
- [ ] 没有整段心理描写。
- [ ] 旁白没有替代被删的戏。
- [ ] 对白没有解释观众已经看到的画面。
- [ ] 每个人物有可区分的声音。
- [ ] 集尾有钩子。
- [ ] 格式是场景头 + 动作 + 对白，没有镜头语言。
