# 声音与旁白设计知识库

适用 Agent：`voice_designer`

## 四种声音

1. 对白：角色开口说话，需要对口型。
2. 画外音：角色不在画面内，但声音是角色的（电话、门外、回忆）。
3. 内心独白：角色在心里说，画面中不张口。
4. 旁白：叙述者说，不是角色开口；克制、少情绪。

四种不能混写；旁白不替角色开口，内心独白不写成对白。

## 音色档案

- 年龄感与性别、音色、音区、语速、口音/咬字、气质与情绪基线、代表台词。
- 声音与身份一致：少年不能低沉中年音，老年不能少女音。
- 同项目角色有区分度：音色/音区/语速至少一项明显不同。
- 主角、反派、关键配角必须有稳定音色。
- 同一角色跨集跨场复用同一音色档案和参考音频。

## 旁白

- 只补充画面之外的信息，不重复画面已经说清楚的内容。
- 不替角色说话，不承担被删掉的戏。
- 风格统一、克制、少情绪；同一项目最好同一个旁白音色。
- 标注画外音，画面角色不张口。
- 与对白不能抢话；需要时留气口。

## 语速与停顿

- 对白按 4 字/秒估算；爆点可慢，信息密集可快，但不超过容量。
- 长句在标点或语义停顿处拆，不一口气念完。
- 重要信息前留半拍；情绪转折后留一拍。
- 旁白比对白更慢、更稳，不用播音腔压过剧情。

## 环境声与 BGM

- 同场景环境声连续；服务空间：室内/室外、白天/夜晚、雨/风/人群。
- BGM 不进入视频提示词，由后期混音处理；BGM 点与情绪节拍对齐。
- 需要静默时明确写“静默”，不默认断掉。
- 响度层级：对白最前，旁白次之，环境声铺底，BGM 不抢。

## 常见失败

角色声音差不多；少年音配老年脸；旁白情绪过满；旁白替角色说话；对白太长被迫加速；环境声每镜都换；BGM 从头铺到尾。

## 交付前检查

- [ ] 每个主要角色有音色档案和代表台词。
- [ ] 角色之间有区分度。
- [ ] 对白/画外音/内心/旁白分型正确。
- [ ] 旁白克制，不替角色说话，不重复画面信息。
- [ ] 语速和停顿符合容量。
- [ ] 同场景环境声连续。
- [ ] BGM 不进入视频提示词，由后期处理。
- [ ] 需要静默的地方明确写了静默。
- [ ] 同一角色跨集复用同一音色。
