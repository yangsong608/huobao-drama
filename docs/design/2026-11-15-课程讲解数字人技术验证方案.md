# 课程讲解数字人技术验证方案

- 日期：2026-11-15
- 状态：待批准执行
- 验证基线：当前工作区（4.0.49）
- 范围：课件解析、页级讲稿、配音、真人或卡通讲师、逐页合成、成本与质量门禁
- 结论预告：优先验证「真人固定底片 + LatentSync」，并行验证「卡通 Avatar Runtime」，H3/InfiniteTalk 只作为重点页候选
- 说明：本方案只定义验证，不包含实现代码、构建、安装、提交或生产发布；实现代码属于执行阶段

---

## 1. 背景与目标

### 1.1 业务需求

课程讲解数字人用于讲授课程，不是短剧表演。典型流程是：

1. 导入 PPT 或 PDF 课件。
2. 按页提取内容，生成页级讲稿。
3. 用真人或卡通讲师逐页讲解。
4. 将幻灯片、讲师画面、字幕、翻页与高亮合成为课程视频。
5. 讲稿修改后，只重做受影响页面，不整课重跑。

核心诉求不是「生成一个会说话的人」，而是「稳定、可编辑、可批量生产的课程视频」。

### 1.2 当前基础

火宝短剧当前已经具备可复用的工程能力：

| 能力 | 现状 | 对课程场景的价值 |
|---|---|---|
| 任务与恢复 | sys_task、多类 job 表、启动恢复、断点续跑 | 可直接承载逐页生成与失败恢复 |
| 配音 | 云端与本地 TTS、音色、Take、字幕相关能力 | 可复用页级配音与音色一致性 |
| 媒体合成 | FFmpeg 合并、转场、导出 | 可复用幻灯片与讲师画面合成 |
| 视频生成 | H3、ComfyUI 网关、云端适配器 | 可生成片头、片尾、重点页讲师片段 |
| 存储 | SQLite、项目媒体目录、静态文件服务 | 可保存页面、音频、片段与成片 |
| 界面 | Nuxt 3 工作台、任务中心、设置页 | 可新增课程工作台，但不应继续膨胀现有单集工作台 |

当前主要约束：

- 核心单集工作台已经很大，课程功能必须独立建模块，不能继续塞进同一文件。
- 本地 H3 网关对参考视频/音频输入存在已知限制；H3 音频驱动数字人不能作为 MVP 的唯一路径。
- 现有 GPU 环境出现过 10GiB 级显存不足；H3 课程批量生成必须按 480P 预览、串行执行设计。
- 仓库当前没有自动持续集成；验证必须留下可复现的脚本、命令记录与产物证据。
- 课程功能涉及真人肖像、声音克隆、卡通形象与模型许可证，必须在上线前完成授权核验。

### 1.3 验证目标

本次验证只回答四个问题：

1. PPT/PDF 能否稳定还原为逐页画面与可用文本，文字、图表、公式不丢失？
2. 页级讲稿能否达到课程讲师可用水平，并且可人工低成本修改？
3. 真人固定底片、卡通 Avatar Runtime、H3/InfiniteTalk 三条讲师路线，哪条满足质量、成本与可维护性？
4. 十页课程能否端到端跑通，并达到可接受的渲染时间、人工修复率和稳定性？

### 1.4 成功标准

验证结束时，必须能给出一个明确结论：

- 至少一条讲师路线在十页课程上端到端通过。
- 幻灯片文字与版式没有被视频模型破坏。
- 讲稿、配音、讲师画面、字幕、合成均通过质量门槛。
- 成本、时间、人工修复率有实测数据，不是估算。
- 明确 MVP 路线、长期路线、H3 的使用边界，以及下一阶段实施建议。

## 2. 范围与非目标

### 2.1 本次范围

| 范围 | 说明 |
|---|---|
| 课件导入 | PPTX 与 PDF，含文本层、扫描件、图表、公式、代码页 |
| 页面还原 | 逐页 PNG、页码、宽高、文本、备注、图片说明 |
| 讲稿生成 | 全课大纲、页级讲稿、术语一致性、人工编辑 |
| 配音 | 页级音频、音色一致性、发音词典、字幕时间戳 |
| 真人讲师 | 固定底片加逐页口型同步 |
| 卡通讲师 | 三维或二维 Avatar Runtime，含基础手势与指向 |
| 重点页讲师 | H3、InfiniteTalk、EchoMimic 的短片段能力 |
| 合成 | 幻灯片加讲师画中画、字幕、翻页、高亮、响度 |
| 任务 | 单页重生成、断点续跑、内容哈希、失败隔离 |
| 成本 | 每完成一分钟课程的 GPU 分钟、墙钟时间、人工修复时间 |

### 2.2 非目标

本次不验证以下内容：

- 不做完整课程平台、课程商城、学员管理、多租户与账号权限。
- 不做实时直播数字人。
- 不做自动出题、自动批改、学习分析。
- 不做 PPT 原生动画的完整还原；首轮允许拍平为静态页，动画作为增强项。
- 不做多语言课程批量生产；首轮以中文为主，保留英文术语。
- 不训练或微调数字人模型。
- 不修改现有短剧生产链路，不改变现有网关业务。
- 不进行生产部署、构建、安装或提交；这些动作需要单独批准。

## 3. 待验证假设与决策问题

| 编号 | 假设 | 需要的证据 | 若不成立的后果 |
|---|---|---|---|
| H1 | PPTX/PDF 可以稳定还原为逐页画面与文本 | 页面顺序、文字缺失、字体回退、图表与公式抽检 | 课件层不可用，后续全部阻塞 |
| H2 | LLM 可以基于页面内容生成讲师可用的讲稿 | 教学覆盖、事实准确、口语化、时长、衔接 | 只能人工写稿，效率目标不成立 |
| H3 | 真人固定底片加 LatentSync 能满足课程口型质量 | 真人底片、逐页口型、身份稳定性、人工评分 | 真人 MVP 路线失败，需改用其他讲师路线 |
| H4 | 卡通 Avatar Runtime 能满足课程形象、口型与手势 | 三维或二维形象、viseme、手势、指向、渲染稳定性 | 长期低成本路线不成立 |
| H5 | H3/InfiniteTalk 适合做重点页，而不是批量主渲染 | 网关音频输入、片段质量、耗时、显存 | H3 只能做片头片尾，甚至完全退出课程链路 |
| H6 | 逐页任务、内容哈希、断点续跑可以稳定工作 | 杀进程恢复、单页重生成、缓存命中、页面隔离 | 长课程返工成本不可控 |
| H7 | 固定版式可以保证讲师不遮挡幻灯片内容 | 画中画安全区、密集页面、字幕区、不同画幅 | 需要更复杂的版式或人工排版 |
| H8 | 十页课程的成本与时间在可接受范围 | GPU 分钟、墙钟时间、人工修复率 | 方案无法规模化，需要重新选型 |

决策问题：

1. MVP 是否采用真人固定底片加 LatentSync？
2. 长期是否采用卡通 Avatar Runtime？二维还是三维？
3. H3/InfiniteTalk 是否只做重点页？当前网关是否支持音频参考输入？
4. 课程功能是否作为火宝的新项目类型，而不是新平台？
5. 首版是否接受静态幻灯片加高亮/放大，而不追求 PPT 原生动画？

## 4. 候选技术路线

### 4.1 路线 A：真人固定底片加 LatentSync

做法：

1. 录制或生成一段十到三十秒的真人讲师底片：正面、半身、口型可见、背景干净、动作幅度小。
2. 每页先合成 TTS 音频。
3. 用 LatentSync 将每页音频同步到底片，生成逐页讲师片段。
4. 用 FFmpeg 将幻灯片与讲师画中画合成。

优点：

- 口型质量稳定，身份一致。
- 最低八 GB 显存可跑 LatentSync 1.5。
- 单页重生成成本低，适合长课程。
- 不需要视频大模型生成整段讲师画面。

风险：

- 讲师动作重复，需要多段底片轮换。
- 视频模型无法指向幻灯片，需要用高亮和放大代替。
- 底片质量决定最终效果，底片不好则全线不好。

### 4.2 路线 B：卡通 Avatar Runtime

做法：

1. 准备三维 VRM 或二维 Live2D 讲师形象。
2. TTS 输出音素或 viseme，驱动口型。
3. 预置手势库：点头、摊手、思考、强调、指向标题、指向图表。
4. 用 WebGL 或离线帧序列渲染讲师透明背景视频。
5. 与幻灯片合成。

优点：

- 近实时，成本极低。
- 形象、机位、表情天然一致。
- 讲稿改了可以立刻重渲。
- 可以做预设指向和手势，适合教学。

风险：

- 需要美术资产与 Avatar Runtime 开发。
- 真实感不如真人。
- 手指指向与复杂图表标注仍需要人工预设目标区域。
- 三维与二维的适用课程类型不同，需要选型。

### 4.3 路线 C：H3、InfiniteTalk、EchoMimic 重点页

做法：

1. 用角色图或真人照片加音频，生成十到二十秒讲师片段。
2. 仅用于片头、片尾、章节过渡、重点结论页。
3. 与路线 A 或 B 的常规页面混合。

优点：

- 表现力和镜头感最好。
- 适合品牌课程和招生课的重点镜头。
- 可以复用现有 H3 与 ComfyUI 网关。

风险：

- 成本高。按现有实测，四十秒成片约四十到七十分钟 GPU 时间。
- 长课程逐页生成不现实。
- 当前网关对参考音频输入存在限制，必须先验证。
- 长视频仍可能出现身份、服装、背景漂移。

### 4.4 路线 D：混合方案

推荐采用：

- 常规页面：路线 A 或路线 B。
- 片头、片尾、重点页：路线 C。
- 课件与讲稿、配音、合成、任务系统共用一套底座。

混合方案的核心不是「三套系统」，而是「一个讲师渲染接口，三种实现」。课程页面只依赖统一的讲师片段产物，不关心它由哪种方式生成。

### 4.5 路线对比

| 维度 | 路线 A 真人底片 | 路线 B 卡通 Runtime | 路线 C 视频模型 |
|---|---|---|---|
| 课程真实感 | 高 | 中高 | 高 |
| 单页成本 | 低 | 极低 | 极高 |
| 长课程可行性 | 高 | 极高 | 低 |
| 形象一致性 | 高 | 极高 | 中 |
| 改稿后重渲 | 快 | 极快 | 慢 |
| 指向与手势 | 弱 | 强，可预设 | 弱 |
| 工程复杂度 | 中 | 中高 | 中 |
| 许可证风险 | 中 | 中 | 中高 |

## 5. 现状约束与依赖核验

### 5.1 工程约束

| 约束 | 要求 |
|---|---|
| 数据隔离 | 使用独立 SQLite 路径与样例课程，不接触用户生产库 |
| 现有业务 | 不修改现有短剧生产流程与网关业务；新增能力必须隔离 |
| 界面 | 新建课程工作台，不继续扩大现有单集工作台 |
| 任务 | 复用现有任务队列与恢复机制；每页一个可重试单元 |
| 合成 | 复用现有 FFmpeg 能力；首轮不引入新的渲染框架 |
| 显存 | 视频模型串行执行；先 480P 预览，再 720P 终稿；不做并发抢显存 |
| 证据 | 每次验证留下真实产物、日志、截图与媒体元数据；不以节点注册代替跑通 |
| 审批 | 模型下载、GPU 长任务、付费语音调用、构建、安装、提交均需单独批准 |

### 5.2 依赖核验清单

执行前必须逐项核验。缺失项按阻塞处理，不能写成「可以」。

| 依赖 | 用途 | 当前状态 | 核验方式 | 缺失后果 |
|---|---|---|---|---|
| LibreOffice 与中文字体 | PPTX 转 PDF/PNG | 待核验 | 用含特殊字体的 PPTX 转换并人工比对 | 课件层阻塞 |
| PDF 渲染与 OCR | PDF 页面与扫描件 | 待核验 | 文本层、扫描件、公式页各测一页 | 部分课件阻塞 |
| Docling 或 Marker | 复杂 PDF 版面解析 | 待核验 | 对比标题、列表、表格、图片顺序 | 讲稿输入质量不足 |
| 中文 TTS 与音色 | 页级配音 | 待核验 | 试听技术术语、数字、英文缩写 | 配音层阻塞 |
| 真人底片 | 路线 A | 待核验 | 检查口型可见、光线稳定、无遮挡 | 路线 A 阻塞 |
| LatentSync 权重 | 路线 A | 待核验 | 加载模型并跑一段真实音频 | 路线 A 阻塞 |
| 卡通形象资产 | 路线 B | 待核验 | 检查模型、骨骼、表情、商用授权 | 路线 B 阻塞 |
| Avatar Runtime | 路线 B | 待核验 | 跑通口型与一个手势 | 路线 B 阻塞 |
| H3 音频参考能力 | 路线 C | 待核验 | 用真实音频参考提交一次任务 | 路线 C 仅能做无音频参考的片段 |
| InfiniteTalk 或 EchoMimic | 路线 C 备选 | 待核验 | 跑通一张图加一段音频 | 路线 C 备选受阻 |
| FFmpeg | 合成与质检 | 已有 | 读取时长、分辨率、音轨、黑帧 | 合成层阻塞 |
| GPU 与磁盘 | 生成与存储 | 待核验 | 显存、磁盘余量、任务串行 | 长任务阻塞 |

### 5.3 阻塞规则

- 缺少模型权重、LoRA、底片、音色参考或 Avatar 资产时，对应路线标记为阻塞。
- 不得用其他路线的成功结果替代被阻塞路线的证据。
- 不得把「节点已加载」「模型已下载」写成「能力可用」。
- 只有真实任务成功并产出可播放、可检查的成片，才算该路线验证通过。

## 6. 测试样本与素材

### 6.1 课件样本

| 编号 | 类型 | 页数 | 特征 | 主要验证 |
|---|---|---:|---|---|
| S1 | PPTX 文字型 | 10 | 标题、要点、备注、少量图标 | 页序、文字、备注、讲稿 |
| S2 | PPTX 图表型 | 10 | 表格、柱状图、流程图、嵌入字体 | 图表还原、版式、画中画避让 |

| S5 | PDF 图文型 | 6 | 大图、少量文字、营销版式 | 视觉模型讲稿、画面还原 |

首轮只取 S1 与 S3 各三页做快速验证；通过后再扩展到十页课程。

### 6.2 讲师素材

| 素材 | 要求 |
|---|---|
| 真人底片 | 十到三十秒，正面半身，口型清晰，光线稳定，背景干净，无遮挡，无大幅走动 |
| 真人备用底片 | 两到三段不同景别或手势，用于打破重复感 |
| 卡通三维形象 | VRM 或等价格式，含面部表情、口型 viseme、上半身骨骼与基础手势 |
| 卡通二维形象 | Live2D 或等价格式，含口型参数与表情参数 |
| 卡通静态图 | 用于视频模型重点页测试，正面、清晰、无遮挡 |
| 重点页参考图 | 与真人和卡通形象一致，避免跨页身份变化 |

### 6.3 声音素材

| 素材 | 要求 |
|---|---|
| 音色参考 | 十到十五秒干净人声，无背景音乐，无混响 |
| 技术术语表 | 至少三十个课程术语，含英文缩写、数字、单位、公式符号 |
| 多音字清单 | 课程中出现的多音字与易错词 |
| 语速样本 | 慢、中、快三档，用于课程节奏选择 |

### 6.4 版权与授权

| 项目 | 要求 |
|---|---|
| 真人肖像 | 本人书面授权，明确课程用途与传播范围 |
| 真人声音 | 声音克隆授权，明确使用期限与平台 |
| 卡通形象 | 模型、贴图、骨骼、动画的商用授权 |
| 课件内容 | 使用自有或已授权课件；验证样本不得使用未授权教材 |
| 模型许可证 | LatentSync、InfiniteTalk、EchoMimic、H3、Avatar Runtime 分别核验 |
| 音乐与字体 | 只使用可商用音乐与字体；字体嵌入与再分发需核对许可 |

## 7. 指标体系与通过标准

### 7.1 课件还原

| 指标 | 方法 | 通过标准 |
|---|---|---|
| 页序 | 与源文件逐页对照 | 百分之百一致 |
| 文字缺失 | 页面图与源文本对照 | 关键文字零缺失 |
| 文字溢出/截断 | 人工检查页面图 | 零严重溢出 |
| 字体回退 | 对比标题、正文、符号 | 无不可接受回退；关键页面零回退 |
| 图表/表格 | 人工检查坐标、图例、单位 | 百分之九十以上页面可直接使用 |
| 公式/代码 | 人工检查符号、缩进、换行 | 关键页面可直接使用；不允许错位到无法讲解 |
| 扫描件 OCR | 与页面图对照 | 主要段落可读；噪声不影响讲稿 |

### 7.2 讲稿质量

采用双人评分，一分最低，五分最高。

| 维度 | 权重 | 通过标准 |
|---|---:|---|
| 内容覆盖 | 百分之三十 | 平均不低于四分；关键点无遗漏 |
| 事实准确 | 百分之二十五 | 零关键事实错误；公式、数字、术语与课件一致 |
| 口语化 | 百分之二十 | 平均不低于四分；不照读幻灯片 |
| 结构与衔接 | 百分之十五 | 平均不低于四分；页间过渡自然 |
| 时长控制 | 百分之十 | 每页四十五到九十秒；偏差不超过百分之二十 |

3. 修改一页讲稿，验证只重生成该页。
4. 不改任何内容，二次渲染验证缓存命中。
5. 统计 GPU 分钟、墙钟时间、人工修复率与失败页。

#### 自测

- 已完成页不重复生成。
- 单页失败不影响其他页。
- 单页重生成时间达到目标。
- 二次渲染缓存命中达到目标。

#### 验证

- 人工完整观看成片。
- 对照第 7 节指标逐项打分。
- 输出成本模型与失败清单。
- 通过则进入决策评审。

---

### 9.10 V9 决策评审

#### 要求

基于实测数据选择 MVP 路线、长期路线与 H3 使用边界，形成明确的下一步实施建议。

#### 约束

- 不以仓库热度或主观印象替代实测数据。
- 未通过的路线必须明确写出失败原因与阻断项。
- 不把「待验证」写成「已完成」。
- 评审结论必须可追溯到证据路径。

#### 参考

- 第 7 节指标。
- 第 9 节各工作包结果。
- 第 12 节风险清单。

#### 设计

1. 汇总三条路线的质量、成本、稳定性与风险。
2. 按决策规则选择 MVP 与长期路线。
3. 明确 H3/InfiniteTalk 的使用边界。
4. 输出下一阶段实施建议与工作量估算。
5. 形成验证报告与决策记录。

#### 自测

- 每个结论都有证据路径。
- 每条未通过路线都有阻断项。
- 成本模型包含人工修复时间。
- 决策与指标一致，不矛盾。

#### 验证

- 由课程业务、工程、算法与评审共同确认。
- 通过后进入实施计划编写；未通过则重新定义问题或补做验证。

大体积视频与音频放在临时目录，只把报告、截图与索引纳入文档目录；不要把大文件提交到仓库。

### 11.2 留证字段

每次任务至少记录：

- 课程编号、页码、讲稿版本。

- 输出时长、分辨率、帧率、编码、音轨、响度。
- 人工评分、失败原因、修复动作。
- 证据路径与截图编号。

### 11.3 验收级别

每条路线必须逐级通过：

| 级别 | 含义 |
|---|---|
| 零 | 文件不存在 |
| 一 | 模型或节点已安装 |
| 二 | 工作流可加载，连线与参数有效 |
| 三 | 真实任务提交成功 |
| 四 | 产出可播放、可检查的媒体 |
| 五 | 首帧、中帧、末帧与整段观看通过 |

- 截图使用中文序号命名，例如入口、页面还原、画中画、字幕、失败对比。

- 所有结论必须能追溯到具体证据路径。

## 12. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 特殊字体缺失 | 页面版式错位 | 固定渲染环境与字体包；导入后先预览 |
| 扫描件 OCR 噪声 | 讲稿事实错误 | 保留页面图；关键页人工校对；公式页用视觉模型 |
| 图表理解错误 | 讲稿讲错数据 | 图表页人工复核；视觉模型只做辅助 |
| 技术术语发音错误 | 课程质量下降 | 发音词典、逐句试听、只重配错句 |
| 真人口型不自然 | 观看体验差 | 换底片、调参数、必要时改用卡通路线 |
| 卡通形象不自然 | 信任感不足 | 选择正式风格；先做三页样片 |
| 画中画遮挡内容 | 信息缺失 | 内容密度检测；自动切换分栏或纯幻灯片 |
| 长课程显存不足 | 任务中断 | 480P 预览、串行执行、分段与卸载 |
| 长课程形象漂移 | 一致性差 | 路线 A 固定底片；路线 B 固定模型；路线 C 只做短片段 |
| 单页失败拖垮整课 | 返工成本高 | 单页任务隔离、断点续跑、失败页清单 |
| 讲稿频繁修改 | 重渲成本高 | 内容哈希、单页重生成、版本保留 |
| 模型许可不清 | 商用风险 | 逐模型核验；GPL 与非商用组件只做参考或隔离 |
| 真人肖像与声音授权 | 法律风险 | 书面授权；限定用途与期限 |
| 课件版权 | 法律风险 | 使用自有或授权课件；验证样本不外传 |
| 验证数据污染生产 | 数据风险 | 独立库与独立目录；禁止连接生产库 |
| 结果不可复现 | 无法决策 | 固定版本、固定参数、记录哈希与任务编号 |

## 13. 决策门与产出

### 13.1 决策门

| 决策门 | 条件 | 不通过的处理 |
|---|---|---|
| G0 依赖 | 依赖清单全部有状态，阻塞项明确 | 停止对应路线，不用替代品冒充 |
| G1 课件 | H1 成立，关键页面还原通过 | 调整解析与字体方案，重新验证 |
| G2 讲稿 | H2 成立，评分与硬性条件通过 | 调整提示词、术语表或人工写稿比例 |
| G3 真人路线 | H3 成立，质量与成本达标 | 换底片、调参数或放弃路线 A |
| G4 卡通路线 | H4 成立，形象、口型、手势达标 | 调整形象或运行时；必要时只做二维 |
| G5 视频模型 | H5 成立，网关音频输入可用，成本达标 | 路线 C 只做片头片尾或退出 |
| G6 端到端 | H6、H7 成立，三页课程通过 | 修复合成的版式、任务与字幕问题 |
| G7 十页课程 | H8 成立，成本与稳定性达标 | 缩减课程长度或更换路线 |
| G8 最终评审 | 至少一条路线全链路通过 | 重新定义问题，不进入实施 |

### 13.2 决策规则

- 路线 A 通过：作为 MVP 默认路线。
- 路线 B 通过：作为长期课程与频繁改稿的默认路线。
- 路线 A 与 B 都通过：混合使用，A 做品牌课，B 做长期课程库。
- 路线 C 通过但成本高：只用于片头、片尾、章节过渡与重点页。
- 路线 C 因网关音频输入不支持而阻塞：不作为课程主路线，明确记录阻塞项。
- 所有路线都不通过：停止实施，重新评估课件形态、课程长度或外部服务。

### 13.3 产出

验证结束后必须交付：

1. 验证报告：目标、方法、样本、结果、失败清单、证据索引。
2. 路线决策：MVP 路线、长期路线、H3 使用边界。
3. 成本模型：每完成分钟 GPU 成本、十页课程墙钟时间、人工修复时间。
4. 质量基线：课件还原、讲稿、配音、口型、合成的评分与失败页。
5. 风险清单：阻塞项、许可证、授权、显存与数据风险。
6. 实施建议：数据表、接口、界面、任务、分阶段计划；另起实施计划文档。

## 16. 附录

### 16.1 样本准备清单

- 十页文字型 PPTX，含备注与特殊字体。
- 十页图表型 PPTX，含表格、流程图、嵌入字体。
- 六页公式/代码 PDF，中英文混排。
- 六页扫描 PDF，含页眉页脚与轻微倾斜。
- 六页图文型 PDF，含大图与营销版式。
- 真人底片两到三段。
- 卡通三维或二维形象一套。
- 音色参考十到十五秒。
- 技术术语表三十项。
- 多音字与易错词清单。

### 16.2 讲稿评分表

| 维度 | 一分 | 三分 | 五分 |
|---|---|---|---|
| 内容覆盖 | 大量遗漏 | 主要点覆盖 | 完整且有取舍 |
| 事实准确 | 关键错误 | 少量小错 | 全部准确 |
| 口语化 | 照读幻灯片 | 基本口语 | 自然像讲师 |
| 结构与衔接 | 散装 | 有过渡 | 前后呼应 |
| 时长控制 | 严重超时或过短 | 接近目标 | 精准可控 |

### 16.3 讲师画面评分表

| 维度 | 一分 | 三分 | 五分 |
|---|---|---|---|
| 口型 | 明显不同步 | 基本同步 | 自然准确 |
| 身份 | 明显漂移 | 基本稳定 | 完全一致 |
| 伪影 | 严重影响观看 | 轻微可见 | 不可见 |
| 手势 | 僵硬或缺失 | 基本自然 | 有教学表达 |
| 指向 | 完全不准 | 大致方向 | 准确命中 |

### 16.4 最终验收清单

- 课件页序、文字、图表、公式通过。
- 讲稿覆盖、准确、口语化、时长通过。
- 配音发音、自然度、音色、响度、字幕通过。
- 讲师口型、身份、嘴部可见、伪影通过。
- 合成版式、字幕、音画同步、黑帧、响度通过。
- 单页重生成、断点续跑、缓存命中通过。
- 成本、时间、人工修复率达到目标。
- 许可证、肖像、声音、课件授权核验完成。
- 证据路径完整，结论可追溯。

### 16.6 术语

| 术语 | 含义 |
