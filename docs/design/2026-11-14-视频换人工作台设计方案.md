# 视频换人工作台设计方案

- 日期：2026-11-14
- 状态：设计待评审
- 范围：新增独立“视频”模块，支持 H3 单脸换脸与 H3 Recast 角色替换两种模式
- 前置结论：H3 Recast 是工作流，网关 + 命名工作流是调用方式，两者不是二选一

## 1. 背景与目标

现有产品已经有“短剧”和“小说”两个顶级模块。短剧负责从剧本到分镜、视频、配音、混音、剪辑、成片；小说负责长篇创作与改编。视频换人是一个独立的后期制作能力：用户给一段参考视频、一个目标人脸或角色，系统保留原视频的动作、场景和原声，把视频中的人换掉。

本方案新增一个独立的“视频”模块，提供项目列表、素材输入、AI 分析、最终提示词、视频生成、进度日志和版本管理。

目标：

- 用户可以在一个工作台内完成“上传素材 → AI 分析 → 确认参考帧/提示词 → 生成 → 预览/导出”；
- 复用现有 AI 配置、网关、ComfyUI 工作流、任务轮询和四语言界面；
- 两种模式共用项目、素材、镜头、进度、日志和版本体系；
- 不把 ComfyUI 工作流 JSON 暴露给终端用户。

非目标：

- 第一版不做多人跨镜头角色追踪；
- 第一版不做自动换装、换背景、换场景；
- 第一版不做训练专属人脸模型；
- 第一版不做云渲染集群，仍使用现有 4090 服务器。

## 2. 已冻结决策

| 决策 | 结果 |
|---|---|
| 项目边界 | 新建独立“视频”顶级模块，拥有独立项目列表和数据表 |
| 换人范围 | 双模式：H3 单脸换脸 + H3 Recast 角色替换 |
| 单脸换脸引擎 | 第一版直接使用 H3 单脸工作流，不使用 ReActor |
| 多镜头 | ffmpeg 自动检测硬切；镜头内超过最大生成时长再按时长分块；逐镜/逐片生成后合并并保留原声 |
| 场景参考帧 | AI 自动生成，用户必须确认或重新生成 |
| 调用方式 | 新网关实例调用 8189 上的命名 ComfyUI 工作流 |
| 用户配置 | 新增独立的视频换人 AI 配置，不复用普通视频配置 |

## 3. 两种模式的边界

### 3.1 H3 单脸换脸

- 目标：只替换人脸，身体、服装、发型、背景、动作、原声尽量保持不变；
- 引擎：H3 单脸工作流，路线参考 FaceSwap_MiniMaxH3_REF2VA：REF2VA 主模型 + Turbo LoRA + FaceSwap LoRA + CRT-Nodes + VHS；
- 输入：源视频、1–4 张参考人脸、H3 提示词（含 Faceswap 触发词）、seed、steps；
- 不要求场景参考帧，不改变身体和服装；场景和动作由源视频约束；
- 速度：比逐帧换脸慢，但比 H3 Recast 3 人同镜轻；必须异步任务；
- 时长：单次生成默认上限 8 秒，超过按时长分块，见 6.2.1；
- 限制：第一版单人；需要 REF2VA Turbo LoRA（优先 8step，现有 4step 需实测）、FaceSwap LoRA、CRT-Nodes；可能出现背景轻微漂移；
- 文本提示词：直接参与 H3 生成，用于目标人物、表情、动作和画质描述；
- 输出：换脸视频、原始音轨。

### 3.2 角色替换

- 目标：换脸、身体、服装，保留原视频动作、场景和原声；
- 引擎：H3 Recast 工作流 + BFS Character Swap LoRA；
- 输入：源视频、场景参考帧、1–3 人物 caption、生成参数；
- 速度：4090 上 6 秒 / 3 人约 26 分钟，必须异步任务；
- 时长：单次生成默认上限 6 秒；单个镜头超过 6 秒按时长分块，见 6.2.1；
- 限制：单个生成任务只接受单镜头、无硬切；1–3 人；需要场景参考帧；镜像和反光不支持；细微变化可能退回原样；
- 文本提示词：用于 AI 分析、人物 caption、场景参考帧提示词和最终结构化提示词；
- 输出：角色替换视频、原始音轨、可选口型修复版本。

两种模式共用项目、源视频、参考人脸、镜头拆分、运行记录、进度日志和版本管理；模式决定后续分析和生成链路。

## 4. 页面与交互

### 4.1 顶部导航

在现有“短剧 / 小说 / 设置”之间新增“视频”入口，建议顺序为“短剧 / 小说 / 视频 / 设置”，保留现有用户习惯。

导航复用现有顶部栏；视频模块使用全高工作台布局，不引入新的 UI 框架。

### 4.2 左侧项目列表

- 新建项目：填写项目名称，选择模式（H3 单脸换脸 / H3 Recast 角色替换）；
- 搜索：按项目名称；
- 筛选：全部、草稿、分析中、待生成、生成中、已完成、失败；
- 项目项：缩略图、名称、模式标签、状态、更新时间；
- 项目菜单：打开、重命名、复制、删除；
- 当前项目高亮，切换项目时保留右侧运行状态；
- 删除项目需要二次确认，并清理项目媒体和运行记录；
- 平板/手机端折叠为抽屉，不挤压右侧工作区。

### 4.3 右侧上部：输入与素材分析

左侧输入区：

- 提示词：中文/英文均可，显示字数，提供示例；
- 参考视频：拖拽或选择，显示时长、分辨率、fps、音频、镜头数；
- 参考人脸：拖拽或选择，显示人脸裁剪和质量评分；
- H3 单脸支持 1–4 张参考人脸，第一版只启用 1 张；角色替换模式支持 1–3 个人物槽位，第一版只启用 1 人；
- 配置选择：视频换人 AI 配置；
- 操作按钮：分析素材、生成场景参考帧（仅角色替换）、开始生成。

中间分析区：

- 视频信息；
- 镜头列表：镜头序号、起止时间、时长、片段数、是否可处理；
- 镜头可展开为片段列表：片段序号、源起止、重叠、预计耗时、状态；
- 超长镜头显示分割点、重叠和连续性策略；
- 人物列表：位置、服装、动作、是否为目标；
- 风险提示：多镜头、无音频、人脸过小、遮挡、反光、片段数过多、预计耗时过长。

右侧结果区：

- H3 单脸换脸模式：目标人脸、目标镜头、H3 提示词、预计耗时；
- 角色替换模式：场景参考帧预览、人物 caption、最终结构化提示词、生成参数；
- 角色替换模式的场景参考帧必须由用户确认后才能开始生成；
- 最终提示词可逐项编辑、锁定、重新分析；
- 每次生成保存一个冻结版本，重跑使用冻结版本。

### 4.4 右侧下部：生成结果与日志

- 视频播放器：输出视频、原视频对照、版本切换；
- 输出信息：时长、分辨率、fps、音频流、文件大小；
- 操作：下载、复制路径、重新生成、取消、加入剪辑（后续）；
- 进度：阶段时间线、当前镜头/片段、已完成片段数、队列位置、耗时；
- 连续性面板：接缝前后帧预览、SSIM、颜色差、人脸相似度、警告和“重试此段”；
- 日志：底部可折叠抽屉，按时间显示阶段、级别、消息；错误时自动展开；
- 失败时显示具体阶段、片段、网关任务 ID、ComfyUI 错误摘要和重试按钮；
- 多镜头/多片段时显示逐镜、逐片段、接缝检查和合并进度。

### 4.5 其他操作

- 取消当前运行：取消网关任务、标记未开始片段为取消；
- 从失败片段重试：已完成的片段跳过，不重跑整个镜头；
- 重新生成：保留素材和分析，使用新 seed 或修改后的最终提示词；
- 复制项目：复制源视频、参考人脸和提示词，不复制输出；
- 删除项目：二次确认，清理媒体、运行和日志；
- 打开输出目录、复制最终提示词、导出项目摘要。

## 6. 后端流水线

### 6.1 素材探测

使用现有 ffmpeg/ffprobe 工具：

- 读取时长、分辨率、fps、编码、旋转、音频流；
- 检测无音频、竖屏、超长、超大文件；
- 生成分析代理；
- 生成 24fps、H.264/AAC 的生成用归一化视频；
- 单独提取原片音轨作为最终音轨母版，逐段生成不拼接分段音频；
- 读取当前工作流的最大生成时长，计算镜头内需要拆成的片段数；
- 原片保留用于对照和音频回填；
- 所有 ffmpeg 调用使用参数数组，不拼接 shell 字符串。

### 6.2 镜头拆分与时长分块

- 使用 ffmpeg 场景检测识别硬切；
- 输出镜头列表，每个镜头写入 video_swap_shots；
- 先按硬切拆镜头，再对每个镜头按时长拆片段，写入 video_swap_chunks；
- H3 单脸换脸和角色替换都必须遵守工作流最大生成时长；
- 镜头边界是硬切，不加重叠；镜头内片段之间必须有重叠，用于连续性；
- 合并时使用原视频音轨，避免逐段音频拼接产生断点。

### 6.2.1 长视频分割、生成、拼接与连续性

适用场景：单个镜头时长超过工作流最大生成时长，或多镜头视频需要逐镜处理。

分割规则：

- 每种模式有独立的 max_generation_seconds：H3 单脸默认 8 秒，H3 Recast 默认 6 秒，均可在 AI 配置中覆盖；
- 每个片段必须有最短时长，默认 5 秒；尾部不足最小时并入前一片段或调整切点；
- 镜头内片段默认重叠 1 秒；第一段没有头部重叠，最后一段没有尾部重叠；
- 切点优先选在低运动、无对白、人脸清晰的稳定帧，避免切在说话中间、快速动作、遮挡或转场处；
- 切点允许在目标位置前后小幅移动，以找到稳定帧；
- 总片段数超过上限时阻断并提示，避免一个项目排入几十个长任务。

连续性规则：

- 同一镜头内的片段使用同一组人物 caption、同一场景参考帧、同一 seed；
- 场景参考帧默认每个镜头一张；如果镜头内光线/场景明显变化，允许按片段生成参考帧，但必须保持同一人物身份并做一致性评分；
- 片段生成时多生成头部/尾部重叠帧，拼接前按帧号精确裁掉重叠；
- 所有片段统一 24fps CFR、同一分辨率、同一像素格式；
- 如果工作流支持首帧/参考帧条件，可把上一段最后一帧作为下一段的连续性参考；不支持时不能假设该能力，必须依赖源视频重叠和接缝检查；
- 接缝处比较上一段最后一帧与下一段第一帧的 SSIM、颜色直方图和人脸 embedding；
- 接缝差异超过阈值时，只重试后一段，允许调整切点或 seed，不重跑整个镜头；
- 可选 2–4 帧交叉淡化，但不能用淡化掩盖明显的动作断裂；
- 最终音频使用原片音轨母版，不采用逐段生成音频拼接。

拼接规则：

- 生成剪辑决策表：镜头、片段、源时间、生成文件、裁切入点/出点；
- 重叠裁切口径：后段裁掉头部重叠，前段保留尾部重叠；后段 core = 源区间 − overlap_before_ms，保证所有 core 拼接后总时长等于源视频；
- 按镜头顺序拼接片段，镜头边界保留硬切；镜头内接缝按裁切结果拼接；
- 统一编码参数后 concat，避免时间戳跳变和音画漂移；
- 合并后校验总时长、总帧数、音频长度和源视频一致；
- 单片段失败时阻断合并并显示失败片段；不允许静默用原片片段替代，除非用户明确选择并接受未换人区域。

连续性验收：

- 接缝无肉眼可见跳变、颜色突变或人物身份突变；
- 动作方向、姿态、镜头运动连续；
- 原声不断裂、不重复、不漂移；
- 总时长与源视频一致，允许因帧网格产生不超过一帧的误差；
- 接缝指标和重试记录写入运行日志。

### 6.3 抽帧与人脸分析

- 每个镜头抽取 3–5 张代表帧；
- 使用 InsightFace 检测人脸、评分清晰度、角度和遮挡；
- 选择人脸最大、最正、无遮挡的帧；
- 多人物时标记人物顺序和位置；
- H3 单脸换脸模式选择目标人脸和目标帧；
- 角色替换模式选择场景参考帧的底图。

### 6.4 AI 视觉分析

- 使用支持图片输入的文本/视觉模型；
- 描述场景、人物、服装、动作、景别、光线；
- 根据用户提示词识别“换谁”；
- H3 单脸换脸模式输出目标人物、目标镜头、质量风险、H3 单脸提示词和 Faceswap 触发词；
- 角色替换模式输出人物 caption、场景参考帧提示词、全局风格、负面词和生成参数；
- 不对年龄、种族、健康等敏感属性做推断，人物描述以位置、服装、发型、动作为主。

### 6.5 场景参考帧

仅角色替换模式需要：

- 从源视频选择最佳帧；
- 使用 Qwen-Image-Edit 或图片 AI 配置，把参考人脸/角色换入该帧；
- 保留原构图、姿态、服装场景和光线；
- 生成 2–4 个候选；
- 用户在 UI 中确认、选择或重新生成；
- 默认每个镜头一张场景参考帧，镜头内所有片段共用；
- 如果镜头内光线/场景明显变化，允许按片段生成，但必须保持同一人物身份并做一致性评分；
- 未确认时禁止提交 H3 Recast；
- 场景参考帧和最终提示词一起冻结到运行记录。

### 6.6 最终提示词

角色替换模式输出结构化提示词，不是单一字符串：

| 字段 | 用途 |
|---|---|
| 场景参考帧提示词 | 生成或重生成场景参考帧 |
| 人物 1–3 caption | H3 Recast 人物描述 |
| 全局风格 | 保持原片风格 |
| 负面词 | 排除字幕、水印、畸形等 |
| 生成参数 | 分辨率、steps、seed、口型修复 |
| 连续性参数 | 同一镜头内固定 seed、场景参考帧和 caption |

H3 单脸换脸模式输出结构化提示词：

| 字段 | 用途 |
|---|---|
| 目标人物 | 换谁 |
| 目标镜头/时间范围 | 处理范围 |
| 参考人脸 | 使用哪 1–4 张参考图 |
| H3 单脸提示词 | 包含 Faceswap 触发词、表情、动作、画质描述 |
| 生成参数 | 分辨率、steps、seed、参考图数量 |
| 质量风险 | 清晰度、角度、遮挡、背景漂移 |

### 6.7 生成与后处理

- H3 单脸换脸模式提交 h3-face-swap 命名工作流；
- 角色替换模式提交 h3-recast 命名工作流；
- 逐片段提交、逐片段轮询、逐片段保存；片段是最小重试单位；
- 每个片段完成后做接缝检查，再接下一个片段；
- 同一镜头所有片段完成后，按镜头拼接；所有镜头完成后，合并整片；
- 检查总时长、总帧数、音频流和接缝指标；
- 角色替换可选口型修复；
- 输出写入项目目录，登记版本；
- 失败片段保留错误、网关任务 ID 和接缝数据，支持单独重试，不重跑整个镜头。

## 7. 网关与 ComfyUI

### 7.1 实例划分

现有 8192 网关继续指向 8188 生产 H3，不改动。

新增换人网关：

- 代理端口 8194；
- 管理端 8195，仅监听 127.0.0.1；
- ComfyUI 指向 127.0.0.1:8189；
- 数据目录 `/data/huobao-h3-gateway-swap`，不放根盘；现有 8192 的 `/var/lib/huobao-h3-gateway` 位于根盘，根盘仅约 8GB 可用，作为既有风险记录；
- 独立 Token、SQLite 数据库；
- 工作流：h3-face-swap、h3-recast。

这样换人任务不会阻塞正常出片，8189 可以独立重启和调模型。

### 7.2 网关必须补的能力

当前命名工作流输入类型只有 text、number、integer、boolean、json、image，没有 video。需要：

- 新增 video 输入类型；
- 新增视频上传接口或扩展上传接口；
- 把视频写入 ComfyUI input 目录；
- 提高请求体上限和上传超时；
- 在 input_map 中映射 VHS_LoadVideo 的视频字段；
- 支持多图输入，用于场景参考帧和多人物人脸；
- 支持按工作流设置更长的上游超时；
- 保持签名 URL、任务持久化、取消和恢复能力。

### 7.3 工作流注册

h3-face-swap：

- 输入：source_video、reference_face_1 至 reference_face_4、prompt（含 Faceswap 触发词）、seed、steps；
- 输出：MP4；
- 路线参考 FaceSwap_MiniMaxH3_REF2VA：REF2VA 主模型 + Turbo LoRA + FaceSwap LoRA + CRT-Nodes + VHS；
- 不需要场景参考帧；
- 第一版单人，第二阶段扩展到多参考人脸。

h3-recast：

- 输入：source_video、scene_reference、person_1_caption 至 person_3_caption、person_1_face 至 person_3_face（口型修复可选）、seed、steps、可选口型修复；
- 输出：MP4；
- 单镜头一次任务；
- 第一版单人，第二阶段扩展到 3 人。

实现偏差（2026-11-14）：实际采用 ComfyUI 0.43 原生 H3 Ref2VA 工作流 + H3 Character Swap V1.5 + Turbo 4step，单人；输入为 source_video、scene_reference、prompt、seed。未接入 BFS Character Swap LoRA、BFSNodes；person caption/face 暂不直接进入首版工作流，prompt 由最终提示词承载角色描述。H3 Relay 已安装并完成 20 秒 PoC、2 秒 app 集成验收，见 6.2.1。

工作流保存在网关/ComfyUI，前端不提供 JSON 编辑入口。

### 7.4 8189 依赖清单

已有：REF2VA/FL2VA 主模型、Qwen3VL 文本编码器、视频/音频 VAE、KJNodes、comfy-kitchen、InsightFace buffalo_l。

H3 单脸需要补：CRT-Nodes、VideoHelperSuite、SS_FaceSwap_MiniMax_H3_REF2VA 或同路线 FaceSwap LoRA、REF2VA Turbo 8step LoRA（现有 4step 需先实测）、Faceswap 触发词。

角色替换需要补：H3-FaceRefine、VideoHelperSuite、NativeAudioLock、FearnworksNodes、BFS Character Swap LoRA、face_yolov8m。

H3 Relay 长视频（已接入）：ComfyUI-H3Relay（GPL-3.0）、SAM3.1 `sam3.1_multiplex_fp16.safetensors`、静态 ffmpeg 7.0.2 与 ffprobe wrapper。二进制和依赖库放在持久化 bind `/data/comfyui-whaletrans/ComfyUI/bin`，`docker-compose.yml` 已加 `/opt/ComfyUI/bin` 到 PATH；容器重建后已验证 Relay 2 秒任务成功。ffmpeg 使用 imageio 自带的静态二进制，ffprobe 使用带持久化依赖库的 wrapper，避免再次依赖容器内 apt 临时安装。

文本编码器优先复用现有 qwen3vl_32b_minimax_h3_nvfp4_awq，只有节点不兼容时才下载 int8 版本。

场景参考帧生成：8188 已有 qwen_image_edit_2509 模型和 Comfyui-QwenEditUtils；8189 需要复制该节点，或通过 8192 的图片工作流生成后把图片交给 8194。

## 8. AI 配置

新增服务类型 video-swap，不复用普通 video 配置。

配置字段：

| 字段 | 说明 |
|---|---|
| provider | comfyui |
| Base URL | 8194 换人网关 |
| API Key | 换人网关 Token |
| face_workflow_slug | h3-face-swap |
| character_workflow_slug | h3-recast |
| 分析文本配置 | 支持图片输入的视觉文本模型 |

| max_generation_seconds | H3 单脸默认 8 秒，H3 Recast 默认 6 秒 |
| chunk_overlap_seconds / min_chunk_seconds | 默认 1 秒重叠、最短 5 秒 |
| max_chunks | 单次运行最大片段数，超出阻断 |

全局顶部栏的“缺失配置”提示不加入 video-swap，避免不使用该功能的用户被反复提示；只在视频模块内部预检。

## 9. 状态机、进度与日志

项目状态：

draft → analyzing → ready → generating → completed / failed

运行阶段：

uploaded → probing → shot_detection → chunking → analyzing → scene_ref_ready → prompt_ready → queued → generating → chunk_done → seam_check → shot_done → merging → postprocessing → completed / failed

H3 单脸换脸跳过 scene_ref_ready；角色替换必须经过 scene_ref_ready 和人工确认。镜头内超过最大生成时长时，必须经过 chunking，片段按 chunk_done → seam_check 推进。

日志规则：

- 每次运行独立日志；
- 记录阶段、级别、消息、时间、镜头序号、片段序号；
- 记录切点、重叠帧数、接缝指标、重试次数；
- 网关任务 ID、ComfyUI 错误摘要写入日志；
- UI 轮询运行状态，显示最近日志；
- 错误时自动展开日志；
- 日志不暴露服务器路径、Token、环境变量和原始 prompt 中的敏感信息；
- 取消后未开始片段标记为取消，已提交任务调用网关取消；
- 重启后恢复轮询，已完成片段跳过，未完成片段重试或标记中断。

## 10. 预检与错误处理

阻断项：

- 未配置 video-swap；
- 网关不可达；
- 换人工作流不存在或未启用；
- ComfyUI 节点/模型缺失；
- 源视频无法解析；
- 参考人脸未检测到或质量过低；
- 角色替换模式没有确认场景参考帧；
- 磁盘空间不足；
- 视频超过绝对体积/总时长上限；
- 预计片段数超过 max_chunks，无法安全拆分。

警告项：

- 多镜头已自动拆分；
- 镜头超过最大生成时长，已自动分块；
- 源视频无音频；
- 人物过小或遮挡；
- 反光/镜面；
- cu130 警告；
- 预计耗时较长；
- 队列繁忙；
- 接缝指标低于阈值，建议重试该片段。

输出检查：

- 文件存在且可播放；
- 时长与源视频一致；
- fps、分辨率符合预期；
- 有音频流，或明确标记为静音；
- 总帧数、总时长与源视频一致，允许帧网格造成的一帧误差；
- 逐镜合并后无缺失镜头，逐片段合并后无缺失片段；
- 每个接缝都有 SSIM/颜色差/人脸相似度记录；
- 失败时保留网关任务 ID、片段编号和错误摘要。

## 13. 验收标准

H3 单脸换脸：

- 6 秒单镜头、单人，输出 MP4 带原音轨；
- 人脸相似、时序稳定、背景不明显漂移；
- H3 单脸提示词和 Faceswap 触发词可编辑、可冻结；
- 进度、日志、取消、重试可用；
- 项目关闭重开后可看到历史版本。

角色替换：

- 6 秒单镜头、单人，场景参考帧可生成、可确认、可重生成；
- 最终提示词可编辑、可冻结；
- H3 Recast 输出保留动作、场景和原声；
- 失败时显示阶段、网关任务 ID 和错误；
- 3 人版本在第二阶段验收。

多镜头：

- 2 个硬切镜头的视频能拆成 2 个镜头；
- 长镜头在镜头内继续拆片段，逐片段生成后再按镜头、整片合并；
- 合并视频时长和音轨正确；
- 单镜失败可单独重试，不需要重跑全部。

长镜头分块与连续性：

- 一个 20 秒连续镜头能按最大生成时长拆成多个片段；
- 片段之间有 1 秒重叠，拼接前精确裁掉；
- 接缝无明显跳变、颜色突变或人物身份突变；
- 原声连续，无重复、断裂或漂移；
- 总时长和总帧数与源视频一致，允许帧网格造成的一帧误差；
- 单个片段失败可单独重试，不重跑整个镜头；
- 接缝指标低于阈值时，UI 显示警告并允许调整切点或 seed。

预检：

- 缺配置、网关不可达、工作流缺失、参考人脸质量低、磁盘不足都有明确阻断提示；
- 不使用假数据冒充真实生成验收。
