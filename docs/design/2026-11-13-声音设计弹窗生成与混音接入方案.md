## 1. 背景与结论

当前有两个声音能力，但没有接在一起：

- 第四步“声音设计（场景/剧情级）”只读展示声音计划。它能列出 BGM、环境声、音效、静默四类 cue，以及 cue 覆盖的镜头范围，但没有生成、试听、下载和加入混音的动作。
- 混音工作台的“生成声音”已经接入 ComfyUI Stable Audio Open，能按场景生成环境声、场景音效、群众声、BGM，并自动建轨。但它读取的是场景/分镜字段，不读取 `sound_plans` / `sound_cues`，因此第四步设计出来的具体声音线索没有被真正执行。
- 混音素材库已经支持试听、删除、插入轨道；`episode_audio_assets` 已经能保存生成音频。缺的是把“某条声音线索”变成“某条可追踪、可试听、可放置的音频素材”。

本方案的结论：

1. 声音设计抽屉是唯一执行入口：每条 cue 一行生成/试听/下载/加入音轨，不另开一套声音生成页面。
2. 生成单位是单条 cue，不是整个声音单元，也不是整份计划；同一计划可以逐条替换、逐条重生成。
3. 生成结果写入 `episode_audio_assets`，混音素材库自动可见；加入音轨由用户手动触发，不在生成时自动改混音。
4. 时间分析优先使用合片后的实际时间轴；未合片时用分镜计划时长先生成入库。未合片时允许生成、试听、下载，但“加入音轨”要等实际时间轴可用，避免按计划时间放错位置。
5. 生成使用现有 `audio-gen` ComfyUI 服务与 Stable Audio Open 工作流，不新增音频供应商；文本模型只负责把 cue 和分镜内容编译成英文提示词，模型不可用时走确定性模板。

## 2. 目标与非目标

### 2.1 目标

- 声音设计抽屉的每条 BGM/环境声/音效 cue 都有生成、试听、下载、加入音轨动作。
- 生成前能分析该 cue 覆盖的分镜范围、实际或计划起止时间、场景地点/时间、分镜内容、台词窗口。
- 生成结果与 cue 绑定，能显示未生成、生成中、已生成、失败和重生成状态。
- 生成结果自动进入本集混音素材库，带“声音设计”来源、类别、cue 范围和描述，不需要手工导入。
- 用户点“加入音轨”后，按 cue 类别选择正确轨道和总线，在 cue 的实际时间位置创建片段；重复点击不重复建片段。
- 声音计划重跑、cue 重生成、分镜重绘后，素材与 cue 的对应关系仍然可追踪，旧素材不静默覆盖新素材。

### 2.2 非目标

- 不做自动音乐编曲、歌词生成、人声歌曲、声音克隆。
- 不做逐帧 Foley 或视频转音频同步；本期只做基于 cue 和分镜内容的音频生成。
- 不把生成音频写进 H3 视频原声，也不替用户自动混音。
- 不在生成时自动建轨或自动覆盖用户混音。
- 不引入云端音频供应商；首期只支持 ComfyUI `audio-gen`。
- 不改变现有“混音工作台 → 生成声音”的场景级入口；两套入口共享同一套生成器、素材表和混音轨道能力。

## 3. 总体数据流

1. 第四步保存声音计划，`sound_cues` 按 unit、类别、起止镜头和描述落库；保存时计算一次计划时间，写入 cue 的起止毫秒。
2. 用户打开声音设计抽屉，后端读取最新计划、cue、分镜、合片时间轴和本集音频素材，返回每条 cue 的来源、时间、台词窗口、生成状态和已生成素材。
3. 用户点某条 cue 的“生成”，前端提交 cueId、是否覆盖、可选提示词和可选配置；后端创建 `dubbing_jobs(kind='sound-plan')`，返回 jobId。
4. 后端按 cue 解析实际时间或计划时间，收集覆盖镜头的场景/时间/内容/台词，编译英文提示词，调用 ComfyUI 音频工作流生成、下载、响度归一化、入库。
5. 生成结果写入 `episode_audio_assets`，`metadataJson` 记录 planId、cueId、类别、镜头范围、起止时间、提示词、seed、workflowHash；同时更新 `sound_cues.asset_id` 和生成状态。
6. 抽屉轮询任务状态，显示进度和每条 cue 的结果；已生成的 cue 出现试听、下载、加入音轨。
7. 用户点“加入音轨”，后端校验存在实际合片时间轴，按 cue 类别找到或创建轨道，在 cue 起止时间创建片段；返回 trackId/clipId，前端刷新混音计划。
8. 混音素材库读取 `episode_audio_assets`，自动显示这条“声音设计”素材；素材标题带 cue 范围，插入时优先使用 cue 的实际起点。

## 4. 数据模型与迁移

### 4.1 sound_cues 增补

| 字段 | 用途 |
|---|---|
| `asset_id` | 当前激活的生成素材，空表示未生成或已删除 |
| `generation_status` | `idle / running / ready / failed`，用于抽屉按钮和断线恢复 |
| `generation_error` | 最近一次失败原因 |
| `generated_at` | 最近一次成功生成时间 |

`start_ms / end_ms` 已存在，本方案开始真正写入：

- 保存声音计划时先按分镜计划时长计算并写入，来源标记为计划时间。
- 生成和加入音轨时，如果已有合片时间轴，重新按实际时间计算并覆盖，来源标记为实际时间。
- 时间来源不额外建字段，写入素材 metadata 和接口返回，避免 cue 表承担过多展示语义。

### 4.2 episode_audio_assets 复用

不新建素材表，继续使用 `episode_audio_assets`：

| 字段 | 写入 |
|---|---|
| `kind` | 继续使用 `soundscape`，复用现有素材库分类与标签 |
| `engine` | `stable-audio-open` |
| `model` / `model_license` | 来自 audio-gen 配置 |
| `source_hash` | cue 级缓存键 |
| `metadata_json` | 来源 `sound-plan`、planId、cueId、unitKey、category、from/to 镜头、startMs/endMs、timeSource、prompt、negativePrompt、seconds、seed、workflowHash、normalized、degraded |

素材标题和类别由 metadata 决定，不靠文件名推断。

### 4.3 episode_audio_clips 增补

增加 `sound_cue_id` 可空列，用于：

- 判断某条 cue 是否已经加入音轨，避免重复点击生成重复片段。
- cue 重生成后，能找到旧片段并提示替换，而不是产生两条同名片段。
- 混音界面显示片段来源。

### 4.4 任务记录

复用 `dubbing_jobs`，`kind='sound-plan'`：

- `payload_json`：planId、cueIds、overwrite、configId、可选提示词覆盖。
- `result_json`：assetIds、cueIds、counts、warnings。
- `step`：面向用户的中文步骤，例如“生成 环境声 · 线索 #4–#6”。
- 同一集只允许一个 `sound-plan` 生成任务；运行中再次点击生成返回 409，抽屉禁用其他生成按钮并继续展示当前任务进度。

### 4.5 迁移策略

- Drizzle schema 与 SQLite DDL 同步增加 `sound_cues` 三个状态列和 `asset_id`，增加 `episode_audio_clips.sound_cue_id`。
- 现有 SQLite 通过幂等 `ALTER TABLE` 迁移，不改旧数据语义；旧 cue 的 `asset_id` 为空，显示未生成。
- 旧声音计划不自动生成音频；用户打开抽屉后按需生成。
- 旧 `soundscape` 素材不受影响，继续显示在素材库。

## 5. 时间与内容分析

### 5.1 时间范围

对每条 cue：

1. 通过 `from_shot_id / to_shot_id` 找到起止分镜。
2. 优先读合片时间轴的 `clips`，取起止分镜对应片段的并集。
3. 时间轴缺少某个分镜时，用分镜 `duration` 的计划累计时间补齐，并在返回中标记计划时间。
4. 完全未合片时，全部使用计划时间；生成照常，加入音轨暂不可用。
5. BGM/环境声使用 cue 全范围；音效从 cue 起点加 150 毫秒开始，时长夹取 2–10 秒，结束不超过 cue 终点；静默不生成。

### 5.2 内容收集

每条 cue 收集以下内容供提示词编译：

- cue 本身：类别、描述、强度、进入/退出方式、unit 标签、镜头范围。
- 覆盖分镜：地点、时间、氛围、画面描述、视频提示词、分镜音效字段、时长。
- 覆盖场景：场景地点、时间、最终画面提示、场景环境声（如果有）。
- 台词窗口：时间轴中落在 cue 范围内的台词，用于避免 BGM 压过对白、判断环境声是否应避开清晰人声。
- 时间来源：实际时间轴或计划时长，供界面和素材 metadata 展示。

### 5.3 提示词编译

- 使用当前激活文本模型，每次最多 6 条 cue，批量返回英文提示词和负向提示词；失败只降级该批。
- BGM：电影感纯音乐、情绪/强度、无 vocals、可循环、不要逐镜重启。
- 环境声：连续底噪、地点/时间/天气、无对白、无音乐、可循环。
- 音效：具体动作/物体/事件、Foley、短、干、无对白、无音乐。
- 静默：不生成，提示词为空，按钮禁用。
- 文本模型不可用时，复用现有声音场景编译器的词典和模板降级，标记 `degraded=true`。
- 抽屉展示“生成依据”：来源镜头、时间、场景、内容摘要和最终提示词；提示词可展开编辑，编辑值只影响本次生成，不反写声音计划。

### 5.4 时长与循环

| 类别 | 生成秒数 | 混音放置 |
|---|---|---|
| BGM | 30–45 秒 | 按 cue 范围循环，800 毫秒淡入淡出 |
| 环境声 | 30–45 秒 | 按 cue 范围循环，300 毫秒淡入淡出 |
| 音效 | 2–10 秒 | 在 cue 起点后放置，不循环，300 毫秒淡入淡出 |
| 静默 | 不生成 | 不建素材，不建轨 |

Stable Audio Open 单次约 45 秒；超过部分在混音片段上循环，接缝用淡化处理。

## 6. 生成任务编排

### 6.1 配置与并发

- 复用 `audio-gen` ComfyUI 配置；未配置时生成按钮禁用，接口返回 503 并提示先在设置页添加音频生成服务。
- 当前默认 Stable Audio Open；`audio-gen` 工作流可替换为其他 ComfyUI 音频模型。后续若按类别分模型（例如 BGM 用 ACE-Step、短音效用 TangoFlux），只需扩展类别到工作流的映射，本方案的 cue 流程不变。
- 复用现有 ComfyUI 队列串行键，避免与视频生成、混音台“生成声音”同时打爆显存。
- 单集同时只允许一个 `sound-plan` 任务；任务运行中其他生成按钮禁用，可取消。

### 6.2 单项执行

1. 校验 cue 属于当前集最新声音计划，且类别不是静默。
2. 解析时间与内容，编译提示词。
3. 计算 deterministic seed 和 `source_hash`；未开启覆盖且存在 ready 素材时直接复用。
4. 调用 ComfyUI 音频工作流，轮询、下载、ffprobe 校验、响度归一化。
5. 写入 `episode_audio_assets`，更新 `sound_cues.asset_id / generation_status / generated_at`。
6. 单条失败只标记该 cue 失败，继续下一条；全部失败任务失败。

### 6.3 批量“生成全部缺失”

- 抽屉头部提供“生成全部缺失”，把当前计划中未生成且非静默的 cue 放进同一个任务。
- 已完成或已失败的 cue 默认跳过；用户可勾选“覆盖已生成”。
- 进度按 cue 数推进，抽屉内逐条显示状态。

### 6.4 取消与重启

- 取消设置内存取消标记，best-effort 从 ComfyUI 队列删除当前 prompt。
- 已生成素材保留，不建轨。
- 服务重启后，运行中的 `sound-plan` 任务标记失败，提示重新生成；`generation_status=running` 的 cue 回落为 failed 或 idle。

### 6.5 缓存与重生成

- `source_hash` 包含 episodeId、planId、cueId、prompt、negativePrompt、seconds、seed、model、workflowHash、normalizeLoudness。
- 相同输入再次生成命中缓存，直接复用素材并更新 cue 绑定。
- “重新生成”强制 `overwrite=true`，生成新素材并切换 cue 的 active asset；旧素材保留在素材库，可手工删除。
- 声音计划重跑后 planId 变化，旧 cue 的素材不会自动命中新 cue；抽屉按新计划显示未生成，旧素材仍在素材库并标注旧计划版本。

## 7. 接口设计

### 7.1 读取声音计划

扩展现有接口 `GET /storyboards/sound-plan/:episodeId`：

| 返回字段 | 说明 |
|---|---|
| `plan` | id、version、delivery、summary、created_at |
| `cues` | 原有字段，增加 start_ms、end_ms、time_source、source（场景/分镜摘要）、dialogue_in_range |
| `cues[].asset` | 已生成素材的 id、url、duration_ms、model、created_at、status |
| `cues[].can_generate` | 非静默且 audio-gen 配置可用 |
| `cues[].can_attach` | 素材 ready 且存在实际合片时间轴 |

### 7.2 生成

`POST /episodes/:id/sound-plan/generate`

| 参数 | 说明 |
|---|---|
| `cue_ids` | 必填，单条或批量 |
| `overwrite` | 是否覆盖已生成 |
| `config_id` | 可选，默认当前 audio-gen |
| `prompts` | 可选，cueId 到提示词的覆盖 |

返回 jobId、status、total。错误语义：404 cue 不存在；409 已有运行任务；503 未配置 audio-gen。

### 7.3 状态与取消

- `GET /episodes/:id/sound-plan/status`：任务状态、进度、步骤、每条 cue 的状态和素材。
- `POST /episodes/:id/sound-plan/cancel`：取消当前任务。
- 状态接口同时用于断线恢复和抽屉轮询。

### 7.4 下载

`GET /episodes/:id/audio/assets/:assetId/download`

- 只允许本集、未删除、ready 的素材。
- 响应头使用附件下载，文件名由 cue 类别、镜头范围和素材扩展名生成，过滤路径字符。
- 不允许客户端传任意路径。

### 7.5 加入音轨

`POST /episodes/:id/sound-plan/cues/:cueId/attach`

| 参数 | 说明 |
|---|---|
| `track_id` | 可选，指定已有轨道；不传时按类别选择 |
| `replace_existing` | 可选，已存在同 cue 片段时是否替换 |

行为：

- 校验 cue 素材 ready，且存在实际合片时间轴；未合片返回 409 并提示“请先完成合片”。
- 按 cue 类别选择总线：BGM→bgm，环境声→original，音效→sfx。
- 优先复用当前集中同角色、非虚拟、非锁定的轨道；没有则创建 `origin='sound-plan'` 的生成轨。
- 在 cue 的实际起止时间创建片段；BGM/环境声素材短于 cue 范围时 `loop=true`；音效按素材时长放置。
- 如果 `sound_cue_id` 已存在片段，默认不重复创建，返回已有 trackId/clipId；`replace_existing=true` 时更新位置和素材。
- 返回 trackId、clipId、startMs、endMs，前端刷新混音计划。

## 8. 前端设计

### 8.1 声音设计抽屉

保留现有按 unit 分组、按 BGM/环境声/音效/静默分行展示的结构，在每条 cue 行增加：

- 来源行：镜头范围、实际/计划起止时间、场景地点/时间、内容摘要、范围内台词数量。
- 状态徽标：未生成、生成中、已生成、失败。
- 动作按钮：生成/重新生成、试听/停止、下载、加入音轨。
- 已生成信息：素材时长、模型、生成时间；失败时显示错误和重试。
- 可展开“生成依据”：来源分镜、编译后的英文提示词、可编辑提示词、负向提示词。

抽屉头部：

- “生成全部缺失”按钮和任务进度条。
- 取消按钮。
- 未配置 audio-gen 时显示提示，生成按钮禁用。
- 未合片时“加入音轨”禁用，提示先合片；生成、试听、下载仍可用。

交互细节：

- 试听同一时间只允许一个音频播放；再次点击停止。
- 下载使用后端附件接口，不使用裸静态路径。
- 生成中禁用该 cue 的重复生成，但允许查看/试听已生成旧素材。
- 生成完成刷新 cue 行和混音素材列表；切换计划版本时清理旧轮询。

### 8.2 混音素材库

- 生成素材自动出现在 `MixStemLibrary`，类别标签沿用“环境声/场景音效/配乐”，增加“声音设计”来源标识。
- 素材标题优先显示 cue 描述和镜头范围，例如“环境声 · 街道夜 · #4–#6”，而不是完整英文提示词。
- 素材的“插入”动作：如果 metadata 带 `source=sound-plan` 和实际 startMs，则按 cue 起点放置；其他素材保持播放头插入。
- 素材试听和删除沿用现有能力；删除素材时同步清理引用片段，避免不可播放片段。
- 生成完成后如果混音台已打开，通过同步事件或刷新素材列表让新素材可见；不自动修改现有轨道。

### 8.3 四语言文案

新增文案键覆盖：生成、重新生成、生成全部缺失、试听、停止、下载、加入音轨、未生成、生成中、已生成、失败、未配置音频服务、请先合片、计划时间、实际时间、来源分镜、生成依据、提示词、时长、模型、替换已有片段等。中英日韩四种语言同步补齐。

## 9. 混音接入细节

### 9.1 轨道选择

| cue 类别 | role | bus | 默认音量 | 轨名 |
|---|---|---|---|---|
| bgm | bgm | bgm | 1.0 | 配乐（声音设计） |
| ambience | ambience | original | 0.7 | 环境声（声音设计） |
| sfx | sfx | sfx | 0.8 | 场景音效（声音设计） |

- 轨道复用顺序：先找同 role 的 `origin='sound-plan'` 轨；没有再找同 role 的用户轨（`origin` 为空、非虚拟、非锁定）；都没有才新建 `origin='sound-plan'` 轨；用户可指定 `track_id`。
- 不复用 `origin='soundscape'` 的“生成声音”轨：那条轨由场景级生成任务整体重建，加入 cue 片段会在下次重跑时被清掉。
- 新建轨 `origin='sound-plan'`，只在没有可复用轨道时创建。
- 轨道保持 `ducking=true`，BGM 与环境声可被对白侧链压低。

### 9.2 片段放置

- BGM/环境声：startMs=实际 cue 起点，endMs=实际 cue 终点；素材短时循环。
- 音效：startMs=实际 cue 起点 + 150 毫秒，endMs=min(startMs+素材时长, cue 终点)；不足 500 毫秒跳过并提示。
- 淡入淡出：BGM 800 毫秒；环境声/音效 300 毫秒；覆盖整集起点/终点时对应淡入或淡出为 0。
- 片段名：`声音设计 · 环境声 · #4–#6`。
- 同一 cue 重复加入时更新而不是新增；cue 重新生成后，旧片段仍引用旧素材，用户可点“替换”或重新加入。

### 9.3 原声床与虚拟轨兼容

- 声音设计生成的环境声不关闭合片原声床；沿用 `origin != 'soundscape'` 的原声床判断，并扩展到 `origin != 'sound-plan'`。
- 生成 BGM 轨存在时，虚拟 BGM 不叠加；用户删除后恢复。
- 不把声音设计素材误当作分离 stem 自动建轨；`autoCreateStemTracks` 继续排除 `kind='soundscape'`。

## 11. 验收标准

1. 声音设计抽屉每条非静默 cue 都有生成/重新生成、试听、下载、加入音轨动作，静默 cue 按钮禁用。
2. 生成前能看到来源镜头、实际/计划时间、场景和内容摘要；可展开查看/编辑最终提示词。
3. 未配置 audio-gen 时生成被禁用并给出明确提示；未合片时生成、试听、下载可用，加入音轨禁用。
4. 单条生成成功后素材入库，cue 显示已生成、时长、模型；试听可播放，下载文件可播放且文件名可读。
5. 重新生成会生成新素材并切换 cue 的 active asset，旧素材保留；相同输入未覆盖时命中缓存。
6. 批量生成全部缺失能逐条推进，单条失败不中断其他 cue，取消后已生成素材保留。
7. 生成素材自动出现在混音素材库，带“声音设计”、类别和 cue 范围标签。
8. 合片后点加入音轨，按类别选择正确轨道和总线，在 cue 实际时间创建片段；BGM/环境声短素材循环，音效不循环。
9. 重复加入同一 cue 不重复建片段；replace 选项可更新旧片段。
10. 声音设计环境声不关闭原声床，生成 BGM 不叠加虚拟 BGM，分离 stem 自动建轨不受影响。
11. 合片、混音保存、试听、导出、声音计划重跑、混音台“生成声音”回归通过。
12. 四语言文案齐全；后端、前端、类型检查和真实链路验证通过。

## 12. 风险与边界

| 风险 | 影响 | 应对 |
|---|---|---|
| Stable Audio 约 45 秒 | 长 BGM/环境声需要循环，接缝可能可闻 | 循环 + 淡化；后续可接 ACE-Step 等长音频模型 |
| ComfyUI 与视频生成争用 GPU | 音频任务排队或超时 | 全局串行、进度提示、可取消 |
| 文本模型不可用 | 提示词细节丢失 | 确定性模板降级并标记 degraded |
| 提示词与画面不匹配 | 声音氛围不符 | 展示来源和提示词，可编辑后重生成 |
| 声音计划重跑 | 旧 cue 和素材失配 | 新计划新 cue；旧素材保留并标旧版本 |
| 未合片生成 | 计划时间与实际时间不一致 | 加入音轨等实际时间轴；未合片时按钮禁用 |
| BGM 压过对白 | 听感与信息受损 | 强度约束、混音 ducking、试听检查 |
| 模型许可 | 商用风险 | 素材记录 modelLicense，由用户确认 |
| 素材磁盘增长 | 占用空间 | 素材库删除；删除时清理片段 |

## 13. 本轮不做

- 不构建、不安装、不提交、不推送。
- 不新增云端音频供应商。
- 不做视频转音频 Foley。
- 不自动建轨、不自动改混音。
- 不生成静默 cue 的音频。
