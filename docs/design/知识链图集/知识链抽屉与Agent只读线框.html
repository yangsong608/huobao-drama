设计说明（落到实现时的硬约束）

  1. 一套界面，不新增页面。入口是 .prod-section-bar 里一个新按钮，面板是 .task-drawer-overlay > aside.task-drawer，宽度取 min(720px,100%)（与声音计划抽屉一致）；不新建路由、不新建播放器、不做第二个知识浏览页。
  2. 与现有抽屉分工明确。步骤追踪回答「跑到哪一步、失败在哪」；知识链回答「读了什么、谁给的、能不能复现」；声音计划回答「声音怎么排 + 单条线索生成/试听/下载/加入音轨」（后者由另一份声音设计稿负责，本设计不重复实现）。三者共用抽屉骨架与头部/指标/正文三段结构，互不复制内容。
  3. 样例数据可核验。文档 id、stages、agents 分配全部取自设计文档 11.1 迁移表的真实 8 份知识（分镜包只用其中 6 份短剧文档）；不虚构「场景契约」「钩子结构」等文档——场景契约是数据结构，不是知识文档。计数自洽：去重 6 份 = 预拆 2 + 修补 3 + 校验 3 + 声音 2 的去重结果。
  4. 确定性步骤必须视觉可辨。逐镜校验与声音校验用蓝色左边与「确定性 · 无 LLM」标签，文案写「读取规则口径」，绝不写成「注入提示词」；也不出现任何「校验 Agent」入口，已下线的批量动作检验不复活。
  5. 决策七字段全展示。decision_key / stage / producer_step / contract_version / payload / hash / created_at 一列不少，payload 折叠展开；契约版本显示代码常量 2026-11-13.1，不允许前端另写一份。
  6. 快照与发布分离。抽屉永远显示任务快照值；发现当前发布版本更新时只给差异提示与「用新版本重新拆分」，绝不静默切换运行中的知识。
  7. 回写操作不在抽屉里做。「回滚知识版本 / 回滚方案版本」跳设置页对应版本历史；抽屉内只有复现、定位镜头、确认保留 warning、复制诊断四类动作，远程只读时全部置灰。
  8. Agent 知识只读要删干净。移除取消分配、分配、删除、保存、正文 textarea、必读勾选与创建入口；卡片改为 frontmatter 只读栅格 + 查看正文 + 在 Obsidian 中打开。写接口返回 409 时前端不再出现可点的写按钮。
  9. Agent 列表统一事实源。由 GET /agent/meta 渲染（含 legacy / critical），前端不再硬编码；storyboard_breaker 不显示，storyboard_auditor 标「旧·只读」，关键知识提示改用统一 ConfirmDialog，不再用 window.confirm。
