设计说明

  1. 新增顶级页签 knowledge：插在 rules（流程规则）与 breakdown（分镜拆分）之间，同步加入 SETTINGS_TABS 白名单与 GUEST_HIDDEN_TABS（手机接力访客不可见，与 ai/storage/mcp/agents 一致）。知识不再只藏在 Agent 配置里。
  2. 复用控件：外壳沿用 settings-nav（220px）+ settings-scroll；子页签沿用 agent-pane-tabs-nav 分段样式，不新造页签组件、不做无关重构（D18：本轮只新增一个轻量 diff 组件）。
  3. 只读边界：全页无「保存正文 / 删除 / 分配 Agent / 必读勾选」；旧写接口返回 409 时，界面只展示只读说明，不弹可编辑表单。写 Vault 只有初始化导出与导出索引两个按钮，且都标注「不覆盖已有文件」。
  4. 冲突可定位、按文档阻断：冲突表给出文件相对路径 + 行号 + 问题 + 怎么办，并提供「复制清单」，方便粘进 Obsidian 修改；冲突只让对应文档不发布，其余照常发布，摘要写清「发布 N · 冲突未发布 M」（D20），「同步并发布」不因冲突置灰。
  5. 能力门禁：沿用 FFmpeg 能力卡的置灰范式（tag + 说明 + btn[disabled]），新增 503 RESEARCH_UNAVAILABLE 的界面处理：保留输入、指明缺哪项能力、给出启用方式，不静默降级。
  6. 候选与方案分开：研究候选在本页处理（未写入：预览草稿 / 写入收件箱 / 拒绝；已写入：在 Obsidian 中打开 / 重新写入 / 拒绝）；拆分与校验方案的批准在「分镜拆分 → 方案候选」，本页只给跳转，不做第二套审批。
  7. 分类目录只读：分类树、注册表、MOC 预览都只读；未注册组合与未分类候选以徽标提示，点击跳到冲突清单。小说域明确标注「本期不接入分镜运行时」。
  8. 不新增旧入口：不出现 storyboard_breaker，不恢复已下线的批量动作检验页签与文案。
