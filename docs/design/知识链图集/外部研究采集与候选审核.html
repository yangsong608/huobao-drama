Flowchart · External Research & Review

外部研究采集：能力门禁 → 收件箱候选 → 人工审核

能力分层：L1 公开文章正文抽取 / GitHub API 与 raw / 公开字幕，无需新增运行时依赖，全平台；L2 知乎与小红书授权会话读取，需新增桌面专用采集窗口与独立 session，仅桌面；L3 无字幕视频本地 ASR 与关键帧 OCR，需引入 sidecar 与模型（需批准）。 采集边界：不绕过登录、验证码、付费墙与风控，不保存账号密码，不大规模爬取，只做分析与短引用，保留原文链接与时间戳。 证据与治理：D 级（知乎回答 / 小红书笔记 / 短视频）只作灵感与假设，不单独形成硬规则；外部来源默认 90 天复查，平台规则与模型能力类 30 天；每次抓取落一条 research_jobs 作为版本事实源。 小说域：分类注册表在 P0 一次建全（含小说 9 类），小说候选同样走收件箱与人工审核，本期不接入短剧运行时。
