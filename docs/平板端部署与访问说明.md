# 平板端部署与访问说明

本文说明平板浏览器访问火宝短剧时的部署拓扑、HTTPS 反向代理要求、可安装（PWA）条件与验收清单。
文中域名、地址、证书路径一律使用占位符，请在实际环境中替换，不要把真实地址与凭据写进仓库。

## 一、拓扑：平板 → HTTPS 反向代理 → 同源应用

```
平板浏览器 ──HTTPS──> 反向代理（证书 + 访问控制） ──内网──> 火宝短剧前端 + 后端 API
```

- 页面、`/api`、`/static` 必须来自**同一个来源**（同一协议 + 同一主机 + 同一端口）。
- 禁止把前端与后端拆成两个域名分别访问：PWA 安装、Service Worker 作用域、`/api` 相对路径与媒体地址都按同源设计。
- 前端构建产物由反向代理静态托管，`/api` 与 `/static` 反代到后端服务（默认端口 `5679`）。

## 二、根路径部署

- 只支持部署在站点根路径 `/`。`manifest.webmanifest` 的 `start_url`、`scope`、Service Worker 作用域与 `/api` 基址都固定为根路径。
- 反向代理**不得添加子路径前缀**（例如不要发布到 `/app/` 或 `/huobao/`），否则清单作用域、Service Worker 注册与静态资源路径全部失效。
- 后端 CORS 白名单只包含 `localhost:3013` 与 `localhost:5679`（开发用途）。平板访问不能依赖 CORS，必须通过同源反代进入。
- 前端开发端口 `3013`、后端端口 `5679` 仅用于本机开发，不作为平板入口。

## 三、HTTPS 与访问控制

- PWA 安装与 Service Worker 注册都要求**安全上下文**：必须是 `HTTPS`（或浏览器认定的 localhost）。纯 HTTP 的内网地址不满足条件，安装入口不会出现。
- 证书由反向代理负责（可用企业 CA 或公网证书）。平板需信任签发该证书的根证书。
- 应用自身没有登录体系，访问控制全部由反向代理承担：请使用反代自带的基础认证、IP 允许列表或企业统一身份网关。
- **禁止把 5679 直接暴露到公网**，也禁止为了让平板直连而关闭访问控制。

> 示例：入口写作 `https://<平板入口域名>/`，证书路径写作 `</path/to/fullchain.pem>` 与 `</path/to/privkey.pem>`。

## 四、反向代理要求

- 透传 `Range` 请求头并原样返回 `206 Partial Content`：视频/音频拖动与断点续播依赖该语义，反代不得把 Range 请求改写成整段下载。
- 小说 SSE 接口 `/api/v1/novel-jobs/*/stream` 必须关闭响应缓冲（关闭 proxy buffering / gzip 流式压缩），否则增量文本会被攒到最后一次性下发。
- 请求体上限不低于 `64MB`（项目文件、参考图与音频导入）。
- 静态资源启用 gzip 或 brotli 压缩；`/api` 的流式响应本身不要再压缩。
- 长连接超时（proxy_read_timeout 等）需大于 SSE 的最长生成时间，避免中途被断开。

## 五、MIME 与缓存头

| 路径 | 要求 |
| --- | --- |
| `/manifest.webmanifest` | 以 `application/manifest+json` 返回；短缓存即可 |
| `/sw.js` | `Cache-Control: no-cache`（或极短缓存 + `must-revalidate`），确保更新能被发现 |
| `/index.html`、导航路由 | 不得长缓存，必须每次回源校验 |
| `/_nuxt/*` | 文件名带内容哈希，可设置长期 immutable 缓存 |
| `/icons/*.png`、`/favicon.png` | 可中等缓存；更新图标时改名或加版本参数 |

- Service Worker 注册使用 `updateViaCache: 'none'`，浏览器不会用 HTTP 缓存里的 `sw.js` 判定更新，但反代仍应给 `sw.js` 设置 `no-cache` 以免中间层缓存旧脚本。

## 六、公网媒体与 `PUBLIC_BASE_URL`

应用在生成参考图、音色试听等对外可访问媒体地址时会读取环境变量 `PUBLIC_BASE_URL`：请在部署环境的变量配置中把它设为平板可访问的站点根地址（含协议的主机名），不要提交到仓库，也不要写进本文档。

两种验收口径，二选一并在交付记录中注明：

1. 推荐：`PUBLIC_BASE_URL` 指向同源反代入口，`/static` 只读资源在访问控制下放行（例如只允许 GET/HEAD，且仍受反代认证保护）。
2. 兜底：继续拦截 `/static`，接受公网媒体不可直接打开，「生成验收」环节由内网完成。

无论哪种口径，**禁止为了验收关闭访问控制**。

## 七、安装与更新

- iPad / iPhone Safari：打开站点 → 点击「分享」→「添加到主屏幕」。iOS 不派发安装事件，页面头部的安装入口会展示这条说明。
- Android Chrome / Edge：头部出现「安装」按钮，点击后按系统面板确认；也可在浏览器菜单中选择「安装应用 / 添加到主屏幕」。
- 桌面 Chromium 浏览器在满足安装条件时同样显示安装入口；不满足条件时不显示按钮，不占位。
- 卸载：从主屏幕长按图标删除；或在浏览器站点设置中清除该站点的数据。
- 清缓存：清除站点数据会同时删除 Cache Storage 与 Service Worker，下次打开会重新安装外壳。
- 更新：新版本部署后，已打开的页面会提示「新版本已就绪」。**只提示、不强制刷新**，保存当前工作后自行重新打开即可；未关闭全部页面时旧版本继续可用。

> 发布新版本时把 `frontend/app/public/sw.js` 的 `PWA_SHELL_CACHE` 版本号递增（如 `huobao-shell-v2`），激活时会清理旧外壳缓存，避免旧哈希资源长期占用平板存储。

## 八、验收清单

- [ ] `manifest.webmanifest` 响应头为 `application/manifest+json`，`id`/`start_url`/`scope` 均为 `/`。
- [ ] 平板通过 `HTTPS` 同源入口打开，头部出现安装入口；安装后以独立窗口启动，无浏览器地址栏。
- [ ] 打开 `chrome://serviceworker-internals` 或开发者工具 Application 面板，确认 Service Worker 已激活。
- [ ] **Cache Storage** 中只有 `huobao-shell-v1` 等外壳缓存，**不含 `/api`、`/static` 条目**。
- [ ] 视频拖动进度条，Network 面板出现状态码 `206` 的分段响应。
- [ ] 小说生成页在弱网/长任务下仍能看到 SSE 增量输出（不是一次性出现）。
- [ ] 断网后约数秒内出现离线提示；恢复网络后提示自动消失，接口自动恢复。
- [ ] Electron 桌面端打开开发者工具，确认没有注册 Service Worker、没有安装入口与离线提示。
- [ ] 反向代理层确认 `5679` 未直接对公网开放。

## 九、禁止事项

- 禁止把后端 `5679` 端口直接暴露公网，或让平板绕过反代直连后端。
- 禁止关闭反向代理的访问控制来换取验收通过。
- 禁止把应用挂到子路径（如 `/app/`）发布。
- 禁止在仓库、文档、截图中写入真实域名、内网 IP、证书私钥、密码、Token 或 `PUBLIC_BASE_URL` 的实际取值。
- 禁止用 HTTP 明文入口验收安装能力（非安全上下文下无法安装）。

## 十、部署前置验收

部署后、标记 PWA 验收通过之前，逐项核对下表。任一项不满足即按阻塞记录，不以结构测试、浏览器仿真或「之前能用」代替运行时实测。本文只写检查口径，不写任何真实地址。

| 检查项 | 验收要求 | 记录方式 |
| --- | --- | --- |
| 应用根路径 | 入口部署在站点根路径 `/`；`/api`、`/static`、`manifest.webmanifest`、`sw.js` 与页面同源可直达，反代不得添加子路径前缀 | 用 `curl -I` 记录入口与清单状态码 |
| 清单 MIME | `manifest.webmanifest` 响应头为 `application/manifest+json` | 记录响应头原文（不含域名） |
| `sw.js` 不缓存 | `Cache-Control: no-cache`（或 `max-age=0, must-revalidate`），不得 immutable | 记录响应头 |
| `index.html` 不缓存 | `index.html` 与导航路由不得长缓存，每次回源校验 | 记录响应头 |
| `/_nuxt/` 长缓存 | 文件名带内容哈希的资源为 `public, max-age=31536000, immutable` | 抽一个哈希资源记录响应头 |
| Range / 206 | 透传 `Range` 请求头；命中分段时返回 `206 Partial Content` 与正确的 `Content-Range`，不得改写为整段下载 | 视频拖动时 Network 面板截图 |
| SSE 不缓冲 | `/api/v1/novel-jobs/*/stream` 关闭代理缓冲与流式压缩，增量文本逐段下发 | 弱网/长任务下看到持续增量 |
| 访问控制 | 反代认证、IP 允许列表或企业身份网关保持开启，不得为验收临时关闭 | 记录开启状态与策略名称（不含地址） |
| 5679 不暴露公网 | 后端 `5679` 只允许本机或受信内网访问，公网与平板直连均不可达 | 反代与防火墙侧各记录一次 |
| HTTPS | 平板入口为安全上下文，证书由反代提供且已被平板信任 | 记录证书链验证结果 |

- 本文档只能核对**静态口径**；运行时响应头、证书与代理配置属于部署环境证据，没有部署环境时一律标记「阻塞（未部署）」。
- 任一项「未验证」不得推导为「满足」。

## 十一、生成前置验收

「生成前置」与部署前置分开记录，避免出现「PWA 能安装、生成不可用」。`PUBLIC_BASE_URL` 只有三种状态，部署前先确认属于哪一种并写进交付记录：

1. **未配置**：仅限本机开发使用。平板入口不生成对外媒体地址，参考音频/参考图相关能力不可用，真机生成验收标记阻塞。
2. **同源反代**（推荐）：取值为平板入口的站点根地址（含协议，不含子路径），`/static` 在访问控制下只读放行（例如只允许 `GET`/`HEAD`，仍受反代认证保护）。
3. **外部地址**：指向独立的外部媒体主机。需确认平板可访问、证书可信、访问控制不被绕过，并记录该主机与站点不同源带来的额外风险。

其他检查项：

- `/static` 上游可达：反代到后端 `5679` 的 `/static/*` 路径可读，`Accept-Ranges` 与 `206` 语义正常。
- 访问控制不得关闭：任何一态下都不得为验收关闭反代认证；`PUBLIC_BASE_URL` 的实际取值只存在于部署环境变量，不写进仓库与本文档。
- 真实生成：使用本地参考媒体时必须完成一次真实生成并成功，作为唯一有效证据；失败即「阻塞」，不得用云端代测、仅上传成功或结构测试冒充。
- 无运行实例、无模型会话或模型额度不足时，把「真实生成」标注「阻塞（无运行实例/模型会话）」，不以改配置绕过。

## 十二、性能预算与首屏预取审计

### 12.1 包体预算（gzip）

| 指标 | P0 基线 | P10 预算 |
| --- | --- | --- |
| 入口脚本 | 310KB | 不超过 330KB |
| 最大单文件 / 最大路由块 | 380KB | 不超过 420KB |
| `_nuxt` 总量 | 3.8MB | 不超过基线的 105% |

- 口径：入口脚本 gzip 310,042 字节，最大单文件 gzip 380,499 字节，`_nuxt` 总量 3.8MB（均为 P0 记录值）。
- 改造后必须重新构建并复测入口脚本 gzip、最大路由块 gzip、入口 CSS gzip 与 `_nuxt` 总量；**构建未获批准前，改造后的包体与首屏指标一律标记「待构建复测」**，不得用 P0 数字冒充改造后结果。
- 首屏指标：本地 HTTPS 下平板仿真 LCP 不高于 2.5 秒、布局偏移不高于 0.1；网络受限时记录实测条件与数值，不伪造达标。

### 12.2 首屏预取审计

- `index.html` 中的 `modulepreload` 恰好 1 条，且 `href` 指向入口脚本；其余按 Nuxt 默认 `prefetch` 输出。
- `prefetch` 的脚本清单不得包含剪辑（edit）、混音（mix）、视频制作（episode）等重路由块字样；若默认预取与首屏带宽竞争，改为按需或空闲时预取，并以 Network 面板实测为准。
- 对照 P0 记录的 25 条预取链接清单，确认没有新增首屏重路由预取；新增一条即视为回归。
- 现有 `frontend/.output/public/index.html` 是 P0 构建产物（改造前），只能用于核对预取结构；改造后的首屏预取与包体复测状态为「待构建复测」。

## 十四、真机验收与已知限制

### 14.1 真机范围

- 至少一台 iPad Safari 与一台安卓 Chrome 平板。真机需覆盖：安装到主屏幕、独立窗口启动、离线壳、播放与全屏行为、上传、下载或分享、音频首次播放解锁、返回手势关闭覆盖层。
- 没有设备时，布局与结构可依据结构测试验收；安装、离线、分享、上传、音频解锁、返回手势一律标记「阻塞（无设备）」，不得用桌面仿真或 DevTools 设备模式代替。
- 手机宽度（小于 744）不承诺工作台可用：只保证无横向溢出、弹窗可关闭、可返回。

### 14.2 已知限制

- **软键盘**：iPad Safari 弹出软键盘时可视高度变化与 `--app-vvh` 同步存在时序差，底部操作栏可能短暂被遮挡，需真机确认；安卓 Chrome 的 `resize` 行为同样以真机为准。
- **安全区**：横屏下左右安全区（刘海/圆角）由 `env(safe-area-inset-*)` 处理；非全面屏设备取 0，不影响布局；带保护壳或贴膜时可视区域可能小于安全区计算值。
- **媒体控件**：焦点陷阱已把 `audio[controls]`/`video[controls]` 纳入可聚焦集合；原生控件内部的 Tab 顺序由浏览器决定，真机表现待验证。
- **返回手势**：覆盖层打开时，安卓返回键与 iPad 返回手势先关闭覆盖层；开启历史记录的覆盖层层层关闭。设置页数据迁移中按两次返回仍可能离开设置页（迁移由后端继续），属已知限制，不阻塞验收。
- **视频编码**：Safari 对 HEVC/MOV 的支持依赖系统版本；视频上传上限为 50MB，超出时页面提示先裁剪或分段。HEIC/HEIF 会被前端直接拒绝，并提示改用 JPEG/PNG/WebP（或先在相册导出为 JPEG）。
- **页面隐藏轮询**：关键轮询在页面隐藏时停止、恢复可见立即补一次；`usePwa` 的离线健康复测为退避式健康检查，不在此列，页面隐藏期间仍按原节奏运行。
- **结构测试边界**：结构测试只证明代码结构与开关存在，不证明真实渲染、真机能力与业务结果；验收结论必须以本文第十至十四节的运行时证据为准。
