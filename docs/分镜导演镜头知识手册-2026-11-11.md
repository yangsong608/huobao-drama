# 分镜、导演与镜头知识手册

日期：2026-11-11
适用范围：短剧/影视项目的分镜拆分、导演设计、AI 视频提示词编写与分镜审核
说明：本文综合影视分镜与短剧行业公开资料，并结合本项目当前管线整理；不是学术标准，落地时以项目画幅、模型能力和审核策略为准。

## 一、一句话结论

**分镜不是“画面描述”，而是一份可执行的拍摄/生成合同：它必须同时说清“观众看什么、为什么看、动作怎么发生、镜头怎么接、声音怎么听、模型怎么生成”。**

只写“人物很愤怒”“气氛紧张”“镜头缓慢推进”不算分镜；能让导演、摄影、剪辑、配音和视频模型各自知道自己该做什么，才算分镜。

## 二、先建立五个基本概念

| 概念 | 定义 | 在短剧里的作用 |
|---|---|---|
| 镜头 Shot | 一次连续拍摄或一次连续生成的最小单位 | 决定观众此刻看到什么 |
| 场景 Scene | 同一时间、同一地点发生的一段戏 | 决定空间、光线、人物关系 |
| 段落 Sequence | 一组镜头完成一个叙事单元 | 决定节奏、钩子、信息释放 |
| 节拍 Beat | 一次信息、情绪或关系变化 | 拆段的最小依据 |
| 分镜 Storyboard | 用文字或图把镜头顺序、内容、时长、声音、衔接写清楚 | 让全链路对同一画面有共同预期 |

导演思维的核心不是“画面好不好看”，而是连续问三个问题：

1. **观众此刻应该看谁、看什么？**
2. **这个镜头让观众知道了什么，或感受到了什么变化？**
3. **下一个镜头为什么能接上？**

三个问题有一个答不出来，这个镜头通常就是无效镜头。

## 三、一个完整分镜必须回答的九个问题

1. **谁**：角色是谁、什么年龄状态、什么关系、什么情绪。
2. **在哪**：哪个场景、什么时间、什么天气、空间布局如何。
3. **做什么**：主动作是什么，动作的开始状态和结束状态是什么。
4. **为什么**：这个镜头承担什么戏剧功能，删掉会损失什么。
5. **怎么拍**：景别、角度、机位高度、焦段/透视、构图、光线。
6. **多长**：镜头时长、内部节拍、是否需要停顿或呼吸。
7. **怎么接**：入点、出点、动作匹配、视线匹配、屏幕方向、轴线。
8. **怎么听**：对白、旁白、内心独白、环境声、音效、BGM、静默。
9. **怎么生成/验收**：参考图、首尾帧、负面约束、seed、比例、分辨率、音频模式。

## 四、分镜字段清单

下面是“一个分镜应该包含什么”的完整清单。不是每个项目都要全部填满，但**关键字段缺失会让下游只能猜**。

### 1. 基础信息

| 字段 | 说明 |
|---|---|
| 集数/场次/镜号 | 唯一标识，便于剪辑、配音、审核和回滚 |
| 剧本来源 | 对应剧本场次、段落或台词行，便于核对覆盖 |
| 时长 | 秒数，精确到 0.1 秒；不要只写“短镜头” |
| 版本/状态 | 草稿、已审核、已生成、需重做 |
| 画幅/分辨率 | 16:9、9:16、1:1 等；与项目设置一致 |

### 2. 叙事功能

| 字段 | 说明 |
|---|---|
| 戏剧功能 | 交代、推进、阻碍、反转、揭示、情绪释放、钩子 |
| 节拍 | 这场戏的第几个信息/情绪变化 |
| 信息变化 | 观众看完这个镜头，新增了什么事实或判断 |
| 情绪曲线 | 紧张、松弛、怀疑、愤怒、心疼、期待等 |
| 钩子 | 悬念、反转、危险、信息差；短剧段尾尤其重要 |

### 3. 空间与调度

| 字段 | 说明 |
|---|---|
| 场景 ID/地点/时间 | 必须引用资产库中的场景，不要临时造场景名 |
| 空间布局 | 门、窗、桌、柜台、出入口、前后景关系 |
| 人物站位 | 谁在左、谁在右、谁靠近镜头、谁在背景 |
| 前中后景 | 画面层次；避免人物贴在背景上 |
| 轴线侧 | 对话双方的关系线，摄影机在哪一侧 |
| 光线/天气 | 光源方向、色温、明暗、晨昏、雨雪、烟尘 |

### 4. 人物状态

| 字段 | 说明 |
|---|---|
| 角色 ID/全名 | 同一角色只能有一个规范名，别名要能归一 |
| 年龄状态 | 幼年、少年、成年、老年；同一角色不同年龄要有独立参考 |
| 服装/发型/伤痕/配饰 | 本镜的固定状态；跨镜变化必须给出原因 |
| 表情 | 眼神、眉、嘴、面部肌肉；不要只写“很生气” |
| 视线 | 看谁、看哪里、看画内还是画外 |
| 身体重心/姿态 | 站、坐、跪、倚、前倾、后退、握拳、发抖 |
| 动作起止 | 从什么状态开始，到什么状态结束；动作是否完成 |
| 道具交互 | 拿、放、推、递、砸、藏；用哪只手；道具在哪 |

### 5. 镜头语言

| 字段 | 说明 |
|---|---|
| 景别 | 远景、全景、中景、近景、特写、大特写 |
| 角度 | 平视、俯视、仰视、侧面、背面、过肩、荷兰角 |
| 机位高度 | 高机位、齐眼、低机位、地面机位 |
| 焦段/透视 | 广角、标准、长焦；广角强调空间，长焦压缩空间 |
| 构图 | 三分、中心、对称、前景遮挡、框中框、留白、视线空间 |
| 运镜 | 固定、推、拉、摇、移、跟、升降、环绕、手持 |
| 运动速度/方向 | 慢推、快推、左摇、右移、跟随、拉远 |
| 对焦/景深 | 谁清晰、谁虚化；焦点是否转移 |
| 镜头动机 | 为什么动；推是进入情绪，拉是揭示/抽离，摇移是跟随视线 |

**一个子镜头只用一个主动运镜。** 又要推、又要摇、又要环绕，模型和观众都会失去重点。

### 6. 对白与旁白

| 字段 | 说明 |
|---|---|
| 说话人 | 角色全名；画外音、电话、广播要标清 |
| 文本 | 逐字台词，含标点、语气词、停顿 |
| 类型 | 对白、画外旁白、内心独白、电话/广播、群声 |
| 情绪 | 愤怒、克制、嘲讽、恳求、试探、哽咽 |
| 语速/停顿 | 快、慢、停顿位置、重音 |
| 口型 | 是否需要同步口型；旁白和内心独白不应有口型 |
| 字幕 | 是否上字幕；字幕与语音是否一致 |
| 容量 | 按 4 字/秒估算，留 1 秒呼吸；长句拆段不删字 |

**必须区分三种“说”：**

- **对白**：角色在画内开口，有口型，通常给近景/特写。
- **画外旁白**：叙述者不在画面内，不应有口型，画面可以继续演。
- **内心独白**：角色心里想，不应开口；如果写成“低声说”，就变成了对白。

### 7. 连续性

| 字段 | 说明 |
|---|---|
| 与前镜关系 | 接动作、接视线、接声音、接道具、接时间 |
| 入点/出点 | 上一镜结束在哪一帧状态，本镜从哪一状态开始 |
| 动作匹配 | 开门、拿杯、转身等动作跨镜是否连贯 |
| 视线匹配 | 角色看画外，下一镜是否给出他看到的东西 |
| 屏幕方向 | 人物从左到右走，切镜后不能无故变成右到左 |
| 180° 轴线 | 对话双方的关系线不能无动机越过 |
| 30° 规则 | 同一主体相邻镜头，角度/景别要有明显差异，避免跳切 |
| 道具连续性 | 杯子在哪只手、刀口朝哪、血迹/水渍是否连续 |
| 服装连续性 | 同一场戏的服装、发型、配饰不能无故变化 |
| 时间连续性 | 清晨/正午/黄昏/夜晚；光线和影子方向要一致 |

### 8. 光影与色彩

| 字段 | 说明 |
|---|---|
| 主光源 | 窗、门、灯、火光、月光、天光 |
| 方向 | 顺光、侧光、逆光、侧逆光、顶光、底光 |
| 色温 | 暖金、冷蓝、中性；晨光/午光/暮色 |
| 对比 | 高对比、低对比、柔光、硬光 |
| 色调 | 低饱和、暖色、冷色、单色 |
| 氛围 | 烟、雾、尘、蒸汽、雨、雪、风 |
| 光影变化 | 本镜内是否有光线变化；变化要有动机 |

### 9. 声音

| 字段 | 说明 |
|---|---|
| 环境声 | 街道、厨房、饭馆、风声、雨声、人群 |
| 音效 | 拍桌、碗碎、脚步、门响、油煎、刀刻 |
| BGM | 情绪、乐器、节奏、进点/出点；通常按段落或场景设计 |
| 静默 | 静默也是声音设计；静默前要有声音对比 |
| 声音桥 | 下一场的声音先进入，或上一场的声音延续 |
| 音色 | 角色音色、旁白音色、年龄感、口音 |
| 混音 | 对白优先、环境铺底、BGM 不压台词 |

### 10. 转场

| 字段 | 说明 |
|---|---|
| 转场类型 | cut、fade、dissolve、wipe、match cut、声音转场 |
| 转场动机 | 时间跳跃、空间转换、情绪转折、动作匹配 |
| 转场时长 | 0 帧硬切、几帧叠化、黑场停留 |
| 转场前后的画面 | 上一镜尾帧与下一镜首帧是否可接 |
| 是否允许空镜 | 空镜必须承担呼吸、时间、空间或情绪功能 |

### 11. AI 视频生成专用字段

| 字段 | 说明 |
|---|---|
| 参考图 | 角色多角度、场景、关键道具；必须与资产库一致 |
| 首帧/尾帧 | 需要精确衔接时提供；首尾帧优先级高于文字描述 |
| 身份锁定 | 脸型、发型、服装、体型、年龄；不能只写“同一个人” |
| 场景锁定 | 同一地点只用一个场景资产；时间变化用光线，不新建场景 |
| 道具锁定 | 关键道具必须有参考图；名称、描述、图片三者一致 |
| 动作强度 | 小、中、大；动作越大，越容易变形 |
| 负面约束 | 不换脸、不换装、不加人、不生成字幕/文字、不风格漂移 |
| seed | 需要跨镜稳定时固定；换 seed 会带来风格/细节漂移 |
| 比例/分辨率 | 与项目一致；不要用竖屏提示词生成横屏项目 |
| 音频模式 | 原生音频、环境声、静音、后期配音；要明确 |

### 12. 验收字段

| 字段 | 说明 |
|---|---|
| 可生成 | 模型能否理解；动作是否超载；参考图是否齐全 |
| 可剪辑 | 入点/出点是否干净；是否有足够反应镜头/插入镜头 |
| 可配音 | 台词长度、口型、停顿是否合理 |
| 可审核 | 是否有明确的对错标准，而不是“感觉不对” |
| 可回滚 | 修改是否可追溯；关键资产是否被锁定 |

## 五、镜头语言速查

### 1. 景别

| 景别 | 画面范围 | 主要功能 | 短剧使用提示 |
|---|---|---|---|
| 远景 | 环境为主，人物很小 | 交代空间、时间、人物渺小 | 不要连续使用；横屏更需要 |
| 全景 | 人物全身+环境 | 交代人物关系、动作完整性 | 开场、换场、群像 |
| 中景 | 腰部以上 | 叙事主力，兼顾动作与表情 | 对话、走位、关系变化 |
| 近景 | 胸部以上 | 情绪、反应、台词 | 短剧主力，但不要连续怼脸 |
| 特写 | 面部/手/道具 | 放大情绪、强调信息 | 关键台词、关键道具 |
| 大特写 | 眼睛/手指/刀口/屏幕 | 强情绪、强信息 | 短促使用，别滥用 |

### 2. 角度

| 角度 | 心理效果 | 常见用途 |
|---|---|---|
| 平视 | 中性、平等、客观 | 日常对话、纪实感 |
| 俯视 | 压制、渺小、被审视 | 权力关系、失败、孤独 |
| 仰视 | 压迫、崇高、威胁 | 反派、英雄、权威 |
| 侧面 | 观察、距离、侧写 | 对话、犹豫、隐藏情绪 |
| 背面 | 神秘、跟随、代入 | 开场、走向未知 |
| 过肩 | 对话关系、空间连接 | 正反打、争执 |
| 荷兰角 | 失衡、不安、疯狂 | 强情绪、惊悚，慎用 |

### 3. 运镜

| 运镜 | 动机 | 风险 |
|---|---|---|
| 固定 | 让表演停留、让观众凝视 | 长时间固定容易呆板 |
| 推 | 进入情绪、强调细节 | 推太快会晕；推错对象会误导 |
| 拉 | 揭示环境、抽离、孤独 | 拉太慢会拖；拉太远会丢人物 |
| 摇 | 跟随视线、展示空间 | 摇太快会糊；无动机摇镜很假 |
| 移 | 跟随人物、制造动感 | 移动路径要清楚 |
| 跟 | 代入、连续动作 | 背景变化大，模型容易崩 |
| 升降 | 改变权力关系、揭示空间 | 成本高，AI 难稳 |
| 环绕 | 强调人物/关系 | 极易变形，短剧慎用 |
| 手持 | 真实、紧张、临场 | 过度使用会廉价 |

### 4. 构图

- **三分法**：主体放在三分线/交点，适合大多数画面。
- **中心构图**：强调人物、压迫感、仪式感；短剧常用。
- **对称构图**：秩序、权威、对峙。
- **前景遮挡**：增加空间层次，制造窥视感。
- **框中框**：门、窗、镜子，强调被困/观察。
- **留白**：给视线、动作、情绪留空间；不要让人物贴边。
- **视线空间**：人物看左，左边留空间；看右，右边留空间。

### 5. 连续性与剪辑语法

| 语法 | 作用 | 一句话记忆 |
|---|---|---|
| 建立镜头 | 交代空间与人物关系 | 先让观众知道“这是哪” |
| 正反打 | 对话双方交替 | 你说完，我看你；我说完，你看我 |
| 过肩 | 连接对话双方 | 肩膀是空间的桥 |
| 反应镜头 | 让观众看到“听完之后” | 台词重要，反应更重要 |
| 插入镜头 | 强调道具/细节/信息 | 让观众看见关键证据 |
| 切出镜头 | 缓解跳切、补空间 | 用环境/物件缓冲 |
| 动作匹配 | 动作跨镜连续 | 开门开到一半，下一镜接着开 |
| 视线匹配 | 看→所见 | 他看画外，下一镜给他看的东西 |
| 180° 规则 | 保持左右关系 | 摄影机不越过对话双方的轴线 |
| 30° 规则 | 避免跳切 | 同一主体相邻镜头，角度/景别要有明显差异 |
| 蒙太奇 | 用镜头组压缩时间/信息 | 一组镜头讲完一个过程 |

### 6. 节奏

- **短剧钩子**：前 3 秒给冲突、危险、信息差或强情绪；不要用空镜、走路、风景开场。
- **段落长度**：常见 6–15 秒；本项目方案多用 8–15 秒或 6–12 秒。
- **平均镜头长度**：竖屏短剧常见 2–4 秒一切；横屏叙事可以更长，但对话戏也需要反应镜头和景别变化。
- **信息变化**：每个段落至少一次新事实、新威胁、新决定或新反应。
- **呼吸**：台词之间留 0.5–1 秒；不要全程无停顿。
- **集尾钩子**：最后一个画面/台词要留下未解决的问题、未完成的动作或未揭示的信息。

## 六、短剧、竖屏与横屏的差异

| 维度 | 竖屏短剧（9:16） | 横屏短剧/剧集（16:9） |
|---|---|---|
| 画面信息 | 窄，适合单人/双人 | 宽，适合群像、空间、关系 |
| 景别偏好 | 中景、近景、特写为主 | 全景、中景、近景均衡 |
| 人物构图 | 居中偏上，眼睛在上三分之一 | 三分法、左右关系、前中后景 |
| 镜头时长 | 2–4 秒平均，节奏快 | 可以更长，但要有镜头变化 |
| 开场 | 3 秒内强钩子 | 可以用建立镜头，但仍要尽快给冲突 |
| 主要风险 | 怼脸、单调、空间不清 | 空镜过多、节奏拖、人物关系不清 |
| 台词 | 短、密、冲突强 | 可以长，但要有反应/插入镜头 |

**本项目当前是 16:9**（`dramas.aspect_ratio = 16:9`）。因此不能直接套用“9:16、特写/近景占 60–70%、主体居中偏上”的竖屏方案；否则会出现大量怼脸近景、固定机位、缺少全景和群像关系的问题。

## 七、AI 视频分镜的额外约束

AI 视频模型不是摄影组，它不会自动补全空间、轴线、道具和表演。分镜必须把“模型容易猜错的东西”写成硬约束。

### 1. 身份锁定

- 每个主要角色至少一张干净、正面/四分之三侧面的定妆参考图。
- 同一角色多角度参考图优先于单张图。
- 角色别名必须归一：`唐大郎`、`唐大郎（唐奕）`、`唐奕` 不能在三套名字之间漂移。
- 年龄状态要单独建资产：幼年唐奕、少年唐奕不能共用一张少年参考图。
- 服装/发型/配饰属于身份的一部分；同一场戏不能无故变化。

### 2. 场景锁定

- **一个物理地点只建一个场景资产**；清晨/正午/黄昏是同一场景的光线变体，不是三个不同场景。
- 场景参考图要能看清空间布局：门、窗、桌、柜台、出入口。
- 同一地点的不同集数必须复用同一场景资产，否则桌子的位置、柜台的朝向都会漂移。
- 换场必须换场景 ID；同场景内的时间变化用光线/色温描述。

### 3. 道具锁定

- 剧情关键道具必须有参考图，且名称、描述、图片三者一致。
- 参考图要能看出道具的结构特征；如果参考图本身像另一个东西，模型会忠实生成错误的东西。
- 道具要有“在谁手里、哪只手、朝哪、是否损坏”的状态描述。
- 道具连续性要跨镜检查：杯子、刀、书信、琴头、茶碗不能凭空消失或变形。

### 4. 动作锁定

- 一个镜头只安排一个主动作或一个情绪变化。
- 写清动作的开始状态和结束状态；不要只写“他在雕刻”。
- 不要把多个地点、多个动作压进一个镜头；模型会漏掉或混淆。
- 动作越大，越容易变形；复杂动作拆成相邻镜头或相邻运镜节点。
- 需要精确衔接时，用首帧/尾帧或动作匹配描述。

### 5. 台词锁定

- 按 4 字/秒估算，留 1 秒呼吸；3 秒段建议不超过 12 字。
- 长句只在原文标点或语义停顿处拆到相邻段，拼起来必须逐字一致。
- 不允许为了塞进 3 秒而删字、改字、压缩信息。
- 对白、画外旁白、内心独白必须分型；内心独白不能写成“低声说”。
- 台词必须逐字复制到视频提示词；不能用概括代替。
- 使用 H3 时，所有要发声的文本必须进入 `<d>[Chinese] ...</d>`；标签外文本一律视为画面描述。

### 6. 声音锁定

- 每个角色要有音色档案/参考音频；同一角色跨镜使用同一音色。
- 旁白要有独立音色，不能和角色音色混用。
- 逐镜原生音频容易出现音色漂移；若要稳定，优先后期配音或提供参考音频。
- BGM 通常按段落/场景设计，不要逐镜生成；逐镜生成会导致音乐情绪断裂。
- 静默也是声音设计；静默前要有声音对比，静默中要有环境声。

### 7. 负面约束

每个提示词建议明确写：

- 不换脸、不换发型、不换服装、不改变年龄感。
- 不新增未列出的角色。
- 不生成字幕、文字、水印、UI。
- 不改变场景布局、道具位置。
- 不生成未描述的动作、武器、血迹、天气。
- 不风格漂移（写实/国漫/3D 风格保持一致）。

### 8. 生成参数

- 比例、分辨率与项目一致。
- 需要跨镜稳定时固定 seed；换 seed 会带来细节漂移。
- 动作强度与镜头复杂度匹配；复杂运镜降低稳定性。
- 音频模式明确：原生、环境声、静音、后期配音。
- 首尾帧优先级高于文字描述；有首尾帧时，文字只写动作和情绪。

## 八、分镜质量门禁

### 1. 生成前检查

- [ ] 剧本每一场、每一句关键台词、每一个关键动作都有对应分镜。
- [ ] 段落数、总时长在目标区间内（建议 ±20%），不是只有下限。
- [ ] 没有重复节拍、重复镜头、无信息增量的镜头。
- [ ] 每个段落只讲一个冲突单元；没有把多场压进一段。
- [ ] 每个镜头回答“观众看什么、为什么看、看完知道什么”。
- [ ] 同一主体相邻镜头的景别/角度有明显差异；没有连续三个同景别同角度。
- [ ] 每个场景有建立镜头；对话戏有正反打/过肩/反应镜头。
- [ ] 每个角色使用规范全名；所有说话人都已绑定。
- [ ] 每个关键道具都有参考图；名称/描述/图片一致。
- [ ] 同一地点只有一个场景资产；时间变化用光线表达。
- [ ] 每个子镜头只有一个主动作、一个主动运镜。
- [ ] 台词容量、3 秒分段、逐字一致性通过。
- [ ] 对白/旁白/内心独白分型正确。
- [ ] 轴线、视线、屏幕方向、动作匹配写清楚。
- [ ] 声音/BGM/静默设计写清楚。
- [ ] 负面约束、参考图、首尾帧、seed、比例写清楚。

### 2. 生成后检查

- [ ] 角色脸型、发型、服装、年龄感跨镜一致。
- [ ] 场景布局、道具位置跨镜一致。
- [ ] 关键道具形状正确，没有变成另一个东西。
- [ ] 动作起止状态与分镜一致，没有多动作/漏动作。
- [ ] 没有未列出的角色、武器、文字、字幕。
- [ ] 口型与台词同步；旁白没有口型。
- [ ] 音色跨镜一致；BGM 不压台词；静默设计有效。
- [ ] 入点/出点可剪；动作/视线能接上。
- [ ] 没有重复镜头、死镜头、无信息镜头。
- [ ] 提示词描述与画面一致；没有“写了但没生成”或“生成了但没写”。

## 九、常见失败模式

| 失败模式 | 典型表现 | 根因 | 修正 |
|---|---|---|---|
| 重复分镜 | 同一动作/同一台词出现两次 | 拆分时重复保存、没有去重 | 增加重复检测；按节拍去重 |
| 过度拆分 | 一场戏拆成很多 8–12 秒镜头 | 只有下限、没有上限；按台词逐句拆 | 段落数/总时长上限；一个冲突单元一段 |
| 场景错绑 | 剧本写小饭馆，分镜全用主角店铺 | 场景资产缺失；模型复用现有场景 | 按剧本场景建资产；场景 ID 校验 |
| 角色别名漂移 | `唐大郎` / `唐大郎（唐奕）` / `唐奕` 混用 | 没有别名归一 | 规范名+别名表；未知名报错 |
| 未绑定角色 | 角色在提示词里，但没绑定参考图 | 只检查名称存在，不检查绑定 | 说话人/出场人强制绑定 |
| 旁白当对白 | 内心独白变成角色开口 | 没有台词类型 | 对白/旁白/内心独白分型 |
| 旁白超容量 | 12 秒镜头塞 24 秒旁白 | 只检查单句，不检查总容量 | 总容量检查；拆段 |
| 旁白失声 | 旁白格式不对，H3 判定无对白 | 旁白没进 `<d>` 标签 | 编译前校验 `<d>` 数量与预期 |
| 多动作压缩 | 一个镜头里喂药+端水+上街 | 一个镜头安排多个地点/动作 | 一个主动作；拆镜 |
| 道具错误 | 吉他琴头生成成木槌 | 参考图本身错误/缺失 | 道具参考图语义校验 |
| 多余角色 | 画面出现未列出的老人 | 模型自由发挥；参考图污染 | 负面约束；生成后人物检测 |
| 空镜模板化 | 室内清晨却生成风雨/门把手 | 过渡模板开放枚举 | 关闭枚举；按场景/剧情定制 |
| 镜头语言单一 | 40/57 近景、42/57 固定 | 竖屏方案套在横屏项目 | 画幅自适应方案；景别/机位配比 |
| 场景布局漂移 | 同一店铺三张不同布局参考图 | 同一地点多条场景记录 | 一地点一资产；变体只改光线 |
| 声音漂移 | 同一角色每镜音色不同 | 无参考音频/音色档案 | 音色锁定；后期配音 |
| BGM 断裂 | 每镜音乐情绪不同 | 逐镜生成 BGM | 段落级 BGM；后期混音 |
