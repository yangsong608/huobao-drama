# 页面视觉优化落地方案

- 状态：设计稿，未实施
- 日期：2026-11-06
- 定位：不改业务逻辑、不改路由、不重写大页面的前提下，把现有橙色工作台收敛成一套视觉语言，并补上阅读、密度、动效偏好
- 上游方案：[全链路集成与优化方案](./2026-11-06-全链路集成与优化方案.md)
- 关联方案：[小说工作台落地方案](./2026-11-06-小说工作台落地方案.md) · [导演台落地方案](./2026-11-06-导演台落地方案.md) · [剪辑工作台落地方案](./2026-11-06-剪辑工作台落地方案.md) · [智能体落地方案](./2026-11-06-智能体落地方案.md)

## 1. 结论

现有界面不是“没有设计”，而是**令牌有了，规则没有**：

- `studio.css` 已有 574 行完整主题：明暗两套表面/文字/品牌橙/状态色、间距、圆角、阴影、按钮、标签、弹窗、菜单、下拉面板（`frontend/app/assets/studio.css:4-144`、`146-200`、`269-311`、`404-425`、`490`）。
- 但缺三样：**字号层级、控件高度/密度、动效偏好**。正文字号只有 14px 一档，页标题 2rem 一档，中间没有层级（`studio.css:246-267`）。
- 阅读正文仍用界面无衬线 13px / 1.8，没有阅读字体、没有行宽限制（`frontend/app/assets/novel.css:44-49`）。
- 三套工作台顶栏各自手写：剧集 40px 卡片式（`frontend/app/views/drama/episode.vue:5384-5396`）、剪辑 52px 平铺（`frontend/app/components/edit/EditTopBar.vue:126-129`）、混音 42px 平铺（`frontend/app/components/MixStage.vue:1458-1470`）；配音工作台又是弹窗内标题（`frontend/app/components/DubbingWorkbench.vue:158-170`）。
- 量化证据：10–11px 字号 **258 处**、9px **51 处**、硬编码色值 **238 处**、`prefers-reduced-motion` **0 处**、焦点样式 **38 处**、媒体查询 **24 处**、`transition:` **108 处**。
- 单文件过大：`episode.vue` 8,555 行、`settings.vue` 3,747 行、`drama/detail.vue` 2,465 行、`EditWorkbench.vue` 1,003 行。这决定了不能做全局替换。

因此本方案的主线只有一条：

> **加规则、抽壳子、逐页换；不换路由、不改数据、不重写页面。**

先补一套字号/控件/动效/阅读令牌，再抽 3 个共享壳组件，只落在剪辑与混音两个工作台；验收通过后再推广到剧集、小说、设置、项目页、交付中心、导演台和智能体抽屉。品牌橙、明暗主题、现有 `AppHeader` / `AppMenu` / `ConfirmDialog` 不动。

不做视觉换肤，不做组件库迁移，不引入新的前端框架。

## 2. 现状与证据

### 2.1 可保留的基础

| 资产 | 现状 | 代码落点 |
| --- | --- | --- |
| 主题机制 | `data-theme` 先于首帧写入，跟随系统，无闪烁 | `frontend/app/composables/useTheme.ts:4-44` |
| 明暗令牌 | 表面、文字、品牌橙、成功/错误/信息/警告、间距、圆角、阴影、z-index | `frontend/app/assets/studio.css:4-144`、`146-200` |
| 按钮 | `.btn` 36px、`.btn-sm` 30px、`.btn-icon` 30×36、统一焦点环 | `studio.css:269-311` |
| 标签/弹窗/遮罩 | `.tag`、`.dialog`、`.dialog-head/body/foot`、`.overlay` | `studio.css:334-425`、`490-500` |
| 菜单 | `AppMenu` / `AppMenuItem`，已统一下拉面板、键盘高亮、danger 项 | `frontend/app/components/AppMenu.vue`、`AppMenuItem.vue` |
| 共享组件 | `AppHeader`、`BaseSelect`、`ConfirmDialog`、`ThemeToggle`、`LocaleSwitcher`、`ModelSelect`、`MentionTextarea` | `frontend/app/components/` |
| 小说作用域 | `.novel-scope` 表单基元、Markdown 正文、窄屏单列 | `frontend/app/assets/novel.css:1-116` |
| 布局 | `default`（顶栏 + 内容）、`studio`（全屏工作台）、`novel`（顶栏 + 小说作用域） | `frontend/app/layouts/` |

这些是“继续用”的资产，不推翻。问题在于它们没有被写成规则，页面只能各写一套。

### 2.2 主要问题

1. **字号碎片化**：9px 51 处、10–11px 258 处；混音顶栏的状态与 chip 是 9–9.5px（`MixStage.vue:1462-1467`），剪辑提示条按钮 10px（`EditWorkbench.vue:951-953`）。这些在 1280×800 下已经接近不可读。
2. **没有字号角色**：`--font-display` 与 `--font-body` 是同一套系统无衬线（`studio.css:95-96`），页标题、区块标题、正文、元信息之间没有稳定比例，页面各写 `font-size`。
3. **顶栏四套**：40 / 42 / 52px 三种高度，卡片式与平铺式混用，按钮高度 22–36px 混用。用户从剪辑切到混音，头部会跳。
4. **没有阅读排版**：`.md-body` 13px / 1.8、无最大行宽、无首行/段距规则（`novel.css:44-62`），长章节阅读疲劳；写作区与阅读区没有视觉区分。
5. **没有密度与动效偏好**：全站动画常开，`prefers-reduced-motion` 0 处；列表、表格、弹窗的行高不可调。
6. **对比度与焦点不齐**：`--text-3: #9aa1ad` 在白底约 2.5:1，却承载 11–12px 的提示与元信息（`studio.css:30`）；`--accent-text: #ea580c` 在白底约 3.6:1，11–12px 橙色文字不达 AA（`studio.css:36`）。只有 38 处 `focus-visible`，大量自绘按钮没有焦点环。
7. **硬编码色重复**：238 处十六进制色值；小说布局把品牌橙再次写死为 JS 常量（`frontend/app/layouts/novel.vue:19-31`）；配音提示条另写一套警告/错误色（`DubbingWorkbench.vue:162-164`）。明暗主题一旦调整，这些地方不会跟着变。
8. **空态、加载、错误、禁用原因分散**：各页各写一套；主操作被禁用时只变灰，不说明原因。
9. **大文件使全局改动高风险**：8,555 行的页面里做全局字号替换，无法可靠回归；只能按块改。
10. **新手可发现性不足**：重要操作只有图标 + `title`，没有可见文字；快捷键只写在快捷键弹窗里，菜单里没有等价入口。这与“桌面端新手可见、可点”的产品要求冲突。

### 2.3 为什么不是重写

- 现有拖拽、快捷键、时间线命中区依赖当前 DOM 结构与类名；重写会把“视觉优化”变成“交互回归”。
- 大页面单文件使全局 CSS 改动不可控；按页替换壳组件，单页可独立回滚。
- 现有令牌已经覆盖 80% 的颜色与表面需求，缺的是**用法规则**，不是新设计系统。
- 导演台和智能体抽屉尚未实现，可以直接用新规则起步，不需要二次改造。

## 3. 范围与非目标

### 3.1 本期范围

- 新增一组字号、控件高度、密度、动效、焦点、阅读令牌，全部**追加**到 `studio.css`，不修改现有变量值。
- 新增 3 个共享壳组件：`StudioTopBar`、`InspectorPanel`、`EmptyState`；另加 1 个可选 `StudioStatusBar`。
- 统一工作台顶栏高度与信息层级；先落地剪辑、混音，再落地剧集。
- 小说阅读模式：阅读字体、字号、行宽、段距、专注阅读。
- 设置页新增“界面”页签：密度、动效、阅读字体/字号/行宽、操作文字标签。
- 可访问性：正文对比度、焦点环、减少动效、键盘可达。
- 新手可发现性：主操作显示文字；图标操作必须有 `title` 与 `aria-label`；快捷键必须有菜单等价入口。
- 把项目页、交付中心、导演台、智能体抽屉的视觉规则纳入同一套令牌。

### 3.2 非目标

- 不换品牌色，不改橙色主视觉，不重做明暗主题。
- 不新增页面路由，不改后端业务接口，不改数据库结构。
- 不重写 `episode.vue` / `settings.vue` / `drama/detail.vue`，不拆分大文件。
- 不引入 Tailwind、组件库、CSS-in-JS 或新的构建步骤；小说页继续用现有 naive-ui。
- 不做整套图标重绘，不做插画系统，不做移动端适配（仅保证 1024px 宽不横向溢出）。
- 不改变时间线的操作方式与默认密度；时间线保持紧凑，密度偏好只作用于列表、表单、卡片。
- 不做“全站字号一次性替换”；只在新组件和本次触碰的块内执行新规则。

## 4. 目标形态与设计原则

### 4.1 一套工作台视觉语言

```text
AppHeader 60px（保留）
┌──────────────────────────────────────────────────────────┐
│ StudioTopBar 44px  返回 / 标题 / 状态胶囊 / 主操作        │
├──────────┬───────────────────────────────┬───────────────┤
│ 素材/镜头 │ 舞台 / 时间线 / 正文           │ 检查器 300–320 │
│ 236–260  │ flex                           │               │
├──────────┴───────────────────────────────┴───────────────┤
│ StudioStatusBar 24px（可选：保存状态 / 选中项 / 时间）      │
└──────────────────────────────────────────────────────────┘
```

- 导航层（`AppHeader`）保持 60px，不动。
- 工作台顶栏统一 44px 平铺，1px 下边框，左右 16px；不再用卡片式顶栏。
- 内容层是唯一“亮面”；顶栏、侧栏、检查器用次级表面，避免整页都是白卡片。
- 品牌橙只用于：主按钮、当前选中、当前步骤、关键数字；不用于大面积背景。
- 每个顶栏最多一个主操作；其余操作降级为次按钮或“更多”菜单。

### 4.2 字号角色

| 角色 | 字号 / 行高 / 字重 | 用途 | 令牌 |
| --- | --- | --- | --- |
| 页面标题 | 18 / 1.3 / 700 | 页面级 H1 | `--text-h1` |
| 区块标题 | 15 / 1.4 / 650 | 卡片、面板、分组标题 | `--text-h2` |
| 强调正文 | 14 / 1.55 / 550 | 关键说明、空态标题 | `--text-strong` |
| 界面正文 | 13.5 / 1.6 / 400 | 表单、列表、对话 | `--text-body` |
| 控件标签 | 12.5 / 1.3 / 600 | 按钮、标签、字段名 | `--text-label` |
| 元信息 | 12 / 1.4 / 500 | 时间、数量、状态、提示 | `--text-meta` |
| 微型标签 | 11 / 1.35 / 700 | 仅 eyebrow / 全大写分组名 | `--text-micro` |
| 阅读正文 | 16 / 1.85 / 400 | 小说章节、长文预览 | `--text-reading` |
| 等宽数字 | 12.5 / 1.5 / 500 | 时间码、帧号、码率 | `--text-mono` |

规则：

- 新代码与本次触碰的块**不出现 9px / 10px**；最小 11px，且只用于 eyebrow。
- 元信息不再用 9.5px + `text-3`；统一 12px + `text-2`。
- 时间线内部允许 11px，但必须用 `--text-micro`，不再写裸数值。
- 页面标题不放大到 2rem 以上；全屏工作台用 14–18px，避免挤压顶栏。

### 4.3 控件高度与密度

| 尺寸 | 高度 | 用途 |
| --- | --- | --- |
| `xs` | 24px | 时间线图标、检查器内小按钮 |
| `sm` | 28px | 工作台顶栏按钮、状态胶囊 |
| `md` | 32px | 表单、列表行内操作、对话框次按钮 |
| `lg` | 36px | 对话框主按钮、页面主操作（沿用现有 `.btn`） |

- 密度只作用于列表、表单、卡片：`compact` 行高 30px，`comfortable` 行高 36px。
- 时间线、轨道头、波形区固定紧凑，不随密度偏好变化，避免破坏已有命中区。
- 默认 `compact`，与今天的工作台观感一致；`comfortable` 是可选增强，不是默认改版。

### 4.4 动效

- 三档时长：`--motion-fast: 120ms`、`--motion-base: 180ms`、`--motion-slow: 240ms`；缓动沿用 `--ease-out`。
- 只动 `opacity` 与 `transform`；不动宽度、高度、`top/left`，避免布局抖动。
- 进入用 180ms，离开用 120ms；页面级入场最多 240ms，列表 stagger 不超过 5 项（现有 `.stagger-1..5` 保留）。
- `prefers-reduced-motion: reduce` 或用户选择“减少动效”时：取消淡入/位移/缩放，只保留透明度瞬时切换；加载 spinner 与进度条保留。
- 悬停不放大卡片；按下只允许 `scale(0.97)`（现有 `.btn:active` 保留）。

### 4.5 对比度与焦点

- 承载信息的文字最低使用 `--text-2`；`--text-3` 只用于禁用、装饰、分隔符。
- 新增 `--accent-text-strong: #c2410c`（暗色主题沿用 `#ffb076`），用于浅色底上的 11–12px 橙色文字；现有 `--accent-text` 保留给图标与大字号。
- 所有可交互元素必须有 `:focus-visible` 焦点环，统一 `box-shadow: var(--focus-ring)`；不允许 `outline: none` 后不补焦点样式。
- 颜色不是唯一状态信号：成功/警告/错误同时带图标或文字；选中项同时有背景与左侧/底部指示条。

### 4.6 新手可发现性

- 主操作：图标 + 文字，例如“导出成片”“生成混音”“开始拆镜”，不能只有图标。
- 次操作：允许图标，但必须有 `title` 与 `aria-label`；点击区域不小于 24×24。
- 每个快捷键都要在可见菜单里有等价项；快捷键弹窗只做加速，不做唯一入口。
- 禁用状态必须给出原因：`title` + 顶栏/按钮旁一行 12px 说明；不能只降低透明度。
- 破坏性操作（删除、覆盖、丢弃草稿）必须有确认，确认按钮写动作名，不写“确定”。

### 4.7 阅读体验

- 新增 `--font-reading`：`"Songti SC", "Noto Serif SC", "Source Han Serif SC", "SimSun", Georgia, serif`，缺字时回退 `--font-body`。
- 阅读正文 16px / 1.85 / 400，最大行宽 68ch，段距 0.8em，左对齐不两端对齐。
- 标题与正文之间用 1.2–1.6em 间距，不靠加粗堆层级。
- 批注锚点用底色 + 下划线，不改字号、不加粗，避免打断阅读节奏。
- 专注阅读只隐藏章节树与资料检查器，不隐藏顶栏返回与保存状态；不改变任何数据与保存逻辑。

### 5.2 小工具类

只加 4 个，避免工具类膨胀：

```css
.focus-ring:focus-visible { outline: none; box-shadow: var(--focus-ring); }

```

### 5.3 共享壳组件

#### `StudioTopBar.vue`（新增，约 90 行）

- Props：`title?: string`、`subtitle?: string`、`backTo?: string`、`dense?: boolean`。
- Slots：`left`、`center`、`right`、`title`。
- Emits：`back`（未传 `backTo` 时由父级处理）。
- 结构：44px 高、平铺、1px 下边框、左右 16px；左侧返回按钮 28×28；标题 14px/650；副标题 12px；右侧操作区 `gap: 6px`。

#### `InspectorPanel.vue`（新增，约 80 行）

## 7. 配置化设计

### 7.1 两层配置

| 层 | 存储 | 谁改 | 作用 |
| --- | --- | --- | --- |
| 部署默认值 | `app_settings`，键 `ui.defaults.*` | 管理员/部署者 | 新用户与未覆盖用户的默认观感 |
| 设备偏好 | `localStorage`，键 `huobao:ui-prefs` | 当前用户 | 本机显示偏好，首帧即可应用 |

优先级：**设备偏好 > 部署默认值 > 内置默认**。`ui.allowUserOverride=false` 时忽略设备偏好，强制使用部署默认值。

### 7.2 部署默认值

全部走现有 `app_settings` 键值表，不新增表；读取时清洗，写入时钳制，风格与 `novel.*` 一致（`backend/src/services/app-settings.ts:478-565`）。

| 键 | 默认 | 范围/枚举 | 作用 | 环境变量 |
| --- | --- | --- | --- | --- |
| `ui.defaults.density` | `compact` | `compact` / `comfortable` | 列表/表单/卡片默认密度 | `UI_DEFAULTS_DENSITY` |
| `ui.defaults.motion` | `system` | `system` / `full` / `reduced` | 默认动效策略 | `UI_DEFAULTS_MOTION` |
| `ui.defaults.readingFont` | `serif` | `serif` / `sans` | 阅读字体 | `UI_DEFAULTS_READING_FONT` |
| `ui.defaults.readingSize` | `16` | 15–18 | 阅读字号 | `UI_DEFAULTS_READING_SIZE` |
| `ui.defaults.actionLabels` | `true` | 布尔 | 主操作是否显示文字 | `UI_DEFAULTS_ACTION_LABELS=0` |
| `ui.allowUserOverride` | `true` | 布尔 | 是否允许本机覆盖默认值 | `UI_ALLOW_USER_OVERRIDE=0` |

接口：`GET /settings/ui`、`PUT /settings/ui`，返回 `{ defaults, allowUserOverride }`。只影响显示，不影响任何业务数据。

### 7.3 设备偏好

```json
{
  "density": "compact",
  "motion": "system",
  "readingFont": "serif",
  "readingSize": 16,
  "readingWidth": "normal",
  "actionLabels": true
}
```

- 读取时逐项校验，非法值回退默认；不抛错、不阻塞页面。
- `useUiPrefs.ts` 在模块顶层同步写 `<html data-density>` 与 `<html data-motion>`，与 `useTheme` 同构，避免首帧闪烁；服务端默认值异步到达后，仅在用户未覆盖时应用。
- 最近一次服务端默认值缓存在 `huobao:ui-defaults`，下次启动首帧直接使用，避免“先紧凑后舒适”的跳动。
- 设置页“恢复默认”清除 `huobao:ui-prefs`，回到部署默认值。
- 不把设备偏好写入数据库，不在多设备间同步；这是显示偏好，不是项目配置。

### 7.4 不放进配置的东西

- 品牌橙、表面色、圆角、阴影：属于设计系统，不给用户改。
- 顶栏高度、检查器宽度：属于布局约束，页面级覆盖，不做用户配置。
- 时间线密度：固定紧凑，避免用户把轨道压到不可操作。
- 字体族：只提供衬线/无衬线两档，不允许自由输入，避免排版失控。

- 主操作补可见文字；图标按钮补 `title` 与 `aria-label`；禁用原因可见。
- 步骤条、资产列表、分镜卡片字号统一到 11/12/13.5 三档。
- 验收：剧集主流程（剧本→资产→分镜→视频→配音→交付）无功能变化；1280×800 顶栏不换行、不溢出。

### U4 次级页面与可访问性（1–1.5 天）

- 项目列表/详情、交付中心、设置页、导出对话框统一。
- 对比度修正：元信息改 `text-2`；浅色小字橙色改 `accent-text-strong`。
- 焦点环补齐；键盘 Tab 顺序检查；颜色不作为唯一状态。
- 验收：抽样 30 个可交互元素全部有可见焦点；正文/元信息对比度达到 AA；无仅颜色表达的状态。

### U5 新页面接入与终验（1 天，随导演台/智能体并行）

- 导演台（2D+3D）与智能体抽屉（助手+导演专员）直接使用本方案令牌与壳组件。
- 全站截图对比；清理未使用的临时类与重复样式。
- 验收：新页面无 9/10px 文字；顶栏、检查器、空态与既有工作台一致；2D/3D 与助手/导演专员切换不改变栏宽；不与 `AppMenu` 的 z-index 冲突。

合计约 **6.5–9 天**；U5 与导演台/智能体同批并行，不单独排期。

## 11. 兼容与回滚

| 项 | 兼容方式 | 回滚 |
| --- | --- | --- |
| 现有 CSS 变量 | 只追加新令牌，不改旧值 | 删除追加块 |
| 现有页面 | 逐页替换壳，单页可独立发布 | 还原该页一个组件/样式块 |
| 主题 | `data-theme` 机制不变 | 无需回滚 |
| 小说 naive-ui | 只加阅读 CSS，不改 `themeOverrides` | 移除阅读规则 |
| 设置页签 | 插在“关于”之前，不改第 1 项 | 移除 `'ui'` 与对应块 |
| 服务端配置 | 无 `ui.*` 键时使用内置默认 | 删除键或设回默认 |
| 设备偏好 | 非法值回退；无值用默认 | 清除 `huobao:ui-prefs` |
| 动效 | 默认 `system`，与今天一致 | 设 `full` 或移除 reduced 规则 |
| 路由/数据 | 完全不改 | 无 |

补充约束：

- 顶栏高度从 52/42/40 统一到 44 后，如果某页时间线高度不足，优先隐藏可选状态条，不压缩时间线命中区。
- 任何页面在 1280×800 下出现内容溢出，必须回退该页顶栏改造，不允许用全局缩放兜底。
- 字号规则只约束新代码与本次触碰块；不为了“全站统一”去批量替换 8,555 行页面。

## 12. 风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 剧集页面过大，改顶栏引发意外回归 | 高 | 只替换顶栏块；改前截图；按块 diff；不改全局选择器 |
| 顶栏变矮导致时间线可视区域变化 | 中 | 1280×800 验收；状态条可选；必要时保留 48px 变体，仅该页使用 |
| 阅读衬线字体缺失或渲染差异 | 中 | 完整回退栈；中英日韩各测一段；缺字回退无衬线 |
| 密度偏好影响表单布局 | 中 | 密度只作用于列表/表单行高，不改字号、不改时间线 |
| 对比度调整改变品牌观感 | 低 | 只改小字橙色与元信息灰色；主色、按钮、图标不变 |
| 设置页签插入影响现有 tour | 低 | 插在“关于”前；现有 tour 只依赖第 1 项；新增页签不加 tour |
| 共享组件过度抽象 | 中 | 只做 4 个壳；不内建业务；页面插槽传操作 |
| 导演台/智能体实现晚于 UI 令牌 | 低 | U0–U4 独立完成；U5 跟随两个工作包并行，不阻塞前四项 |
| 字体/密度偏好导致首帧闪烁 | 低 | 模块顶层同步写 `data-*`；缓存服务端默认值 |
