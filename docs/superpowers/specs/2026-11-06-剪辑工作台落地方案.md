# 剪辑工作台落地方案

- 状态：设计稿，未实施
- 日期：2026-11-06
- 定位：成片后的**可选精修与支持能力**；在现有剪辑台补齐“可导出成片”的闭环，并把剪辑时间与混音工作台打通。不替换现有拼接导出、混音、交付与成片中心，不重写时间线
- 上游方案：[全链路集成与优化方案](./2026-11-06-全链路集成与优化方案.md)
- 关联方案：[小说工作台落地方案](./2026-11-06-小说工作台落地方案.md) · [导演台落地方案](./2026-11-06-导演台落地方案.md) · [智能体落地方案](./2026-11-06-智能体落地方案.md) · [页面视觉优化落地方案](./2026-11-06-页面视觉优化落地方案.md)

## 1. 结论

现有剪辑台不是“没有剪辑能力”，而是**剪完出不去**：

- `EditPlanV1` 已经覆盖片段、裁剪、速度、空隙、淡入淡出、转场、字幕、标记、叠加层、滤镜、变换。
- 草稿、版本、撤销、冲突检测、粗剪、字幕建议都已经能用。
- 但后端明确返回 `can_export: false`，`renders` 恒为空，`backend/src/routes/edit.ts` 没有任何渲染/导出路由。
- 前端顶栏只有保存、字幕建议、粗剪、版本，没有导出按钮。

因此本方案的主线只有一条：**把已保存的剪辑版本渲染成 MP4，并进入现有交付中心**。音频对齐、右键菜单、标记、字幕样式都围绕这条主线补齐，不新建第二套时间线、不新建第二套混音台、不重写成片中心。

剪辑台是**多一种支持功能**，不是现有链路的替代：

- 现有整集拼接、通用导出、混音台、交付中心与成片中心的入口、按钮、数据流和默认路径保持原样。
- 进入剪辑台、保存剪辑版本、生成剪辑导出都不是生成、合并、交付的前置条件；不使用剪辑台时，现有流程照常可用。
- 剪辑台内新增的导出、混音胶囊、右键菜单与标记只在剪辑台内提供，不成为唯一入口。
- 关闭 `edit_workspace` 或 `EDIT_EXPORT` 后，现有入口与旧流程必须完整可用。

成片记录复用现有 `episode_exports`，不新建表；这部分字段（`render_mode`、`edit_revision_id`、`edit_plan_hash`、`subtitle_mode`、`file_name`、`project_id`）已经在表里预留。

### 2.2 明确缺口

1. **没有剪辑成片渲染**：`getEpisodeEditState()` 返回 `renders: { cut: null, audio_ref: null }`、`can_export: false`（`backend/src/services/edit-service.ts:174-186`）。
2. **没有导出路由**：`backend/src/routes/edit.ts` 只有状态、素材、草稿、版本、粗剪、字幕建议。
3. **音频轨是占位**：时间线音频轨只有“与视频同源”提示，没有混音波形，也不能选择混音版本（`frontend/app/components/edit/EditTimeline.vue:85-91`）。
4. **同步状态不可操作**：`mix_status` 只显示“已对齐/已过期/缺失”，点不进去，也不告诉用户哪一段变了。
5. **编辑易用性不足**：没有右键菜单、标记、字幕检查器、字幕样式；字幕只能拖动。
6. **素材库只有分镜与配音 take**：`audio: { mix: null, audio_ref: null }`、`import_enabled: false`（`backend/src/services/edit-media-library.ts:99-105`）。
7. **默认导出预设指向不存在的键**：`projectSettingsForAspect()` 返回 `edit-vertical-hd` / `edit-horizontal-hd` / `edit-source`，但 `export-presets.ts` 只有 `vertical-hd` / `horizontal-hd` / `vertical-high` / `audio-wav` / `stems`（`backend/src/services/edit-plan.ts:206-210`、`backend/src/services/export-presets.ts:39-125`）。这是一个必须先修的真实缺陷。

## 3. 范围与非目标

### 3.1 本期范围（P3a-1）

- 从**已保存的剪辑版本**导出 MP4。
- 导出对话框：画幅预设、字幕模式、音频来源、设为当前成片。
- 导出进度、取消、重试、最近成片列表、跳转交付中心。
- 复用键与磁盘空间检查。
- 音频工作台显示剪辑同步状态，可跳回剪辑台。
- 导出自动使用已对齐的混音；混音过期时明确降级为剪辑原声并提示。
- 时间线右键菜单、标记、字幕检查器与字幕样式。
- 配置化开关、只读保护、紧急回滚。

P3a 内部按依赖推进：E0 状态与配置 → E1 渲染内核 → E2 导出闭环；E2 验收通过后才进入 E3 音频同步与 E4 易用性。本方案 E0–E4 对应总方案 P3a-1；P3a-2 的共用编辑内核见总方案 5.5–5.9 的 K1–K4，E5 对应 K5/P3b。整体实施批次见总方案 0.5。

### 3.2 非目标

- 不替换、不改写、不隐藏现有整集拼接导出、通用导出、混音台、交付中心与成片中心；不把进入剪辑台或保存剪辑版本设为生成、合并、导出或交付的前置条件。
- 不把剪辑台内的导出按钮、混音胶囊、右键菜单与标记扩展成唯一入口；关闭 `edit_workspace` 或 `EDIT_EXPORT` 后旧路径仍完整可用。
- 不重写剪辑台，不引入多视频轨、关键帧、画中画编辑 UI。
- 不做滤镜/变换/叠加层的可视化编辑；这三类字段暂不参与渲染（见 §6.5）。
- 不做“自动把混音时间重新对齐到剪辑”的破坏性操作。
- 不做渲染农场、分布式转码、GPU 编码。
- 不改 `storyboards`、`video_merges`、`mix_revisions` 的既有语义。
- 不做成片中心（film hub）改造；P3b 只做接入，且以成片中心方案获批为前提。
- 本方案 E0–E4 只覆盖 P3a-1；多选/框选、音频轨波形与音频片段检查器、帧级时间码、J/L 切、交叉淡化、音量包络属于 P3a-2（总方案 K1–K4），不在本方案排期。

### 3.3 与音频工作台的分工

| 工作台 | 负责 | 不负责 |
| --- | --- | --- |
| 剪辑工作台 | 画面顺序、裁剪、速度、转场、字幕、成片导出 | 调音台推子、总线、降噪、音效生成 |
| 音频工作台 | 轨道、总线、M/S、闪避、响度、混音版本 | 画面顺序、转场、字幕时间轴编辑 |

两边只通过两个哈希握手：`edit_sync_hash`（画面时间）与 `dialogue_sync_hash`（台词时间）。不复制对方的编辑能力。

## 4. 目标形态

### 4.1 页面结构

```text
┌ 顶栏：返回 | 剪辑 | 集名 | 模式 | 混音状态 | 撤销/重做 | 保存 | 导出 | 版本 | 素材库 ┐
├ 左：素材库 280px ┬ 中：预览 + 时间线 flex ┬ 右：检查器 300px ┤
│ 分镜 / 台词 / 混音 │ 画面、字幕轨、音频轨、标记 │ 片段 / 字幕 / 导出提示 │
└───────────────────┴────────────────────────┴──────────────────────┘
```

- 顶栏新增**导出**主按钮，位置在保存之后、版本之前。
- 导出按钮的可用状态由后端 `capabilities.can_export` 决定，前端不自行推断。
- 混音状态胶囊可点击，弹出原因与“去混音工作台”入口。
- 时间线音频轨在混音对齐时显示混音波形；未对齐时仍显示“剪辑原声”占位。
- 右侧检查器在选中片段时显示片段参数；选中字幕时切换到字幕检查器。

### 4.2 导出对话框

| 字段 | 选项 | 默认 |
| --- | --- | --- |
| 画幅预设 | 自动 / 竖屏高清 / 横屏高清 | 自动（按剧集画幅） |
| 字幕 | 软字幕 / 烧录 / 无 | 软字幕 |
| 音频 | 自动 / 当前混音 / 剪辑原声 / 静音 | 自动 |
| 设为当前成片 | 是 / 否 | 否 |
| 预计时长 / 大小 | 只读 | 由后端返回 |

- “自动”音频规则：混音存在且 `mix_status.status === 'aligned'` → 用混音；否则用剪辑原声；两者都没有 → 静音并提示。
- 草稿未保存时，导出按钮显示“先保存”，点击先执行保存再打开对话框；不直接拿草稿渲染。
- 导出中显示进度条、阶段文案、取消按钮；关闭对话框不取消任务。
- 完成后展示“打开成片 / 在交付中心查看 / 复制路径”。

### 4.3 混音状态联动

剪辑台顶栏：

- `aligned`：绿色“混音已对齐”。
- `stale`：黄色“混音已过期”，点击展开原因：
  - `legacy_mix` → 旧混音没有剪辑时间基准。
  - `timing_changed` → 画面时间变化。
  - `dialogue_changed` → 台词时间变化。
- `missing`：灰色“未生成混音”。

音频工作台顶栏增加同一状态的镜像胶囊，并提供“回到剪辑台”按钮。音频工作台不新增导出按钮，避免两个入口做同一件事。

## 6. 渲染管线

### 6.1 总原则

1. **只渲染已保存版本**。导出前若草稿脏，先保存；渲染读取 `edit_revisions.plan_json`，保证版本可追溯。
2. **画面与声音分开生成，最后封装**。画面先出无声 MP4；音频来自混音或剪辑原声；最后用现有 `renderExportVideo()` 封装。
3. **单集互斥**。同一集同时只允许一个剪辑导出；用 `episode_locks`（kind=`edit_export`）或内存集合 + 数据库状态双重保护。
4. **可取消**。每个导出持有 `AbortController`，取消时终止 FFmpeg 子进程并清理临时文件。
5. **失败不污染旧成片**。新记录失败只标记自身 `failed`，不修改当前成片。

### 6.2 阶段与进度

| 阶段 | 进度 | 内容 |
| --- | --- | --- |
| 校验 | 0–5% | 读取当前版本、校验计划、检测不支持字段、磁盘空间 |
| 片段归一 | 5–30% | 逐片段裁剪、变速、缩放/补边、统一帧率与像素格式、淡化 |
| 画面组装 | 30–55% | 处理空隙、硬切或溶解转场，输出无声 MP4 |
| 音频 | 55–72% | 已对齐混音渲染为 WAV；否则从画面提取剪辑原声；静音则生成静音轨 |
| 字幕与封装 | 72–92% | 生成 SRT/ASS，软字幕或烧录，调用 `renderExportVideo()` |
| 校验 | 92–100% | `validateExport()` 检查时长、分辨率、字幕流、响度，写回记录 |

### 6.3 画面组装

- 每个片段先归一为项目画幅、项目帧率、H.264、`yuv420p` 的临时文件。
- 裁剪：`sourceInMs` / `sourceOutMs`；速度：视频 `setpts=PTS/speed`，音频 `atempo`（超出 0.5–2.0 时串联）。
- 淡入淡出：视频 `fade`，音频 `afade`，上限 1500 ms。
- 空隙：`gapBeforeMs` 用黑场 + 静音补齐。
- 硬切：优先用 concat demuxer，稳定且快。
- 溶解：相邻片段用 `xfade`，偏移量按 `computeLayout()` 的时间线计算；音频用 `acrossfade`，缺音轨的片段补 `anullsrc`。
- 只支持 `dissolve`；`white` / `push-left` / `blur` 在导出前直接报错，不静默降级。
- 图片片段：`-loop 1 -t 时长`，按片段时长生成。

### 6.4 音频选择

| `audio_source` | 行为 |
| --- | --- |
| `auto` | 混音 `aligned` → 混音；否则剪辑原声；都没有 → 静音 + 警告 |
| `mix` | 必须存在对齐混音，否则 409 |
| `clip` | 从归一后的片段音轨拼接；没有音轨的片段补静音 |
| `silent` | 生成等长静音轨 |

混音音频直接调用 `renderMixAudio()` 输出 24-bit WAV；剪辑原声从画面组装阶段的音频轨提取为 WAV。最终都由 `renderExportVideo()` 重新编码为 AAC 48 kHz 双声道。

### 6.5 不支持字段的处理

| 字段 | 处理 |
| --- | --- |
| `overlays` 非空 | 阻止导出，返回 `EDIT_RENDER_UNSUPPORTED`，列出 `overlays` |
| `filter.preset != 'none'` | 阻止导出，列出片段与预设 |
| `transform` 非默认值 | 阻止导出，列出片段与字段 |
| `transitions` 非 `dissolve` | 阻止导出，列出转场类型 |

理由：UI 目前没有这些编辑入口，正常用户不会触发；静默忽略会产出与用户预期不符的成片，因此选择明确失败。后续做完对应 UI 再逐项开放。

### 6.6 字幕

- 字幕来源为 `plan.subtitles`，不是重新从台词生成。
- 用 `toSrt()` 与 `toAss()` 生成两份文件；软字幕用 SRT，烧录用 ASS。
- 样式映射：
  - `default` → 默认白字黑边。
  - `outline` → 加粗描边。
  - `box` → 半透明底框。
- 字号与边距复用配音默认值（`getDubbingDefaults()`），保证与交付中心其他成片一致。
- `follow=true` 的字幕已经跟随片段；渲染前用 `computeLayout()` 重新计算，避免草稿时间与版不一致。

### 6.7 复用键与并发

复用键：

```text
sha256(
  render_mode | edit_plan_hash | preset | subtitle_mode |
  audio_source | mix_revision_id | subtitle_hash | source_video_hash
)
```

- 命中最近一条 `completed` 且文件存在的记录 → 直接返回 `reused: true`。
- 只允许单集一个进行中的剪辑导出；全局并发由 `edit.export.concurrency` 控制（默认 1）。
- 启动前用 `estimateExportBytes()` 估算空间，并检查项目磁盘余量。

### 6.8 清理

- 临时文件放在项目 `temp/edit-render-<recordId>/`，成功或失败后删除。
- 保留成片目录 `episodes/<episodeId>/exports/<recordId>/`，与现有导出完全一致。
- 删除成片记录时复用现有删除逻辑，连带删除文件。

## 9. 分阶段实施

E0–E2 是渲染/导出闭环的基础，未通过不进入 E3/E4；这里的顺序是依赖顺序，不是业务优先级。

### E0 状态与配置（0.5–1 天）

- 修正默认预设键，旧计划里的 `edit-*` 别名继续可解析。
- `getEpisodeEditState()` 返回真实 `renders`、`can_export`、`export_blocked_reason`。
- 新增 `GET/PUT /settings/edit` 与设置页“剪辑与导出”卡片。
- 顶栏导出按钮按能力显示禁用原因。
- 验收：只读模式按钮禁用且文案正确；`on` 模式按钮可点但暂不弹窗。

### E1 渲染内核（2–3 天）

- 实现 `edit-render.ts`：归一、裁剪、速度、空隙、淡化、硬切、溶解。
- 实现音频三种来源与字幕 SRT/ASS。
- 单元测试用 3 个短片段覆盖：裁剪、速度、空隙、溶解、无音轨、静音。
- 验收：命令行/服务函数产出的 MP4 时长与 `computeLayout()` 一致（误差 ≤1 帧），音画同步。

### E2 导出闭环（2–3 天）

- `edit-export-service.ts`：创建记录、进度、取消、复用、磁盘检查、失败重试。
- `POST/GET /episodes/:id/edit/exports`。
- 导出对话框、顶栏进度、完成提示、交付中心可见。
- 复用 `episode_exports` 的取消/重试/设为当前/删除。
- 验收：同计划二次导出命中复用；改一个裁剪点后重新渲染；刷新页面能恢复进度。

### E3 音频工作台同步（1–1.5 天）

- 剪辑台混音状态可点击，展示三类原因与“去混音”。
- 音频工作台显示同一状态与“回到剪辑台”。
- 导出“自动”音频按对齐状态选择混音/原声，并在对话框展示原因。
- 验收：制造 `timing_changed` 后，剪辑台出现黄色过期、导出默认改用原声；重新生成混音后恢复绿色并改用混音。

### E4 基础易用性：右键、标记、字幕（1.5–2 天）

- 右键菜单：在播放头分割、删除、波纹删除。
- 标记：播放头添加、列表跳转、上一个/下一个、删除。
- 字幕检查器：文本、起止帧微调、样式、应用到全部。
- 快捷键说明同步更新。
- 验收：右键三项操作可撤销；标记可跳转；字幕样式在导出中生效。

### E5 成片中心接入（2–3 天，需成片中心方案获批）

- 素材库增加“成片/合片”源与当前混音。
- 导出记录写 `source_merge_id` / `film_id` / `project_id`。
- 成片中心可直接“进入剪辑”。
- 验收：从成片中心进入剪辑，导出后回到成片中心可见新成片；不产生重复记录。

P3a-1（E0–E4）合计约 7–10.5 天；P3a-2（K1–K4）另计；E5 对应 P3b，单独排期。

## 10. 验收清单

### 10.1 渲染正确性

- [ ] 3 个片段、各裁剪 1 秒、首尾淡入淡出、1 个溶解转场：导出时长与时间线误差 ≤1 帧。
- [ ] 片段速度为 0.5× / 2× 时，画面与音频同步，无变调。
- [ ] `gapBeforeMs` 渲染为黑场 + 静音，不吞掉相邻片段。
- [ ] 图片片段按指定时长输出，不闪烁。
- [ ] 字幕软/烧录/无三种模式均正确；烧录中文字体正常。
- [ ] 无音轨片段不导致导出失败。

### 10.2 音频与同步

- [ ] 混音对齐时，“自动”使用混音；导出文件的 `mix_revision_id` 正确。
- [ ] 混音过期时，“自动”使用剪辑原声，并在对话框展示 `timing_changed` / `dialogue_changed`。
- [ ] `requireAlignedMix=true` 且混音过期时返回 409，不创建记录。
- [ ] `audio_source=mix` 但无混音时返回 409。
- [ ] 音频工作台与剪辑台显示同一状态。

### 10.3 导出流程

- [ ] 草稿未保存时导出先保存，记录关联最新 `edit_revision_id`。
- [ ] 同计划、同参数、同混音重复导出返回 `reused: true`，不重复渲染。
- [ ] 修改片段后再次导出生成新记录。
- [ ] 导出中可取消；取消后状态 `cancelled`，临时文件清理。
- [ ] 失败后保留错误信息，可重试。
- [ ] 刷新页面后进度恢复；完成后出现在交付中心。
- [ ] 设为当前成片后，交付中心“当前”标记正确。

### 10.4 权限与安全

- [ ] `off` 模式：页面不可用，接口 403，不写任何记录。
- [ ] `readonly` 模式：可查看、可播放、不可导出，`can_export=false`。
- [ ] `on` 模式：可编辑、可导出。
- [ ] 非法路径、非法预设、非法字幕模式返回 400。
- [ ] 不支持字段（overlays/filter/transform/非 dissolve 转场）返回明确错误，不产成片。

### 10.5 兼容性

- [ ] 现有混音导出、分轨导出、合片导出行为不变。
- [ ] 现有草稿、版本、恢复、粗剪、字幕建议行为不变。
- [ ] 旧计划中的 `edit-vertical-hd` / `edit-horizontal-hd` / `edit-source` 可解析。
- [ ] 交付中心、成片中心读取 `episode_exports` 的逻辑不变。

## 11. 兼容与回滚

| 场景 | 措施 |
| --- | --- |
| 导出异常 | `EDIT_EXPORT=off`，顶栏隐藏导出，接口 403；已有成片保留 |
| 工作台需要只读 | `edit_workspace=readonly`，沿用现有写闸门 |
| 配置错误 | `PUT /settings/edit` 白名单 + clamp，未知键忽略 |
| 渲染结果异常 | 删除该条 `episode_exports`，不影响历史成片；不改源素材 |
| 数据库 | 无迁移，无需回滚 |
| 前端回滚 | 导出按钮与对话框均为新增，移除入口即可恢复旧界面 |

## 12. 风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| FFmpeg 滤镜图复杂 | 音画不同步、时长漂移 | 分阶段生成；以 `computeLayout()` 为唯一时间基准；固定 fixture 测试 |
| 变速与音频 | 变调、爆音 | `atempo` 串联；导出前校验音轨时长 |
| 长集导出占用 CPU | 阻塞其他任务 | 单集互斥、全局并发 1、异步执行、可取消 |
| 混音与剪辑漂移 | 成片对不上口型 | `mix_status` 显式提示；默认降级原声；不静默使用过期混音 |
| 磁盘不足 | 导出中途失败 | 启动前估算 + 507；失败清理临时文件 |
| 字幕字体缺失 | 烧录乱码/方框 | 复用现有 `buildBurnFilter()` 与字体配置；导出前探测 |
| 旧预设键 | 导出报“不支持预设” | E0 先修别名解析 |
| 用户误以为能导叠加层 | 导出被阻止 | 对话框提前展示不支持字段清单 |
