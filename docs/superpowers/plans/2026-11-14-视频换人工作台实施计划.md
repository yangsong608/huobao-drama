# 视频换人工作台实施计划

- 日期：2026-11-14
- 状态：待评审，未开始执行
- 设计依据：[2026-11-14-视频换人工作台设计方案.md](file:///Volumes/软件目录/comfyui/工具/huobao-drama/docs/design/2026-11-14-视频换人工作台设计方案.md#L1)
- 目标：新增独立“视频”模块，第一版同时支持 H3 单脸换脸与 H3 Recast 角色替换，支持多镜头拆分、长镜头分块、逐片生成、接缝检查和合并

## 架构摘要

后端新增视频项目、运行、镜头、片段和日志数据；新增项目 CRUD、素材上传、ffmpeg 分析、AI 分析、场景参考帧、最终提示词、生成运行器、接缝检查和合并服务。网关新增视频输入类型，并新增 8194 换人网关指向 8189；8192 → 8188 保持不动。前端新增顶级“视频”模块、左侧项目列表和右侧上下工作区；AI 配置新增 video-swap 服务类型。

## 技术栈

后端沿用 Hono、Drizzle、better-sqlite3、ffmpeg-static、Node 22；前端沿用 Nuxt 3、Vue 3、Pinia、vue-i18n、纯 CSS 设计体系；网关沿用 Python 标准库与独立管理端；ComfyUI 使用 8189 隔离实例。

## 全局约束

- 不执行 git commit、push、reset、checkout 或任何丢弃工作区改动的命令；提交仅在用户明确要求时进行。
- 当前工作区仍有未提交改动，执行前先记录基线，不把本次改动与既有改动混为一谈。
- 后端测试必须使用 Node 22；前端测试使用 Node 24；数据库测试使用隔离 SQLITE_PATH。
- 8192 → 8188 生产链路保持不动；换人只走 8194 → 8189，管理端 8195 仅回环。
- 不从 `local-h3/gateway/deploy/install.sh` 覆盖生产网关；不修改现有 8192 manifest、工作流模板或 8188 自定义节点。
- 不使用 `pkill -f main.py`；Stop/Start 8188 与 8189 必须按端口和容器名操作。
- 前端不暴露 ComfyUI 工作流 JSON；工作流保存在网关/ComfyUI，客户端只选命名工作流。
- 不修改用户已有 AI 配置来掩盖失败；新增独立 video-swap 配置。
- 所有 ffmpeg 调用使用参数数组，不拼接 shell 字符串。
- 长视频必须先按硬切拆镜头，再按最大生成时长拆片段；片段重叠、原声音轨母版、接缝检查和逐片重试是硬约束。
- 不假设 H3 Recast 支持“上一段末帧作为下一段参考”；只有工作流实际支持时才使用，否则依赖源视频重叠和接缝检查。
- 真实验收必须使用 8189 实际生成，不允许用假 ComfyUI、假输出或仅构建通过冒充验收。
- 模型、LoRA、节点安装和服务器操作需要单独批准；许可证未确认的资产不得进入交付路径。
- 构建、安装、发布、端口变更和模板版本变更分别需要单独批准。
- 计划文档和实现阶段均不写代码；代码在“开始执行”后由执行者逐个计划点实现。
