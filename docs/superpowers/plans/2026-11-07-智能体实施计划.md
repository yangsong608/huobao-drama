# 跨业务智能体实施计划（A0–A4）

> **给执行者：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按计划点逐项执行。每一步的实施代码由执行者在执行时编写，本文件只定义要求、约束、参考、设计、自测与验证；计划正文不包含实现代码。

**目标：** 把统一智能体内核嵌入现有业务页面，交付“只读问答 + 三类提案 + 建议卡 + 导演专员”，不新增独立聊天页，不改造五个生产 Agent，不让助手直接写业务表；配置集中到现有设置页“智能体”中心。

**架构：** A0 先拆分生产 Agent 与两个预设、建立页面适配器注册机制、空 `AgentDock` 与设置中心骨架；A1 建会话/消息/作用域/SSE 与第一批只读工具和页面适配器；A2 补剪辑/混音/交付只读能力与三类提案；A3 加建议卡、导演专员、页面绑定与配置收口；A4 做诊断、保留清理、会话审计与全量回归。会话按 `workspace_key` 单线程跨页，助手与导演专员共用同一运行时和同一抽屉。

**技术栈：** Nuxt 3 + Vue 3.5（SPA）、Hono、Drizzle + better-sqlite3、Mastra 1.17、Node `node:test` + `tsx`、Vue I18n（zh/en/ja/ko）。

## 2. 范围、非目标与完成定义

### 2.1 本期范围

- `assistant` 助手与 `director` 导演专员两个预设，共用同一运行时、会话表、消息表、提案表与 `AgentDock`。
- 页面适配器：首页/项目列表、小说列表、小说详情、项目详情、分集工作台、导演台、剪辑工作台、混音台、交付中心。
- 单线程跨页：`home`、`novel-library`、`novel:<id>`、`drama:<id>` 四类 `workspace_key`；同一项目跨页共用线程，跨项目不混线程。
- 会话、消息分页、流式、取消、断线恢复、进程重启中断标记、非流式回退。
- 只读工具：首页项目概览、小说、项目、集、资产、分镜、配音、剪辑、混音、交付、导演计划。
- 三类提案：`storyboard.update`、`asset.prompt.update`、`line.update`；差异、审批、拒绝、冲突检测、7 天过期、审计字段。
- 建议卡：五个生产 Agent 与八个页面/阶段目标；助手只建议，执行走现有页面按钮/弹窗。
- 集中配置：设置页“智能体”中心八个子区；页面绑定、工具与权限、模型与预算、会话与审计、诊断。
- 开关、模型、上下文预算、会话保留、四语文案。

### A2-4 提案应用、拒绝、冲突与审计

**要求**

### A4-2 会话保留清理与软删除收口

**要求**
- 实现 30 天保留清理：对超过 `agent.session.retentionDays` 的归档/软删除会话，清理消息正文、工具调用/结果与建议 JSON；保留会话壳、消息行与提案记录。

**约束**
- 不新增表、不新增清理接口；清理在服务层调度。
- 清理只清内容字段，不删行；提案审计必须保留。
- 不清理未归档/未删除的活动会话。
- 不打印被清理内容；不操作开发库。
- 不提交。

**参考**
- 设计稿 §5.2、§8.4、§9.2、§12.6、§13。
- 基础层 `agent_sessions`/`agent_messages`/`agent_proposals`。
- A1-1 的会话服务与 A2-4 的提案过期。

**设计**

## 6. 风险与回滚

| 风险 | 影响 | 缓解 |
|---|---|---|
| Mastra `workspace` 自动注入文件/命令工具 | 绕过只读白名单 | 两个预设显式不挂 `workspace`；注册表测试断言无文件/命令工具；技能只通过 `loadAgentSkills()` 注入 |
| `validAgentTypes` 仍由默认提示词推导 | 新增预设被旧 `/chat` 放行 | A0-1 改为显式生产集合；测试断言 `/agent/assistant/chat` 400 |
| 动态工具解析在 Mastra 1.17 不可用 | 工具集无法按作用域裁剪 | 先核对类型；不可用时按作用域构建一次性 Agent 实例，仍按白名单裁剪；不升级依赖 |
| 只读路径懒创建工程/版本/总线 | 助手首次问答写业务表 | A2-1 增加 `readOnly` 并覆盖 `compileEpisodePlan()` 无成片降级分支；测试断言相关表行数不变；页面默认行为保持 |
| 混音同步哈希重复实现 | 与剪辑台状态不一致 | 以 E3-1 `edit-mix-sync.ts` 为唯一事实源；未落地时延后混音工具，不在智能体包重复计算 |
| 提案并发/双击重复应用 | 业务数据写两次 | 状态机 + `target_hash` + 事务内条件更新；受影响行数 0 返回 409 |
| 提案目标被并发修改 | 覆盖用户新值 | 应用前重算哈希；不一致 409 并标记 `conflict`，不强制覆盖 |
| 跨项目/跨集作用域越权 | 读到或写到其他项目数据 | 服务端解析与归属校验；工具强制 `drama_id`/`episode_id`/`novel_id`；跨项目测试 |
| 页面适配器漂移 | 入口显示但作用域错误 | 单路由单适配器；精确匹配；诊断页模拟路由；子组件不注册 |
| 建议被误解为已执行 | 用户以为任务已开始 | 建议卡明确“未执行”；只提供“打开流程/打开页面”；系统提示禁止声称已执行 |
| 建议跨项目误用当前适配器 | 打开错误页面/工程 | 比较 `prefill` 与当前作用域；不一致时导航；`runSuggestion` 失败回退“打开页面” |
| 上下文溢出 | 回答截断、成本高 | 摘要 + 工具按需读取 + 历史/结果预算；超限截断并提示 |
| SSE 被代理缓冲 | 看不到增量 | 沿用小说任务 SSE 的心跳、关闭缓存模式；15 秒 `: ping` |
| 进程重启回答卡 running | 用户等待无结果 | 启动恢复置 `interrupted`；重连回放终态；提案过期、建议清空 |
| 消息渲染 XSS | 模型/工具输出注入 | 安全 Markdown 子集；禁用原始 HTML/事件属性；工具/卡片纯文本；外链图片不自动加载 |
| 设置中心过重 | 配置难找 | 八个子区 + 搜索；供应商与流水线保留原位并链接 |
| 导演台 D0 未落地 | 导演专员无法验收 | A3-2 隐藏入口；配置与提示词先落地；D0 后再联调 |
| 保留清理误删审计 | 无法追溯提案 | 只清消息内容字段；保留会话壳、消息行与提案；测试断言 |
| 环境变量误判 | 以为刷新页面即可回滚 | 文档化 `AGENT_*` 需重启；设置页显示强制关闭只读提示 |
| 配置被页面绑定扩大 | 工具/作用域越权 | 只做交集；空数组非法；保存时校验白名单子集 |

**回滚顺序**
1. 关闭业务开关：`agent.dock.enabled=false`、`agent.director.enabled=false`、`agent.suggestions.enabled=false`、`agent.proposals.enabled=false`；必要时 `AGENT_*` 环境变量并重启隔离后端。
2. 移除页面适配器入口（不改后端数据）。
3. 保留三张表与数据，不执行删表；需要彻底回退时由用户批准备份后处理。
4. 提示词可通过 `/prompts/:type/reset` 回退；不影响五个生产 Agent。
