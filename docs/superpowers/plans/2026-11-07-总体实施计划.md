# 全链路工作台总体实施计划

> **给执行者：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行。步骤使用 `- [ ]` 复选框跟踪。

**目标：** 把六份设计稿落成可验收的增量交付：先建基础层，再并行小说、导演、剪辑、智能体四个工作包，最后用页面视觉与智能体建议收口；全程不改现有生产链路。

**架构：** B0 先建共享令牌、壳组件、配置命名空间、七张新表与测试基线；B1 四个工作包按各自内部依赖并行；B2 做智能体建议/导演专员、视觉 U2–U5 与可选 N4；K1–K4 共用时间线内核和 E5/P3b 成片中心单独立项。

**技术栈：** Nuxt 3 + Vue 3.5（SPA）、Hono、Drizzle + better-sqlite3、FFmpeg、Node `node:test` + `tsx`、Vue I18n 四语言。

## 全局约束

- `reference/` 只读；不修改、不复制、不提交其中任何文件。
- **不提交、不构建/打包、不安装依赖、不重启应用**，除非用户明确要求；所有改动默认保持未提交。
- 不打印或泄露任何 Key、Token、DSH 密码或 `ps ssh` 输出。
- 保持端口不变：前端开发 3013，后端开发 5679；不改 G5、MCP、ComfyUI 模板与现有路由。
- 数据库只做加法：新表、新索引、新列；不改旧列语义，不做破坏性迁移。
- 所有新能力默认走安全开关：导演台 `off`、剪辑沿用现有 `edit_workspace`、智能体提案可关闭；关闭后旧页面行为不变。
- 面向用户的文案使用中文，并同步 `zh/en/ja/ko` 四份 locale；技术标识、表名、接口名保持英文。
- 不新建第二套时间线、播放器、成片列表、智能体独立页面。
- 后端测试必须使用隔离的 `SQLITE_PATH`、`HUOBAO_DATA_DIR`、`STORAGE_PATH` 与 `MYSQL_AUTO_IMPORT=false`，不得触碰开发库。
- 每个任务结束记录验证结果；没有运行证据不得标记完成。
- **计划正文只写要求、约束、参考、设计、自测与验证，不写实现代码。** 代码实现是执行者在每个计划点内按设计完成的具体动作，不进入计划正文。
- 计划点固定使用六段式：要求、约束、参考、设计、自测、验证；需要时补“完成定义”。

## 3. 跨包共享契约

### 3.1 配置命名空间

基础层一次性建立以下命名空间；业务包只消费，不重复定义默认值。

| 命名空间 | 键数 | 归属计划 | 关键默认 |
| --- | --- | --- | --- |
| `ui.*` | 6 | 视觉 U2 | density `compact`、motion `system`、readingFont `serif`、readingSize `16`、actionLabels `true`、allowUserOverride `true` |
| `director.*` | 11 | 导演 D0 | mode `off`、view.default `2d`、view3d.enabled `true`、duration 8–15s、fps 24、maxShots 200、previs 20 |
| `edit.*` | 11 | 剪辑 E0c/E3/E4 | export.enabled `true`、defaultPreset `auto`、subtitleMode `soft`、audioSource `auto`、requireAlignedMix `false`、concurrency `1`、ux.contextMenu/markers/subtitleStyles `true`、filmSources `false` |
| `agent.*` | 18 | 智能体 A0 | dock.enabled `true`、director.enabled `true`、stream.enabled `true`、proposals/suggestions `true`、maxSteps `8`、timeoutSec `120`、context.maxChars `12000`、message.maxChars `4000`、tools.maxResultChars `6000`、history.maxMessages `20`、retentionDays `30`、model 空 |

规则：
- 每个命名空间提供 `DEFAULTS`、`sanitize*`、`get*`、`set*` 四个导出；设置接口挂在 `backend/src/routes/settings.ts`。
- 数值越界 clamp，枚举非法回退默认，未知键忽略；`agent.message.maxChars <= agent.context.maxChars` 不满足时拒绝保存（400）。
- `agent.pages`、`director.apply.fields`、`agent.proposals.types`、`agent.suggestions.actions` 只允许规格白名单子集，非法配置拒绝保存。
- 环境变量优先级高于数据库，只用于紧急回滚；`AGENT_*`/`EDIT_*` 为 `off` 时强制关闭；保存时不得把环境变量值落库；不做进程内热更新。

### 3.4 错误与响应

- 成功统一 `success(c, data)`；参数错误 `badRequest`；未找到 `404`；状态冲突 `409`；只读/关闭 `403`；业务校验失败 `422`；提案过期或目标已删除 `410`。
- 业务错误使用现有 `EditWorkspaceError` 或同等结构，返回稳定 `code` 与中文 `message`。
- 前端不根据 HTTP 文本猜错误，按 `code` 分支；未知错误显示通用提示并保留原始 `message`。

### 3.5 测试基线

- 后端单测：`cd backend && npx tsx --test tests/<file>.test.ts`。
- 后端类型：`cd backend && npm run typecheck`。
- 全量后端：`cd backend && npm test`。
- 前端构建：`cd frontend && npm run build`；**执行前需用户批准**。
- 前端手工验证：`cd backend && npm run dev` + `cd frontend && npm run dev`，浏览器 `http://localhost:3013`。
- UI 自测使用复制数据库，不操作开发库；截图保留日期与路径。

## 4. 完成定义

一个任务只有在以下四项都满足时才算完成：

1. 新增/修改的行为有对应测试，或明确说明无法自动测试并给出手工步骤。
2. 相关测试命令实际运行并通过，输出被记录。
3. 关闭开关/回退配置后，旧页面与旧接口行为不变。
4. 没有提交、没有构建/安装/重启，除非用户另行批准。

一个工作包只有在以下三项都满足时才算完成：

1. 业务计划内的验收清单逐项通过。
2. 兼容性检查通过：旧接口、旧页面、旧数据不受影响。
3. 回滚路径可执行：关闭开关或删除新增入口即可回到交付前状态。

## 6. 风险与回滚

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 七张表一次性建表出错 | 所有工作包被阻塞 | 基础层先跑幂等测试；只加表不改旧表 |
| 配置命名空间互相覆盖 | 设置保存失败或默认值错 | 每命名空间独立前缀与清洗；单测覆盖 |
| 导演 3D 依赖未安装 | D3 无法启动 | 依赖安装单列并需批准；加载失败回退 2D |
| 剪辑状态契约改动影响现有导出 | 导出按钮/进度异常 | 保留现有导出接口；只加字段；测试覆盖只读/旧工程 |
| 智能体写入越权 | 业务数据被改 | 只读工具 + 三类提案 + 服务端快照/冲突检测 |
| 视觉改造碰大文件 | 剧集页回归 | 只改顶栏块与触碰弹窗；按块 diff |
| 并行工作包改同一文件 | 冲突 | 基础层先建表/配置；业务包只改各自文件 |

回滚顺序：
1. 关闭业务开关（`director.mode=off`、`AGENT_DOCK=off`、`edit.export.enabled=false`）。
2. 移除页面入口（不改后端数据）。
3. 保留新表与新数据，不执行删表；需要彻底回退时再由用户批准备份后处理。
