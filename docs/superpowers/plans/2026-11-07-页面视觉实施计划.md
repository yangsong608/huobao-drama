### 1.2 D5 裁决与消费边界

总体计划 §1 的 D5 裁决为：**U0/U1 由基础层交付，视觉包只做 U2–U5**。因此本计划只消费以下已交付契约，不重新定义：

| 契约 | 基础层交付 | 本计划用法 |
|---|---|---|
| 设计令牌 | `studio.css` 追加的字号、行高、字体、控件高度、密度、动效、焦点、阅读令牌 | 页面与组件只引用令牌名，不写裸字号、裸时长、裸色值 |
| 工具类 | `focus-ring`、`text-meta`、`text-title`、`reading` | 需要时使用；不新增第二套工具类 |
| 壳组件 | `StudioTopBar`、`InspectorPanel`、`EmptyState`；`StudioStatusBar` 可选 | U3 剧集顶栏、U4 空态、U5 新页面 |
| 配置命名空间 | `ui.*` 六个键：`ui.defaults.density`、`ui.defaults.motion`、`ui.defaults.readingFont`、`ui.defaults.readingSize`、`ui.defaults.actionLabels`、`ui.allowUserOverride` | U2 读取与保存；不新增第七个服务端键 |
| 设置接口 | `GET /settings/ui`、`PUT /settings/ui`，返回 `defaults` 与 `allowUserOverride` 两个字段 | U2 消费；实际 HTTP 路径为 `/api/v1/settings/ui` |
| 运行属性 | 根节点 `data-density`、`data-motion`；阅读模式 `data-reading` | U2 写入与验收；不改 `data-theme` |

`ui.allowUserOverride=false` 时，忽略设备偏好并强制使用部署默认值；设备偏好数据保留，不自动删除，恢复开关后仍可读取。

### 1.7 完成定义

一个任务只有同时满足以下四项才算完成：

1. 新增或修改的行为有对应结构测试，或明确说明无法自动测试并给出手工步骤与预期。
2. 相关命令实际运行并通过，输出与证据路径被记录。
3. 关闭偏好或回退配置后，旧页面与旧接口行为不变。
4. 没有提交、没有构建/安装/重启，除非用户另行批准。

一个阶段只有同时满足以下三项才算完成：

1. 本阶段自测与验证逐项通过。
2. 兼容性检查通过：旧路由、旧页面、旧数据、旧主题不受影响。
3. 回滚路径可执行：清除 `huobao:ui-prefs`、关闭 `ui.allowUserOverride`、回退 `data-density`/`data-motion` 或还原单页块即可回到交付前状态。

- 顶栏忙碌态：生成中、保存中、导出中沿用现有状态；按钮文字与禁用条件不变；禁用时保留 `title` 原因，并在顶栏或按钮旁显示一行 12px 说明。
- 资产/分镜状态：空、加载、失败、已选中、已绑定；空态使用 `EmptyState` 或现有空态块，文案沿用现有键。
- 弹窗状态：打开、编辑中、保存中、校验失败、关闭；关闭按钮有可访问名称；主按钮在保存中显示进行态并禁用重复提交。
- “更多”菜单：关闭、打开、键盘高亮；菜单项与常显按钮共享禁用条件；菜单层使用 `--z-menu`，不被顶栏或弹窗遮挡。

**交互**

- 返回、配音、剪辑、交付、刷新、任务、模型选择的事件与参数保持原样；移动到“更多”菜单的项必须保留原处理函数与禁用条件。
- 顶栏操作在 1280×800 下全部可点；溢出时按“省略可选元信息 → 收低频操作进更多菜单 → 截断标题”的顺序处理，不换行。
- 弹窗打开后 Tab 顺序在弹窗内可完成主要操作；关闭按钮可用键盘触发；破坏性操作沿用现有确认，确认按钮写动作名。
- 主操作显示文字（如“开始拆镜”“生成视频”“交付”），不只图标；图标按钮保留 `title` 与 `aria-label`。
- 禁用按钮不只降低透明度：保留 `title`，并在可见位置显示 12px 原因；原因文案来自现有禁用条件，不新增业务判断。
- 步骤条点击仍跳转现有子步骤；资产/分镜卡片点击仍打开现有详情或选择；不改变拖拽、快捷键与时间线操作。

**响应式**

- 1280×800 为硬门槛：顶栏不换行、不溢出；时间线可视轨道数不因顶栏变矮而减少超过 1 条；需要时隐藏可选状态条，不压缩时间线命中区。
- 窄屏沿用现有纵向堆叠规则；顶栏在窄屏可分行，但不得遮挡主内容或产生横向滚动。
- 弹窗最大高度沿用 `.dialog` 的视口约束，正文独立滚动，底部操作始终可见。

**可访问性**

- 返回、关闭、帮助、任务、模型选择、图标操作全部有可访问名称；图标按钮同时有 `title` 与 `aria-label`。
- 所有可交互元素有 `:focus-visible` 焦点环，使用 `--focus-ring`；不自绘无焦点样式。
- 步骤条、资产卡、分镜卡的状态不只靠颜色：选中同时有背景与指示条，完成/进行中同时有图标或文字。

## 4. 视觉验收

### 4.1 字号层级

| 角色 | 令牌 | 值/行高 | 使用范围 |
|---|---|---|---|
| 页面标题 | `--text-h1` | 18 / 1.3 | 项目页、设置页、详情页 H1 |
| 区块标题 | `--text-h2` | 15 / 1.4 | 卡片、面板、分组标题 |
| 强调正文 | `--text-strong` | 14 / 1.55 | 关键说明、空态标题 |
| 界面正文 | `--text-body` | 13.5 / 1.6 | 表单、列表、对话 |
| 控件标签 | `--text-label` | 12.5 / 1.3 | 按钮、标签、字段名 |
| 元信息 | `--text-meta` | 12 / 1.4 | 时间、数量、状态、提示 |
| 微型标签 | `--text-micro` | 11 / 1.35 | 仅 eyebrow / 全大写分组名 |
| 阅读正文 | `--text-reading` | 16 / 1.85 | 小说章节、长文预览 |
| 等宽数字 | `--text-mono` | 12.5 / 1.5 | 时间码、帧号、码率 |

- 新代码与本次触碰块不出现 9px/10px；最小 11px 且只用于 eyebrow。

- 页面标题不放大到 2rem 以上；全屏工作台标题用 14–18px。
- U5 新页面同表执行，不另立字号。

### 4.2 顶栏与外壳

- 剧集、剪辑、混音、导演台页签内工具栏均为 44px 平铺、左右 16px、1px 下边框；不再使用卡片式顶栏。

- 检查器头部 40px、正文独立滚动、底部固定；空态统一 `EmptyState`。
- 每个顶栏最多一个主操作；其余为次按钮或“更多”菜单；不新增业务按钮。

### 4.3 空态统一

### 4.4 焦点环可见

- 所有可交互元素必须有 `:focus-visible` 焦点环，统一使用 `--focus-ring`。
- 不允许 `outline: none` 后不补焦点样式；自绘按钮、卡片菜单、筛选 chip、设置导航、弹窗关闭、交付操作、导出按钮全部覆盖。

- U4 抽样 30 个元素全部通过；记录元素、页面、焦点可见、环颜色、Tab 顺序。

### 4.5 对比度 AA

- 正文、元信息、标签、状态说明达到 WCAG AA：普通文字不低于 4.5:1；18.66px 以上或 14px 粗体不低于 3:1。
- 元信息使用 `--text-2`；`--text-3` 只用于禁用、装饰、分隔符，不承载 11–12px 信息文字。
- 浅色底上的 11–12px 橙色文字使用 `--accent-text-strong`；暗色主题使用其暗色值。
- 状态 chip 的文字颜色与其背景达到 AA；不达标的 chip 调整文字色或背景，不改品牌主色。
- 记录实测比值与测量方法；不以肉眼判断代替。

### 4.6 减少动效

- 系统开启“减少动态效果”或用户选择“减少动效”时，淡入、位移、缩放停止；只保留透明度瞬时切换。

- 减少动效下不出现布局抖动与焦点丢失。

### 4.7 四语言无缺失

## 6. 风险与回滚

### 6.1 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 剧集页面过大，改顶栏引发意外回归 | 高 | 只替换顶栏块；改前截图；按块 diff；不改全局选择器 |
| 顶栏变矮导致时间线可视区域变化 | 中 | 1280×800 验收；状态条可选；必要时隐藏可选状态条，不压缩命中区 |
| 阅读衬线字体缺失或渲染差异 | 中 | 完整回退栈；中英日韩各测一段；缺字回退无衬线 |
| 密度偏好影响表单布局 | 中 | 密度只作用于列表/表单/卡片行高，不改字号、不改时间线 |
| 对比度调整改变品牌观感 | 低 | 只改小字橙色与元信息灰色；主色、按钮、图标不变 |
| 设置页签插入影响现有 tour | 低 | 插在“关于”前；现有 tour 只依赖第 1 项；新增页签不加 tour |
| 共享组件过度抽象 | 中 | 只消费基础层四个壳；不内建业务；页面插槽传操作 |
| 导演台/智能体实现晚于 U5 | 中 | U2–U4 独立完成；U5 记录阻塞，不伪造页面；待页面交付后补终验 |
| 字体/密度偏好导致首帧闪烁 | 低 | 模块顶层同步写 `data-*`；缓存 `huobao:ui-defaults` |
| 临时类清理误删既有样式 | 中 | 只删本计划引入且确认无引用的类；不做全局 purge；清理后逐页截图 |

### 6.2 回滚

| 项 | 回滚方式 | 保留内容 |
|---|---|---|
| 设备偏好异常 | 设置页“恢复默认”或清除 `huobao:ui-prefs`；回到部署默认 | 部署默认值与缓存不删 |
| 用户覆盖需要强制关闭 | 设置 `ui.allowUserOverride=false`；设备偏好不生效 | `huobao:ui-prefs` 保留，恢复开关后可再用 |
| 密度异常 | 根节点 `data-density` 回到 `compact` 或移除 | 旧行高与布局不变 |
| 动效异常 | 根节点 `data-motion` 回到 `system`/`full`，或移除 reduced 规则 | 旧动画恢复；spinner 不受影响 |
| 阅读排版异常 | 移除 `data-reading` 或回退 `novel.css` 追加块 | 现有 `.md-body` 默认规则保留 |
| 单页视觉异常 | 还原该页一个组件/样式块 | 旧类名、旧 DOM 结构、旧事件保留 |
| 顶栏/弹窗异常 | 还原顶栏块或触碰弹窗块 | 其余页面与弹窗不受影响 |
| 设置页签异常 | 移除 `ui` 页签与对应块 | 第 1 项仍为 AI；tour 不受影响 |
| 新页面视觉异常 | 由对应工作包关闭入口或回退页面块 | 不改数据与路由；不新增视觉开关 |

回滚原则：

- 先关闭显示偏好或移除页面块，再考虑改令牌；不通过全局缩放兜底。
- 保留旧样式与页面结构，逐页、逐块回退；不删除旧类名直到验收通过。
- 路由、数据、业务接口无需回滚，因为本计划不改它们。
- 任何页面在 1280×800 下出现内容溢出，必须回退该页改造，不允许用全局缩放兜底。
