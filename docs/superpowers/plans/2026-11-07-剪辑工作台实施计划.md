# 剪辑工作台实施计划（E0c、E3、E4）

> **给执行者：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按计划点逐项执行。每一步的实现代码由执行者在执行时编写，本文件只定义要求、约束、参考、设计、自测与验证；计划正文不包含实现代码。

**目标：** 在现有剪辑导出服务之上收口 E0c、E3、E4：把状态契约、能力门禁、预设与画幅口径改成真实可用；让混音对齐状态在剪辑台与音频工作台之间同源；让导出可选混音、剪辑原声或静音；补齐片段级右键、标记与字幕样式门禁。不重写导出、不新建第二套时间线、不做 K1–K4 共用内核。

**架构：** 保留现有 `/episodes/:id/edit/render` 与 `/episodes/:id/edit/render/:exportId` 路由，只扩展请求体、返回体与内部生命周期。新增只读的 `edit-mix-sync.ts` 作为混音与剪辑对齐事实源，`createMixRevision()` 在创建混音版本时写入两个同步哈希；`edit-export-service.ts` 增加音频来源、复用、磁盘、取消、重试与并发上限；`renderEditVideo()` 增加外部音轨与中止信号。前端在现有顶栏、导出对话框、时间线与检查器上增量改造，继续复用现有命令栈、播放器与混音工作台。

**技术栈：** Nuxt 3 + Vue 3.5（SPA）、Hono、Drizzle + better-sqlite3、FFmpeg、Node `node:test` + `tsx`、Vue I18n（zh/en/ja/ko）。

- 预设与画幅：canonical 预设键、`auto` 解析、`square-hd`、旧键别名、1:1 工程设置修正。
- 状态契约：`renders.latest/items`、`audio.mix_revision_id`、`capabilities.can_export/export_blocked_reason`。
- 能力门禁：顶栏导出按钮、设置页“剪辑与导出”卡片、`settingsAPI.edit/saveEdit`。
- 导出前置：不支持字段阻断、最大时长、磁盘估算与 507、复用键与 `reused`。
- 导出生命周期：取消、失败重试、删除保护、进度恢复、全局并发上限。
- 混音同步：`edit-mix-sync.ts`、`createMixRevision()` 写哈希、`GET /mix` 返回 `edit_sync`。
- 双工作台镜像：剪辑台混音胶囊可点击、原因展开、去混音；音频工作台镜像胶囊与回到剪辑台。
- 导出音频：`auto/mix/clip/silent` 四来源、外部 WAV、混音过期原因、`requireAlignedMix`。
- 片段级右键：在播放头分割、删除、波纹删除，并与现有帧级菜单共存。
- 标记：播放头添加、列表跳转、上一个/下一个、删除、标尺旗标、快捷键。
- 字幕门禁：`edit.ux.subtitleStyles` 控制样式区显示；文本、时间、跟随不受影响。
- 四语文案。

### 2.2 非目标与延期项

本批不做：

- 不重写 `edit-timeline.ts`、`edit-commands.ts`、`edit-render-plan.ts` 的既有归一、裁剪、变速、空隙、淡化、硬切、字幕封装能力。
- 不实现溶解转场、滤镜、叠加轨、缩放位移渲染；遇到这些字段直接阻断并给出中文原因。
- 不实现 K1–K4：多选/框选、J/L 切、交叉淡化、音量包络、标记增强。
- 不实现 E5/K5/P3b 成片中心接入与 `edit.filmSources.enabled`。

- 不实现“混音过期时自动重新生成混音”；只提示并提供去混音入口。

### 2.3 完成定义

E0c 完成时：

- `GET /episodes/:id/edit` 返回真实的 `renders.latest/items`、`audio.mix_revision_id` 与 `capabilities.can_export/export_blocked_reason`。
- 只读模式导出按钮禁用并显示原因；`on` 模式且导出开启时可点。
- `auto` 与 `square-hd` 可导出；1:1 工程不再输出竖屏尺寸；旧计划键仍可解析。
- 设置页“剪辑与导出”卡片可读写 10 个键；非法值被清洗。

E4 完成时：

- 快捷键说明同步更新，且不覆盖既有 Space/方向键/S/Delete。

### E0c-4 导出前置校验：阻断、时长、磁盘与复用

**要求**

- 服务端在创建导出记录前完成五类校验：工作台可写、导出开关开启、计划无阻断字段、时长不超上限、磁盘空间足够。
- 阻断字段：`overlays` 非空；任一 `filter.preset != 'none'`；任一 `transform.scale != 1` 或 `transform.x != 0` 或 `transform.y != 0`；任意 `transitions` 非空；任一 `speed` 不在 0.5–2（含边界）。
- 阻断时返回 422 `EDIT_RENDER_UNSUPPORTED`，消息列出字段与片段；不创建记录、不写任何文件。
- 时长超过 `edit.export.maxDurationSec` 返回 422 `EDIT_DURATION_LIMIT`。
- 磁盘不足返回 507 `EDIT_DISK_FULL`；估算包含成片与混音 WAV 中间件。
- 复用：同工程、同计划哈希、同预设、同字幕模式、同音频来源、同混音版本，且最近一条 completed 记录文件存在时，直接返回该记录与 `reused:true`，不创建新记录、不重新渲染。
- 导出记录补齐 `subtitle_hash`、`source_video_hash`、`mix_revision_id`、`plan_revision_id`、`dialogue_sync_hash`；`params_json` 写 `renderMode/audioSource/subtitleMode/setCurrent/preset/title`。

**约束**

- 阻断优先于复用：有阻断字段时即使存在旧文件也不得复用。
- 复用只认最近一条 completed 且未删除、文件存在的记录；文件缺失时继续新建。
- `set_current` 与 `title` 不参与复用键；复用命中且 `set_current=true` 时，把已有记录投影的成片设为当前，不新建记录。
- 磁盘检查失败（`statfs` 不可用）时跳过前置检查，不阻断导出；由渲染失败兜底。
- 不修改 `buildRenderReport()` 的警告用途；新增独立的阻断清单函数，警告仍用于对话框提示“其余降级项”。

### E0c-5 取消、重试、删除保护、进度恢复与并发上限

**要求**

- 剪辑导出持有 `AbortController`；取消时中止当前 FFmpeg 子进程，状态置 `cancelled`，清理临时文件与未完成输出，不投影成片。
- `POST /exports/:id/cancel` 对 `renderMode='edit'` 的记录可用，接受 `pending/running/rendering`；返回最新记录。
- `POST /exports/:id/retry` 对编辑记录回到编辑管线，不调用通用 `scheduleExport()`；重试使用当前保存的计划与当前音频来源参数，更新哈希与版本字段后重新渲染。
- `DELETE /exports/:id` 对 `rendering` 返回 409“导出进行中，请先取消再删除”；对 `cancelled/failed/completed` 保持现有行为。
- 页面刷新后，若最新记录处于 `pending/running/rendering`，顶栏显示进度胶囊，点击打开对话框并恢复轮询；关闭对话框不取消任务。
- 全局并发由 `edit.export.concurrency` 控制（1–2）；达到上限时新请求返回 409 `EDIT_EXPORT_CONCURRENCY`，不排队、不创建记录。
- 单工程互斥保留现有 `EXPORT_ALREADY_RUNNING`。

**约束**

- 取消是用户显式动作；失败与取消必须区分，取消不得被 catch 覆盖为 `failed`。
- 中止后不得留下半成品 MP4 或混音 WAV；最终成片目录只保留 completed 文件。
- 重试不得改变原记录的 `id`；不得创建第二条记录；失败原因清空后重新写入。
- 重试时若计划已被删除或工程不存在，返回 404/409，不崩溃。
- 并发计数只在进程内有效；多进程部署不在本期范围，文档需注明。
- 服务重启收尾逻辑保留：模块加载时把遗留 `pending/running/rendering` 标为失败；不得与取消逻辑冲突。

### E3-3 导出音频来源矩阵

**要求**

- 启动导出接受 `audio_source`：`auto/mix/clip/silent`；非法值返回 400。
- `auto`：`edit_sync.status==='aligned'` → 混音；否则有片段原声 → 原声；两者都没有 → 静音。对话框展示实际选择与原因。
- `mix`：必须存在对齐混音与可渲染混音计划，否则 409 `EDIT_MIX_NOT_ALIGNED`；`requireAlignedMix=true` 时 `auto` 也返回 409，不降级。
- `clip`：使用片段归一后的音轨；无音轨片段补静音；导出不因缺音轨失败。
- `silent`：生成与时间线等长的静音轨。
- 混音音频用 `renderMixAudio()` 输出 24-bit WAV；最终由 `renderEditVideo()` 统一编码 AAC 48 kHz 双声道。
- 导出记录写 `mix_revision_id` 与 `params_json.audio_source`；复用键包含二者。

**约束**

- 不改变现有 `renderEditVideo()` 在无外部音轨时的行为：仍按片段音轨拼接。
- 外部音轨必须按 `computeLayout()` 的 `durationMs` 裁剪/补静音，误差不超过 1 帧；不得让混音长度决定成片长度。
- 混音渲染失败不得静默回退到原声；`auto` 选择混音后失败即失败，用户可改选原声重试。
- 临时 WAV 放在 `temp/edit-render-<exportId>/`；成功、失败、取消后删除，不进入交付中心目录。
- `mix_revision_id` 只在对齐混音实际参与渲染时写入；`clip/silent` 写 null。
- 不新增音频来源配置键；使用基础层 `edit.export.audioSource`。

**参考**

- 设计稿 §4.2、§6.4、§6.6、§6.7、§9 E3、§10.2。

**设计**

- 请求体新增 `audio_source`；`startEditExport()` 解析并校验；`auto` 在服务端解析为 `mix` 或 `clip` 或 `silent`，把解析结果写入 `params_json.audio_source`（保留 `auto_requested` 便于诊断），并据此选择管线。
- 解析优先级：读 `mixSyncStatusOf()`；`aligned` 且存在混音计划 → `mix`；存在任何片段 `source.hasAudio` → `clip`；否则 `silent`。
- `mix` 管线：`compileMixPlan(episodeId, dramaId)` → `renderMixAudio(plan, { outputPath: tempWav, format:'wav', codec:'pcm_s24le', sampleRate:48000, channels:2 })`；若混音计划时长与布局不一致，仍以布局为准裁/补。

**约束**

- 标记时间必须 clamp 到 `[0, layout.duration_ms]`；不得产生负值或超出片尾。
- 标记 id 在计划内唯一；新建时扫描现有 `mk_*` 取最大编号加一，避免与后端 `normalizeMarkers` 的缺省 id 冲突。

## 6. 风险与回滚

| 风险 | 影响 | 缓解 |
|---|---|---|
| FFmpeg 取消依赖子进程 signal | 取消后进程残留或半成品 | `execFile` signal + `finally` 清理；短片段与长片段各验证一次 |
| 外部音轨长度与布局不一致 | 成片时长漂移、音画不同步 | 以 `computeLayout()` 为唯一基准，`atrim`/`apad` 到帧；导出后 ±1 帧校验 |
| 混音哈希写入改变现有混音语义 | 旧混音被判过期 | 只在创建时写；旧行保持 null 并显示 `legacy_mix`；不回填 |
| 阻断转场影响现有用户 | 已有溶解计划的导出被拒绝 | 对话框提前列出阻断项；错误文案说明“溶解将在后续版本支持”；默认计划为硬切 |
| `square-hd` 扩展配置枚举 | 基础层清洗拒绝或前端选项缺失 | E0c-1 与 B0-4 对齐；缺失时扩展清洗并补测试 |
| 复用键漏字段 | 命中错误成片 | 复用键含计划哈希、预设、字幕模式、音频来源、混音版本；删除文件不复用 |
| 并发计数泄漏 | 后续导出一直 409 | 成功/失败/取消/重启四条路径统一 `finally`；测试覆盖 |
| 取消与重启收尾竞争 | 状态被覆盖为 failed | catch 先读当前状态；cancelled 不覆盖 |
| 设置卡片与视觉 U4 同文件冲突 | 合并冲突或样式回退 | 本期只改 `general` 卡片块；U4 在其后执行；按块 diff |
| 标记 id 与后端缺省 id 冲突 | 保存后重复 id | 前端扫描 `mk_*` 递增；后端 normalization 只兜底缺省 |
| 只读模式仍可导出 | 数据被写 | 路由 `getWritableEpisode()` 先于 body 解析；状态 `can_export=false`；测试覆盖 |

回滚顺序：

1. 设置 `edit_workspace=readonly` 或 `EDIT_EXPORT=off`，立即隐藏导出入口并拒绝写请求；已有成片保留。
2. 设置 `edit.ux.contextMenu=false`、`edit.ux.markers=false`、`edit.ux.subtitleStyles=false`，隐藏新增 UI。
3. 移除前端新增按钮/标尺旗标（不改后端数据）。
4. 保留 `episode_exports` 与 `mix_revisions` 新写入字段，不删列、不回填；需要彻底回退时由用户批准备份后处理。
