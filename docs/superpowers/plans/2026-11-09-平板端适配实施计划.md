# 平板端适配实施计划

> **给执行者：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行。步骤使用 `- [ ]` 复选框跟踪。

**目标：** 在不改后端、数据库与桌面壳的前提下，让火宝短剧在 744–1366 像素平板浏览器中以 PWA 方式完成「建项目—拆分镜—生成—审片—剪辑—混音—导出」主链路；桌面端 1181 像素以上保持现状，手机端小于 744 像素不列入本轮承诺。

**架构：** 前端增量响应式加触控交互层，复用现有页面、播放器与时间线；PWA 只缓存应用壳与静态资源，业务数据仍走同源 `/api/v1`；平板通过现有服务器部署（前端静态与接口同源，端口 5679）经 HTTPS 反向代理访问；使用本地参考图或音色时，另需配置 `PUBLIC_BASE_URL` 并让上游服务能只读访问 `/static`，否则生成会失败；Electron 桌面壳不参与本轮改造。

**技术栈：** Nuxt 3 + Vue 3.5、原生 CSS 媒体查询与容器查询、Pointer Events、Web App Manifest、Service Worker、Web Share API、Node `node:test` 结构测试；Playwright 仅可作为开发依赖且需单独批准。

**设计依据：** 本轮可行性分析结论与 2026-11-09 代码实测；关键证据见第 0 节现状校准。现有分镜拆分方案文档的格式与验收口径作为本计划的编写基准。

## 全局约束

- 只改 `frontend/`、`frontend/tests/` 与 `docs/`；后端路由、数据库、Electron 主进程、Docker 端口与 ComfyUI 模板零改动；`PUBLIC_BASE_URL` 只作为部署环境变量由运维配置，不在仓库、前端或文档中写入真实值。
- 桌面端 1181 像素以上视觉与交互保持现状；所有新增适配规则必须限定在 `max-width: 1180px`、`max-width: 900px`、`max-width: 744px`、仅用于小于 744 边界的 `max-width: 743px` 或 `(hover: none) and (pointer: coarse)` 内；混音工作台容器查询 1180/960，以及仅在 `max-width: 1180px` 内生效的 900 档容器查询与短横屏 `(max-height: 700px)` 是仅有的例外。
- 手机端小于 744 像素不承诺工作台可用；只保证浏览页无横向溢出、弹窗可关闭、不出现不可返回的死路。
- 不新增运行时依赖。PWA 使用原生 Service Worker、Manifest 与 Web Share；时间线缩放复用现有 zoom 状态。Playwright 只能作为开发依赖，且安装前需用户批准。
- 不新建第二套页面、编辑器、播放器或时间线；全部在现有组件内做响应式与触控增强。
- 不做离线写入、不做本地数据库、不做原生移动壳、不做推送与后台同步。
- 平板访问必须经 HTTPS 反向代理与访问控制；应用本身不新增登录体系；不得把 5679 端口直接暴露到公网。
- 触控主要操作目标不小于 44×44 CSS 像素，次要操作不小于 36×36；触控设备上的文本输入字号不小于 16 像素，避免 iOS 聚焦放大。
- 长按阈值固定 500 毫秒、位移阈值 8 像素，仅对粗指针生效；长按是附加入口，不得替代可见按钮、右键菜单或键盘操作。
- 双指缩放只作用于时间线与画布；页面整体缩放保留，不设置 `user-scalable=no`。
- 新增文案同步 `zh/en/ja/ko` 四份 locale；技术标识、接口名与表名保持英文；不得在组件内硬编码中文。
- 不提交、不构建、不安装依赖、不重启应用，除非用户明确要求；构建与安装分别需要批准。
- 没有运行证据不得标记完成；缺少文本模型、视频模型或 TTS 时，相应验收标记阻塞，不以结构测试替代。
- 不读取、打印或提交任何密钥、Token、密码与内网地址。

## 1. 口径裁决

| 编号 | 歧义/冲突 | 裁决 | 理由 |
| --- | --- | --- | --- |
| C1 | 平板用原生壳还是 Web | 本轮只做 PWA 同源 Web，不做原生壳 | 后端依赖 Node、SQLite 与 FFmpeg，无法塞进纯移动端；PWA 可安装、可全屏、可缓存壳 |
| C2 | 目标设备范围 | 744–1366 CSS 像素平板，横竖屏都支持 | 覆盖 iPad mini 到 iPad Pro 与常见安卓平板；小于 744 属于手机 |
| C3 | 手机是否顺带适配 | 不承诺；只保证不横向溢出、弹窗可关闭 | 工作台信息密度高，强行适配手机会拖垮本轮 |
| C4 | 桌面是否允许微调 | 1181 像素以上保持现状，不做视觉升级 | 平板改造不应成为桌面改版，避免回归面失控 |
| C5 | 断点如何统一 | 新增宽度断点为 1180、900、744 三档，另用 743 作为小于 744 的隐藏边界；现有 1080 外层堆叠保留；混音继续使用容器查询 1180/960，并新增仅在 ≤1180 视口生效的 900 档容器查询用于检查器抽屉，短横屏用 `max-height:700` 补充 | 现有 1080/860/720 断点保留语义但不作为新代码入口；配音页 1100 隐藏规则在 P9 删除并由 1180/900 取代 |
| C6 | 页面高度怎么处理 | 应用壳与工作台用 `dvh` 加安全区；浏览页自然滚动 | 只改根容器，避免把弹窗与内部滚动区一起改坏 |
| C7 | 触控菜单如何触发 | 长按 500 毫秒加可见「更多」按钮；右键与键盘保留 | 长按不可发现，必须给新手可见入口 |
| C8 | 拖拽是否重写 | 沿用现有 Pointer Events，只补指针捕获、取消清理与触控命中区 | 现有编辑命令、吸附与历史栈稳定，重写风险高 |
| C9 | 是否禁止页面缩放 | 不禁止；只对时间线与画布启用双指缩放 | 禁止缩放损害可访问性，iOS 也不会完全遵守 |
| C10 | 离线能力边界 | 只缓存应用壳与静态资源；接口与媒体不缓存；不做离线写入 | 业务数据在服务端，离线写入会制造冲突与假成功 |
| C11 | 平板如何鉴权 | HTTPS 反向代理前置于访问控制（VPN、零信任或反代登录）；应用不加登录 | 当前应用无用户模型，临时加登录会牵动全库与全部接口 |
| C12 | 上传下载是否改造 | 沿用现有接口与 50MB/20MB 限制；客户端预检；分享走 Web Share | 分片上传与断点续传不在本轮范围 |
| C13 | 是否引入 PWA 框架 | 不引入；手写 manifest 与 Service Worker | 避免新增运行时依赖与构建插件，保持 Nuxt 生成产物不变 |
| C14 | 是否改后端 | 零改动 | 同源静态、Range、SSE 与上传接口已满足本轮需求 |
| C15 | 小说工作台范围 | 只保证小说列表、详情与章节选择；图谱精细编辑不验收 | 本轮主链路是短剧生产，图谱触控编辑需要单独设计 |
| C16 | 构建与安装 | 计划阶段不构建；验收阶段的构建需用户批准，安装到设备另行批准 | 与现有工程纪律一致 |
| C17 | 清单文件名与 MIME | 保留 `manifest.webmanifest`；P0 只读复核 Hono 映射，P3 验收响应头；仅当反向代理无法保留 `application/manifest+json` 时才改名 `manifest.json` | `.webmanifest` 是标准扩展且后端已支持；改名会丢失标准 MIME，只作兜底 |
| C18 | 本地参考媒体的公网可达性 | 使用本地参考图或音色时，`PUBLIC_BASE_URL` 必须指向平板同源公网 HTTPS，且 `/static/` 对上游只读放行；否则本轮生成验收标记阻塞，不以云端代测冒充通过 | 上游视频与 TTS 服务必须直接取到参考文件，这是现有后端的硬约束 |
| C19 | iOS 状态栏样式 | `apple-mobile-web-app-status-bar-style` 用 `default` | `black-translucent` 会让内容压到状态栏，浅色主题下可读性差；本轮不做沉浸状态栏 |
| C20 | 分屏与台前调度小于 744 | 视为手机范围，只保证不横向溢出、弹窗可关闭、可退出 | 分屏宽度可变且低于工作台信息密度下限，不为它设计第四套布局 |

### 4.3 PWA 契约

- 清单名称「火宝短剧」，短名称「火宝」，`id` 为 `/`，`lang` 为 `zh-CN`，`start_url` 与 `scope` 均为 `/`，`display` 为 `standalone`，`orientation` 为 `any`，`theme_color` 与 `background_color` 均为 `#f7f8fa`。
- 清单静态主题色不使用品牌橙 `#f97316`，避免安装闪屏与浅色应用壳之间出现橙色跳变；应用内 `<meta name="theme-color">` 跟随 `resolvedTheme` 更新为 `#f7f8fa` 或 `#0b0f16`，两者职责分开。
- 应用只支持部署在源站根路径 `/`，不支持子路径；`start_url`、`scope`、Service Worker 作用域与 `/api` 基址都按根路径计算。
- 图标提供 192、512、512 maskable 与 180 苹果主屏图标；maskable 图标四周保留不少于 10% 安全区。
- iOS 元信息补齐 `apple-mobile-web-app-capable=yes`、`apple-mobile-web-app-status-bar-style=default`、`apple-mobile-web-app-title=火宝`、`mobile-web-app-capable=yes` 与 180 像素 `apple-touch-icon`；使用 `default` 状态栏，本轮不做沉浸式状态栏。
- 清单必须由服务器以 `application/manifest+json` 返回；`sw.js` 与清单不得设置 immutable 长缓存，`sw.js` 使用 no-cache 或极短缓存，否则平板无法及时拿到新版本。
- Service Worker 只处理同源 GET；`/api/`、`/static/`、带 Range 的请求、非 GET 请求全部直接放行；离线壳不提供参考媒体与导出文件。
- 导航请求网络优先，超过 3 秒或失败回退缓存的应用壳；`/_nuxt/`、`/icons/`、清单与图标缓存优先并在后台更新。
- 只在生产构建、安全上下文且不存在 `window.huobaoDesktop` 时注册，注册参数使用 `updateViaCache: 'none'`；开发环境与 Electron 桌面壳永不注册。
- `beforeinstallprompt` 必须在 `pwa.client.ts` 启动阶段就捕获并存入模块级状态，不能等组件挂载后才监听；`appinstalled` 后清除可安装标记。iOS 没有该事件，改为显示「分享 → 添加到主屏幕」说明。
- 不调用 `skipWaiting` 与 `clients.claim` 强制接管；新版本就绪时只提示「新版本已就绪，保存后重新打开」，由用户重启应用完成更新。
- 离线状态以 `/api/v1/health` 连续两次失败为准（单次超时三秒），不以 `navigator.onLine` 单独判定；离线只提示，不阻止用户继续编辑，写操作失败时统一提示。

### 4.4 文案契约

新增键统一放在 `tablet` 命名空间，至少包含：页签「镜头 / 编辑 / 预览」、抽屉「素材 / 检查器 / 参数 / 步骤」、动作「更多 / 关闭 / 重置布局 / 分享 / 下载 / 安装到主屏 / 返回」、状态「离线模式 / 离线提示 / 新版本已就绪 / 横屏观看更佳 / 触控提示」、上传提示「视频不超过 50MB / 音频不超过 20MB / 文件过大请先裁剪 / 请选择 JPEG、PNG 或 WebP」、分享提示「当前浏览器不支持文件分享，已改为链接」、音频提示「点击播放启用声音」。四份 locale 键集合必须一致，结构测试逐语言比对。

### 4.5 部署与访问契约

- 拓扑固定为「平板 → HTTPS 反向代理 → 同源应用」；反向代理同时转发页面、`/api` 与 `/static`，不得拆分域名。后端 CORS 白名单只有 `localhost:3013` 与 `5679`，平板必须靠同源反代，不能把 API 指到另一个域名。
- 应用只部署在源站根路径 `/`；反代不得添加子路径前缀，否则 `start_url`、Service Worker 作用域与接口基址全部失配。
- PWA 安装要求安全上下文，平板入口必须是 HTTPS；证书与访问控制由反代负责，应用不加登录。
- 代理必须透传 Range 并返回 206；`/api/v1/novel-jobs/*/stream` 必须关闭响应缓冲；请求体上限不低于 64MB；静态资源启用 gzip 或 brotli。
- `manifest.webmanifest` 必须以 `application/manifest+json` 返回；`sw.js` 使用 no-cache 或极短缓存，`index.html` 不得长缓存，`/_nuxt/` 哈希资源才可 immutable。反代改写 MIME 或缓存头会直接破坏安装与更新。
- 使用本地参考图或音色时，后端部署环境必须设置 `PUBLIC_BASE_URL` 为平板访问的同一公网 HTTPS 源，并保证上游视频与 TTS 服务能在无交互认证下 `GET /static/...`；否则 `generation.ts` 与 `reference-audio.ts` 会直接报错，前端无法补救。
- `/static` 的访问控制只有两种可接受口径：一是对 `GET /static/` 只读放行，依赖随机文件名做弱保护，并在验收中记录该风险；二是继续拦截，但本轮不使用本地参考媒体，相关生成验收标记阻塞。不得为了验收成功而临时关闭访问控制或伪造云端结果。
- 访问控制放在反向代理层，可选 VPN、零信任或反代登录；5679 只允许本机或受信内网访问，禁止公网直连。
- 说明文档记录 iPad Safari 与安卓 Chrome 的安装、更新、清缓存、`PUBLIC_BASE_URL` 配置与已知限制，不写入任何真实密钥或内网地址。

### 4.8 覆盖层与返回键契约
