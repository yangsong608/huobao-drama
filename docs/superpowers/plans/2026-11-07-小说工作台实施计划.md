# 小说工作台实施计划（N0–N4）

> **给执行者：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按计划点逐项执行。每一步的实施代码由执行者在执行时编写，本文件只定义要求、约束、参考、设计、自测与验证。

**目标：** 把现有小说详情页的“写作”页签升级为可长期使用的三栏工作台：左章节树、中写作区、右批注/伏笔/上下文检查器，并让批注、伏笔与上下文包进入导入链路。

**架构：** 复用现有 `novels`、`novel_chapters` 数据与 `ChapterWriterPanel` 的章节加载、自动保存、409 冲突逻辑；新增工作台聚合接口、批注与伏笔两组 CRUD、上下文包预览接口；前端以 `NovelWorkbenchShell` 组合章节树、写作区与检查器。批注不修改正文，伏笔是独立看板，上下文包只读聚合。

**技术栈：** Nuxt 3 + Vue 3.5、Hono、Drizzle + better-sqlite3、Node `node:test` + `tsx`、Vue I18n（zh/en/ja/ko）。

**设计依据：**
- [小说工作台落地方案](../specs/2026-11-06-小说工作台落地方案.md) §3–§8
- [全链路集成与优化方案](../specs/2026-11-06-全链路集成与优化方案.md) §0.5、§3
- [基础层实施计划](2026-11-07-基础层实施计划.md) B0-3、B0-4、B0-5、B0-6
- [页面视觉优化落地方案](../specs/2026-11-06-页面视觉优化落地方案.md) §5

## 1. 范围与非目标

### 1.1 范围

- 小说设置扩展与“写作布局”设置行。
- `NovelWorkbenchShell` 三栏壳，替换详情页写作页签的现有单面板。
- 章节树：章节列表、字数、状态、当前章高亮、搜索、切换。
- 批注：选中文本创建、列表、编辑、解决、删除、锚点重定位、孤儿态。
- 伏笔：看板、创建、编辑、状态流转、证据引用。
- 上下文包：预览、字符预算、按章选择、导入时注入。
- 角色档案：只读聚合（可选交付）。

### 1.2 非目标

- 不改章节生成、蓝图生成、导出、灵感罗盘等既有能力。
- 不做多用户协同、评论回复、版本对比。
- 不让批注参与 409 冲突判断。
- 不做全文搜索引擎；章节树搜索只匹配标题与摘要。
- 不新增独立页面路由；工作台仍在 `/novels/:id` 的写作页签内。

### 1.3 完成定义

- 作者可在同一屏完成“选章—写作—加批注—看伏笔—生成上下文包”。
- 批注在正文编辑后仍能定位；无法定位时进入孤儿态且不丢失内容。
- 伏笔状态只能按允许的路径流转。
- 上下文包预览与导入实际注入一致，超预算时有明确截断提示。
- 后端测试、类型检查通过；前端沿用现有页面壳，无明显布局回退。

## 3. 计划点

### N0 设置扩展与工作台入口

**要求**
- 扩展小说设置，新增十个工作台配置键，并在设置页“小说”页签提供“写作布局”行。
- 写作页签入口改为工作台骨架：`split` 渲染三栏空壳，`tabs` 回退现有单面板；数据接入由 N1-1 完成。

**约束**
- 新键必须进入默认值、清洗、读取、写入与序列化；旧键默认值与行为不变。
- 设置页只新增一行布局选择，不新增独立设置页或页签。
- 工作台默认布局为 `split`；窄屏自动折叠右栏，不强行三栏。
- 配置读取失败时回退默认值，不阻塞页面。
- 骨架阶段不发工作台接口请求，不改变现有保存逻辑。

**参考**
- 规格：小说工作台落地方案 §4.1、§7。
- 现有设置实现：`backend/src/services/app-settings.ts` 的 `NovelSettings`、默认值、清洗、读写序列化；`backend/src/routes/settings.ts` 的 `/novel`。
- 现有设置页：`frontend/app/pages/settings.vue` 的小说配置区。

**设计**

新增键与默认值（均在 `novel.*` 命名空间）：

| 键 | 默认 | 范围/枚举 | 环境变量 |
|---|---|---|---|
| `novel.workbench.layout` | `split` | `tabs` / `split` | `NOVEL_WORKBENCH_LAYOUT` |
| `novel.workbench.tree` | `true` | 布尔 | — |
| `novel.annotations.enabled` | `true` | 布尔 | `NOVEL_ANNOTATIONS=off` |
| `novel.annotations.anchorWindow` | `200` | 20–1000 | — |
| `novel.foreshadow.enabled` | `true` | 布尔 | `NOVEL_FORESHADOW=off` |
| `novel.foreshadow.autoExtract` | `false` | 布尔 | — |
| `novel.contextPack.enabled` | `true` | 布尔 | `NOVEL_CONTEXT_PACK=off` |
| `novel.contextPack.includeAnnotations` | `true` | 布尔 | — |
| `novel.contextPack.includeUnresolved` | `true` | 布尔 | — |
| `novel.contextPack.maxChars` | `4000` | 500–20000，超出按整句截断 | — |

布局语义：
- `tabs`：不加载三栏组件，保留现有写作页签的单面板与章节下拉，作为回退。
- `split`：左章节树 + 中写作区 + 右检查器。

骨架语义：
- 左栏 240px：章节树空态；中栏自适应：写作区占位；右栏 320px：检查器空态。
- 空壳只使用共享壳组件与基础层令牌，不发起接口请求。
- 窄于 960px 收起左栏；窄于 720px 右栏改为抽屉。

降级：
- `novel.workbench.tree=false` 时左栏默认折叠。
- `novel.annotations.enabled=false` 时隐藏批注入口，但已存批注不删除。
- `novel.foreshadow.enabled=false` 时隐藏伏笔入口，数据保留。
- `novel.contextPack.enabled=false` 时导入对话框隐藏上下文包选项。

**自测**
- 设置页切换 `tabs` 与 `split` 并刷新，确认持久化且工作台按布局渲染。
- `split` 下确认三栏空壳尺寸为 240 / 自适应 / 320，且未发出工作台接口请求。
- `tabs` 下确认现有写作、自动保存与 409 冲突流程完全不变。
- 修改 `novel.annotations.anchorWindow` 越界值，确认被钳制。
- 关闭 `novel.workbench.tree`，确认左栏折叠且可手动展开。
- 关闭 `novel.annotations.enabled`，确认批注入口消失且已有批注数据仍可查询。
- 旧小说设置项逐项读写，确认无回归。

**验证**
- 对照键名、默认值、范围逐项核对。
- 设置接口返回不含密钥。
- 关闭工作台开关后页面仍可用，无报错或空白。

### N1-1 工作台接口、章节树与写作区

**要求**
- 提供工作台聚合接口，一次返回布局、章节元数据、批注、伏笔、人物汇总与计数。
- 在 N0 骨架上接入数据：左栏章节树、中栏写作区；写作区复用 `ChapterWriterPanel`。
- 章节树支持列表、搜索、状态与字数、当前章高亮、切换章节。

**约束**
- 聚合接口只读，不产生副作用。
- 章节树数据量按小说章节数一次性返回；单本超过 500 章时仍只返回元数据，不返回正文。
- 切换章节必须复用现有加载与自动保存逻辑，切换前先落盘未保存内容。
- 现有 `ChapterWriterPanel` 的保存、409 冲突、自动保存行为不得改变。
- 三栏宽度使用基础层令牌；右栏默认 320px，可折叠。
- 不得在组件内直接请求接口；请求集中在 `useNovelWorkbench` 或 `useNovelApi`。
- `novel.workbench.layout=tabs` 时不挂载三栏组件、不请求工作台聚合接口，继续使用现有单面板与章节下拉。

**参考**
- 规格：小说工作台落地方案 §4.2、§5.1、§8。
- 现有页面：`frontend/app/views/novel/detail.vue` 写作页签；`frontend/app/components/novel/ChapterWriterPanel.vue` 的 `loadChapter`、`switchChapter`、自动保存与 409 逻辑。
- 现有接口：`backend/src/routes/novels.ts` 的 `GET /:id`、`GET /:id/chapters`。
- 基础层组件：`StudioTopBar`、`InspectorPanel`、`EmptyState`。

**设计**

聚合接口：`GET /novels/:id/workbench`

返回分组：
- `layout`：来自设置的布局与开关。
- `chapters`：章节号、标题、状态、字数、是否有正文，按章节号升序。
- `annotations`：批注摘要列表。
- `foreshadows`：伏笔摘要列表。
- `characters`：人物汇总列表。
- `counts`：`open_annotations`、`unresolved_foreshadows`。

约束：
- 不返回章节正文，正文仍走现有小说详情接口。
- 章节树只返回元数据，避免首屏过大。
- 小说不存在或已软删除返回 404。

错误：
- 小说不存在返回 404。
- 小说已软删除返回 404。
- 无权限沿用现有小说读取边界。

章节树交互：
- 搜索匹配章节标题与蓝图摘要，不匹配正文。
- 当前章在树中高亮并自动滚入可视区。
- 章节状态用文字 + 颜色双重表达，不只靠颜色。
- 树项显示章节号、标题、字数；空间不足时标题省略并保留悬浮完整标题。

三栏壳：
- 左栏宽度 240px，可拖拽 200–320px；中栏自适应；右栏 320px，可折叠为 40px 标签条。
- 顶栏展示小说标题、当前章、保存状态、布局切换。
- 窄于 960px 时默认收起左树；窄于 720px 时右栏改为抽屉。
- 折叠状态在本次会话内保留，不写库。

**自测**
- 打开含 1 章、50 章、500 章的三本小说，确认树渲染与滚动正常。
- 在正文有未保存修改时切换章节，确认先保存再切换。
- 制造 409 冲突，确认现有冲突提示与重载流程不变。
- 搜索标题与摘要命中正确，搜索正文不命中。
- 960px 与 720px 两个断点下确认栏位收起与抽屉行为。
- 切换为 `tabs` 后刷新，确认没有工作台聚合请求，原有写作流程可用。

**验证**
- 聚合接口在小说不存在、已删除、正常三种情况下返回符合错误码契约。
- 切换章节后刷新页面，确认内容与章节号一致。
- 三栏布局在暗色主题与 `comfortable` 密度下不溢出。
- 现有写作页签的生成、定稿、阅读模式入口仍可用。

### N1-2 批注与锚点重定位

**要求**
- 支持选中正文创建批注，批注包含引文、偏移、前后文、备注、类型与状态。
- 支持批注列表、编辑备注、解决、重新打开、删除。
- 正文变化后按规则重定位；失败进入孤儿态并保留原引文。
- 写作区显示批注标记，点击标记或列表项可定位到对应文本。

**约束**
- 批注不得修改章节正文，不得参与章节保存的 409 判断。
- 创建时引文必须能在当前章节正文中找到，找不到返回 400。
- `start_offset < end_offset`，且不超过正文长度；不满足返回 400。
- 同一章节最多 500 条批注，超过返回 400。
- 引文长度上限 500，备注上限 2000，前后文各 40 字符。
- 更新只允许备注、类型、状态与重新选择的锚点。
- 定位顺序固定：精确偏移切片匹配 → 锚点窗口内搜索 → 孤儿态。
- 窗口内多次命中时取距离原偏移最近的一处；距离相同取靠前者。
- 孤儿态批注不自动删除，需用户显式处理。
- 删除章节时同章批注一并逻辑清理，不留下不可达记录。
- 选区跨段时按纯文本偏移处理，不拆分多段批注。

**参考**
- 规格：小说工作台落地方案 §4.3、§5.2、§6.1。
- 数据表：基础层 `novel_annotations`。
- 现有写作区：`frontend/app/components/novel/ChapterWriterPanel.vue` 的 textarea 与保存流程。

**设计**

接口：
- `GET /novels/:id/annotations`：支持按章节、状态过滤；返回前执行锚点校验，命中则回写新偏移，找不到则置孤儿态。
- `POST /novels/:id/annotations`：创建并返回定位结果。
- `PUT /novels/:id/annotations/:annotationId`：更新备注、类型、状态或重新选择的锚点。
- `DELETE /novels/:id/annotations/:annotationId`：删除。

创建入参：
- 章节号、引文、起始偏移、结束偏移、前文、后文、备注、类型。

定位结果：
- `located`：返回新偏移。
- `orphaned`：无法定位，保留引文与原因。

前端状态：
- `annotations`：当前章批注。
- `activeAnnotationId`：当前选中。
- `selection`：当前选区偏移与文本。
- `relocating`：重定位进行中。

交互：
- 选中文本后浮出“添加批注”入口；未选中时入口禁用。
- 批注卡显示引文摘要、备注、类型、状态、创建时间。
- 点击批注卡滚动到正文对应位置并短暂高亮。
- 孤儿批注显示“原文已变化”，提供“重新绑定”与“删除”。
- 解决后的批注默认折叠，可切换显示。

**自测**
- 创建、编辑、解决、重开、删除各跑一遍。
- 在批注前插入文本，确认偏移重定位正确。
- 删除批注引文，确认进入孤儿态且备注保留。
- 制造窗口内两处相同引文，确认取距离原偏移最近的一处。
- 保存正文制造 409，确认批注数据不受影响。
- 删除整章后确认批注不再出现在列表。

**验证**
- 数据库中的偏移、前后文与正文切片一致。
- 批注接口不写章节表；对比操作前后章节正文哈希不变。
- 加载 100 条批注的锚点校验在可接受时间内完成（本地小于 1 秒）。
- 孤儿态在刷新后仍为孤儿态。

### N2 伏笔看板与状态机

**要求**
- 提供伏笔看板：按状态分组，展示标题、埋设章、回收章、证据、备注与来源。
- 支持创建、编辑、删除与状态流转。
- 写作区可查看当前章相关伏笔，并跳转到埋设或回收章节；当前章有未回收伏笔时显示轻提示，不打断输入。
- `novel.foreshadow.autoExtract=true` 时提供“从蓝图提取候选”，候选必须人工确认后才落库。

**约束**
- 标题上限 120，证据上限 500，备注上限 1000。
- `setup_chapter` 必须在 1 到小说章节数之间，否则返回 400。
- `payoff_chapter` 可空；非空时同样必须在 1 到章节数之间，且不得早于 `setup_chapter`，否则返回 400。
- 状态只允许：`planned → planted → reinforced → paid`；`planned/planted/reinforced → abandoned`；`paid/abandoned` 只能显式重开。
- 非法流转返回 409，不静默改写。
- 看板不修改正文；证据只存引用文本，不建立双向绑定。
- `novel.foreshadow.autoExtract=false` 时不自动写库；蓝图候选必须经用户确认后才落库。
- 来源只允许 `manual`、`blueprint`、`agent`。

**参考**
- 规格：小说工作台落地方案 §4.4、§5.3、§6.2。
- 数据表：基础层 `novel_foreshadows`。
- 章节蓝图摘要：`backend/src/services/novel/blueprint.ts` 的章节摘要。

**设计**

接口：
- `GET /novels/:id/foreshadows`：支持按状态、章节过滤。
- `POST /novels/:id/foreshadows`：创建。
- `PUT /novels/:id/foreshadows/:foreshadowId`：更新字段或流转状态。
- `DELETE /novels/:id/foreshadows/:foreshadowId`：删除。

看板分组：
- 计划中、已埋设、已强化、已回收、已放弃。
- 每组显示数量；空组显示空态文案。
- 卡片显示标题、埋设章 → 回收章、来源徽标、最近更新时间。

状态流转操作：
- `planned`：可“标记已埋设”“放弃”。
- `planted`：可“标记已强化”“标记已回收”“放弃”。
- `reinforced`：可“标记已回收”“放弃”。
- `paid`：可“重新打开为已埋设”。
- `abandoned`：可“重新打开为计划中”。

写作区联动：
- 当前章等于埋设章或回收章时，右栏伏笔区置顶相关项。
- 点击章节号跳转到对应章节，不改变伏笔状态。

**自测**
- 五条合法流转与至少三条非法流转各验证一次。
- 创建缺少标题、超长证据、非法来源、回收章早于埋设章，确认返回 400。
- 删除伏笔后刷新，确认看板与写作区联动消失。
- 当前章切换时相关伏笔排序正确，未回收伏笔轻提示出现且不抢焦点。
- `autoExtract=true` 时提取候选只进入待确认列表；取消确认不写库。

**验证**
- 非法流转返回 409 且数据库状态不变。
- 看板计数与数据库分组计数一致。
- 伏笔接口不触碰章节表。
- 空看板显示空态而非报错。

### N3 上下文包预览与导入注入

**要求**
- 提供上下文包预览：按当前小说与所选章节聚合故事圣经、章节摘要、批注、未解决伏笔，并在字符预算内截断。
- 导入对话框新增“包含上下文包”选项与预算输入，导入时把上下文包注入项目故事圣经的 `adaptationNotes`。
- 导入结果页显示上下文包字符数与包含条目数；现有提示词拼装读取新增键不报错。
- 预览与导入使用同一组装逻辑，结果一致。

**约束**
- 上下文包只读，不修改任何源数据。
- 字符预算默认 4000，范围 500–20000；超出预算按整句截断，不截半句，并返回 `truncated`。
- 批注只在 `novel.contextPack.includeAnnotations=true` 时纳入；未解决伏笔只在 `novel.contextPack.includeUnresolved=true` 时纳入。
- 上下文包不得包含 API Key、内部路径或调试信息。
- 导入幂等仍由现有 `request_id` 保证；重复导入不得重复追加 `adaptationNotes`。
- 上下文包生成失败不得阻断导入；返回警告并在 `last_sync_summary` 记录 `context_pack: skipped`。
- 故事圣经新增 `adaptationNotes` 键必须进入现有键清单与标签映射，旧数据读取兼容。

**参考**
- 规格：小说工作台落地方案 §4.5、§8；全链路方案 §3 导入契约。
- 现有导入：`backend/src/routes/novelImports.ts` 的入参解析；`backend/src/services/novel-import.ts` 的提交、故事圣经构建与同步摘要。
- 故事圣经：`backend/src/services/drama-story-bible.ts` 的键清单、标签与格式化。
- 导入对话框：`frontend/app/components/novel/ImportToDramaDialog.vue` 的复选框、预览与提交载荷。

**设计**

预览接口：`POST /novels/:id/context-pack/preview`

入参：
- `chapter_nos`：章节号列表。
- `include_annotations`：是否包含批注，未传时取设置。
- `include_unresolved_foreshadows`：是否包含未解决伏笔，未传时取设置。
- `max_chars`：最大字符数，未传时取设置。

返回：
- `text`：拼装后的文本。
- `chars`：实际字符数。
- `truncated`：是否发生整句截断。
- `included`：纳入的章节数、批注数、伏笔数。

文本结构：
- 标题“【小说改编上下文】”、故事圣经核心段、章节摘要（按章节号升序）、未解决伏笔、批注摘录。

导入扩展：
- 请求体新增 `include_context_pack` 布尔与 `context_pack_max_chars` 数值；`include_context_pack` 缺省为 `false`，保持旧行为。
- 导入提交时若开启，则按同一组装逻辑生成文本并写入 `adaptationNotes`。
- 同步摘要记录是否包含上下文包、预算与实际字符数；生成失败记录 `context_pack: skipped`。
- 重复 `request_id` 返回既有导入，不重复写入。
- 返回体包含 `warnings`，上下文包失败时给出可读提示但不改变导入成功状态。

前端：
- 导入对话框新增“包含上下文包”复选框，默认取设置。
- 勾选后显示预算输入与“预览”按钮。
- 预览对话框显示 `chars`、`truncated`、`included` 与可复制文本。
- 提交中禁用重复点击；失败显示可读错误。

**自测**
- 空章节、单章、多章、超预算四种情况各预览一次。
- 预览文本与导入后故事圣经的 `adaptationNotes` 一致。
- 关闭批注或未解决伏笔开关，确认对应内容不出现。
- 相同 `request_id` 重复导入，确认不重复追加。
- 预算设为最小值与最大值，确认边界行为。

**验证**
- 预览与导入使用同一服务函数，无第二套拼装逻辑。
- `truncated` 与文本实际截断状态一致，截断处为完整句子。
- 故事圣经旧键读取与写入无回归；现有提示词拼装包含 `adaptationNotes` 时正常输出。
- 导入测试覆盖新参数、幂等与故事圣经新增键。
- 小说更新后，现有导入同步状态仍按旧逻辑显示 `has_update`。

## 5. 风险与回滚

| 风险 | 影响 | 应对 |
|---|---|---|
| 现有写作区被大改导致保存回归 | 内容丢失 | 保留保存逻辑，只加选区与标记；回归 409 与自动保存 |
| 锚点窗口过大导致误定位 | 批注错位 | 固定 200 默认、歧义提示、孤儿态兜底 |
| 上下文包超预算截断不透明 | 导入信息缺失 | 返回 `chars`/`truncated`/`included` 与警告，前端明示 |
| 导入重复写入故事圣经 | 数据膨胀 | 复用 `request_id` 幂等，测试覆盖 |
| 三栏在窄屏挤压 | 不可用 | 断点折叠与抽屉，不强行三栏 |

回滚：
- 前端可将写作页签切回原单面板，工作台组件保留不删。
- 后端新增接口与表可保留；关闭设置开关即可隐藏入口。
- 批注与伏笔数据不回滚删除，避免用户数据丢失。
