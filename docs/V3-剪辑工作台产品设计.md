## 0. 一页结论

剪辑工作台不是通用剪辑软件，而是火宝短剧的「AI 素材总装台」：把已经生成好的镜头、配音和字幕，在一条时间线上快速组装成可交付的竖屏短剧。

**产品承诺：**

> 一个没学过 Premiere 的创作者，在素材就绪后 10–15 分钟内完成第一版可导出成片；任何一步都能撤销，任何一次导出都可追溯，任何一次画面改动都不会让声音悄悄错位。

**五个关键决策：**

1. **两个独立页面**：`/edit` 只做画面与字幕，`/mix` 只做声音；两个页面各自只有一个可见预览和一个播放时钟。
2. **一个时间脊梁**：`EditPlan` 定义画面顺序、时长与字幕；`MixPlan` 绑定 `EditPlan` 的时间哈希。画面时长变化会让混音显式变为「需更新」，不静默错位。
3. **完整核心剪辑 = P0 + P1**：P0 是能完成初剪与导出；P1 补齐画中画、滤镜、标题、Take、版本对比等短剧常用能力。P2 才是关键帧、蒙版、调色曲线等专业扩展。
4. **默认简单模式**：一条磁吸主轨、一条字幕轨、一条只读声音参考；默认波纹、默认硬切、默认适配、自动保存。专业模式只是把已有的精确控制展开，不另做一套界面。
5. **成片导出唯一归属剪辑页**：混音页只导出 WAV/M4A/stems；合片、配音、动效产物降级为素材，`episodes.video_url` 只由「设为当前成片」更新。

**发布范围：**

| 阶段 | 内容 | 是否可交付 |
| --- | --- | --- |
| P0 MVP | 单主轨、裁剪/分割/删除/排序/波纹、硬切/叠化、字幕、变速、适配、声音参考、成片导出 | 可以完成简单成片 |
| P1 完整核心 | 画中画/叠加轨、滤镜、标题、Take 切换、自动字幕、精确预览、版本对比、批量导出 | **本设计的正式发布门槛** |
| P2 专业扩展 | 多视频轨、关键帧、蒙版、抠像、调色曲线、变速曲线、倒放/定格、多机位 | 按业务验证后排期 |

**明确不做：**

- 不做通用 NLE 的全功能对标，不做多机位、跟踪、三维、粒子；
- 不做云端协作与多人实时编辑；
- 不做社交平台发布、账号代运营；
- 不在剪辑页做完整混音台、总线、ducking、声音分离；
- 不在混音页做视频排列、裁剪、转场、字幕文本编辑、最终成片导出。

## 1. 定位与用户

### 1.1 一句话定位

**把 AI 生成的碎片镜头，装成一条能直接发布的短剧成片。**

### 1.2 目标用户

| 用户 | 特征 | 核心诉求 |
| --- | --- | --- |
| 独立创作者 | 一个人完成小说改写、生成、配音、剪辑、发布 | 不想学专业软件，希望默认值就能用 |
| 小工作室剪辑 | 2–5 人，分工生成与后期 | 批量处理多集，版本清楚，返工成本低 |
| 运营/制片 | 不直接剪，但要审片与交付 | 打开就能看懂进度、差异和导出结果 |

共同点：懂短剧节奏和平台规范，但不一定懂时间线、帧、码率、响度。产品不能要求他们先成为后期工程师。

### 1.3 核心场景与 JTBD

**场景 A：初剪（最高频）**

- 输入：一集 15–40 个已生成镜头，可能还有多个 Take。
- 任务：按剧本顺序铺满时间线，删掉失败镜头，调整顺序，控制总时长。
- 成功：5 分钟内得到一版完整初剪，能连续播放。

**场景 B：精修**

- 任务：修剪入出点、分割、替换 Take、加转场、加字幕、加标题、调整画幅适配。
- 成功：画面节奏与台词对齐，字幕不挡脸，转场不突兀。

**场景 C：声音协作**

- 任务：画面定稿后去混音页处理对白、原声、BGM；回剪辑页试听并导出。
- 成功：画面改动后能明确知道混音是否失效，并能一键重新对齐。

**场景 D：交付**

- 任务：选择竖屏/横屏、字幕模式、清晰度，导出并确认文件可播放。
- 成功：一次导出成功，有校验报告，能回溯到具体剪辑版本与混音版本。

**JTBD 表述：**

- 当我拿到一集生成好的镜头时，我想快速按剧本顺序铺成时间线，这样我不用逐个下载、拼接、再导入。
- 当某个镜头太长或开头有多余动作时，我想直接拖边缘裁掉，这样我不用重新生成。
- 当台词和画面对不上时，我想看到字幕与声音参考在同一条时间线上，这样我能直接判断该移画面还是改字幕。
- 当我改完画面时，我想知道混音有没有失效，这样我不会导出一条声音错位的成片。
- 当我准备发布时，我想一键得到符合平台规格的成片，这样我不用记码率、分辨率和字幕开关。

### 1.4 差异化

| 差异点 | 说明 | 对用户的价值 |
| --- | --- | --- |
| 生成素材原生 | 镜头、Take、台词、字幕、混音都来自项目数据，不靠文件名猜 | 打开即有素材，不需要先整理文件夹 |
| 一键初剪 | 按分镜顺序自动铺轨，跳过失败镜头 | 把“从零搭时间线”变成“检查并修正” |
| 字幕优先 | 台词本直接生成字幕轨，字幕与镜头双向定位 | 短剧最耗时的对字幕变成默认能力 |
| 声音参考只读 | 剪辑页能看波形、听混音，但不做混音 | 边界清楚，不会出现“两个混音器” |
| 显式失效 | 画面时长变化会让混音标记 stale，并给出重新对齐 | 避免成片音画错位这种致命问题 |
| 默认简单 | 一条主轨、默认波纹、默认硬切、默认适配 | 新用户不用先学轨道和工具 |
| 本地优先 | 桌面版本地渲染、本地文件、无上传等待 | 长视频和隐私素材更可控 |

### 1.5 非目标

- 不做专业调色台、音频工作站、特效合成软件；
- 不做多用户实时协作与评论批注；
- 不做素材市场、模板市场、AI 换脸/换背景；
- 不做发布分发与数据回流；
- 不替代混音工作台，不替代配音工作台的台词与音色管理。

## 2. 设计原则

| # | 原则 | 落地规则 |
| --- | --- | --- |
| 1 | **一条主线** | 素材 → 时间线 → 预览 → 导出；页面不出现第二条平行流程 |
| 2 | **一个可见预览、一个时钟** | 每页只有一个可见播放器；内部可预加载多个解码器，但用户只感知一个播放头 |
| 3 | **默认简单，专业渐进** | 简单模式覆盖 80% 操作；专业模式只展开精确控制，不新增页面 |
| 4 | **磁吸主轨，不让用户管轨道** | 主轨默认无空隙；插入、移动、删除自动闭合；留空是显式动作 |
| 5 | **非破坏编辑** | 所有裁剪、变速、转场只改计划，不改源文件；永远可撤销 |
| 6 | **预览可简化，导出必精确** | 简化转场必须可见标注；导出前可生成精确预览 |
| 7 | **声音有明确主人** | 剪辑页只监听，不混音；所有声音调整跳转混音页 |
| 8 | **改动有后果提示** | 影响混音时长的操作立即标记；不影响的操作不打扰 |
| 9 | **自动保存 + 可恢复** | 300ms 防抖保存；崩溃/关闭后可恢复；版本可回溯 |
| 10 | **失败可行动** | 每个错误都给出下一步：重试、重链、去生成、去混音、复制诊断 |
| 11 | **中文优先，四语可用** | 文案短、动词开头；zh/en/ja/ko 同步；时间码与数字本地化 |
| 12 | **不靠颜色传达唯一信息** | 状态同时用图标、文字、纹理；色盲可辨 |

## 3. 信息架构与路由

### 3.1 目标信息架构

```text
剧集
├─ 剧本
├─ 制作（资产 / 分镜 / 生图 / 生视频）
├─ 配音（台词 / 音色 / 生成）
├─ 剪辑（画面 / 字幕 / 成片导出）      /edit
└─ 混音（对白 / 原声 / 音效 / BGM）    /mix
```

**为什么不是把剪辑塞进配音第 4 步：**

- 配音页的五步是“声音生产”流程，剪辑是“画面总装”流程，两者时间尺度与操作对象不同；
- 同一页面放两个播放器、两条时间线、两套检查器，必然出现“四不像”；
- 分成两页后，每页只有一个时钟，键盘、撤销、自动保存、版本都能独立定义；
- 共享数据放在项目层，不放在页面层。

### 3.2 路由

沿用现有动态路由：

| 页面 | 路由 | 说明 |
| --- | --- | --- |
| 剪辑工作台 | `/drama/:dramaId/episode/:episodeNumber/edit` | 主编辑页 |
| 混音工作台 | `/drama/:dramaId/episode/:episodeNumber/mix` | 现有音频能力迁移 |
| 剧集工作台 | `/drama/:dramaId/episode/:episodeNumber` | 原有剧本/制作/配音入口 |

路由参数使用 `episodeNumber` 与现有 `pages:extend` 保持一致；页面内部通过剧集数据解析 `episodeId`。跨页交接对象使用 `episodeId`，避免依赖 URL 编号。

**查询参数（可选）：**

```text
?at=12345                 播放头毫秒
&in=10000&out=20000       预览区间
&clip=123                 选中片段
&line=456                 选中台词
&from=mix                 来源页，用于返回
```

### 3.3 入口

| 入口 | 行为 | 说明 |
| --- | --- | --- |
| 剧集工作台顶部「剪辑」 | 打开 `/edit` | 主入口 |
| 制作页「拼接导出」 | 改为「打开剪辑工作台」 | 旧合片对话框保留为「生成初剪」快捷动作 |
| 配音页第 4 步「预览与混音」 | 改为「打开混音工作台」 | 第 4 步保留入口卡片与混音状态 |
| 配音页第 5 步「合成导出」 | 改为「去剪辑页导出」 | 导出能力迁移到剪辑页 |
| 剧集工作台顶部「混音」 | 打开 `/mix` | 声音主入口 |
| 导出完成通知 | 打开剪辑页并定位导出记录 | 不另开播放器 |

### 3.4 页面职责去重对照

| 旧入口/旧能力 | 新归属 | 迁移方式 |
| --- | --- | --- |
| 制作页「拼接导出」最终导出 | 剪辑页「成片导出」 | 制作页改为打开剪辑页；合片只生成初剪素材 |
| 配音第 4 步 `AudioMixBoard` | 混音页 | 保留现有 `MixStage` 能力，入口改为跳转 |
| 配音第 5 步 `ExportStage` | 剪辑页导出抽屉 | 迁移 `useExportSession` 与导出记录 |
| `LineList` 中的逐句合成 | 配音页第 3 步 | 剪辑页不提供逐句合成，只提供 Take 选择与定位 |
| `SubtitlePreview` 单视频预览 | 剪辑页预览 | 保留组件作为单片段预览兜底，不承担多片段合成 |
| 制作页视频列表逐个播放 | 剪辑页素材库 | 素材库统一检索、预览、插入 |

### 3.5 迁移节奏

| 阶段 | 页面状态 | 用户可见变化 |
| --- | --- | --- |
| M0 设计 | 旧流程不变 | 无 |
| M1 只读 | `/edit` 可打开，显示当前成片为单片段 | 可查看、定位、导出沿用旧流程 |
| M2 MVP | `/edit` 可编辑、可导出 | 新入口上线，旧入口保留 |
| M3 完整核心 | P1 能力上线 | 旧入口开始弱化 |
| M4 收敛 | 配音第 4/5 步改为跳转卡片 | 旧合片最终导出下线，只保留“生成初剪” |

迁移期间不删除旧数据、不重写 `episodes.video_url` 的既有值；新页面通过版本指针读取，导出成功后才更新当前成片。

## 4. 剪辑工作台页面

### 4.1 布局

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ ← 剧集   第 3 集 · 标题        剪辑 v12 · 已保存     混音：已对齐     撤销 重做  导出 │
├───────────────┬──────────────────────────────────────────────┬───────────────┤
│ 素材库         │ 预览                                          │ 检查器         │
│ [镜头][Take]   │  ┌────────────────────┐                       │ 片段 / 字幕    │
│ [导入][字幕]   │  │                    │  安全区 / 字幕预览     │ 转场 / 画面    │
│ 搜索 / 筛选    │  │     9:16 画面       │                       │ 声音：由混音页  │
│ ─────────────  │  │                    │                       │ 管理 →         │
│ 镜头卡片列表   │  └────────────────────┘                       │               │
│                │  ▶ 00:00:12:08 / 00:01:32:00   音量  质量     │               │
├───────────────┴──────────────────────────────────────────────┴───────────────┤
│ 选择  切割  撤销  重做 | 吸附 | 缩放 | 主轨 · 字幕轨 · 声音参考                  │
│ ┌──────────────────────────────────────────────────────────────────────────┐ │
│ │ 视频主轨  [镜头1][镜头2][镜头3][镜头4] ...                                │ │
│ │ 字幕轨    [台词1] [台词2] [台词3] ...                                     │ │
│ │ 声音参考  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓（只读，点击去混音）                        │ │
│ └──────────────────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 区域职责

| 区域 | 内容 | 关键约束 |
| --- | --- | --- |
| 顶部栏 | 返回、剧集信息、剪辑版本、保存状态、混音状态、撤销/重做、模式切换、导出 | 混音状态必须常驻可见；导出是唯一主按钮 |
| 左侧素材库 | 镜头、Take、导入素材、字幕、声音参考 | 卡片点击选中，双击/加号插入，拖拽到时间线 |
| 中部预览 | 一个可见画面、字幕叠加、安全区、运输条、音量、质量 | 内部视频池，不向用户暴露多个播放器 |
| 下部时间线 | 主视频轨、字幕轨、只读声音参考；专业模式增加叠加轨/标记轨 | 主轨可编辑；声音参考不可编辑 |
| 右侧检查器 | 片段、字幕、转场、画面、声音跳转 | 属性随选中对象切换；无选中时显示工程信息 |
| 导出抽屉 | 预设、字幕模式、检查、进度、历史 | 从右侧滑出，不离开时间线上下文 |

### 4.3 顶部栏

**从左到右：**

1. 返回剧集；
2. 第 N 集 · 标题；
3. 版本徽标：`剪辑 v12`，点击打开版本历史；
4. 保存状态：`保存中… / 已保存 / 保存失败`；
5. 混音状态徽标：`混音已对齐 / 混音需更新 / 尚未混音`，点击跳转混音页或打开重新对齐；
6. 撤销/重做按钮（带最近操作提示）；
7. 模式切换：`简单 / 专业`；
8. 导出按钮（主按钮）。

**规则：**

- 保存失败时，导出按钮降级为禁用，并显示原因；
- 混音需更新时，导出按钮仍可点，但打开导出抽屉后必须先处理；
- 版本徽标只在有未保存更改时显示 `·` 标记；
- 顶部栏高度固定 48px，不随滚动隐藏。

### 4.4 素材库

**标签页：**

| 标签 | 内容 | 默认排序 | 插入行为 |
| --- | --- | --- | --- |
| 镜头 | 分镜生成视频，按场景/分镜号 | 分镜号 | 插入到播放头，或追加到末尾 |
| Take | 同一台词/镜头的多个生成结果 | 最新优先 | 替换选中片段或插入新片段 |
| 导入 | 用户本地视频/图片（P1 图片） | 导入时间 | 插入到播放头 |
| 字幕 | 台词行生成的字幕 cue | 时间 | 定位到对应字幕，不直接插入视频 |
| 声音 | 当前混音、原声参考 | 固定 | 仅定位/跳转混音页 |

**卡片信息：**

- 缩略图或首帧；
- 时长 `00:05`;
- 分镜号/台词摘要；
- 状态：`可用了 / 生成中 / 失败 / 离线`；
- Take 标记：`T1 / T2 / 当前`；
- 悬浮显示静音预览（视频卡片悬停 400ms 后播放 2 秒）。

**筛选与搜索：**

- 按场景、分镜号、台词角色、状态筛选；
- 搜索台词文本、角色名、镜头号；
- 失败/离线素材置顶并标红；
- 提供「只看可用」开关，默认开启。

**一键初剪：**

- 位置：素材库顶部主按钮，空时间线时也在预览区显示；
- 规则：按分镜号顺序取每个镜头的当前 Take；跳过生成中/失败/离线；不插入空镜头；
- 结果：生成连续主轨 + 对应字幕轨；
- 时间线非空时弹三选一：`替换当前时间线` / `追加到末尾` / `取消`；
- 替换前自动创建版本，可撤销；
- 完成后 toast：`初剪完成：18 个片段，总时长 01:32；跳过 2 个未生成镜头`，附「查看」定位到第一个跳过项。

### 4.5 预览与运输条

**画面：**

- 按工程画幅显示，默认 9:16；
- 画面外区域使用深色背景，可切换模糊背景（P1）；
- 字幕叠加在画面内，显示安全区；
- 选中片段时显示源入出点角标；
- 转场预览使用简化叠化，右上角标注 `简化预览`；精确效果以导出或「精确预览」为准。

**运输条：**

```text
[上一片段] [上一帧] [播放/暂停] [下一帧] [下一片段]   00:00:12:08 / 00:01:32:00   音量 [▮▮▮] 质量 [自动]
```

- 时间码格式 `HH:MM:SS:FF`，点击可切换到毫秒；
- 播放/暂停支持空格；
- 逐帧按钮在简单模式隐藏，专业模式显示；
- 上一/下一片段按主轨片段边界跳转；
- 音量只控制监听，不影响导出；
- 质量：`自动 / 540p / 720p / 原画`；自动按代理与网络/解码能力选择；
- 播放时显示实时音频表；削波时显示 `削波` 警告，不自动改混音。

**播放行为：**

- 播放到主轨末尾自动停止，回到开头或停在末尾（设置项，默认停在末尾）；
- 拖动播放头时暂停音频，释放后从新位置继续；
- 快速拖动只显示缩略图，停止 120ms 后加载实际画面；
- 播放中切换片段使用预加载，目标切换延迟 < 120ms；
- 页面隐藏（切标签/最小化）自动暂停并释放解码资源；
- 离开页面时暂停，返回时恢复到上次播放头。

**精确预览（P1）：**

- 入口：运输条「精确预览」或导出抽屉「预览当前区间」；
- 范围：当前选中片段，或 I/O 标记区间，最长 60 秒；
- 服务端按最终渲染链生成低码率预览；
- 生成中显示进度，可取消；
- 完成后在预览区内切换 `精确` 标记，退出即回到实时预览；
- 缓存按 `editPlanHash + range` 复用。

### 4.6 时间线

**轨道：**

| 轨道 | 高度 | 可编辑 | 内容 |
| --- | --- | --- | --- |
| 主视频轨 | 72px | 是 | 视频片段、缩略图条、源入出点、变速/转场徽标 |
| 叠加轨（P1） | 60px | 是 | 画中画、贴图、标题素材 |
| 字幕轨 | 40px | 是 | 字幕 cue、台词摘要、钉住状态 |
| 标记轨（P1） | 24px | 是 | 节拍/审片标记 |
| 声音参考 | 48px | 否 | 混音波形或原声波形；点击跳转混音页 |

**标尺与缩放：**

- 标尺按缩放自适应 `秒 / 5 秒 / 10 秒 / 分钟`；
- 缩放范围 5–500 px/s；
- `Cmd/Ctrl + 滚轮` 以指针为中心缩放；
- `Shift + Z` 适配全部；
- 时间线可横向滚动，播放头自动跟随（可关闭）；
- 主轨片段最小显示宽度 8px，低于阈值只显示色块与选中态。

**片段视觉：**

- 缩略图条按缩放抽取；
- 底部细波形表示源音频（仅参考）；
- 左上角分镜号/角色名；
- 右上角时长；
- 角标：变速 `1.5x`、转场 `◇`、Take `T2`、离线 `!`；
- 选中：高亮描边 + 检查器联动；
- 离线：红色斜纹 + `源文件离线`；
- 受混音影响：片段角落显示小音频图标，点击跳转混音页。

**字幕视觉：**

- cue 块显示文本前 20 字；
- 手动调整过的时间显示图钉；
- 与台词行关联的 cue 悬浮显示 `第 12 句 · 角色名`；
- 超出安全区的 cue 显示黄色警告。

**声音参考视觉：**

- 默认单条汇总波形；
- 专业模式可展开 `对白 / 原声 / 音效 / BGM` 分组，只读；
- 混音需更新时整条显示琥珀色斜纹 + 顶部提示；
- 双击任意位置打开混音页并定位。

### 4.7 检查器

**无选中：**

- 工程信息：画幅、分辨率、帧率、总时长、片段数；
- 混音状态与「去混音」；
- 导出快捷入口；
- 工程设置（专业模式可改）。

**选中视频片段：**

| 分组 | 字段 | 简单模式 | 专业模式 |
| --- | --- | --- | --- |
| 来源 | 分镜号、台词、Take、源文件状态 | 显示 | 显示 |
| 时间 | 时间线入点/出点、源入点/出点、时长 | 只读摘要 | 可输入时间码 |
| 裁剪 | 左/右裁剪 | 拖边缘 | 数值 + 拖边缘 |
| 变速 | 0.5x–2x 预设 | 显示 | 显示 + 自定义 |
| 转场 | 与前一片段/后一片段的转场 | 显示 | 显示 |
| 画面 | 适配（适应/填充）、缩放、位置 | 适配 + 缩放 | 完整数值 |
| 效果 | 滤镜预设、强度（P1） | 隐藏 | 显示 |
| 声音 | `由混音工作台管理` + 跳转 | 显示 | 显示 |
| 操作 | 分割、复制、删除、仅删除留空 | 显示 | 显示 |

**选中字幕：**

- 文本（多行，最多 2 行建议）；
- 开始/结束时间；
- 角色/说话人；
- 样式：默认/描边/背景条；字号、位置；
- `跟随片段` 或 `固定时间`；
- `同步回台词本`（二次确认）；
- 删除 cue（不删除台词本）。

**选中转场：**

- 类型：硬切、叠化、淡入黑、淡出黑；
- 时长 0.1–1.5 秒；
- 预览按钮；
- 删除转场恢复硬切。

### 4.8 导出抽屉

- 从右侧滑出，宽度 420px；
- 顶部：当前剪辑版本、混音版本、时长；
- 中部：预设、字幕模式、文件名、输出位置；
- 底部：前置检查结果、导出按钮、历史记录入口；
- 导出中可最小化为底部进度条，继续编辑？**P0 不允许边导出边编辑同一集**；导出期间编辑入口锁定，避免版本漂移；P1 支持快照导出，允许继续编辑。
- 导出完成后抽屉保持打开，显示校验报告与「播放」「打开文件夹」「设为当前成片」。

## 5. 核心交互规格

### 5.1 添加到时间线

| 操作 | 结果 |
| --- | --- |
| 双击素材卡片 | 插入到播放头位置；主轨后续片段右移 |
| 点击卡片 `+` | 追加到主轨末尾 |
| 拖拽卡片到主轨 | 按落点插入；落点在片段左/右半区决定插入位置 |
| 拖拽卡片到预览区 | 追加到末尾并定位 |
| 拖拽 Take 到已有片段 | 替换该片段的源，保持时间线位置 |
| 拖拽字幕到字幕轨 | 不创建新 cue，定位到已有 cue；字幕由台词生成 |
| 拖拽声音参考到任意位置 | 无操作，仅提示「声音请在混音页调整」 |

**插入规则：**

- 主轨始终连续；插入点后的片段整体右移；
- 插入片段默认使用源完整时长；
- 插入后播放头停在新片段开头；
- 新片段自动选中；
- 若源时长 < 3 帧，拒绝插入并提示；
- 若插入导致总时长超过 60 分钟，拒绝并提示。

### 5.2 选择

| 操作 | 结果 |
| --- | --- |
| 单击片段 | 单选，检查器切换 |
| `Cmd/Ctrl + 单击` | 切换多选 |
| `Shift + 单击` | 连续范围多选 |
| 单击空白 | 取消选择，检查器显示工程信息 |
| `Esc` | 取消选择；播放中则先停止播放 |
| 双击片段 | 预览该片段，播放头到片段开头 |
| 右键片段 | 打开上下文菜单 |

多选后：

- 检查器显示「已选 N 个片段」，只提供通用操作：删除、复制、变速、适配；
- 不支持多选拖拽改变相对顺序（P2）；
- 多选删除默认波纹删除。

### 5.3 移动、排序与插入

**拖动片段本体：**

- 拖动时显示插入指示线；
- 释放后从原位置移除，插入到目标位置；
- 总时长不变；
- 目标位置在原位置之后时，按移除后的索引计算，避免偏移一格；
- 拖动中按 `Esc` 取消；
- 拖动中自动滚动时间线边缘；
- 跨轨道拖动：P0 仅允许主轨内；P1 允许拖到叠加轨，或从叠加轨拖回主轨。

**吸附：**

- 默认开启；
- 吸附目标：播放头、其他片段边缘、字幕 cue 边缘、标记、0 点、总时长；
- 吸附阈值 8px，按住 `Alt/Option` 临时关闭；
- 吸附时显示对齐线；
- 专业模式可关闭吸附（`S`）。

**碰撞：**

- 主轨不允许重叠；落点即插入，不覆盖；
- 叠加轨不允许重叠；落点无空间时拒绝并提示；
- 字幕轨 cue 不允许重叠；重叠时自动裁剪到边界或提示（默认裁剪）。

### 5.4 裁剪

**拖左边缘：**

- 改变源入点与时间线入点；
- 片段右侧边界不变，后续片段不移动（单边裁剪）；
- 若开启「波纹修剪」（专业模式），后续片段跟随移动；
- 不能裁到源入点之前，不能短于 3 帧；
- 最大裁剪受源时长限制。

**拖右边缘：**

- 改变源出点与时间线出点；
- 后续片段默认右移/左移以保持连续（磁吸主轨）；
- 简单模式下默认波纹修剪，专业模式可切换普通修剪；
- 不能超过源出点，不能短于 3 帧。

**裁剪反馈：**

- 拖动时显示 `源 00:00:02:04 → 00:00:04:12` 与 `时长 00:00:02:08`；
- 同时显示相邻片段是否移动；
- 释放后写入一次撤销记录；
- 裁剪影响总时长时，立即标记混音需更新；
- 裁剪不改源文件，不重新生成。

**限制：**

- 变速片段按时间线时长裁剪，源入出点按速度换算；
- 转场占用相邻片段余量时，裁剪不得吃掉转场所需余量；不足时自动缩短转场并提示。

### 5.5 分割

- 快捷键 `Cmd/Ctrl + B`；
- 分割当前选中片段；无选中时分割播放头下主轨片段；
- 分割点必须在片段内部，距两端至少 3 帧；
- 分割后两段源连续，右侧片段自动选中；
- 字幕 cue 不自动分割；专业模式提供「字幕跟随切点」开关（P1）；
- 分割影响总时长？不改变总时长，因此不标记混音 stale；
- 分割后允许独立裁剪、变速、删除；
- 分割可撤销。

### 5.6 删除、波纹与留空

| 操作 | 行为 | 使用场景 |
| --- | --- | --- |
| `Delete / Backspace` | 波纹删除：移除片段并闭合空隙 | 默认 |
| `Shift + Delete` | 仅删除：移除片段，留下黑色空档 | 需要保留节奏空档 |
| 右键「删除并留空」 | 同仅删除 | 简单模式也可用 |
| 右键「关闭空档」 | 将空档闭合 | 清理留空 |
| 右键「删除全部空档」（P1） | 一次闭合所有空档 | 批量整理 |

**规则：**

- 空档以黑色块 + `空档 00:00:01:12` 显示；
- 空档计入总时长，导出为黑场；
- 空档上不能放字幕 cue（可放，但提示不与画面重叠）；
- 空档不影响混音时长判断？**影响**：总时长变化即标记混音需更新；
- 删除最后一个片段后显示空态，不自动删除字幕；
- 删除有台词的片段时，字幕 cue 保留但标记「无画面对应」，用户可手动删除或重新关联。

### 5.7 变速

- 预设：0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x；
- 专业模式可输入 0.25x–4x；
- 变速改变时间线时长，源入出点不变；
- 变速后音频：若该片段使用源音频，默认变调不变速？**产品规则**：源音频跟随变速并做变调补偿（pitch-correct），避免卡通音；最终成片通常使用混音，因此该音频只用于未混音预览；
- 变速后总时长变化，标记混音需更新；
- 变速片段在时间线上显示 `1.5x` 角标；
- 变速可撤销；
- 变速曲线、倒放、定格为 P2。

### 5.8 转场

**P0 转场：**

| 类型 | 说明 | 默认时长 |
| --- | --- | --- |
| 硬切 | 无转场，默认 | 0 |
| 叠化 | 前后画面交叉溶解 | 0.4s |
| 淡入黑 | 从黑场进入 | 0.5s |
| 淡出黑 | 到黑场结束 | 0.5s |

**交互：**

- 拖转场到两个片段交界，显示高亮；
- 一个交界只能有一个转场；
- 点击交界上的转场图标打开检查器；
- 删除转场恢复硬切；
- 转场时长不能超过前后片段可用余量；不足时自动缩短并提示；
- 转场使总时长缩短（叠化重叠）或不变（淡入淡出）？**规则**：叠化按重叠计算，总时长减少转场时长；淡入黑/淡出黑不改变总时长；
- 总时长变化时标记混音需更新；
- 简化预览使用 CSS/着色器叠化，标注「简化预览」；
- 精确预览/导出使用 FFmpeg `xfade`。

**P1 转场：**

- 白场、推拉、模糊叠化；
- 转场预设面板，悬停预览；
- 转场时长数值输入；
- 不支持自定义曲线（P2）。

### 5.9 画面适配与变换

| 设置 | 选项 | 默认 |
| --- | --- | --- |
| 适配 | 适应（留黑边）/ 填充（裁切） | 填充 |
| 缩放 | 50%–200% | 100% |
| 位置 | 居中 / 九宫格 / 自由 | 居中 |
| 旋转 | 0° / 90° / 180° / 270°（P1） | 0° |
| 翻转 | 水平 / 垂直（P1） | 无 |

**规则：**

- 不同分辨率/画幅的素材自动按工程画幅适配；
- 填充模式默认放大到覆盖画面，允许裁切；
- 适应模式保留完整画面，显示黑边/模糊背景；
- 变换只影响画面，不影响时长，不标记混音 stale；
- 叠加轨使用独立的适配设置；
- 关键帧变换为 P2。

### 5.10 滤镜与调色（P1）

**预设：**

- 原片；
- 清晰（轻锐化/对比）；
- 暖色；
- 冷色；
- 电影（低饱和/青橙）；
- 黑白；
- 复古。

**交互：**

- 检查器「效果」分组选择预设；
- 强度 0–100%，默认 100%；
- 提供「应用到全部片段」；
- 预览实时生效（代理画质）；
- 导出使用同一参数；
- 不支持手动曲线、色轮、LUT 导入（P2）。

### 5.11 字幕

**来源：**

1. 台词本（默认）：`storyboard_lines` 生成 cue，带 `lineId`；
2. 手动新增（P1）：在字幕轨双击空白创建；
3. 导入 SRT（P2）。

**生成规则：**

- 一集首次打开剪辑页时，若字幕轨为空且有台词，自动生成建议 cue；
- cue 时间默认跟随对应镜头的片段位置与台词时长；
- 同一镜头多句台词按顺序排布，不重叠；
- 无对应画面的台词显示在字幕轨但标记 `无画面`；
- 生成不覆盖已有手动字幕。

**编辑：**

- 双击 cue 进入文本编辑；
- 拖动 cue 本体移动时间；
- 拖边缘调整入出点；
- 检查器可改文本、时间、样式、角色；
- 手动改时间后 cue 变为 `固定`，不再跟随片段；
- 点击图钉恢复跟随；
- 分割/合并 cue（P1）；
- 全部字幕偏移 ±100ms～±5s（P1）。

**校验：**

- 单行建议 ≤ 20 个汉字，最多 2 行；
- 单条时长 < 0.8s 显示警告；
- 两条 cue 间隔 < 0.1s 显示警告；
- 超出安全区显示警告；
- 警告不阻止导出，但在导出检查中汇总。

**导出：**

- 字幕模式：硬字幕 / 软字幕 / 无；
- 默认硬字幕（平台兼容性优先）；
- 软字幕使用 mov_text 或 SRT 轨道；
- 硬字幕按工程画幅与样式烧录；
- 字幕样式在导出预设中固定，避免预览与导出一致性偏差。

**与台词本的关系：**

- 剪辑页修改字幕文本默认**不回写**台词本；
- 提供「同步回台词本」显式操作，二次确认，说明会影响配音与后续生成；
- 删除 cue 不删除台词本；
- 台词本重新抽取后，剪辑页提示「台词已更新，是否同步字幕」，不静默覆盖手动修改。

### 5.12 文字与标题（P1）

- 通过叠加轨添加文字素材；
- 预设：主标题、副标题、角色名条、地点条；
- 可改文本、字体、字号、颜色、描边、背景、位置、入出时间；
- 默认 3 秒，可拖边缘调整；
- 文字只影响画面，不影响混音；
- 不提供关键帧动画（P2）。

### 5.13 画中画与叠加轨（P1）

- 一条叠加轨，位于主轨上方；
- 支持视频/图片素材；
- 默认缩放 30%，右上角，带圆角/阴影预设；
- 可拖动位置、调整大小、层级（仅一条轨，无层级）；
- 叠加轨片段不能有空隙？允许空隙，空隙透明；
- 叠加轨不参与主轨磁吸；
- 叠加片段的声音默认静音，避免与混音冲突；需要声音时提示去混音页；
- 叠加轨时长变化不影响主轨，但影响总时长时标记混音需更新（以最长轨为准）。

### 5.14 Take 切换（P1）

**入口：**

- 素材库 Take 标签；
- 选中片段后检查器「Take」下拉；
- 右键「切换 Take」。

**规则：**

- 同一台词/镜头有多个 Take 时显示列表；
- 当前 Take 标记 `当前`；
- 切换后保持时间线位置与时长；
- 新 Take 更长：超出部分裁掉，提示可调整出点；
- 新 Take 更短：不足部分显示黑场或冻结帧？**默认黑场 + 警告**，不自动放慢；
- 切换后标记混音「需更新（素材变化）」，因为原声参考可能变化；
- 切换可撤销；
- 不重新生成配音；配音由台词与音色决定。

### 5.15 声音参考与跳转混音

**剪辑页声音能力边界：**

- 可以：监听当前混音、静音监听、看波形、跳转混音页、看到混音状态；
- 不可以：调音量、声像、ducking、总线、分离、重排音频片段、导出 stems。

**监听优先级：**

1. 混音已对齐：播放当前混音；
2. 混音需更新：播放片段原声，并显示横幅「当前混音与画面不匹配，正在监听原声」；
3. 尚未混音：播放片段原声；
4. 全部静音/无音频：静音，显示提示。

**交互：**

- 顶部混音徽标点击：打开混音页或重新对齐；
- 声音参考轨双击：打开混音页并定位播放头；
- 检查器「声音」分组：显示「由混音工作台管理」+「去调整」；
- 选中片段右键「调整这段的声音」：打开混音页，定位到该片段对应台词/时间；
- 混音页返回：恢复播放头与选中片段。

### 5.16 标记与备注（P1）

- 在标尺上按 `M` 添加标记；
- 标记可命名、改色、删除；
- 标记显示在标记轨与标尺；
- 导出不包含标记；
- 审片备注可挂在标记上（仅本地，不做协作）；
- 标记可吸附。

### 5.17 播放头与预览规则

- 播放头位置以毫秒存储，显示按帧对齐；
- 拖动播放头时显示时间码气泡；
- 播放头经过片段边界时，预加载下一片段；
- 播放头在空档时显示黑场；
- 播放头在字幕 cue 内时，字幕叠加；
- 播放头在转场区间时，显示简化转场；
- 播放头超出总时长时，停在末尾；
- 播放中修改计划：默认暂停并应用修改，避免预览状态与计划不一致；简单模式提示「已暂停以应用修改」，专业模式可开启「边播边改」（P2）。

### 5.18 撤销、重做、自动保存与版本

**撤销/重做：**

- 记录所有计划变更：插入、移动、裁剪、分割、删除、变速、转场、字幕、变换、滤镜、Take 切换、工程设置；
- 不记录：播放、暂停、缩放、滚动、选择、检查器展开；
- 历史上限 50 步；
- 撤销/重做后播放头尽量恢复到相关位置；
- 菜单显示操作名，如「撤销 分割片段」。

**自动保存：**

- 300ms 防抖；
- 保存到草稿，不每次生成版本；
- 状态：`保存中 / 已保存 / 保存失败`；
- 保存失败不阻塞编辑，但阻止导出，并提示磁盘/权限原因；
- 关闭页面前若有未保存更改，浏览器内提示；桌面版直接保存草稿后退出；
- 再次打开时若有未提交草稿，提示「恢复上次编辑 / 丢弃草稿」。

**版本：**

- `保存版本`（`Cmd/Ctrl + S`）创建 `edit_revisions`，可填写备注；
- 自动里程碑：首次编辑、替换时间线前、导出前；
- 版本列表显示缩略图、时间、时长、片段数、备注；
- 恢复版本 = 以该版本为内容创建新版本，不删除历史；
- 版本对比（P1）：并排显示总时长、片段数、增删改片段列表；点击差异定位。

**并发：**

- 同一集在两个窗口打开时，使用 `baseVersion` 乐观锁；
- 后保存者收到「此集已在另一窗口修改」；
- 选项：`重新加载最新` / `另存为副本` / `覆盖并保留我的修改`（覆盖需二次确认）；
- 不静默合并。

### 6.3 “完整核心”发布标准

满足以下全部条件，才可称为 P1 完整核心：

1. 能从零完成：一键初剪 → 裁剪 → 分割 → 删除 → 排序 → 变速 → 转场 → 适配 → 滤镜 → 画中画 → 标题 → 字幕 → 精确预览 → 导出。
2. 能处理异常：离线素材、缺混音、混音 stale、导出失败、保存失败、崩溃恢复。
3. 能跨页协作：剪辑 → 混音 → 重新对齐 → 回剪辑 → 导出。
4. 能回溯：每次导出关联剪辑版本与混音版本，能恢复历史版本。
5. 能简单使用：新用户不看文档，10–15 分钟完成第一版成片。

## 7. 混音工作台边界与跨页一致性

### 7.1 边界

| 能力 | 剪辑页 | 混音页 |
| --- | --- | --- |
| 视频排列/裁剪/分割/转场 | 主责 | 只读参考 |
| 字幕文本/时间/样式 | 主责 | 只读参考 |
| 画中画/滤镜/标题 | 主责 | 不显示 |
| 对白/原声/环境/音效/BGM | 只读波形 + 跳转 | 主责 |
| 音量/声像/ducking/总线 | 只读状态 | 主责 |
| 混音试听 | 监听当前混音 | 主责 |
| 混音导出 WAV/M4A/stems | 不提供 | 主责 |
| 成片导出 | 主责 | 不提供 |
| 版本 | `edit_revisions` | `mix_revisions` |

### 7.2 状态模型

剪辑页顶部始终显示以下之一：

| 状态 | 含义 | 用户动作 |
| --- | --- | --- |
| `混音已对齐` | 当前混音基于当前剪辑时间 | 可直接导出 |
| `混音需更新` | 画面时长或源素材变化 | 去混音页重新对齐，或仅导出画面 |
| `尚未混音` | 没有混音版本 | 去混音页创建，或仅导出画面 |
| `混音生成中` | 混音任务进行中 | 等待，可继续编辑；完成后提示 |
| `混音失败` | 最近一次混音失败 | 查看原因、重试、去混音页 |

**会标记 `混音需更新` 的操作：**

| 操作 | 是否影响混音 |
| --- | --- |
| 插入/删除/移动片段 | 是（总时长/顺序变化） |
| 裁剪片段 | 是（时长变化） |
| 变速 | 是（时长变化） |
| 叠化转场 | 是（总时长变化） |
| 淡入/淡出黑 | 否（总时长不变） |
| 分割 | 否（总时长不变） |
| Take 切换 | 是（素材变化，需刷新原声参考） |
| 仅删除留空 | 是（总时长不变但出现空档，混音时间轴需确认） |
| 画面适配/缩放/旋转 | 否 |
| 滤镜/标题/画中画 | 否（画中画若延长总时长则影响） |
| 字幕改动 | 否 |
| 工程画幅变化 | 否 |
| 帧率变化 | 是（时间基准变化） |

**原则：** 只影响画面的操作不打扰声音；影响时间或源素材的操作必须显式提示。

### 7.3 重新对齐

**入口：**

- 剪辑页混音徽标；
- 混音页顶部横幅「画面已更新，需要重新对齐」；
- 导出抽屉前置检查。

**流程：**

1. 点击「重新对齐」；
2. 显示差异摘要：
   - 画面总时长：`01:32 → 01:28`；
   - 移动片段：3 个；
   - 删除片段：1 个；
   - 新增片段：2 个；
   - 受影响的台词：5 句；
3. 选择对齐策略：
   - `保留人工调整（推荐）`：按 `lineId / clipId` 匹配，保留音量/声像/片段增益；无法匹配的片段进入待确认；
   - `按当前画面重排`：以新 EditPlan 重建混音时间轴，人工调整重置，需二次确认；
4. 执行对齐，生成混音草稿（不直接保存版本）；
5. 混音页试听检查；
6. 保存为新 `mix_revisions`；
7. 回到剪辑页，状态变回 `混音已对齐`。

**待确认列表：**

- 新增画面没有对应声音：列出片段，提供「用原声」「生成配音」「静音」；
- 删除画面的声音：列出轨道片段，提供「删除」「保留到末尾」「移入音效轨」；
- 时长不足/超出：显示差额，允许拉伸淡入淡出或移动。

**不静默丢弃：** 任何无法匹配的混音片段都必须出现在待确认列表，保存前不能忽略。

### 7.4 跳转上下文

```ts
interface WorkbenchHandoff {
  episodeId: number
  playheadMs: number
  rangeStartMs?: number
  rangeEndMs?: number
  selection?: { kind: 'clip' | 'line' | 'cue'; id: number | string }
  from?: 'edit' | 'mix'
}
```

**规则：**

1. 剪辑页「调整这段的声音」→ 混音页，播放头一致，选中对应台词/片段；
2. 混音页「查看画面」→ 剪辑页，播放头一致，选中对应片段；
3. 返回时恢复来源页的缩放、滚动、选中与播放头；
4. 跳转前暂停并释放播放器；
5. 两页都只有一个可见播放器，不共享实例；
6. 顶部显示对方状态，避免来回切换后迷失。

## 8. 成片导出

### 8.1 前置检查

打开导出抽屉时自动检查：

| 检查项 | 阻断 | 提示与动作 |
| --- | --- | --- |
| 时间线为空 | 是 | 「先添加至少一个片段」+ 一键初剪 |
| 混音需更新 | 是（最终导出） | 「画面已变化，先重新对齐混音」+ 去对齐 / 仅导出画面 |
| 尚未混音 | 是（最终导出） | 「还没有混音」+ 去混音 / 仅导出画面 |
| 混音生成中 | 是 | 「混音生成中，完成后可导出」 |
| 素材离线 | 是 | 列出离线片段 + 重链/重新生成 |
| 保存失败 | 是 | 「先解决保存失败」+ 重试 |
| 字幕警告 | 否 | 汇总数量，可继续 |
| 总时长 0 | 是 | 同空时间线 |
| 存储空间不足 | 是 | 显示所需空间 + 清理建议 |

**仅导出画面（临时）：**

- 位于导出抽屉「更多」；
- 明确标注「临时文件，不含最终混音，不建议交付」；
- 使用片段原声，混音缺失时静音；
- 文件名追加 `_temp`；
- 不更新 `episodes.video_url`；
- 不进入正式导出历史（或标记为临时）。

### 8.2 导出预设

| 预设 | 分辨率 | 帧率 | 视频码率 | 音频 | 适用 |
| --- | --- | --- | --- | --- | --- |
| 竖屏超清（默认） | 1080×1920 | 工程帧率 | 8 Mbps | AAC 192 kbps | 抖音/快手/视频号 |
| 竖屏高清 | 720×1280 | 工程帧率 | 4 Mbps | AAC 160 kbps | 快速预览/低配 |
| 横屏超清 | 1920×1080 | 工程帧率 | 8 Mbps | AAC 192 kbps | B 站/YouTube |
| 源尺寸 | 工程分辨率 | 工程帧率 | 自动 | AAC 192 kbps | 内部归档（P1） |

**字幕模式：**

| 模式 | 说明 | 默认 |
| --- | --- | --- |
| 硬字幕 | 烧录进画面，平台兼容性最好 | 是 |
| 软字幕 | 独立字幕流，可开关 | 否 |
| 无字幕 | 不输出字幕 | 否 |

**文件命名：**

```text
EP03_成片_v12_20261105_1430.mp4
```

- 集号、版本、时间；
- 文件名可编辑；
- 输出目录默认项目 `exports/`，可改；
- 导出前显示预计大小。

### 8.3 导出流程

```text
点击导出
  → 前置检查
  → 确认预设/字幕/文件名
  → 创建导出任务（快照当前 EditPlan + MixPlan + 字幕）
  → 渲染视频轨（cut.mp4）
  → 渲染混音（mix.wav）
  → 合成字幕与封装
  → 校验
  → 完成
```

**阶段与进度：**

| 阶段 | 进度 | 文案 |
| --- | --- | --- |
| 准备 | 0–5% | 正在准备素材 |
| 渲染画面 | 5–55% | 正在渲染画面 42% |
| 渲染声音 | 55–75% | 正在渲染声音 |
| 合成字幕 | 75–90% | 正在合成字幕 |
| 校验 | 90–100% | 正在校验成片 |
| 完成 | 100% | 导出完成 |

**规则：**

- 导出使用点击时的快照，后续编辑不影响本次导出；
- P0 导出期间锁定本集编辑；P1 允许继续编辑并提示「本次导出使用 v12 快照」；
- 取消：立即停止 FFmpeg，保留日志，删除临时文件；
- 失败：保留已生成中间文件 24 小时，支持重试；重试从失败阶段继续（P1），P0 从头重试；
- 并发：同一集同时只允许一个导出任务；不同集可并行（队列上限 2，P1）；
- 桌面版导出完成发系统通知；
- 关闭窗口时若有导出任务，提示「导出将在后台继续」或「取消并退出」。

### 8.4 校验与报告

导出完成后自动校验：

| 项 | 标准 | 失败处理 |
| --- | --- | --- |
| 文件存在/可读 | 能打开 | 失败 |
| 时长 | 与 EditPlan 总时长误差 ≤ 100ms | 警告/失败 |
| 分辨率 | 与预设一致 | 失败 |
| 帧率 | 与工程一致 | 警告 |
| 视频流 | H.264，可解码 | 失败 |
| 音频流 | AAC，双声道，可解码 | 失败 |
| 字幕流 | 软字幕时存在 | 失败 |
| 响度 | 目标 LUFS 范围内 | 警告 |
| 首帧/尾帧 | 非全黑（除非用户设置） | 警告 |

**报告展示：**

- `通过` / `有警告` / `失败`；
- 每项显示实际值与标准值；
- 失败时提供「查看日志」「重试」「复制诊断信息」；
- 诊断信息脱敏，不含密钥与完整路径中的用户名。

### 8.5 导出历史

- 列表：时间、版本、预设、时长、大小、状态、校验结果；
- 操作：播放、打开文件夹、设为当前成片、删除（二次确认）、复制参数；
- `设为当前成片` 更新 `episodes.video_url` 与 `episode_exports.isCurrent`；
- 同一时间只有一个当前成片；
- 历史保留最近 20 条或 30 天，可配置；
- 删除当前成片需先选择另一个版本或确认清空；
- 导出记录关联 `editRevisionId` 与 `mixRevisionId`，可回溯。

### 8.6 错误与恢复

| 错误 | 文案 | 动作 |
| --- | --- | --- |
| 素材离线 | 「3 个镜头的源文件不在了，导出已暂停。」 | 重链、重新生成、移除片段 |
| 混音未对齐 | 「画面改过了，当前混音对不上。」 | 重新对齐、仅导出画面 |
| 存储不足 | 「导出需要约 1.2 GB，当前只剩 300 MB。」 | 清理空间、改目录 |
| FFmpeg 失败 | 「渲染在 62% 失败：视频编码器错误。」 | 重试、降低预设、复制诊断 |
| 字幕烧录失败 | 「字幕样式包含不支持的字体。」 | 换字体、导出无字幕 |
| 任务被取消 | 「导出已取消，临时文件已清理。」 | 重新导出 |
| 应用崩溃 | 下次打开显示「上次导出未完成」 | 重试、查看日志 |

### 9.3 错误

**原则：**

- 说清“发生了什么、为什么、下一步”；
- 不显示堆栈、内部路径、密钥；
- 可复制的诊断信息单独提供；
- 阻断性错误必须给出一个主行动；
- 非阻断错误用 toast，不弹模态。

**示例：**

| 场景 | 文案 |
| --- | --- |
| 保存失败 | 「保存失败：磁盘空间不足。修改还在当前页面，请先清理空间再重试。」 |
| 版本冲突 | 「这一集已在另一个窗口被修改。重新加载最新版本，或把你的修改另存为副本。」 |
| 预览解码失败 | 「这个镜头无法预览，可能是编码格式不支持。仍可导出，或先转码。」 |
| 转场时长不足 | 「相邻片段余量不足，转场已缩短到 0.2 秒。」 |
| 字幕重叠 | 「两条字幕重叠了 0.3 秒，已自动裁剪到边界。」 |
| 导出被阻断 | 「导出前需要先处理 2 个离线素材。」 |

### 9.4 加载

- 时间线与素材库使用骨架屏，不用全屏 spinner；
- 预览首帧加载显示缩略图 + 小进度环；
- 代理生成中显示 `预览代理生成中，当前使用原画`；
- 波形/缩略图异步加载，不阻塞操作；
- 长任务显示阶段与预计剩余时间（超过 10 秒）。

### 9.5 文案原则

- 动词开头，短句；
- 用“画面/声音/成片”而不是“视频轨/音频轨/输出”；
- 用“混音需更新”而不是“stale”；
- 用“重新对齐”而不是“重算时间轴”；
- 对用户不可见“EditPlan/MixPlan/hash”等内部术语；
- 中英文都不超过两行；
- 数字与时间码使用等宽字体。

## 10. 性能与体验指标

### 10.1 性能预算

| 指标 | 目标 | 失败阈值 |
| --- | --- | --- |
| 页面首次可交互 | < 1.5s（本地，50 片段） | > 3s |
| 时间线滚动帧率 | 60fps（200 片段） | < 40fps |
| 播放起播 | < 300ms | > 800ms |
| 片段切换 | < 120ms | > 300ms |
| Seek（代理） | < 200ms | > 500ms |
| 裁剪/拖动响应 | < 16ms/帧 | > 33ms |
| 自动保存 | < 50ms 主线程阻塞 | > 150ms |
| 导出进度更新 | 1s/次 | > 3s |
| 一键初剪（30 片段） | < 1s | > 3s |
| 精确预览（30s） | < 30s（1080p 代理） | > 90s |

### 10.2 降级策略

| 场景 | 降级 |
| --- | --- |
| 原画解码卡顿 | 自动切 720p 代理 |
| 代理未就绪 | 540p 转码预览 / 缩略图 |
| 同时解码片段过多 | 视频池限制 3 个，预加载 1 个 |
| 时间线片段过多 | 缩略图降采样，只渲染视口 |
| 音频加载失败 | 静音预览 + 提示，不阻塞画面 |
| 内存不足 | 释放离屏视频，提示降低预览质量 |
| WebAudio 不可用 | 退化为 `<video>` 原声 + 提示 |

### 10.3 长剧集

- 支持 60 分钟、300 片段；
- 时间线虚拟化：只渲染视口 ±1 屏；
- 缩略图分级缓存：低分辨率条 + 按需关键帧；
- 波形按缩放级别分级；
- 导出分段渲染 + 拼接（超 10 分钟自动启用）；
- 撤销历史只存差异，不存整份计划；
- 自动保存在后台序列化，避免主线程卡顿。

## 11. 可访问性与国际化

### 11.1 键盘

- 核心路径可纯键盘完成：素材选择 → 插入 → 移动（专业模式快捷移动）→ 裁剪（数值）→ 删除 → 导出；
- 所有按钮可 Tab 聚焦，焦点环清晰；
- 时间线画布提供「片段列表」替代视图（P1），可键盘排序；
- 模态框焦点陷阱与 Esc 关闭；
- 快捷键不与系统/输入法冲突；
- 提供快捷键帮助面板。

### 11.2 视觉

- 对比度 ≥ 4.5:1（文本），≥ 3:1（控件）；
- 状态不只靠颜色：离线用斜纹 + `!`，混音 stale 用斜纹 + 文字，选中用描边 + 高亮；
- 支持系统减少动效；
- 时间线缩放不影响文字可读性；
- 字幕预览提供高对比模式。

### 11.3 屏幕阅读器

- 播放器、时间线、轨道、片段、字幕 cue 都有 `aria-label`；
- 保存状态、导出进度、错误使用 `aria-live`；
- 片段列表替代视图提供顺序、时长、源状态；
- 拖拽操作提供键盘替代（检查器数值输入、菜单移动）；
- 图标按钮有文字标签。

### 11.4 国际化

- 文案 key 同步 zh/en/ja/ko；
- 时间码、数字、文件大小按 locale 格式化；
- 字幕字体按语言选择回退字体；
- 日语/韩语字幕行宽单独配置；
- 文案长度变化不撑破布局；
- 不硬编码中文到组件；
- 导出文件名支持本地化但保留 ASCII 兜底。

## 12. 验收与测试

### 12.1 黄金路径

**路径 A：从素材到成片（核心）**

1. 打开一集有 18 个已生成镜头的剧集；
2. 进入剪辑页，点击「一键初剪」；
3. 时间线出现 18 个连续片段，字幕轨出现台词；
4. 裁剪第 3 个片段开头 1 秒；
5. 在播放头处分割第 7 个片段；
6. 波纹删除第 8 个片段；
7. 拖动第 12 个片段到第 10 个位置；
8. 给第 5/6 片段之间加 0.4s 叠化；
9. 修改一条字幕文本与时间；
10. 点击播放，连续预览，字幕正确；
11. 打开导出，选择竖屏超清 + 硬字幕；
12. 导出成功，校验通过，播放成片；
13. 设为当前成片，返回剧集页看到新成片。

**通过标准：** 全程无阻断错误；总耗时 < 15 分钟；撤销/重做可用；导出音画同步。

**路径 B：横屏与导入素材**

1. 新建/切换横屏工程；
2. 导入一个本地 mp4；
3. 插入到时间线，裁剪、变速 1.5x；
4. 适配填充；
5. 导出横屏，校验通过。

**路径 C：跨页一致性**

1. 完成一版画面与混音，混音已对齐；
2. 回剪辑页删除一个 2 秒片段；
3. 顶部变为「混音需更新」；
4. 打开混音页，看到差异摘要；
5. 选择「保留人工调整」重新对齐；
6. 保存混音新版本；
7. 回剪辑页，状态变回「混音已对齐」；
8. 导出成功，音画同步。

### 12.2 边界验收

| 场景 | 期望 |
| --- | --- |
| 空时间线导出 | 阻断，给出一键初剪 |
| 所有素材离线 | 阻断，列出离线项，可重链 |
| 混音 stale 导出 | 阻断最终导出，允许临时画面 |
| 导出中关闭页面 | 提示后台继续/取消 |
| 保存失败 | 不丢修改，导出禁用 |
| 两个窗口同时编辑 | 检测冲突，不静默覆盖 |
| 裁剪到 0 | 拒绝，最小 3 帧 |
| 分割在片段边界 | 拒绝并提示 |
| 转场超过余量 | 自动缩短并提示 |
| 字幕重叠 | 自动裁剪或提示 |
| 空档导出 | 黑场，时长正确 |
| 叠加轨无片段 | 透明，不影响主轨 |
| Take 更短 | 黑场 + 警告，不自动放慢 |
| 导入不支持编码 | 提示转码，不崩溃 |
| 长剧集 60 分钟 | 可滚动、可导出 |
| 无 WebAudio | 原声兜底 + 提示 |
| 系统减少动效 | 转场/弹窗简化 |

### 12.3 可用性测试

- 招募 5 名目标用户（至少 2 名未用过专业剪辑软件）；
- 任务：把一集 15 个镜头剪成 60 秒成片并导出；
- 观察：首次操作是否找到一键初剪；是否能独立完成裁剪/删除/字幕/导出；
- 通过标准：
  - 任务完成率 ≥ 80%；
  - 中位完成时间 ≤ 15 分钟；
  - 严重可用性问题 0；
  - 80% 用户能解释「混音需更新」的含义；
  - 80% 用户能独立完成重新对齐。

- P0 功能矩阵全部通过；
- P1 功能矩阵中标注“发布门槛”的能力全部通过；
- 黄金路径 A/B/C 自动化或人工验收通过；
- 导出成功率在 50 次真实导出中 ≥ 98%；
- 崩溃恢复成功率 100%（测试注入崩溃）；
- 四语文案完整，无硬编码；
- 无阻断级无障碍问题；
- 关键性能指标达标；
- 旧入口迁移策略验证通过。

## 13. 指标与埋点

### 13.1 北极星

**从“素材就绪”到“首次成片导出成功”的中位时长。**

目标：P1 发布后 ≤ 15 分钟；成熟后 ≤ 10 分钟。

### 13.2 漏斗

```text
打开剪辑页
  → 首次添加片段 / 一键初剪
  → 首次播放
  → 首次导出点击
  → 导出成功
  → 设为当前成片
```

**指标：**

- 打开到首次编辑的转化率；
- 一键初剪使用率；
- 首次导出成功率；
- 导出后设为当前成片比例；
- 从打开到导出的中位时长。

### 13.3 质量

| 指标 | 目标 |
| --- | --- |
| 导出成功率 | ≥ 98% |
| 预览错误率 | < 1% |
| 自动保存失败率 | < 0.5% |
| 崩溃恢复成功率 | 100% |
| 混音 stale 未处理即导出 | 0（应被阻断） |
| 重新对齐后音画不同步投诉 | 0 |
| 版本冲突静默覆盖 | 0 |

### 13.4 事件

| 事件 | 字段 | 用途 |
| --- | --- | --- |
| `edit_open` | episodeId, source | 入口分析 |
| `edit_rough_cut` | clipCount, skippedCount, mode | 初剪使用 |
| `edit_clip_add` | source, position | 素材使用 |
| `edit_trim` | deltaMs, ripple | 剪辑行为 |
| `edit_split` | atMs | 剪辑行为 |
| `edit_delete` | ripple, durationMs | 剪辑行为 |
| `edit_reorder` | from, to | 排序 |
| `edit_speed` | value | 变速 |
| `edit_transition_add` | type, durationMs | 转场 |
| `edit_subtitle_edit` | field, pinned | 字幕 |
| `edit_preview_exact` | rangeMs, success | 精确预览 |
| `edit_export_start` | preset, subtitleMode, revision | 导出 |
| `edit_export_success` | durationMs, size, warnings | 导出质量 |
| `edit_export_fail` | stage, code | 失败分析 |
| `edit_realign_start` | diffSummary | 跨页 |
| `edit_realign_success` | keptAdjustments, pendingCount | 跨页 |
| `edit_recovery` | action | 稳定性 |
| `edit_undo` | action | 可用性 |
| `edit_mode_switch` | mode | 简单/专业 |

**原则：**

- 事件只记录行为与结果，不记录台词内容、文件名、路径；

- 失败事件带脱敏错误码，不带堆栈；
- 埋点失败不影响主流程。

## 14. 迁移与发布

### 14.1 阶段

| 阶段 | 范围 | 出口条件 |
| --- | --- | --- |
| M0 设计 | 本文档 + 技术架构 | 评审通过 |
| M1 只读 | `/edit` 展示当前成片为单片段；素材库只读 | 路由、版本指针、权限、空态可用 |
| M2 MVP | P0 编辑与导出 | 黄金路径 A/B 通过 |
| M3 完整核心 | P1 能力 | 发布门槛通过 |
| M4 收敛 | 旧入口改为跳转；旧最终导出下线 | 旧入口使用率 < 5% 且无阻断问题 |

### 14.2 存量数据

**首次打开某集：**

1. 若已有 `edit_revisions`，读取当前版本；
2. 否则：
   - 若有 `video_merges` 片段数据，按合片片段构建初始 EditPlan；
   - 否则若有 `episodes.video_url`，构建单片段 EditPlan；
   - 否则若已有分镜视频，显示空时间线 + 一键初剪；
   - 否则显示无素材空态；
3. 创建初始版本 `v1`，备注 `自动初始化`；
4. 不修改源文件与旧字段；
5. 混音若存在，绑定当前 EditPlan 的时间哈希；无法绑定则标记 `需更新`。

**旧导出记录：**

- 保留 `episode_exports` 历史；
- 新导出补充 `editRevisionId` / `mixRevisionId`；
- 旧记录的 `planRevisionId` 保留兼容；
- 不批量重写旧记录。

### 14.3 回滚

- M2/M3 期间旧入口仍可用；
- 若新页面出现阻断问题，隐藏 `/edit` 入口即可回到旧流程；
- 已创建的 `edit_revisions` 不删除，问题修复后继续使用；
- 导出记录不迁移、不回滚；
- `episodes.video_url` 只在用户点击「设为当前成片」时更新，回滚不会污染当前成片。

## 附录 B：术语

| 术语 | 含义 |
| --- | --- |
| EditPlan | 剪辑计划：主轨片段、叠加片段、字幕 cue、工程设置的唯一数据源 |
| MixPlan | 混音计划：轨道、片段、总线、ducking、响度的唯一数据源 |
| 时间脊梁 | EditPlan 定义画面时长与顺序，MixPlan 依赖它对齐 |
| 时间哈希 | EditPlan 中影响时长的字段哈希，用于判断混音是否过期 |
| 磁吸主轨 | 主轨片段默认连续，插入/删除自动闭合 |
| 波纹删除 | 删除片段并闭合空隙 |
| 仅删除留空 | 删除片段但保留时间空档，导出为黑场 |
| 转场余量 | 相邻片段可重叠/裁剪的空间，限制转场时长 |
| Take | 同一镜头/台词的某次生成结果 |
| Cue | 一条字幕及其时间范围 |
| 固定字幕 | 手动调整过时间、不再跟随片段的字幕 |
| 代理 | 为预览生成的低分辨率/低码率副本 |
| 精确预览 | 服务端按最终渲染链生成的区间预览 |
| Stale | 混音与当前画面时间或素材不一致，需要更新 |
| 重新对齐 | 按新 EditPlan 调整 MixPlan，尽量保留人工调整 |
| 当前成片 | `episodes.video_url` 指向的最终导出文件 |
| 快照导出 | 导出任务使用点击时固定的计划版本，不受后续编辑影响 |
