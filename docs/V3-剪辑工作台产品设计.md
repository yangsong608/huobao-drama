## 0. 一页结论

剪辑工作台不是通用剪辑软件，而是火宝短剧的「成片精修台」：从「拼接导出」已经生成的成片里选一部，快速完成裁剪、帧级修正、字幕和导出，并把结果放回同一个成片列表。

**产品承诺：**

> 一个没学过 Premiere 的创作者，能用鼠标完成从选成片到导出的全过程；每一帧都能删、能复制、能补图、能拉长；字幕的字体、大小、颜色、位置和时间都能直接改；任何一次导出都可追溯，旧成片不会被覆盖。

**五个关键决策：**

1. **两个独立页面**：`/edit` 只做画面与字幕，`/mix` 只做声音；两个页面各自只有一个可见预览和一个播放时钟。
2. **一个成片目录**：拼接、混音、剪辑的成片都进入同一份 `video_merges` 列表；三个页面用同一个选择器，导出成功后写回同一列表，不互相覆盖。
3. **剪辑以成片为源**：左侧是成片列表；选中一部成片即创建/恢复该成片的剪辑工程。不同成片有不同工程，互不影响。
4. **默认简单、鼠标可达**：一条磁吸主轨、硬切、自动保存；删除帧、复制帧、插入图片、拉长、字幕编辑都能通过右键菜单和可见按钮完成，不要求记快捷键。
5. **非破坏写回**：导出只新增成片；默认不改变「当前成片」，用户显式勾选「设为当前成片」后才更新指针。

**本轮发布范围：**

| 阶段 | 内容 | 是否可交付 |
| --- | --- | --- |
| A 成片中心 | 成片列表、选择器、设为当前、导出投影 | 是 |
| B 混音接入 | 源成片选择、背景声入口、声音素材库、混音导出写回 | 是 |
| C 剪辑工程与字幕 | 成片工程、左侧成片列表、右键菜单、字幕样式/位置/时间 | 是 |
| D 帧级操作与导出 | 删除帧/复制帧/插入图片帧/拉长、受约束渲染器、导出写回 | 是 |
| E 验收收口 | 全量测试、真实 E2E、截图与报告 | 是 |

> 转场、滤镜、画中画/叠加轨、x/y 变换、关键帧、调色、多机位、跟踪、4K/60fps 不在本轮；详见规格说明第 13 章。

**明确不做（本轮）：**

- 不做转场导出、滤镜导出、画中画/叠加轨、x/y 位移、关键帧、调色；
- 不做云端协作与多人实时编辑；
- 不做社交平台发布、账号代运营；
- 不在剪辑页做混音台、总线、ducking、声音分离；
- 不在混音页做视频排列、帧级操作、字幕文本/样式编辑、硬字幕烧录。

## 1. 定位与用户

### 1.1 一句话定位

**把 AI 生成的碎片镜头，装成一条能直接发布的短剧成片。**

### 1.2 目标用户

| 用户 | 特征 | 核心诉求 |
| --- | --- | --- |
| 独立创作者 | 一个人完成小说改写、生成、配音、剪辑、发布 | 不想学专业软件，希望默认值就能用 |
| 小工作室剪辑 | 2–5 人，分工生成与后期 | 批量处理多集，版本清楚，返工成本低 |
| 运营/制片 | 不直接剪，但要审片与交付 | 打开就能看懂进度、差异和导出结果 |

共同点：懂短剧节奏和平台规范，但不一定懂时间线、帧、码率、响度。产品不能要求他们先成为后期工程师。

### 1.3 核心场景与 JTBD

**场景 A：选片与初修（最高频）**

- 输入：「拼接导出」已经生成的一部成片（15–40 个镜头合成的视频）。
- 任务：在左侧成片列表选中它，检查连续播放，删掉多余的帧/片段，调整顺序和总时长。
- 成功：打开就能看到成片，5 分钟内得到一版可导出的初修。

**场景 B：帧级精修**

- 任务：删除某一帧、复制某一帧、插入一张图片作为播放帧、把某个镜头拉长；裁剪入出点、分割、变速、调整适配。
- 成功：画面节奏准确，操作全部能用鼠标右键完成。

**场景 C：字幕精修**

- 任务：改字幕文本、开始/结束时间、字体、字号、颜色、描边、背景、对齐方式、水平/垂直位置。
- 成功：预览与导出位置一致，字幕不挡脸、不越界。

**场景 D：声音协作**

- 任务：画面定稿后去混音页处理对白、原声、BGM、背景声；回剪辑页试听并导出。
- 成功：混音页以选中的源成片为准，切换源成片有明确提示，不会静默错位。

**场景 E：交付**

- 任务：选择竖屏/横屏、字幕模式、清晰度，导出并确认文件可播放。
- 成功：一次导出成功，成片列表出现新版本，可回溯到源成片、剪辑版本与混音版本。

**JTBD 表述：**

- 当我拿到一集拼接好的成片时，我想直接选它开始剪辑，这样我不用再找素材、铺轨。
- 当某个镜头多了一帧或开头有多余动作时，我想删掉这一帧或裁掉边缘，这样我不用重新生成。
- 当某个画面缺失时，我想插入一张图片当播放帧，这样我能先交付再补生成。
- 当台词和画面对不上时，我想看到字幕与声音参考在同一条时间线上，这样我能直接判断该移画面还是改字幕。
- 当我准备发布时，我想一键得到符合平台规格的成片，这样我不用记码率、分辨率和字幕开关。

### 1.4 差异化

| 差异点 | 说明 | 对用户的价值 |
| --- | --- | --- |
| 成片即素材 | 左侧直接列出「拼接导出」的成片，选中即可剪辑 | 不用整理素材、不用重新铺轨 |
| 帧级操作 | 删除帧、复制帧、插入图片帧、拉长都在右键菜单里 | 不用会快捷键，也不用重新生成 |
| 字幕可调样式与位置 | 字体、字号、颜色、描边、背景、对齐、x/y 位置和时间均可编辑 | 导出字幕和预览一致，不挡脸 |
| 声音参考只读 | 剪辑页能看波形、听混音，但不做混音 | 边界清楚，不会出现“两个混音器” |
| 非破坏写回 | 导出新增成片，旧成片不覆盖；默认不抢当前成片 | 可以放心多版本尝试 |
| 默认简单 | 一条主轨、默认波纹、默认硬切、默认适配、鼠标可达 | 新用户不用先学轨道和工具 |
| 本地优先 | 桌面版本地渲染、本地文件、无上传等待 | 长视频和隐私素材更可控 |

### 1.5 非目标

- 不做专业调色台、音频工作站、特效合成软件；
- 不做多用户实时协作与评论批注；
- 不做素材市场、模板市场、AI 换脸/换背景；
- 不做发布分发与数据回流；
- 不替代混音工作台，不替代配音工作台的台词与音色管理。

## 2. 设计原则

| # | 原则 | 落地规则 |
| --- | --- | --- |
| 1 | **一条主线** | 素材 → 时间线 → 预览 → 导出；页面不出现第二条平行流程 |
| 2 | **一个可见预览、一个时钟** | 每页只有一个可见播放器；内部可预加载多个解码器，但用户只感知一个播放头 |
| 3 | **默认简单，专业渐进** | 简单模式覆盖 80% 操作；专业模式只展开精确控制，不新增页面 |
| 4 | **磁吸主轨，不让用户管轨道** | 主轨默认无空隙；插入、移动、删除自动闭合；留空是显式动作 |
| 5 | **非破坏编辑** | 所有裁剪、变速、帧级操作只改计划，不改源成片；永远可撤销；导出新增成片 |
| 6 | **预览可近似，导出必一致** | 变速/淡入淡出预览标注「近似」；导出使用同一计划与样式源 |
| 7 | **声音有明确主人** | 剪辑页只监听，不混音；所有声音调整跳转混音页 |
| 8 | **改动有后果提示** | 影响混音时长的操作立即标记；不影响的操作不打扰 |
| 9 | **自动保存 + 可恢复** | 300ms 防抖保存；崩溃/关闭后可恢复；版本可回溯 |
| 10 | **失败可行动** | 每个错误都给出下一步：重试、重链、去拼接导出、去混音、复制诊断 |
| 11 | **鼠标优先** | 所有核心操作有可见按钮与右键菜单；快捷键只是加速 |
| 12 | **中文优先，四语可用** | 文案短、动词开头；zh/en/ja/ko 同步；时间码与数字本地化 |
| 13 | **不靠颜色传达唯一信息** | 状态同时用图标、文字、纹理；色盲可辨 |

## 3. 信息架构与路由

### 3.1 目标信息架构

```text
剧集
├─ 剧本
├─ 制作（资产 / 分镜 / 生图 / 生视频）
├─ 配音（台词 / 音色 / 生成）
├─ 剪辑（画面 / 字幕 / 成片导出）      /edit
└─ 混音（对白 / 原声 / 音效 / BGM）    /mix
```

**为什么不是把剪辑塞进配音第 4 步：**

- 配音页的五步是“声音生产”流程，剪辑是“画面总装”流程，两者时间尺度与操作对象不同；
- 同一页面放两个播放器、两条时间线、两套检查器，必然出现“四不像”；
- 分成两页后，每页只有一个时钟，键盘、撤销、自动保存、版本都能独立定义；
- 共享数据放在项目层，不放在页面层。

### 3.2 路由

沿用现有动态路由：

| 页面 | 路由 | 说明 |
| --- | --- | --- |
| 剪辑工作台 | `/drama/:id/episode/:episodeNumber/edit` | 主编辑页 |
| 混音工作台 | `/drama/:id/episode/:episodeNumber/mix` | 现有音频能力迁移 |
| 剧集工作台 | `/drama/:id/episode/:episodeNumber` | 原有剧本/制作/配音入口 |

路由参数使用 `episodeNumber` 与现有 `pages:extend` 保持一致；页面内部通过剧集数据解析 `episodeId`。跨页交接对象使用 `episodeId`，避免依赖 URL 编号。

**查询参数（可选）：**

```text
?at=12345                 播放头毫秒
&in=10000&out=20000       预览区间
&clip=clp_a1              选中片段（字符串 ID）
&line=456                 选中台词
&from=mix                 来源页，用于返回
```

### 3.3 入口

| 入口 | 行为 | 说明 |
| --- | --- | --- |
| 剧集工作台顶部「剪辑」 | 打开 `/edit` | 主入口；左侧显示本集成片列表 |
| 制作页「拼接导出」 | 保留为成片中心：列出成片、设为当前、在混音/剪辑中打开 | 不再承担最终混音/剪辑导出 |
| 配音页第 4 步「预览与混音」 | 改为「打开混音工作台」 | 第 4 步保留入口卡片与混音状态 |
| 配音页第 5 步「合成导出」 | 改为「去混音/剪辑页导出」 | 导出能力迁移 |
| 剧集工作台顶部「混音」 | 打开 `/mix` | 声音主入口；顶部选择源成片 |
| 成片卡片「剪辑」 | 打开 `/edit?film_id=...` | 直接定位到该成片的工程 |
| 导出完成通知 | 打开成片列表并定位新成片 | 不另开播放器 |

### 3.4 页面职责去重对照

| 旧入口/旧能力 | 新归属 | 迁移方式 |
| --- | --- | --- |
| 制作页「拼接导出」 | 成片中心 | 保留列表与「生成拼接成片」；增加「在混音中打开」「在剪辑中打开」「设为当前成片」 |
| 配音第 4 步 `AudioMixBoard` | 混音页 | 保留现有 `MixStage` 能力，入口改为跳转；顶部增加源成片选择 |
| 配音第 5 步 `ExportStage` | 混音/剪辑页导出抽屉 | 迁移 `useExportSession` 与导出记录；视频导出写回成片目录 |
| `LineList` 中的逐句合成 | 配音页第 3 步 | 配音 Take 留在配音/混音页；剪辑页只做画面与字幕 |
| `SubtitlePreview` 单视频预览 | 剪辑页预览 | 保留组件作为单片段预览兜底，不承担多片段合成 |
| 制作页视频列表逐个播放 | 成片列表 | 统一展示、检索、预览、选择；不再按分镜/素材堆叠 |

### 3.5 迁移节奏

| 阶段 | 页面状态 | 用户可见变化 |
| --- | --- | --- |
| A 成片中心 | 旧流程不变 | 成片列表统一；导出成功后出现新成片 |
| B 混音接入 | `/mix` 顶部可选源成片 | 混音结果可写回成片列表 |
| C 剪辑工程与字幕 | `/edit` 可打开成片、可编辑字幕 | 左侧成片列表；右键菜单；字幕样式/位置/时间 |
| D 帧级与导出 | `/edit` 帧级操作与导出可用 | 删除帧/复制帧/插入图片/拉长真实生效 |
| E 收敛 | 旧入口改为跳转卡片 | 旧合片最终导出下线，只保留「生成拼接成片」 |

迁移期间不删除旧数据、不重写 `episodes.video_url` 的既有值；新页面通过 `current_film_id` 读取当前成片，导出成功后默认只新增成片，用户显式「设为当前成片」后才更新指针。

```text
└──────────────────────────────────────────────────────────────────────────────┘
```

> 右键菜单与工具栏承担同一批核心操作；用户不需要记快捷键。成片卡片和字幕 cue 也有各自的右键菜单。

### 4.2 区域职责

| 区域 | 内容 | 关键约束 |
| --- | --- | --- |
| 顶部栏 | 返回、剧集信息、当前成片、剪辑版本、保存状态、撤销/重做、导出 | 成片与版本必须常驻可见；导出是唯一主按钮 |
| 左侧成片列表 | 本集成片（拼接/混音/剪辑/导入），可搜索、筛选、排序 | 卡片单击选中并打开对应工程；右键提供「设为当前」「在混音中打开」 |
| 中部预览 | 一个可见画面、字幕叠加、安全区、运输条、音量、质量 | 内部视频池，不向用户暴露多个播放器 |
| 下部时间线 | 主视频轨、字幕轨、只读声音参考 | 主轨可编辑；声音参考不可编辑；右键菜单覆盖核心操作 |
| 右侧检查器 | 字幕、片段、画面、工程、声音跳转 | 属性随选中对象切换；无选中时显示工程信息 |
| 导出抽屉 | 预设、字幕模式、检查、进度、历史 | 从右侧滑出；导出成功后显示「在新成片中查看」 |

### 4.3 顶部栏

**从左到右：**

1. 返回剧集；
2. 第 N 集 · 标题；
3. 当前成片：`拼接 v3`（类型徽标 + 时长），点击打开成片列表；
4. 版本徽标：`剪辑 v12`，点击打开版本历史；
5. 保存状态：`保存中… / 已保存 / 保存失败`；
6. 混音状态徽标：`有可用混音 / 尚未混音`，点击跳转混音页；
7. 撤销/重做按钮（带最近操作提示）；
8. 导出按钮（主按钮）。

**规则：**

- 保存失败时，导出按钮降级为禁用，并显示原因；
- 成片未就绪/文件缺失时，导出按钮禁用并提示重新导出；
- 版本徽标只在有未保存更改时显示 `·` 标记；
- 顶部栏高度固定 48px，不随滚动隐藏。

### 4.4 成片列表（左侧）

**标签页：**

| 标签 | 内容 | 默认排序 |
| --- | --- | --- |
| 全部 | 本集所有可用成片 | 更新时间倒序 |
| 拼接 | `kind='concat'` 的原始拼接成片 | 创建时间倒序 |
| 混音 | `kind='mix'` 的混音导出成片 | 创建时间倒序 |
| 剪辑 | `kind='edit'` 的剪辑导出成片 | 创建时间倒序 |

**卡片信息：**

- 首帧缩略图；
- 标题（默认「拼接 v3 / 混音 v2 / 剪辑 v1」，可重命名）；
- 类型徽标：拼接 / 混音 / 剪辑 / 导入；
- 时长 `00:05`；
- 创建时间；
- 状态：`可用了 / 生成中 / 失败 / 离线`；
- `当前` 徽标（`current_film_id`）；
- `已剪辑` 徽标（该成片有剪辑工程）；
- 混音成片额外显示 `含配音` 徽标。

**选择与操作：**

- 单击卡片：选中并打开/恢复该成片的剪辑工程；已选中卡片高亮；
- 右键卡片：
  - 在剪辑中打开；
  - 在混音中打开（作为源成片）；
  - 设为当前成片（当前项禁用）；
  - 重命名；
  - 删除（当前成片禁用，提示先切换）；
  - 查看导出记录。
- 双击卡片：在预览区从头播放。

**筛选与搜索：**

- 按类型、可用状态、是否当前、是否已剪辑筛选；
- 搜索标题；
- 只展示已完成成片；文件不可读的成片置顶并标记「离线」，生成中/失败的渲染任务只在导出记录里出现；
- 默认只显示本集；切换剧集时清空选择。

**空态：**

- 本集没有成片时显示：「还没有成片。先去制作页的『拼接导出』生成一版拼接成片。」
- 提供「去拼接导出」按钮；
- 不自动创建空工程，不显示不可播放的占位卡片。

**与分镜列表的区别：**

- 剪辑页不展示分镜素材列表，也不提供「一键初剪」；
- 需要调整镜头顺序/替换镜头时，回制作页重新拼接生成新成片，再在剪辑页选择它；
- 这样保证「剪辑的输入」和「用户看到的成片」始终是同一个文件。

### 4.5 预览与运输条

**画面：**

- 按工程画幅显示；工程画幅默认取剧集项目 `aspect_ratio`（现有项目多为 16:9，新建短剧项目可设 9:16）。
- 画面外区域使用深色背景，可切换模糊背景（远期）；
- 字幕叠加在画面内，显示安全区；
- 选中片段时显示源入出点角标；
- 剪辑以硬切播放；源成片本身包含的转场/滤镜按原视频播放，剪辑页不新增也不模拟这些效果；
- 预览区右上角在解码降级时标注 `近似预览`，导出结果以服务端渲染为准。

**运输条：**

```text
[上一片段] [上一帧] [播放/暂停] [下一帧] [下一片段]   00:00:12:08 / 00:01:32:00   音量 [▮▮▮] 质量 [自动]
```

- 时间码格式 `HH:MM:SS:FF`，点击可切换到毫秒；
- 播放/暂停支持空格；
- 逐帧按钮在简单模式隐藏，专业模式显示；
- 上一/下一片段按主轨片段边界跳转；
- 音量只控制监听，不影响导出；
- 质量：`自动 / 720p / 原画`；自动按代理可用性与解码能力选择；
- 播放时显示实时音频表；削波时显示 `削波` 警告，不自动改混音。

**播放行为：**

- 播放到主轨末尾自动停止，回到开头或停在末尾（设置项，默认停在末尾）；
- 拖动播放头时暂停音频，释放后从新位置继续；
- 快速拖动只显示缩略图，停止 120ms 后加载实际画面；
- 播放中切换片段使用预加载，目标切换延迟 < 120ms；
- 页面隐藏（切标签/最小化）自动暂停并释放解码资源；
- 离开页面时暂停，返回时恢复到上次播放头。

**逐帧与区间检查（本轮）：**

- 运输条提供上一帧/下一帧（不依赖快捷键）；
- 选中一帧可右键「从这里分割」或「删除这一帧」；
- 需要核对字幕位置时，拖动播放头到该 cue 的中点即可；
- 服务端精确区间预览为远期能力，本轮不作为验收项。

### 4.6 时间线

**轨道：**

| 轨道 | 高度 | 可编辑 | 内容 |
| --- | --- | --- | --- |
| 主视频轨 | 72px | 是 | 视频片段、图片片段、冻结帧片段；缩略图条、源入出点、变速徽标 |
| 字幕轨 | 40px | 是 | 字幕 cue、台词摘要、钉住状态 |
| 声音参考 | 48px | 否 | 混音波形或原声波形；点击跳转混音页 |

**标尺与缩放：**

- 标尺按缩放自适应 `秒 / 5 秒 / 10 秒 / 分钟`；
- 缩放范围 5–500 px/s；
- `Cmd/Ctrl + 滚轮` 以指针为中心缩放；
- `Shift + Z` 适配全部；
- 时间线可横向滚动，播放头自动跟随（可关闭）；
- 主轨片段最小显示宽度 8px，低于阈值只显示色块与选中态。

**片段视觉：**

- 缩略图条按缩放抽取；
- 底部细波形表示源音频（仅参考）；
- 左上角显示源成片内的镜头序号或「图片」；
- 右上角时长；
- 角标：变速 `1.5x`、图片 `图`、冻结 `冻`、离线 `!`；
- 选中：高亮描边 + 检查器联动；
- 离线：红色斜纹 + `源文件离线`；
- 受混音影响：片段角落显示小音频图标，点击跳转混音页。

**帧级操作入口：**

- 右键片段本体：删除这一帧、复制这一帧、拉长 1 秒、分割、删除片段、设为图片帧；
- 时间线工具栏：`删除帧`、`复制帧`、`插入图片`、`拉长` 四个可见按钮；
- 播放头停在某帧时，按钮作用于该帧；无选中时按钮禁用并提示先选片段；
- 所有帧级操作写入撤销历史，并在状态栏显示「已删除 1 帧 / 已复制 1 帧 / 已插入图片 3 秒」。

**字幕视觉：**

- cue 块显示文本前 20 字；
- 手动调整过的时间显示图钉；
- 与台词行关联的 cue 悬浮显示 `第 12 句 · 角色名`；
- 超出安全区的 cue 显示黄色警告。

**声音参考视觉：**

- 默认单条汇总波形；
- 可展开 `对白 / 原声 / 音效 / BGM` 分组，只读；
- 没有可用混音时整条显示灰色斜纹 + 顶部提示「尚未混音，当前静音预览」；
- 双击任意位置打开混音页并定位。

### 4.7 检查器

**无选中：**

- 工程信息：画幅、分辨率、帧率、总时长、片段数；
- 混音状态与「去混音」；
- 导出快捷入口；
- 工程设置（专业模式可改）。

**选中视频/图片片段：**

| 分组 | 字段 | 说明 |
| --- | --- | --- |
| 来源 | 成片名称、源内时间、片段类型（视频/图片/冻结帧）、源文件状态 | 只读摘要 |
| 时间 | 源入点/出点、时长、前空隙；时间线入点/出点只读 | 可输入时间码 |
| 裁剪 | 左/右裁剪 | 拖边缘（默认波纹）；`Alt` 非波纹 |
| 变速 | 0.5x–2x 预设 | 视频片段可用；图片/冻结帧不可用 |
| 画面 | 适配（适应/填充）、缩放、位置（居中/九宫格）、旋转、翻转、淡入/淡出黑 | 不做自由 x/y 位移 |
| 帧操作 | 删除这一帧、复制这一帧、拉长 1 秒、插入图片 | 与右键菜单一致 |
| 声音 | `由混音工作台管理` + 跳转 | 显示 |
| 操作 | 分割、复制片段、删除、仅删除留空 | 显示 |

**选中字幕：**

- 文本（多行，最多 2 行建议）；
- 开始时间 / 结束时间，精确到毫秒；可拖 cue 本体或边缘；
- 角色/说话人；
- 字体：系统白名单字体（默认苹方/思源黑体，按平台回退）；
- 字号：12–120 px；
- 颜色：文字色、描边色、背景色；
- 描边宽度：0–8 px；
- 背景：无 / 半透明底条 / 不透明底条；
- 对齐：左 / 中 / 右；
- 位置：九宫格快捷位置 + 水平位置 `x%`、垂直位置 `y%`；
- 安全区参考线开关；
- `跟随片段` 或 `固定时间`；
- 删除 cue（不删除台词本）。

> 字幕样式优先级：单条 cue 的显式样式 > 工程默认字幕样式。切换选中字幕不会丢失已设置的样式。

### 4.8 导出抽屉

- 从右侧滑出，宽度 420px；
- 顶部：源成片名称、当前剪辑版本、混音版本（如有）、总时长；
- 中部：预设、字幕模式（硬字幕/软字幕/无）、文件名、输出位置；
- 中部提供「导出后设为当前成片」开关，**默认关闭**；
- 底部：前置检查结果、导出按钮、历史记录入口；
- 导出中可最小化为底部进度条；导出期间锁定同一工程的编辑入口，避免版本漂移；
- 导出完成后抽屉保持打开，显示校验报告与「播放」「打开文件夹」「设为当前成片」「在成片列表中查看」。

## 5. 核心交互规格

### 5.1 添加到时间线

| 操作 | 结果 |
| --- | --- |
| 在左侧单击成片卡片 | 打开该成片的剪辑工程；主轨出现一个整段片段 |
| 右键片段 →「复制这一帧」 | 在当前帧后插入 1 秒静止画面（由服务端抽帧生成图片片段） |
| 右键片段 →「插入图片」 | 打开图片选择器；图片作为播放帧插入到播放头，默认 3 秒 |
| 右键片段 →「拉长 1 秒」 | 视频片段末尾延伸；超出源时长时自动生成冻结帧尾 |
| 拖入本地图片到时间线 | 与「插入图片」相同，按落点插入 |
| 双击字幕 cue | 进入文本编辑，不创建新视频片段 |

**插入规则：**

- 主轨默认连续；插入点后的片段整体右移；只有「仅删除留空」和 `Alt/Option` 非波纹裁剪会产生空档；
- 插入图片默认 3 秒，可在检查器改 0.1–30 秒；
- 插入后播放头停在新片段开头；
- 新片段自动选中；
- 若源时长 < 3 帧，拒绝插入并提示；
- 若插入导致总时长超过 60 分钟，拒绝并提示。

### 5.2 选择

| 操作 | 结果 |
| --- | --- |
| 单击片段 | 单选，检查器切换 |
| `Cmd/Ctrl + 单击` | 切换多选 |
| `Shift + 单击` | 连续范围多选 |
| 单击空白 | 取消选择，检查器显示工程信息 |
| `Esc` | 取消选择；播放中则先停止播放 |
| 双击片段 | 预览该片段，播放头到片段开头 |
| 右键片段 | 打开上下文菜单 |

多选后：

- 检查器显示「已选 N 个片段」，只提供通用操作：删除、复制、变速、适配；
- 不支持多选拖拽改变相对顺序（远期）；
- 多选删除默认波纹删除。

### 5.3 移动、排序与插入

**拖动片段本体：**

- 拖动时显示插入指示线；
- 释放后从原位置移除，插入到目标位置；
- 总时长不变；
- 目标位置在原位置之后时，按移除后的索引计算，避免偏移一格；
- 拖动中按 `Esc` 取消；
- 拖动中自动滚动时间线边缘；
- 本轮仅允许主轨内拖动，不支持跨轨道。

**吸附：**

- 默认开启；
- 吸附目标：播放头、其他片段边缘、字幕 cue 边缘、标记、0 点、总时长；
- 吸附阈值 8px，拖动中按住 `Shift` 临时关闭（`Alt/Option` 保留给非波纹裁剪）；
- 吸附时显示对齐线；
- 专业模式可关闭吸附（`S`）。

**碰撞：**

- 主轨不允许重叠；落点即插入，不覆盖；
- 字幕轨 cue 允许重叠但显示 `字幕重叠` 警告；不静默裁剪内容，由用户调整或使用「自动排布」。

### 5.4 裁剪

默认两端都是**波纹裁剪**：改变源入点/出点后，主轨保持连续，后续片段整体移动。按住 `Alt/Option` 拖动边缘为**非波纹裁剪**：被裁掉的时间写成显式空档，后续片段不动。

**拖左边缘：**

- 改变源入点与片段时长；
- 默认波纹：片段仍贴住前一片段/空档，后续片段随总时长变化整体移动；
- `Alt/Option` 非波纹：片段左边界跟随指针移动，差量写入本片段前空隙（`gapBeforeMs`），后续片段不动；
- 不能裁到源入点之前，不能短于 3 帧；
- 最大裁剪受源时长限制。

**拖右边缘：**

- 改变源出点与片段时长；
- 默认波纹：后续片段整体右移/左移以保持连续；
- `Alt/Option` 非波纹：差量写成后空隙，后续片段不动；末段写入片尾空档（`tailGapMs`）；扩展时受下一片段起点限制，无法吞掉已有片段；
- 不能超过源出点，不能短于 3 帧。

**时间字段口径：**

- 时间线入点/出点由布局派生，只读；
- 可编辑的是源入点、源出点、前空隙、速度；专业模式可输入时间码。

**裁剪反馈：**

- 拖动时显示 `源 00:00:02:04 → 00:00:04:12` 与 `时长 00:00:02:08`；
- 同时显示相邻片段是否移动；
- 释放后写入一次撤销记录；
- 裁剪影响总时长时，立即标记混音需更新；
- 裁剪不改源文件，不重新生成。

**限制：**

- 变速片段按时间线时长裁剪，源入出点按速度换算；
- 图片/冻结帧片段不参与变速，裁剪只改变显示时长；
- 延伸视频片段超出源时长时，自动用最后一帧生成冻结帧尾（1 帧精度）。

### 5.5 分割

- 快捷键 `Cmd/Ctrl + B`；
- 分割当前选中片段；无选中时分割播放头下主轨片段；
- 分割点必须在片段内部，距两端至少 3 帧；
- 分割后两段源连续，右侧片段自动选中；
- 字幕 cue 不自动分割；后续可提供「字幕跟随切点」开关（远期）；
- 分割不改变总时长，因此不标记「混音需更新」；
- 分割后允许独立裁剪、变速、删除；
- 分割可撤销。

### 5.6 删除、波纹与留空

| 操作 | 行为 | 使用场景 |
| --- | --- | --- |
| `Delete / Backspace` | 波纹删除：移除片段并闭合空隙 | 默认 |
| `Shift + Delete` | 仅删除：移除片段，留下黑色空档 | 需要保留节奏空档 |
| 右键「删除并留空」 | 同仅删除 | 简单模式也可用 |
| 右键「关闭空档」 | 将空档闭合 | 清理留空 |
| 右键「删除全部空档」（远期） | 一次闭合所有空档 | 批量整理 |

**规则：**

- 空档以黑色块 + `空档 00:00:01:12` 显示；
- 空档计入总时长，导出为黑场；
- 空档上允许放字幕 cue，但显示 `无画面对应` 警告；
- 本轮只有硬切，空档前后直接切换；
- 空档计入总时长，导出时长随之变化；
- 删除最后一个片段后显示空态，不自动删除字幕；
- 删除有台词的片段时，字幕 cue 保留但标记「无画面对应」，用户可手动删除或重新关联。

**帧级删除/复制：**

| 操作 | 结果 |
| --- | --- |
| 删除这一帧 | 波纹删除当前帧（`1000/fps` 毫秒）；视频片段至少保留 3 帧 |
| 复制这一帧 | 服务端抽取当前帧 PNG，作为 1 秒图片片段插入到当前帧之后 |
| 插入图片 | 上传图片后插入为播放帧，默认 3 秒 |
| 拉长 1 秒 | 片段末尾延长 1 秒；视频源不够时生成冻结帧尾 |
| 删除片段 | 与 `Delete` 相同，波纹删除整段 |

### 5.7 变速

- 预设：0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x；
- 本轮只支持 0.5x–2x，不支持自定义 0.25x/4x；
- 变速改变时间线时长，源入出点不变；
- 变速后音频：源音频跟随变速并做变调补偿（pitch-correct），避免卡通音；最终成片通常使用混音，因此该音频只用于未混音预览；
- 变速片段在时间线上显示 `1.5x` 角标；
- 变速可撤销；
- 变速曲线、倒放、定格为远期能力。

### 5.8 转场（本轮不做）

- 本轮剪辑只输出硬切；不提供叠化、白场、推拉、模糊等转场选择；
- 源成片本身已包含的转场按原视频播放，剪辑页不拆分也不重做；
- 如后续恢复转场，需要重新评审渲染器范围、时长与缓存策略；
- 淡入/淡出黑仍作为片段边缘效果保留在「画面」分组，不改变总时长。

### 5.9 画面适配与变换

| 设置 | 选项 | 默认 |
| --- | --- | --- |
| 适配 | 适应（留黑边）/ 填充（裁切） | 填充 |
| 缩放 | 50%–200% | 100% |
| 位置 | 居中 / 九宫格（不做自由 x/y 位移） | 居中 |
| 旋转 | 0° / 90° / 180° / 270° | 0° |
| 翻转 | 水平 / 垂直 | 无 |

**规则：**

- 不同分辨率/画幅的素材自动按工程画幅适配；
- 填充模式默认放大到覆盖画面，允许裁切；
- 适应模式保留完整画面，显示黑边/模糊背景；
- 变换只影响画面，不影响时长；
- 不做自由拖拽画面位置、不做关键帧变换。

### 5.10 滤镜与调色（本轮不做）

- 本轮不提供滤镜、调色、LUT；
- 源成片已有的画面风格按原视频保留；
- 如后续恢复，需要重新评审渲染器与预览一致性。

### 5.11 字幕

**来源：**

1. 源成片的外挂字幕（默认）：首次创建剪辑工程时导入为 cue；
2. 台词本匹配（可选）：当源成片没有外挂字幕时，按时间轴尝试匹配台词行；
3. 手动新增：在字幕轨双击空白创建；
4. 导入 SRT/ASS（后续版本）。

**生成规则：**

- 首次打开某成片的剪辑工程时，若有外挂字幕则导入；没有则显示空字幕轨并提示「可手动添加或去配音页生成台词」；
- cue 时间来自字幕文件，不强制跟随片段；
- 无对应画面的 cue 显示在字幕轨但标记 `无画面`；
- 导入不覆盖已有手动字幕；只在工程首次创建时执行。

**编辑（全部可用鼠标完成）：**

- 双击 cue 进入文本编辑；
- 拖动 cue 本体移动时间；
- 拖左右边缘调整开始/结束时间；
- 检查器可改文本、开始时间、结束时间、角色；
- 手动改时间后 cue 变为 `固定`，不再跟随片段；
- 点击图钉恢复跟随；
- 右键 cue：编辑文本、编辑样式、编辑时间、复制时间、删除；
- 批量偏移后续版本提供；本轮只支持逐条或选中多条统一平移。

**样式与位置：**

| 字段 | 范围/选项 | 默认 |
| --- | --- | --- |
| 字体 | 系统白名单（苹方/思源黑体/微软雅黑等，按平台回退） | 平台默认中文字体 |
| 字号 | 12–120 px | 48 px |
| 文字颜色 | 色板/十六进制 | 白色 |
| 描边颜色 | 色板/十六进制 | 黑色 |
| 描边宽度 | 0–8 px | 2 px |
| 背景 | 无 / 半透明底条 / 不透明底条 | 无 |
| 背景颜色 | 色板/十六进制 | 黑色 |
| 对齐 | 左 / 中 / 右 | 中 |
| 水平位置 | 0–100% | 50% |
| 垂直位置 | 0–100% | 85% |
| 快捷位置 | 九宫格 | 底部居中 |

- 预览实时反映字体、字号、颜色、描边、背景、对齐与位置；
- 工程可设置默认字幕样式，新 cue 继承；
- 单条 cue 修改后显示「已自定义」标记；
- 导出前检查字体是否可用；不可用时提示并回退到平台默认字体。

**校验：**

- 单行建议 ≤ 20 个汉字，最多 2 行；
- 单条时长 < 0.8s 显示警告；
- 两条 cue 间隔 < 0.1s 显示警告；
- 两条 cue 重叠：保留两者并显示 `字幕重叠` 警告，由用户调整或「自动排布」，不静默裁剪内容；
- cue 超出总时长：截断到总时长并显示警告，不阻断导出；
- 超出安全区显示警告；
- 警告不阻止导出，但在导出检查中汇总。

**导出：**

- 字幕模式：硬字幕 / 软字幕 / 无；
- 默认硬字幕（平台兼容性优先）；
- 软字幕写入 `mov_text` 字幕轨，同时另存外挂 SRT；
- 硬字幕按工程画幅与样式烧录；
- 样式优先级：cue 级样式 > 导出预设默认样式；预设只提供默认值，不覆盖单条 cue 的显式样式，避免“导出后字幕变了”。

**与台词本的关系：**

- 剪辑页修改字幕文本**不回写**台词本，也不提供同步入口；
- 修改字幕文本但未重新生成配音时，显示「字幕与配音不一致」提示；不阻断导出；
- 删除 cue 不删除台词本；
- 台词本重新抽取或修改后不改动剪辑页字幕；需要时由用户手动编辑字幕。

### 5.12 文字与标题（本轮不做）

- 标题、角色名条、地点条依赖叠加轨，本轮不实现；
- 字幕本身的样式与位置编辑已包含在 5.11。

### 5.13 画中画与叠加轨（本轮不做）

- 本轮只有一条主视频轨，不支持画中画、贴图、叠加轨；
- 如后续恢复，需要重新评审渲染器与时间线布局。

### 5.14 Take 切换（本轮不做）

- 剪辑的源是已合成的成片，不再按分镜 Take 装配；
- 需要更换镜头时，回制作页重新生成/拼接，再选择新成片；
- 旧工程的 Take 字段保留兼容，但不在新界面暴露。

### 5.15 声音参考与跳转混音

**剪辑页声音能力边界：**

- 可以：监听当前混音、静音监听、看波形、跳转混音页、看到混音状态；
- 不可以：调音量、声像、ducking、总线、分离、重排音频片段、导出 stems。

**监听优先级（混音 → 源成片原声 → 静音）：**

| 状态 | 播放 | 横幅 |
| --- | --- | --- |
| 有可用混音 | 当前混音 | 无 |
| 尚未混音，源成片有音轨 | 源成片原声（只读） | 「尚未混音，当前播放源成片原声」 |
| 源成片无音轨 | 静音 | 「源成片没有音轨，当前静音预览」 |
| 源成片不可读 | 静音 | 「源成片不可读，请重新选择或导出」 |

- 剪辑页不逐片段临时拼接源音频；只播放源成片音轨或已保存的混音；
- 不回退旧合片音频：旧合片时间与当前剪辑不同，回退会静默错位。

**交互：**

- 顶部混音徽标点击：打开混音页；旧工程才显示「重新对齐」；
- 声音参考轨双击：打开混音页并定位播放头；
- 检查器「声音」分组：显示「由混音工作台管理」+「去调整」；
- 选中片段右键「调整这段的声音」：打开混音页，定位到该片段对应台词/时间；
- 混音页返回：恢复播放头与选中片段。

### 5.16 标记（远期）

- 本轮不做标记轨；
- 后续可在标尺添加标记、命名、改色、删除与吸附；
- 导出不包含标记。

### 5.17 播放头与预览规则

- 播放头位置以毫秒存储，显示按帧对齐；
- 拖动播放头时显示时间码气泡；
- 播放头经过片段边界时，预加载下一片段；
- 播放头在空档时显示黑场；
- 播放头在字幕 cue 内时，字幕叠加；
- 播放头超出总时长时，停在末尾；
- 播放中修改计划：默认暂停并应用修改，避免预览状态与计划不一致；后续可提供「边播边改」（远期）。

### 5.18 撤销、重做、自动保存与版本

**撤销/重做：**

- 记录所有计划变更：裁剪、分割、删除、移动、变速、图片/冻结帧、帧级删除/复制/拉长、字幕文本/样式/时间/位置、适配、旋转/翻转、工程设置；
- 不记录：播放、暂停、缩放、滚动、选择、检查器展开；
- 历史上限 50 步；
- 撤销/重做后播放头尽量恢复到相关位置；
- 菜单显示操作名，如「撤销 分割片段」。

**自动保存：**

- 300ms 防抖；
- 保存到草稿，不每次生成版本；
- 状态：`保存中 / 已保存 / 保存失败`；
- 保存失败不阻塞编辑，但阻止导出，并提示磁盘/权限原因；
- 关闭页面前若有未保存更改，浏览器内提示；桌面版直接保存草稿后退出；
- 再次打开时若有未提交草稿，提示「恢复上次编辑 / 丢弃草稿」。

**版本：**

- `保存版本`（`Cmd/Ctrl + S`）创建 `edit_revisions`，可填写备注；
- 自动里程碑：首次编辑、替换时间线前、导出前；
- 版本列表显示缩略图、时间、时长、片段数、备注；
- 恢复版本 = 以该版本为内容创建新版本，不删除历史；
- 版本对比为后续能力：并排显示总时长、片段数、增删改片段列表；本轮只提供版本列表与恢复。

**并发：**

- 同一集在两个窗口打开时，使用 `baseVersion` 乐观锁；
- 后保存者收到「此集已在另一窗口修改」；
- 选项：`重新加载最新` / `另存为副本` / `覆盖并保留我的修改`（覆盖需二次确认）；
- 不静默合并。

### 5.19 快捷键（可选加速，不是唯一入口）

- 所有核心操作都必须同时提供可见按钮与右键菜单；快捷键只用于熟练用户加速；

- `Shift + Cmd/Ctrl + Z` 重做；
- `Cmd/Ctrl + B` 分割；
- `Delete` 波纹删除；
- `Shift + Delete` 仅删除留空；
- `S` 吸附开关；
- `+ / -` 缩放；
- `Shift + Z` 适配全部；
- `Left / Right` 逐帧；
- `Shift + Left / Right` 逐秒；
- `Home / End` 开头/结尾；
- `I / O` 入点/出点；
- `Cmd/Ctrl + E` 打开导出；
- `?` 快捷键帮助。

### 6.3 本轮发布标准

满足以下全部条件，才可称为本轮完成：

1. 能从成片列表打开一部成片，完成：裁剪 → 分割 → 删除帧 → 复制帧 → 插入图片 → 拉长 → 变速 → 适配 → 字幕样式/位置/时间 → 导出回成片列表。
2. 全部核心操作可只用鼠标完成，右键菜单与工具栏入口一致。
3. 能处理异常：源成片离线、缺混音、混音需更新、导出失败、保存失败、崩溃恢复。
4. 能跨页协作：剪辑 → 混音 → 返回剪辑 → 导出；混音导出同样回到成片列表。
5. 能回溯：每次导出关联剪辑版本与混音版本，成片记录可追溯。
6. 能简单使用：新用户不看文档，10–15 分钟完成第一版成片。
7. 不承诺：转场导出、滤镜、叠加轨/画中画、x/y 自由位移、关键帧、调色、批量导出、版本对比。

### 7.2 状态模型

剪辑页顶部始终显示以下之一：

| 状态 | 含义 | 用户动作 |
| --- | --- | --- |
| `混音已对齐` | 当前混音基于当前剪辑时间 | 可直接导出 |
| `混音需更新` | 画面时长或源素材变化 | 去混音页处理，或临时导出（原声） |
| `尚未混音` | 没有混音版本 | 去混音页创建，或直接导出（源成片原声） |
| `混音生成中` | 混音任务进行中 | 等待，可继续编辑；完成后提示 |
| `混音失败` | 最近一次混音失败 | 查看原因、重试、去混音页 |
| `剪辑草稿未保存` | 当前剪辑有未提交草稿，混音仍基于上一个版本 | 先保存版本，再导出 |

**会标记 `混音需更新` 的操作：**

| 操作 | 是否影响混音 |
| --- | --- |
| 插入/删除/移动片段 | 是（总时长/顺序变化） |
| 删除单帧/复制帧/插入图片/拉长 | 是（总时长或画面时间变化） |
| 裁剪片段 | 是（时长变化） |
| 变速 | 是（时长变化） |
| 淡入/淡出黑 | 否（总时长不变） |
| 分割 | 否（总时长不变） |
| 仅删除留空 | 是（出现空档，混音时间轴需确认） |
| 画面适配/旋转/翻转/九宫格位置 | 否 |
| 字幕改动 | 否 |
| 工程画幅变化 | 否 |
| 帧率变化 | 不允许（跟随源成片，只读） |

**原则：** 只影响画面的操作不打扰声音；影响时间或源素材的操作必须显式提示。切换源成片等同于素材变化，需重新确认混音来源。

**本轮不再使用的旧机制：** Take 切换、叠化转场、滤镜/画中画已不在本轮范围，因此也不作为“混音需更新”的触发项；旧工程若存在这些字段，按硬切/忽略处理并提示。

### 7.3 旧工程重新对齐（仅兼容）

> **本轮口径**：新工程以「源成片 + 混音版本」绑定，不再依赖 `editSyncHash` 时间桥。混音是否需要更新由画面时间与源成片是否变化决定；本节流程只用于打开旧版（按分镜铺轨）工程时的兼容路径，不作为本轮验收项。

**入口：**

- 旧工程顶部「旧版工程」徽标；
- 旧混音版本横幅「画面已更新，需要重新对齐」；
- 导出抽屉前置检查。

**流程：**

1. 点击「重新对齐」；
2. 显示差异摘要：
   - 画面总时长：`01:32 → 01:28`；
   - 移动片段：3 个；
   - 删除片段：1 个；
   - 新增片段：2 个；
   - 受影响的台词：5 句；
3. 选择对齐策略：
   - `保留人工调整（推荐）`：按 `lineId / clipId` 匹配，保留音量/声像/片段增益；无法匹配的片段进入待确认；
   - `按当前画面重排`：以新 EditPlan 重建混音时间轴，人工调整重置，需二次确认；
4. 执行对齐，生成混音草稿（不直接保存版本）；
5. 混音页试听检查；
6. 保存为新 `mix_revisions`；
7. 回到剪辑页，状态变回 `混音已对齐`。

**待确认列表：**

- 新增画面没有对应声音：列出片段，提供「用原声」「生成配音」「静音」；
- 删除画面的声音：列出轨道片段，提供「删除」「保留到末尾」「移入音效轨」；
- 时长不足/超出：显示差额，允许拉伸淡入淡出或移动。

**不静默丢弃：** 任何无法匹配的混音片段都必须出现在待确认列表，保存前不能忽略。

### 7.4 跳转上下文

```ts
interface WorkbenchHandoff {
  episodeId: number
  filmId?: number
  playheadMs: number
  rangeStartMs?: number
  rangeEndMs?: number
  selection?: { kind: 'clip' | 'line' | 'cue'; id: number | string }
  from?: 'edit' | 'mix'

```

**规则：**

1. 剪辑页「调整这段的声音」→ 混音页，播放头一致，选中对应台词/片段；
2. 混音页「查看画面」→ 剪辑页，播放头一致，选中对应片段；
3. 返回时恢复来源页的缩放、滚动、选中与播放头；
4. 跳转前暂停并释放播放器；
5. 两页都只有一个可见播放器，不共享实例；
6. 顶部显示对方状态，避免来回切换后迷失。

### 7.5 播放时钟契约

| 页面 / 场景 | 主时钟 | 同步方式 | 漂移阈值 | 回退顺序 |
| --- | --- | --- | --- | --- |
| 剪辑 `/edit` 有音频 | WebAudio（混音或源成片原声） | 视频定期 seek 到音频位置 | **120ms** | 混音 → 源成片原声 → 静音 |
| 剪辑 `/edit` 无音频 | 当前视频 | 播放头跟随视频；切片段时更新 | 原生 | 静音预览 + 横幅提示 |
| 剪辑页暂停拖动 | 播放头 | 视频 seek 到对应帧 | — | — |
| 混音 `/mix` | 现有视频（只读画面） | WebAudio 多轨跟随视频时钟 | **320ms** | 视频 → 静音预览（波形仍可编辑） |

- 120ms 与 320ms 是**场景差异，不是矛盾**：剪辑页的重点是口型与画面切点，错位更敏感；混音页重点是实时多轨听感，沿用现有 320ms 可避免监听回归。
- WebAudio 不可用时按 10.2 降级为 `<video>` 原声 + 提示，不改变上表的场景定义。
- 两页都保持「一个可见预览、一个播放时钟」；阈值只在各自页面内部生效，不跨页共享播放器。
- 剪辑页音频回退必须显示横幅：`混音需更新，当前播放源成片原声` 或 `暂无可用音频，仅静音预览`，不静默播放错误声音。

| 导出后设为当前成片 | 关 | 勾选后调用统一「设为当前成片」 |
| 导出后打开成片 | 开 | 完成后跳到左侧成片列表并选中新成片 |

> 视频导出成功后新增一部 `kind='edit'` 成片并投影到成片列表；原源成片不被覆盖。音频不成片。

**文件命名：**

```text
EP03_成片_v12_20261105_1430.mp4
```

- 集号、版本、时间；
- 文件名可编辑；
- 输出目录默认项目内按集归档的 `episodes/<集ID>/exports/<导出记录ID>/`，可改；
- 导出前显示预计大小。

### 8.3 导出流程

```text
点击导出
  → 前置检查（源成片/混音/离线/字体）
  → 确认预设/字幕/文件名/是否设为当前
  → 创建导出任务（快照当前 EditPlan + 混音引用 + 字幕）
  → 确保剪辑轨 cut.mp4（缓存）
  → 确保原声参考 audio-ref.m4a
  → 校验并复用当前混音 mix.wav（缺失/过期时阻断最终导出）
  → 合成字幕与封装
  → 校验
  → 投影为新成片（kind='edit'）
  → 完成
```

**阶段与进度：**

| 阶段 | 进度 | 文案 |
| --- | --- | --- |
| 准备 | 0–5% | 正在准备素材 |
| 渲染画面 | 5–55% | 正在渲染画面 42% |
| 准备声音 | 55–75% | 正在准备声音 |
| 合成字幕 | 75–90% | 正在合成字幕 |
| 校验 | 90–100% | 正在校验成片 |
| 完成 | 100% | 导出完成 |

**规则：**

- 导出使用点击时的快照，后续编辑不影响本次导出；
- 导出前若有未保存草稿，自动创建版本（备注「导出快照」），再开始导出；
- 导出期间锁定本集编辑；
- 取消：立即停止 FFmpeg，保留日志，删除临时文件；
- 失败：保留已生成中间文件 24 小时，支持从头重试；
- 并发：同一集同时只允许一个导出任务；不同集可并行（队列上限 2，远期）；
- 桌面版导出完成发系统通知；
- 关闭窗口时若有导出任务，提示「导出将在后台继续」或「取消并退出」。

### 8.4 校验与报告

导出完成后自动校验：

| 项 | 标准 | 失败处理 |
| --- | --- | --- |
| 文件存在/可读 | 能打开 | 失败 |
| 时长 | 与 EditPlan 总时长误差 ≤ 100ms | 警告/失败 |
| 分辨率 | 与预设一致 | 失败 |
| 帧率 | 与工程一致 | 警告 |
| 视频流 | H.264，可解码 | 失败 |
| 音频流 | AAC，双声道，可解码 | 失败 |
| 字幕流 | 软字幕时存在 | 失败 |
| 响度 | 目标 LUFS 范围内 | 警告 |
| 首帧/尾帧 | 非全黑（除非用户设置） | 警告 |

**报告展示：**

- `通过` / `有警告` / `失败`；
- 每项显示实际值与标准值；
- 失败时提供「查看日志」「重试」「复制诊断信息」；
- 诊断信息脱敏，不含密钥与完整路径中的用户名。

### 8.5 导出历史

- 列表：时间、版本、预设、时长、大小、状态、校验结果、对应成片；
- 操作：播放、打开文件夹、设为当前成片、删除（二次确认）、复制参数、重试投影（`film_id` 为空时）；
- `设为当前成片` 只更新 `episodes.current_film_id`，并同步 `video_url/subtitle_url` 兼容镜像；
- 同一时间只有一个当前成片；
- 历史保留最近 20 条或 30 天，可配置；
- 删除当前成片返回 `409 FILM_IS_CURRENT`，需先把其他成片设为当前；
- 导出记录关联 `editRevisionId`、`mixRevisionId`、`sourceFilmId`、`filmId`，可回溯；
- 投影失败不重跑渲染，使用「重试投影」幂等补登记。

### 8.6 错误与恢复

| 错误 | 文案 | 动作 |
| --- | --- | --- |
| 源成片缺失 | 「还没有选择要剪辑的成片。」 | 去左侧成片列表选择 |
| 源成片离线 | 「源成片文件不在了，无法继续。」 | 回拼接导出重新生成 |
| 素材离线 | 「3 个镜头的源文件不在了，导出已暂停。」 | 重链、重新生成、移除片段 |
| 混音需更新 | 「画面改过了，当前混音对不上。」 | 去混音、临时导出（原声） |
| 存储不足 | 「导出需要约 1.2 GB，当前只剩 300 MB。」 | 清理空间、改目录 |
| FFmpeg 失败 | 「渲染在 62% 失败：视频编码器错误。」 | 重试、降低预设、复制诊断 |
| 字幕烧录失败 | 「字幕样式包含不支持的字体。」 | 换字体、导出无字幕 |
| 投影失败 | 「成片入库失败，可重试。」 | 重试投影、查看导出记录 |
| 任务被取消 | 「导出已取消，临时文件已清理。」 | 重新导出 |
| 应用崩溃 | 下次打开显示「上次导出未完成」 | 重试、查看日志 |

### 9.1 全局状态

| 状态 | 表现 | 用户可做什么 |
| --- | --- | --- |
| 加载中 | 时间线骨架 + 预览占位 | 等待，显示进度 |
| 保存中 | 顶部 `保存中…` | 继续编辑 |
| 已保存 | 顶部 `已保存` | 导出、离开 |
| 保存失败 | 顶部红色 + 导出禁用 | 重试、检查磁盘 |
| 混音需更新 | 顶部琥珀徽标 + 声音参考斜纹 | 去混音、临时导出（原声） |
| 导出中 | 底部进度条 + 编辑锁定 | 取消、查看日志 |
| 离线 | 片段红色斜纹 + 顶部汇总 | 重链、回拼接导出 |
| 只读 | 顶部 `只读模式` + 控件禁用 | 返回、查看版本 |

### 9.2 空态

> 同时满足多个空态时，优先级：无可用成片 → 空时间线 → 无字幕 → 无混音。没有源成片时不提供剪辑操作，避免触发必然失败的流程。

**无可用成片：**

```text
这一集还没有成片
先去「拼接导出」生成一版成片，完成后会出现在这里
[ 去拼接导出 ]
```

**空时间线：**

```text
这部成片还没有可剪辑的画面
可以从「图片」插入一张图，或回到拼接导出重新生成
[ 插入图片 ]  [ 去拼接导出 ]
```

**成片已经生成：**

```text
已从成片铺好时间线
共 1 个片段，时长 01:32
[ 开始剪辑 ]
```

**无字幕：**

```text
字幕轨是空的
可以手动添加字幕，或去配音页生成台词
[ 添加字幕 ]  [ 去配音页 ]
```

**无混音：**

```text
还没有混音
当前播放源成片原声，可以直接导出
[ 去混音 ]  [ 直接导出 ]
```

**导出历史为空：**

```text
还没有导出记录
完成第一次导出后，这里会保留版本与校验结果
```

### 9.3 错误

**原则：**

- 说清“发生了什么、为什么、下一步”；
- 不显示堆栈、内部路径、密钥；
- 可复制的诊断信息单独提供；
- 阻断性错误必须给出一个主行动；
- 非阻断错误用 toast，不弹模态。

**示例：**

| 场景 | 文案 |
| --- | --- |
| 保存失败 | 「保存失败：磁盘空间不足。修改还在当前页面，请先清理空间再重试。」 |
| 版本冲突 | 「这一集已在另一个窗口被修改。重新加载最新版本，或把你的修改另存为副本。」 |
| 预览解码失败 | 「这个镜头无法预览，可能是编码格式不支持。仍可导出，或先转码。」 |
| 删除最后一帧 | 「这个片段只剩 3 帧，不能再删了。可以删除整段，或用图片替代。」 |
| 字幕重叠 | 「两条字幕重叠了 0.3 秒。请调整其中一条，或使用自动排布。」 |
| 字幕越界 | 「字幕超出了安全区，导出时可能被裁掉。已提示，可继续。」 |
| 导出被阻断 | 「导出前需要先处理 2 个离线素材。」 |

### 9.4 加载

- 成片列表与时间线使用骨架屏，不用全屏 spinner；
- 预览首帧加载显示缩略图 + 小进度环；
- 代理生成中显示 `预览代理生成中，当前使用原画`；
- 波形/缩略图异步加载，不阻塞操作；
- 长任务显示阶段与预计剩余时间（超过 10 秒）。

### 9.5 文案原则

- 动词开头，短句；
- 用“画面/声音/成片”而不是“视频轨/音频轨/输出”；
- 用“混音需更新”而不是“stale”；
- 用“去混音”而不是“重新对齐”（旧工程兼容入口除外）；
- 对用户不可见“EditPlan/MixPlan/hash”等内部术语；
- 中英文都不超过两行；
- 数字与时间码使用等宽字体。

## 10. 性能与体验指标

### 10.1 性能预算

| 指标 | 目标 | 失败阈值 |
| --- | --- | --- |
| 页面骨架可交互 | < 1.5s（本地） | > 3s |
| 首次打开（40 片段，不含代理生成） | < 2.5s | > 4s |
| 从成片打开工程 | < 1s | > 2s |
| 时间线滚动帧率 | 60fps（100 片段）；200 片段降级 ≥30fps | < 30fps（100 片段） |
| 播放起播 | < 300ms | > 800ms |
| 片段切换 | < 120ms | > 300ms |
| Seek（代理） | < 200ms | > 500ms |
| 裁剪/拖动响应 | < 16ms/帧 | > 33ms |
| 自动保存 | < 50ms 主线程阻塞 | > 150ms |
| 导出进度更新 | 1s/次 | > 3s |
| 删除帧/复制帧响应 | < 500ms（含服务端抽帧则显示进度） | > 2s |
| 字幕拖动/改样式 | < 16ms/帧 | > 33ms |

### 10.2 降级策略

| 场景 | 降级 |
| --- | --- |
| 原画解码卡顿 | 自动切 720p 代理 |
| 代理未就绪 | 原画预览（可能卡顿）/ 缩略图兜底 |
| 同时解码片段过多 | 视频池限制 3 个，预加载 1 个 |
| 时间线片段过多 | 缩略图降采样，只渲染视口 |
| 音频加载失败 | 静音预览 + 提示，不阻塞画面 |
| 内存不足 | 释放离屏视频，提示降低预览质量 |
| WebAudio 不可用 | 退化为 `<video>` 原声 + 提示 |

### 10.3 容量与长剧集

**硬上限**：200 片段、60 分钟、计划 JSON 8MB；超过拒绝保存/导出并提示。

**性能承诺**：MVP 只承诺 10 分钟 / 100 片段；典型短剧 1–3 分钟 / 15–40 片段必须流畅。100–200 片段允许降级，不承诺原画交互帧率。

- 时间线虚拟化：只渲染视口 ±1 屏；
- 缩略图分级缓存：低分辨率条 + 按需关键帧；
- 波形按缩放级别分级；
- 导出分块渲染 + 拼接：每 20 个片段或每 120 秒一块，硬切交界处切分；
- 超长集进入前显示预计耗时，渲染转后台任务，可继续其他集编辑；
- 撤销历史只存差异，不存整份计划；
- 自动保存在后台序列化，避免主线程卡顿。

### 11.1 鼠标与键盘

- 核心路径可只用鼠标完成：成片选择 → 帧级操作/裁剪 → 字幕样式与时间 → 导出；

- 时间线缩放不影响文字可读性；

### 11.3 屏幕阅读器

### 11.4 国际化

- 导出文件名支持本地化但保留 ASCII 兜底。

## 12. 验收与测试

### 12.1 黄金路径

**路径 A：从成片到新成片（核心）**

1. 在「拼接导出」完成一集拼接成片，成片列表出现一张 `拼接` 卡片；
2. 卡片右键「在剪辑中打开」，进入剪辑页，左侧显示成片列表，当前成片已选中；
3. 时间线自动铺好 1 个片段，字幕按成片外挂字幕或台词本生成；
4. 在播放头处「删除当前帧」，后续画面波纹前移 `1000/fps`；
5. 「复制当前帧」，生成 1 秒图片片段；
6. 「插入图片」，从本机选择一张图片，默认 3 秒；
7. 把末段「拉长」1 秒，生成冻结尾；
8. 裁剪第 1 个片段开头 1 秒，再分割一次并调整顺序；
9. 选中一条字幕，修改字体、字号、文字色、描边、背景、九宫格位置与起止时间；
10. 全程只用鼠标完成，工具栏与右键菜单入口一致；
11. 打开导出，选择竖屏超清 + 硬字幕，勾选「导出后设为当前成片」；
12. 导出成功，左侧成片列表出现新的 `剪辑` 成片；原拼接成片仍存在；
13. 剧集页当前成片已更新。

**通过标准：** 全程无阻断错误；总耗时 < 15 分钟；撤销/重做可用；导出音画同步；帧操作真实改变成片。

**路径 B：混音 → 剪辑 → 回写**

1. 混音页顶部选择同一集的一部拼接成片作为源；
2. 完成混音并导出视频成片，选择「复制源成片外挂字幕」；
3. 成片列表出现 `混音` 成片；
4. 在剪辑中打开该混音成片，调整字幕样式并导出；
5. 成片列表出现 `剪辑` 成片，混音成片不被覆盖。

**路径 C：跨页一致性**

1. 剪辑页完成一版画面，混音已对齐；
2. 删除一个 2 秒片段，顶部变为「混音需更新」；
3. 点「去混音」，播放头与集一致；
4. 混音页看到源成片仍是同一部，重新生成混音并导出；
5. 回剪辑页状态恢复为「混音已对齐」；
6. 导出成功，音画同步。

**路径 D：源成片切换与边界**

1. 左侧成片列表切换到另一部成片，工程自动恢复或新建；
2. 旧工程不被覆盖；
3. 删除当前成片被拒绝并提示 `FILM_IS_CURRENT`；
4. 源成片文件缺失时阻断并给出回拼接导出入口。

**路径 E：并发与恢复**

1. 两个窗口打开同一集，先后保存；后保存者看到冲突对话框，可重新加载/另存副本/覆盖；
2. 刷新页面出现草稿恢复提示，恢复后内容与刷新前一致；
3. 导出中关闭应用，重启后任务标记失败并可重试；
4. 导出中尝试编辑，出现锁定提示。

### 12.2 边界验收

| 场景 | 期望 |
| --- | --- |
| 未选择源成片 | 阻断，引导去成片列表 |

| 空时间线导出 | 阻断，提示插入图片或回拼接导出 |

| 长剧集 60 分钟 | 可滚动、可导出 |
| 无 WebAudio | 源成片原声兜底 + 提示 |
| 系统减少动效 | 弹窗简化 |
| 删除当前成片 | 409，提示先切换 |
| 投影失败 | 导出记录保留，可重试投影 |

### 12.3 可用性测试

- 招募 5 名目标用户（至少 2 名未用过专业剪辑软件）；
- 任务：从成片列表选一部成片，完成帧级操作、字幕样式调整并导出；
- 观察：首次操作是否找到成片列表与右键菜单；是否能不用快捷键完成删除帧/复制帧/插入图片/拉长/字幕样式；
- 通过标准：
  - 任务完成率 ≥ 80%；
  - 中位完成时间 ≤ 15 分钟；
  - 严重可用性问题 0；
  - 80% 用户能解释「混音需更新」的含义。

### 12.4 发布门槛

- 本轮功能矩阵（本文 6.2「本轮」列）全部通过；
- 黄金路径 A/B/C/D/E 自动化或人工验收通过；
- 导出成功率在 50 次真实导出中 ≥ 98%；
- 崩溃恢复成功率 100%（测试注入崩溃）；
- 四语文案完整，无硬编码；
- 无阻断级无障碍问题；
- 关键性能指标达标；
- 旧入口迁移策略验证通过。

## 14. 迁移与发布

### 14.1 阶段

| 阶段 | 范围 | 出口条件 |
| --- | --- | --- |
| A 成片中心地基 | 数据列、成片列表、当前成片指针、投影、共享成片选择器 | 现有拼接成片列表不回归 |
| B 混音接入 | 源成片选择、混音检查器重排、背景声入口、视频导出投影 | 旧混音导出不回归 |
| C 剪辑工程与字幕 | 成片工程、左侧成片列表、字幕样式/位置/时间 | 打开成片即可剪辑 |
| D 帧级操作与导出 | 删除帧/复制帧/插入图片/拉长、受约束渲染器、导出投影 | 帧操作真实改变成片 |
| E 验收与收口 | 全量测试、真实 E2E、截图、文档、旧入口文案 | 发布门槛通过 |

### 14.2 存量数据

**首次打开某集的剪辑页（顺序固定）：**

1. 若指定了 `film_id`，加载该成片对应工程；
2. 若已有该成片的 `edit_projects`，恢复草稿/当前版本；
3. 否则为源成片创建新工程与 `v1` 版本：单个 `source.kind='merge'` 片段，时长取成片时长；
4. 字幕：优先解析成片外挂 `.srt`；否则按台词本放置并裁剪到成片时长；
5. 若该集只有旧的分镜铺轨工程，顶部标记「旧版工程」，可另存新版本，不强制迁移；
6. 若该集没有任何成片，左侧成片列表为空态，引导去拼接导出；
7. 不修改源文件与旧字段；
8. 旧混音版本保留 `edit_sync_hash` 兼容字段，新混音绑定源成片。

**旧导出记录：**

- 保留 `episode_exports` 历史；
- 新导出补充 `film_id`、`source_film_id`、`edit_revision_id`、`mix_revision_id`；
- 旧记录的 `planRevisionId` 保留兼容；
- 不批量重写旧记录，不批量投影旧成片。

### 14.3 回滚

- A–D 期间旧入口仍可用；
- 若新页面出现阻断问题，隐藏 `/edit` 入口即可回到旧流程；
- 已创建的 `edit_projects`/`edit_revisions` 不删除，问题修复后继续使用；
- 导出记录不迁移、不回滚；
- `episodes.current_film_id` 只由「设为当前成片」更新；删除当前成片返回 `409`，不做自动回退；回滚不会污染当前成片。

## 附录 B：术语

| 术语 | 含义 |
| --- | --- |
