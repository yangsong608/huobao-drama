### 豆包语音 Invalid X-Api-Key 修复与桌面重打（2026-11-04 16:52–17:02）

**根因**

- 豆包语音 v3 新版控制台要求 `X-Api-Key`，且必须是**语音技术控制台**创建、已开通豆包语音（`speech_saas_prod`）的 Key；方舟（Ark）API Key 不能用于语音服务。
