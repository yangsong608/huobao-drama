# 分镜修复示例：第 3 集第 18 镜「噎住震惊」

日期：2026-11-11
对象：`storyboards.id=321`，第 3 集（`episode_id=48`）第 18 镜
性质：可执行修复稿；本轮未写入数据库

## 一、为什么选这一镜

第 18 镜是第 3 集“旁白格式导致 H3 判定无对白”的代表：

- 分镜写了两句旁白，但旁白没有用 `「」` 包住，也没有进入 `<d>` 标签；
- 最终任务 629 的提示词出现了 `This shot has no spoken dialogue: do not voice any line...`；
- 也就是说，分镜里写了旁白，成片可能完全没有这句旁白。

同时它还有角色多余绑定和时间轴断裂：

- 出场人物绑定了 4 人，实际画面只需要唐奕和范仲淹；
- 孙郎中、范公子没有出现在画面里，但请求里仍可能带他们的参考图；
- 时间轴 9–11 秒，镜头时长 12.25 秒，最后一段既不是 3 秒，也没有对齐镜头时长。

这一镜可以在不拆分的前提下修好，适合作为“单镜修复”的样板。

## 三、问题诊断

| 问题 | 证据 | 影响 |
|---|---|---|
| 旁白未进 `<d>` | 任务 629 最终提示词出现 `This shot has no spoken dialogue: do not voice any line...` | 旁白可能失声；审核只报了“时长不足”，没有发现“最终提示词禁止发声” |
| 角色多余绑定 | 绑定 4 人，但画面只需要唐奕和范仲淹；孙郎中、范公子没有 `<Picture N>` | 模型可能多画人，或把未绑定角色生成成另一张脸 |
| 时间轴断裂 | 9–11 秒，镜头 12.25 秒；最后一段 2 秒 | 模型时间轴和真实时长不一致，尾帧容易提前结束 |
| 3 秒分段不严格 | 9–11 秒是 2 秒段 | 违反方案“每 3 秒一段、最后一段按 duration 收尾” |
| 缺少负面约束 | 没有“只出现两人、不出现其他人”的约束 | 第 4 集第 7 镜已经出现过多余老人，同类风险 |
| 缺少口型/声音类型 | 旁白写成普通描述，没有声明“唐奕不开口、无口型” | 模型可能让唐奕边说边有口型，或把旁白当角色台词 |

## 五、与旧版的差异

| 维度 | 旧版 | 新版 |
|---|---|---|
| 旁白格式 | `旁白（画外音，普通话，语速平缓）：...`，无引号 | `旁白（画外音）：「...」`，会被 H3 编译为 `<d>` |
| 旁白类型 | 没有声明，可能被当角色台词 | 明确 `voice_over`，唐奕不开口、无口型 |
| 角色 | 绑定 4 人，孙郎中/范公子未出现 | 只绑定唐奕、范仲淹；其余全部移除 |
| 时间轴 | 0-3 / 3-6 / 6-9 / 9-11（2 秒尾段） | 0-3 / 3-6 / 6-9 / 9-12.25 |
| 动作 | “噎住”“震惊”“望向”较抽象 | 喉咙发紧、瞳孔微缩、呼吸一滞、手指收紧、转头，动作有起止 |
| 负面约束 | 无 | 只出现两人、不换脸/不换装/不加人/不生成字幕 |
| 声音 | 原生音频，旁白可能失声 | 旁白后期配音或旁白音色档案；生成阶段建议 `ambient`，避免口型 |
| BGM | 只存在 `bgm_prompt` | 明确为后期 BGM cue，不进入视频请求 |

## 六、H3 提交前预检

修复版提交前应检查：

- 预期发声条数：3 条（唐奕万万没想到 / 皇帝竟下圣旨 / 让百姓议政不砍头还有赏）。
- 实际 `<d>` 条数：3 条。
- 最终提示词不能出现 `This shot has no spoken dialogue...`。
- 出场人物 `@` 名称必须能解析到角色 24 和 39。
- 不应出现 `@孙郎中`、`@范公子` 的 `<Picture N>`。
- 最后一段时间轴结束必须等于 12.25 秒。
- 每段必须是 3 秒（最后一段 3.25 秒）。

## 七、验收标准

- [ ] 画面只出现唐奕和范仲淹，没有孙郎中、范公子、老人或其他人物。
- [ ] 唐奕全程嘴唇闭合，没有说话口型；旁白是画外音。
- [ ] 旁白三句完整出现，没有被静音、没有被改成唐奕开口。
- [ ] 0-3 / 3-6 / 6-9 / 9-12.25 时间轴正确，最后一段收在 12.25 秒。
- [ ] 唐奕从“噎住”到“转头惊疑”有清楚的动作起止，不是一张静止特写。
- [ ] 唐奕脸、发型、服装与参考图一致；范仲淹脸、服装与参考图一致。
- [ ] 没有字幕、文字、水印；没有场景布局变化。
- [ ] 后期旁白音色与全剧旁白一致；BGM 在后期铺，不压旁白。
- [ ] 审核不再报 `reference_character_unknown`、`reference_character_unbound`、`prompt_timeline_broken`。
