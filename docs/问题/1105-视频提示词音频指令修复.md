# 视频提示词音频指令修复（#232）

日期：2026-11-05
范围：云端视频（豆包 Seedance 2.0）与本地 H3 / ComfyUI 链路

## 现象

- 任务 #232 使用豆包官方 API，提示词中没有任何说话或旁白，成片人物仍有独白。
- 本地 H3 选择静音模式后，人物口型仍在动；提示词里没有对白/说话/旁白。
- 删除提示词中的「音频：人声清晰靠前，环境音压低，无背景音乐；旁白/心声为画外音，不张口。」后，独白消失。

## 根因

1. 旧提示词模板与技能要求生成器在 `video_prompt` 第二行固定写入上述音频行。
2. 云端适配器把提示词原样交给 Seedance，并带 `generate_audio=true`；「人声清晰靠前」「旁白/心声为画外音」被模型理解为必须生成人声与画外旁白。
3. 存量用户工作区已有 `.template-version=6`，模板版本未变时不会覆盖；只更新内置模板，老用户仍会按旧规则继续生成。
4. 英文模板与英文技能漏改，英文会话仍会写 `Audio: ... narration/inner voice is off-screen, mouth not moving.`。

## 修复

### 1. 停止生成音频行（四语言模板 / 技能 / 规则）

- `backend/workspace/prompts/prompt_generator.{md,en,ja,ko}.md`、`storyboard_breaker.{md,en,ja,ko}.md`、`skills/prompt-generator/video-prompt/SKILL.{md,en,ja,ko}.md` 统一改为：不要写「音频：」要求行或音色/混音指令（声音由生成参数控制）；只有本镜确有旁白时，才在对应时间段写「旁白（画外音…）：…」。
- 桌面随包模板 `desktop/resources/workspace-template/` 同步。
- `backend/src/agents/index.ts` 与 `backend/src/services/pipeline-rules.ts` 同步规则文案。

### 2. 提交前清洗存量提示词

- 新增 `backend/src/services/video-prompt-sanitize.ts`：
  - 只删除以 `音频：` / `Audio:` 开头且包含旧模板关键词的整行；
  - 删除残留「旁白/心声为画外音」子句；
  - 保留用户主动写的真实旁白、对白和合理声音描述。
- `backend/src/routes/tasks.ts` 在所有视频任务提交前执行（云端与本地 H3 同一口径），发生变更时写 `legacy-audio-line-stripped` 日志。
- `backend/src/services/comfyui-timeline.ts` 在 timeline segment 构建时同样清洗，防止整集工作流绕过逐镜提交入口。

### 3. 静音/环境声语义

- 云端 silent：`generate_audio=false`，并在落盘后强制去音轨。
- 本地 H3：`audio_mode=silent` 由 shim 覆盖英文音频指令，新增 `characters do not speak and keep their mouths closed`，减少无对白时仍张口；`ambient` 仍保留说话口型供后期对轨。
- native：只有提示词明确描述画外旁白时才允许旁白，不再无条件要求 voice-over narration。

### 4. 存量工作区迁移（不改 TEMPLATE_VERSION）

- 新增 `desktop/src/workspace-template.ts`：启动时扫描 `workspace/prompts` 与 `workspace/skills` 下的 `.md`，只替换已知旧音频句，保留用户其他编辑，重复执行无副作用。
- `syncWorkspaceTemplate` 在模板版本相同的情况下也执行迁移，日志 `workspace legacy audio prompt migrated`。
- 已对本机 `~/Library/Application Support/HuobaoDrama/workspace` 执行迁移：5 个旧文件更新，第二次执行 0 变更。
