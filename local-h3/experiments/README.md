## 一、管线对照实验（8 镜，火宝第 1 集分镜）

| 组 | 驱动 | 参考图 | 首帧 | 上下文 | 耗时 | 结果 |
|---|---|---|---|---|---|---|
| 基线 | 火宝 UI → 桥接 r2v/t2v | 有（角色卡） | 无 | 无 | 每镜 2–4 min | 画风可，人物会变 |
| **A** | r2v（ref2va + 0.1 LoRA） | 有 | 无 | 无 | 1086s / 8 镜 | 人物漂、脸糊 |
| **B** | fl2v | 无 | 资产图 | 无 | 1085s | 人物稳，每镜“重新起势” |
| **C** | fl2v 首尾全链（尾帧=下镜首帧） | 无 | 有 | continuity | 1118s | **比 B 差**：跨镜硬配尾帧逼模型变形 |
| **D** | fl2v 滚动首帧（串行） | 无 | 上一镜尾帧 | 无 | ~1080s | 连贯明显好，但人物漂移（误差累积） |

**关键结论**：首帧能锁人物但会“重启”；参考图（r2v）能自由构图但人物漂；两者不能简单二选一。

## 二、E 系列（3 镜小样，快速迭代）

| 组 | 核心做法 | 结论 |
|---|---|---|
| **E1** | fl2v 滚动首帧 + **注噪** + 官方 I2VA 句式 | 三镜人物稳定（15.5s）；注噪有效 |
| **E2** | r2v + **MotionContext 上下文** + Trim | 链路跑通（13.7s），Trim 自动剪掉重叠帧 |
| **E3** | 首帧 + 上下文合体 | 目前画风/连续最平衡（15.5s） |
| **E4** | 火宝原词 8 镜 + 首帧 + 上下文 | 76s 一次出片；人物跟首帧走（首帧错则全错） |
| **E5** | R2V + **AddGuide 钉首帧** + 上下文 | 构图钉住了，但**人物被错首帧带跑**——硬约束压过参考图 |
| **E6** | 去掉 AddGuide，参考图当软参考 | 两个女角色长得**一样**——参考图没被点名，等于没用 |
| **E7** | 参考图 + `<Picture 1..5>` 起名 | 两个女角色**区分开了**、紫花袄复现 |
| **E8** | 点号传参 `ref_images.ref_image_0` | **参考图真正生效**（探针验证）；人设局部对上 |
| **E9** | 火宝同参：fl2va + 4step + Director r2v + `@图片N` | 人设对上、画面干净；**缺风格词** |
| **E10** | E9 + guofeng 风格词 | 风格词改变画风（用户不接受：风格变了） |
| **E11** | E10 结构 + 我生成的肖像 + 8 步 + 720p | 清晰度↑、无字幕，但**人物/风格都不是项目的**（被否） |
| **E12** | E11 结构 + **huobao 角色卡** + **无风格词** | 1024×576 / 29.7s / 单 timeline；人设接近卡，字幕仍出现 |

## 三、已确证的技术点

| # | 结论 | 证据 |
|---|---|---|
| 1 | ComfyUI autogrow 输入必须**点号**（`ref_images.ref_image_0`），嵌套 dict 被静默丢弃 | 探针：嵌套≈不传，点号才有差异 |
| 2 | `MotionContextLoadLatent` 的目录必须存在，`clip_index` 必须指向已存段（首段用 0） | 报错实录 |
| 3 | `AddGuide` 钉首帧会压过参考图 | E5 vs E6/E7 |
| 4 | 中文正文进提示词会被烧成字幕；负条件在 cfg=1.0 下作用有限 | E9/E12 抽帧 |
| 5 | 4 步 turbo 偏软；8 步明显更实（代价约 2×） | E11 对比 E9 |
| 6 | 单条 timeline 多段可每段独立 refs/prompt，无需 ffmpeg 拼接 | E11/E12 |
| 7 | 下载产物必须写**不同路径**，否则 `open(dst,'wb')` 会截断源文件（丢过一次 19 分钟的片子） | 实录 |
