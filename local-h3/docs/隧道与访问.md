# 隧道与访问方法

## 为什么需要隧道

服务器上的 ComfyUI 只监听 `127.0.0.1:8188`（不对外暴露），本机的桥接脚本却要访问 `http://127.0.0.1:8188`。
所以必须在本机开一条 SSH 本地端口转发，把本机 8188 映射到服务器的 8188。

```
本机 127.0.0.1:8188  ──加密通道──►  服务器 127.0.0.1:8188
```

## 启动顺序

1. 建隧道（本文件）
2. 起桥接：`bash local-h3/scripts/start.sh`
3. 全链路检查：`bash local-h3/scripts/health.sh`

## 建立方式

### 方式 A：DSH 的 ssh_tunnel（推荐）

```
ssh_tunnel  action=start
            alias=<H3_SERVER_IP>
            localPort=8188
            remotePort=8188
            remoteHost=127.0.0.1
```

返回 `tunnel started: tun-1 ... [forwarding]` 即成功。
查看：`ssh_tunnel action=list`；停止：`ssh_tunnel action=stop tunnelId=tun-1`。

DSH 使用 `~/.dsh/dsh-ssh.json` 中已保存的主机凭据（本机为密码认证），无需每次输入。
**优点**：由 DSH 宿主托管，不会随终端退出而消失。
**注意**：DSH 重启后隧道消失，需要重开。

### 方式 B：手工 SSH 转发

```bash
export H3_HOST=<H3_SERVER_IP>
ssh -f -N -L 8188:127.0.0.1:8188 -o ExitOnForwardFailure=yes root@"$H3_HOST"
```

`-N` 表示不执行远程命令，只转发；`-f` 表示认证成功后转入后台。
若本机默认密钥（`~/.ssh/id_ed25519`）尚未加入服务器 `authorized_keys`，直连会得到
`Permission denied (publickey,password)`，需要在终端输入一次密码。
也可以先启用密钥登录，之后不再输密码：

```bash
ssh-copy-id -i ~/.ssh/id_ed25519.pub root@"$H3_HOST"
ssh -f -N -L 8188:127.0.0.1:8188 -o ExitOnForwardFailure=yes \
  -i ~/.ssh/id_ed25519 root@"$H3_HOST"
```

密码只保存在本机 DSH 配置里，不要写入脚本、命令历史或仓库。
Mac 休眠/重启/切换网络后转发会断开，重跑同一条命令即可。

## 验证

```bash
curl -s -m 5 -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8188/system_stats
```

`200` 且后续 JSON 含 `comfyui_version` 即通；`000`/空表示隧道断。

## 常态检查（出片前必做）

```bash
bash local-h3/scripts/health.sh
```

一次检查 8188 监听、ComfyUI `system_stats`、H3 节点、两个桥接、火宝前后端。

**注意：`http://127.0.0.1:8190/health` 只能证明视频桥进程活着，不能证明 8188 通。**
隧道可能在任务中途断开，表现为桥接一直健康、任务却失败：

- `URLError: <urlopen error [Errno 32] Broken pipe>`：参考图上传阶段隧道断开；
- `URLError: <urlopen error [Errno 61] Connection refused>`：提交阶段隧道已断。

任务失败后是终态，不能续跑；重建隧道并验证 8188 后，重新提交该分镜视频。

## 检查与停止

```bash
# 监听端口（应有 ssh 进程）
lsof -nP -iTCP:8188 -sTCP:LISTEN

# 转发进程
ps -eo pid,command | grep '[s]sh -f -N -L 8188'

# 停止：替换为上面查到的 PID
kill <PID>
```

## 访问入口一览

| 想访问 | 地址 | 前提 |
|---|---|---|
| 火宝界面 | `http://localhost:3013` | 火宝前后端已启动（5679/3013） |
| 火宝 API | `http://localhost:5679/api/v1` | 同上 |
| ComfyUI 界面 | `http://127.0.0.1:8188` | 隧道已通 |
| 视频桥 | `http://127.0.0.1:8190` | 桥接已启动 + 隧道已通 |
| 图片桥 | `http://127.0.0.1:8191` | 同上 |

## 常见问题

| 现象 | 处理 |
|---|---|
| 桥接报 `URLError: Connection refused` | 隧道断了；重建后 `curl 8188` 验证 |
| 任务失败含 `Broken pipe`（上传参考图阶段） | 8188 隧道在任务中途断开（常见于 Mac 休眠/切网）；8190 `/health` 仍可能是绿的。重建隧道并 `curl 8188` 验证，然后重新提交任务 |
| 8190 `/health` 正常但出片失败 | `/health` 不代表隧道通；跑 `bash local-h3/scripts/health.sh` 或直接查 8188 |
| 浏览器打不开 `127.0.0.1:8190` | 它是 API 不是网页；用 `curl .../health` 验证 |
| 隧道建好但立刻断开 | Mac 休眠/重启/切换网络会断开；重新执行建立命令，长期使用优先 DSH 的 ssh_tunnel |
| 端口 8188 被占用 | 先停掉旧的转发进程（`lsof -nP -iTCP:8188` 找 PID 后 `kill`） |
